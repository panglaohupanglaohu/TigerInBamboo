# 本章导演与拍摄约束

先盘物件 → 完整故事 → 可执行镜头表 → 实拍 → 看图 → 排版。画面只来自 localhost:8931/TigerMessenger；菜单不得入格；禁止文生图。

研读 NYFA 一手公开教学目标（2026-11-07），不是完成其课程：
- https://www.nyfa.edu/filmmaking/projects/ ：从剧本拆成 shot list、beat sheet、floor plan，保持时间空间连续。
- https://www.nyfa.edu/cinematography/projects/ ：无声画面应能交代行动，相邻镜头可连续剪接。
- https://www.nyfa.edu/digital-editing/projects/ ：按开端、发展、结局选择镜头；剪辑维持故事连续。

结合既有 EDENA-STUDY / EDENA-CAMERA-STUDY，采用宽景、小人物、清晰格框、宽留白与三横条节奏；不复制漫画台词。封面先读完整故事。建立四家店的空间，再让同一组场所在攻击中改变意义，最后回到开门的全景。主体局部坐标机位避免逐镜轨道角度累加或被游戏相机覆盖。每格4秒，首尾6秒是阅读感，不是视频时长。

确定性检查：对象缺失必须失败；记录真实舰队触发与阶段；capture-clean 检查通过再读 canvas；不以文字叙事冒充游戏演出。逐张看图决定重拍，不凭 manifest 自动验收。
