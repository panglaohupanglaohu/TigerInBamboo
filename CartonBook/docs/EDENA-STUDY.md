# 《The World of Edena》分镜 / 视角研习笔记

研习对象：Moebius《Edena》公开页（Reactor 开篇图、Door of Perception 扫描、Dark Horse 预览「REPAIRS」等）。  
目的：抽出可执行规则，用于 CartonBook 游戏截屏漫画（非文生图）。

## 从原页看到的

| 页类型 | 格数 | 机位 / 比例 | 文字 |
|--------|------|-------------|------|
| 全页 splash | 1 | 极宽地平线，人物极小 | 几乎无字 |
| 纪念碑感 | 1 | **低机位**，主体占上 2/3，人在脚下 | 一个小气泡 |
| 室内 | 1 宽格 | 眼高，全身仍小于房间景深 | 角上短旁白 |
| 机械/通道 | 1 横幅 | 略俯，人很小 | 静默 |
| 「REPAIRS」叠页 | 3–4 层竖条 | 宽→中→近/拆分 | 每格 1–2 短旁白框 |
| 建筑墙 / 屋 | 3–4 层 | 顶条小人远景；中条插入近景；底条再拉开 | 可全静默 |

共性：**矩形格、均匀白 gutter、页边留白大、地方大于人、文字极省、标题可嵌在顶条画面内。**

## 六条落地规则（书店镇专用）

1. **开篇全幅宽景**：街/店面撑满画面，玩家剪影约占高度 5–20%；此页不对白。  
2. **竖条叠页 ≈3 带**：顶全宽抵达 → 中全宽或 1/3+2/3 → 底安静宽景；禁止美漫式 6–9 宫格。  
3. **改尺度不改混乱**：宽镇景 → 眼高全身仍小 → **一次**近景插入（门把手/招牌）→ 再拉开；立面低机位最多一次。  
4. **字少**：每格至多一条 2–4 行旁白 + 偶发小气泡；静默格正确；字不挡主体。  
5. **章题在顶横幅内**（左题 / 右署名），勿做厚重独立顶栏。  
6. **格内景深**：前景空地/路面 → 中景人 → 远景立面/货架；至少一格接近「空」的负空间。

## 对旧样章的批评

旧 `bookshop-letter`：偏网页卡片 + 多格挤页 + 顶栏导航感强 + 对白气泡压画面 + 截屏含 HUD。  
这些都不像 Edena 册页节奏。

## CartonBook 强制落实（本轮）

| # | 规则 | 文件落点 |
|---|---|---|
| 1 | 封面整幅宽景，人高约 5–20%，无对白 | `recipe` cover：`dist≥34`、无 `dialog`；`layout` 封面无气泡 |
| 2 | 内页 ≈3 条竖向横幅，矩形格+均匀 gutter+大页边 | 模板 `edena-stack-3` / `edena-close-insert`；禁 `panels-5` 九宫 |
| 3 | 宽→眼高仍小→**一次**近景插入→再拉开；低机位立面≤1 | storyboard `note`+`camera`；仅 s02 或 s04 之一用低仰 |
| 4 | 每格≤1 条短旁白；偶发小气泡；静默格合法 | `showCaption`/`showDialog` 精简 |
| 5 | 章题写在**顶条横幅内**（左题右署名），无独立顶栏 | `.strip-title-bar` 叠在首格内；隐藏 `.page-header` |
| 6 | 景深：前景空地、中景人、远景建筑 | camera `pitch`/`dist` 注释要求；取景靠远距+略俯/眼平 |
