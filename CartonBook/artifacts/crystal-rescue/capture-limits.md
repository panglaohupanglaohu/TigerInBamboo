# 截屏与剧情边界

所有像素来自8931游戏主场景；无生成图。故事里的居民互助、信件内容与水晶城回信是新编叙事，非新增的游戏任务或可玩关卡。保存序列化剧情状态仅限本次隔离浏览器。

首轮实拍发现现有主线在 chapter=2 的苔庭目标 getTargetPosition() 返回 null；原游戏阶段无法直接连续推进。本册后半从游戏合法存档结构 chapter=3 的隔离状态开始，随后使用原 rescue-action 交互救回红狐、认出虎虎并进入护送。不能把这一拍摄流程说成完整主线通关验证；不改用户存档或游戏剧情实现。

首轮遮挡/失败结果保存在 final-capture-result.json 与 contact-*.jpg；最终采用 family-final-result.json 和最终接触表复核。


最终团聚镜采用同一主场景的真实小岛，摆放原有信使、红狐、虎虎作漫画摄影 tableau；无外部生成图、无角色缩放或资产重造。摆位仅在独立浏览器生效，不冒充游戏原生团聚演出。因原UI按钮 disabled 状态滞后而失败的镜头已重拍或改用先前合格实拍，来源记录在各镜 reusedFrom / sha256。

最终采用163个分镜位置、134幅不同实拍像素；其中29次有意回接既有场所/角色画面，记录了来源，不以它们冒称163幅不同拍摄。封面占两个PDF书本页。小说新编情节以页内文字表达，不声称完整主线已通关。
