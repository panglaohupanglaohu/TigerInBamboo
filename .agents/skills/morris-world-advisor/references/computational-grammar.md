# 可计算的织锦语言（项目推论，不是Morris历史算法）

历史事实与项目参数须分开。V&A说明自然观察、程式化和前后景交织；WM Gallery的Acanthus记录有66cm重复单元与30块木版。下述函数是本项目为三维实时场景提出的工程表达，不能声称Morris用过L-system、WFC或这些数字。

| 层 | 可计算表达 | 视觉判断与反例 |
|---|---|---|
| 主枝蔓 | 三次Bezier B(t)，枝长递减，端部切线连续；两条相向弯曲骨架交替穿插 | 先能读出连续流向，再填叶；独立随机花点不构成骨架 |
| 叶 | 中脉C(t)，两侧宽w(t)=w0 sin(pi t)^0.7，以低频5–7叶裂调制边缘；末端回卷 | 轮廓深裂但圆转，叶与茎真正连接；不做等边三角叶或球团 |
| 叶脉 | 主脉+每瓣次脉，次脉沿瓣走向，线宽随t缩小 | 先主后次；金色微粒不代替脉络 |
| 重复 | 相邻单元交错半幅，镜像/转向受骨架控制，seed固定 | 有节奏且不露机械行列；全图无约束随机会失去织物秩序 |
| 前后层 | 背景细枝小花、主层宽叶、前层少量大花，三层遮挡图保持无环 | 大小交错，间隙露出底色；不是一层密集贴片铺满 |
| 花 | 杯形/盘形/高花序三类，瓣数、花心、沿茎疏密各有词汇 | 蜀葵的竖向节律与低繁花区分；不让全部花同一圆盘 |
| 动物 | 兔以长耳/后臀/前足成轮廓，鸟以头胸翼尾分区；毛羽用顺形条带 | 缩略图可辨物种；纹样服从体型，非写实毛发+泛用金箔 |
| 材质 | 少量色面+顺形刻线/织纹，限制镜面高光，保留明暗体积 | 从斜侧/背面仍成立；不把浮雕贴图误称完整模型 |
| 建筑 | 主塔、翼楼、入口、庭院分级；木石砖瓦有构造逻辑，与植物相接 | 现有城堡身份与可走门洞保持；不是添加更多尖塔 |

本项目候选色表：底色#143D4A，深叶#355044，中叶#6C7952，赭叶脉#AB9762，奶油花#E3D5AF，砖红#A34C3C；都是参考推定起点，不是博物馆色度测量。主枝2–3条、次枝每条3–6段、主叶每枝5–9片、花2–3种规模为局部模块试验范围，不能强行套到每棵树。

三维布局约束优先：路沿至植物碰撞体留实际骑手净空；桥前保留看见桥拱、横溪和对岸的视线走廊；骑手连马高度小于高树一半；四层由低花坪、溪丘、城堡肩、后峰构成。路径应花径→桥面→开放农门→盘山→城门，溪从桥下穿过。视觉上连通不能代替真实地面承托与全程骑乘。

建议最小试验：一簇卷叶+三花、一个鸟/兔、一个城墙花蔓接点。固定seed与相机，分别检查正面/侧面/背面轮廓、连接、色面、背景间隙，再合入整岛。保留现有琴庭音乐和古松，避免同时改变布局与材质使对照失效。
