# 配色与模块建模重点

以下是项目方法建议，不是假称来自 Oskar 的调色参数或私有技术。首次研究深入到有出处的样片和相应年代，随后用当前场景实验验证。

## 配色

研究 Bad North 的画面可读性、Townscaper 的建筑色块组织；不要未经证据把所有后期 Oskar 动图归入两款游戏。提取参考色时标注截图来源、光照和取样区域；照片像素包含照明与后期，不能原样视作材质 albedo。

给方案提供少量语义色角色：主石材、阴面石材变化、屋顶、门窗/金属、植被、海水与雾。先检查灰阶主体/背景关系、暖冷组织、饱和度主次，再比较日光/阴天/夕阳。分开调材质本色、环境光、太阳光和色调映射，保持曝光一致做前后对照。最终数值必须通过目标图与运行时画面验证；没有采样不要编造“作者官方色板”。

十二门徒遵循蓝灰海岩、低饱和植被与海水层次，日落可有暖受光面但不能整块变黄。高山圣城遵循已认可伊斯坦布尔研究：石材、旧砖、屋顶和海湾有区别，城堡作为主视觉组织明度；具体色值以认可目标及场景测试为准。历史厚重感来自材料变化、结构承托、边角磨损与尺度，不只是调暗加脏。

## 用户所谓 MFC 的语境

本项目历次讨论主要涉及 WFC 与 MC。首次说明该映射并保留原术语待查证，不向用户反复追问。不要声称 MFC/MCF 是 Oskar 已证实使用的统一算法。

- WFC：候选模块和邻接约束求解，决定可放什么。
- MC / Marching Cubes：基于局部占据或标量场的表面构建思想；具体建筑模块怎样连接须看作者材料，不能直接用光滑等值面替代手工城堡模块。
- 受约束网格松弛：只改善软坡或形状，不等于 WFC，也不是全部几何的通用后处理。

岩群必须先有海蚀基座、凹槽、宽台面、硬崖、坡肩和破碎顶的实际网格。定义边界曲线、方向、高程与承托，水平组合形成山肩，竖向组合形成台阶。台面有真实面积才能种植，横线不是台面。城堡先有连续台基、主体、翼楼、塔楼、城墙转角、门洞及上城坡道模块；接口含开口与净空，不能把城墙延长堵港口。

至少比较一个人工拼装样块与一个约束生成样块。岩群用无云轮廓、侧面台阶和海面交界验收；城堡用远景主次、近景承托和港口至城内连续路径验收。美术模块不成立时，优先改模块而非扩大随机种子数量。
