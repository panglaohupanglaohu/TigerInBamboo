# 调色、打包与地图表达

来源、时间账本和详细观察：项目 `artifacts/research/oskar-series-20261006/RENDERING_AND_TOOLS.md`。以下媒体均12时刻取样，未取得源码。

## 调色板作为依赖关系

[Oskar，2023-10-11](https://x.com/OskSta/status/1712088611934371876)展示调色板创作工具：调整色节点和区域、添加三角色域及另一渐变条。作者未说明色空间。项目可将受光岩、阴面岩、草、林、海、彩墙设为共享语义节点，再派生变化；不要分别散落硬编码。若采用OKLab等空间，明确是项目选择。固定曝光测试灰阶主次、暖冷和饱和度，不能把工具所有颜色同时用于成品。

## 矩形打包的空间树不等于三维碰撞

[Oskar，2024-03-05](https://x.com/OskSta/status/1764958522398146667)明确：二叉树矩形打包，位置候选部分暴力搜索，树用于快速碰撞查询。可用于UV图集分配或二维占地宽阶段；不证明车辆/木马/山体三角形碰撞。图集需留mipmap gutter、稳定岛ID、密度和不重叠检查；场景碰撞另测真实变换、体积及移动扫掠。

## 地图导航的外部参考

[AllCityKitty，2023-11-12](https://x.com/AllCityKitty/status/1723738415177363639)是高尔夫tile效果演示，**不是Oskar作品**。27.38秒样本可见棋盘岛屿、目标环、白色预览轨迹、效果卡及过关提示。用户希望借鉴地图表达；提取地貌色块、入口焦点、路径预览和镜头聚焦，不把击球轨迹当步行寻路。

我们的地区节点绑定真实scene/entrance ID，导航图查询后才显示可行路线，未知或未连通路线不画为可走。地图边界看起来相邻不能证明桥或港口连通。不要为学习界面替换用户游戏玩法。
