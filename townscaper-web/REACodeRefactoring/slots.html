865200072685912064（2017-05-18，「a small browser demo to help explain how the WFC algorithm works」）：原片是标题 SLOTS + 10×8 槽位表，每格一张缩略图，底部 RESET / SOLVE / 暗按钮。 这里槽位表跑在共享 solveWFC 上：边值 = 两角点值之和 mod 3，变体池 27 种（cornerVariantTiles）；槽位里画的是该格当前候选集的叠影（数字 = 候选数），定下来后变成那一张缩略图； 时序动画逐帧播放求解器真实的候选快照（traceLimit），红线是 explain 记录回溯出的依赖链（决定/给定格 → … → 被删候选的格）。缩略图美术是程序化替代（天蓝底 + 赭红拱 / 凹口 + 沙色台基），不是原素材。
