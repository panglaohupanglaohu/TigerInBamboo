# ARCHITECTURE — 重构版的系统结构

## 一句话

**一张网格、一份体素。** 地形管线写岩石层，建筑管线写其余层；两者写进同一个顶点池、一起烘焙光照；水层只看"哪些格是陆地"。小镇、地形、融合三个场景共用全部代码，只是生成器不同。

## 数据流

```
core/grid.js ──► core/world.js (World: solid / rock / color / river)
                     ▲   ▲   ▲
   terrain/generate ─┘   │   └─ world/app.js（玩家建造 / 拆除 / 刷色）
   world/scenes ─────────┘      （小镇 / 地形 / 融合）
                     │
                     ▼  （版本号变了才重建）
   world/worldmesh.js ──► terrain/shape.js ──► terrain/terrainmesh.js ─┐
                      ──► build/buildings.js ─────┼─► core/meshwriter.js（同一个顶点池）
                                                                    ▼
                                         light/bake.js（分层 AO + 彩色反弹）
                                                  ▼
   world/view.js ◄── 几何体（一次 draw call）+ 倒影；water/shore.js（岸线 / 浪带 / 浪裙）
```

## 依赖规则

- `core/` 不依赖任何其他目录（three.js 除外）。
- `terrain/`、`build/`、`light/`、`water/` 只依赖 `core/`，彼此不互相引用。
- `world/` 负责把它们组装起来；`ui/` 只通过 `view` 和 `world` 的公开方法操作场景。
- 生成器只写 `World`，网格生成器只读 `World`。

## 约定

- 层高 `L = 0.5`，网格半径 14（2516 格），最多 12 层。
- 颜色一律 `new THREE.Color('#hex')`，**不要**再 `convertSRGBToLinear()`。
- 每处实现在注释里写帖子 ID 和原文关键句。
