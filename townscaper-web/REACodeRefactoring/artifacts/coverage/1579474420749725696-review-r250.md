## 代码落点与差距

`src/terrain/bn-island-field.js`（本片专用移植，逐式对齐裁判 `REACode/engine/islands.js`）：

- `buildIsland` 域扭曲 fbm + 脊线 → 径向衰减 → 台地量化 → 一次平滑 → 材质分类 → 可走格；
- `buildIslandGeometry` 每格 2 个顶面三角（明暗 0.97/1.03 假刻面）+ 落差 ≥0.12 的四向竖崖裙（ROCK_DARK 0.86/0.82）；
- `placeIslandHouses` 平顶候选（草/草顶材质 + 四邻 |Δh|≤0.02）→ 最小间距 3 格 → spire 0.35；
- `findPath` 8 向 A*（本片未用到，随模块一起验）。

本轮新增运行验收：`bn-island-field.html`（此前该模块**没有任何页面入口**，只有 Node 侧 `tests/bn-island-referee.mjs` 的对拍）：

- 两档显示对应片中的两个阶段：线框档画全部三角边（每三角 3 段，共 57624 个端点），着色档画同一批三角的顶点色；
- 「搭出」滑杆用**同一个 drawRange 口径**同时驱动线框与面片（三角序 → 边序一一对应），因此 0%→100% 是逐三角长出，与片中「从一根线长成整座岛」同型（差别：本页按行序长，原片自岛心向外）；
- 小屋按 `placeIslandHouses` 的真实候选落位，箱体 + 黄锥顶（spire 拉高）。

仍缺（卡点不变）：

- **C 算法未公开**：原片三角网生成器、坡面细节、真屋模联合出屋算法未公开，本实现不能认证为原作算法；
- **B 美术资产**：黄顶小屋、精确色板、机位轨迹无源素材，程序近似；
- 本页搭出顺序（行序）与原片（岛心→外）、机位与配色均为本地近似。
