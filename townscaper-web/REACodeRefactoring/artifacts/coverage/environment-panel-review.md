# 首页环境能力入口验收

本轮响应首页无法直观看到风、天气能力的问题；属于已有能力的实景接线与界面改进，没有新增视频学习，逐帧累计仍为94/285，剩191。原版REACode未修改。

## 实际接线

- 首页默认展开「风与天气 · 已接入能力」，直接控制同一个View的风场箭头、飘雪与表面雪色、薄雾、流动云层、迎风旗帜、岸浪、瀑布、海鸥。
- 风向滑杆修改共享uWind，再重建按实际体素层避障的风场、箭头及雪粒子采样场；不修改World数据。不把显示箭头当成开启风模拟。
- 光照时段接现有day/dusk/night；北境场景额外显示已有六套环境配色，其中雨等推断主题明确标识，未实现降雨粒子。
- 云/瀑布使用实际mesh/group.visible读取状态，避免仅有setter的属性导致勾选状态失真。键盘、学习面板和换场景后的值同步。
- 更多能力实验另列八个入口；完整管线与视频列表仍可展开，pipeline总览新增返回实景控制入口。

## 验收与边界

测试：tests/environment-panel-browser.cjs；结果：environment-panel-browser.json。两种网格分别验证八个开关、180度风向的场重建及外围采样反向、World版本不变、昼夜切换、场景默认云状态、北境雨天配色、返回融合隐藏北境选择器、完整管线展开。检查3181×543宽屏及390×844手机布局，截图environment-panel-{mixed,quad,wide,mobile}.png。

雪是已有粒子与着色效果，不是物理积雪；雨目前只是北境配色。实验入口不代表所有实验已成为默认渲染路径。界面参数暂不新增存档协议。
