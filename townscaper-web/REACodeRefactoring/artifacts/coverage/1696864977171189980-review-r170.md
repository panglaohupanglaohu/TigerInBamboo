## 逐帧观察（本轮复看 + 沿用 r169 的分段）

- **0000–0199**：全岛缓慢环绕，顶面以米黄/桃色大斑为主，崖壁米白+水平层理；这一版色块偏大、斑与斑之间靠得近。
- **0200–0283（本轮复看）**：同一座岛，米黄大斑几乎铺满顶面，**到崖肩整齐收住**、崖壁纯米白（这正是「不糊到重要边界上」那句）；0280–0283 顶面出现更大的一片绿色斑，边缘仍在崖肩内。
- **0284–0287**：四帧**纯黑剪影**（换版本的黑场，不是画面内容）。
- **0288–0299**：换成另一版（色斑更细、绿/桃交替更明显），崖肩仍是干净收口。
- **0300–0501**：继续环绕 + 近景，末帧静止。

## 判定

**有机制**：与 A 片同一条流水线 —— 顶面大笔触图集 + 崖肩距离场（顶面在崖肩前收住）+ 崖面只在沿口下很浅一段延续 + 舌头。本片的「反证」意义在于：**笔触变大而边界不被糊**，所以 ①图集尺度可调 ②崖肩收住所依赖的 rimMask/bleedMask 必须与尺度解耦。

## 代码落点与差距

与 `1696896119794479541` 同一套落点（`blotch-atlas.js` / `blotch-tongue-c09.js` / `view-shading.js` / `blotches.html`），本轮修正也相同：
- rim 场新增 **B 通道 = 崖肩顶面（邻域 max）**，`below` 改用 B（崖面 XZ 压边界时 G 的双线性会掺下格，实测 11/15 个崖肩 below 为负 → bleedMask 恒 0）；
- 舌头同样改用 B，去掉「向墙内偏 0.18」的近似；
- 探针量具改为「窄条 0.06 + alpha=0 清屏认覆盖像素 + 均值」，替掉 r169 取 max 的写法（渗漏是乘性压暗，max 永远读到未上色处）。

**尚差的一层**：本片的判据是「笔触变大但边界不乱」，其中「边界不乱」= 崖肩收住 + 等深收口，仍缺像素级的等深读数（同 A 片，`bleed=20` 与 `bleed=0` 逐像素相同这一异常待查）；「笔触变大」已可量（`?scale=.09→.045` 一条扫描线上的色块边界 6→0、顶面着色 10.0%）。图集是程序化替身，原片配色未对。
