## 逐帧观察

- 0000–0030：一条长船在浅水面上向右上慢速航行，船后拖出一条**很窄的浅色带**；船头有一小撮白色泡沫。
- 0031–0090：尾迹变长，**两条白色边线**清晰可辨；两条线在整段尾迹上**基本保持平行**（间距 ≈ 船宽 3–4 倍），不随距离张开。线间不是连续白雾，而是**成排的 X / chevron 泡沫碎块**：近船密、往远端逐排变稀，最后只剩两条边线。
- 0091–0137：船略微改向，尾迹跟着轻微弯折（旧尾迹仍留在原方向）；边线在远端淡出。
- 4× 裁切（0060）：船体是深紫木壳，两侧各有一排桨手；船尾两条白线之间是**断续的蜂窝状泡沫块**，边界线是**连续**的；舷侧没有大团喷溅。
- 4× 裁切（0120）：泡沫碎块已衰减成**稀疏的 X 形**（每排只剩 2–3 个），两条边线仍然连续但更淡；船头前缘有一小片白。

## 判定

**有机制**，而且原片的形制**不是 Kelvin V**：
1. 边线 = 固定横向偏移的两条拖带（间距恒定，不张开）；
2. 内部泡沫 = 按航迹里程**成排**发射，排内**跳格**（有空格 → 断续的 X/chevron）；
3. 船头有一小片泡沫，舷侧没有明显喷溅。

旧 note 的「未恢复 KELVIN 角度」与「原片断续泡沫、舷侧喷溅仍待补」要拆开看：**Kelvin 角在这条片里不成立**（边线平行），所以不是"没恢复到 19.47°"，而是"原片根本没用 V"；断续泡沫确实是缺的；舷侧喷溅在片里看不出来（只有船头一小片）。

## 代码落点与差距

- `src/core/wake-sampling.js#makeWakeParticles`：**新增 `corridor` 档**（默认仍走 V 档，旧行为逐位不变）：
  - 边线粒子只给**固定横向偏移** `beam·corridorBeam/2`（默认 corridorBeam 3.4），横向速度 0 → 两条线平行；
  - 内部泡沫按**航迹里程**发「行」（`rowStep·len`，默认 1.1 个船长一行），行内按 `rowFill`（默认 0.55）跳格 → 断续；
  - 新增 `width(ship)` 读数（非 veil 粒子的最大横向偏移）与 `rows` 计数，便于 A/B。
- **做到哪**：平行边线 + 断续行两件都有了，且参数化（corridorBeam / rowStep / rowFill）。
- **还缺**：① 边线在远端的**淡出曲线**没有逐帧标定（片里远端只剩很淡的一层）；② 船头那撮泡沫的尺寸/寿命未标定；③ 舷侧喷溅在片里不可见，本仓也不该凭空加——`spray` 保留但默认强度未按本片改；④ 靠岸/搁浅行为（本片不含，属 9466 一族）。
- 页面接入：`src/world/boats.js` 目前仍用 V 档（`makeWakeParticles({rate:70, sprayRate:6, life:3.2})`），切 `corridor:true` 需连动 `battle-c02.js` 的船只数量/速度标定，**本轮未切**，留作下一轮（写在 next 里）。
