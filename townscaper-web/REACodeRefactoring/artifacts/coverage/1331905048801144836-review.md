## 逐帧观察

固定机位看一座小岛被一块块盖起来，最后在岛的右端立起灯塔。

- 0000–0030：岛上只有两栋小楼（橙瓦 + 青墙），海面平静，几只海鸥。
- 0031–0079：右端开始叠高，出现一段白墙；左端同时补出一栋深红墙。
- 0080–0139：右侧那一列升到 4–5 层，塔身出现**红白分层**（白墙层 + 红墙层，每层顶上一道红檐），塔顶还没封。
- 0140–0199：塔顶封上灯室雏形：塔身上多出一圈挑出的平台 + 细栏杆，上面一个浅色方块。
- 0200–0299：灯室成形，正面能数出**一排约 5 扇大玻璃**，白色竖棂；玻璃上方一道白色檐板，再上面是**橙色四坡屋顶**（方形金字塔，不是圆锥），顶尖一个小深色柱。
- 0300–0346：机位略降，塔身被拉长到 6–7 层，红白带更明显；末帧 3× 放大确认：方形塔身 → 红唇挑檐 + 一圈**细立杆**栏杆 → 方形玻璃灯室（白棂）→ 白檐板 → 橙四坡顶 + 顶尖。全程白天，没看到夜间旋转光束。

## 判定

有机制：这是"**一格粗、靠海、每邻格都矮至少 2 层**"的塔顶模式 —— 命中之后在建筑顶上罩观景台 + 灯室 + 屋顶。原文说"要求的代码重写比想象中多"，正说明它不是手工摆件而是规则推导出来的。

## 代码落点与差距

- `src/build/lighthouse.js`：规则（MIN_H=5、每邻格矮 2 层以上、至少一个邻格是海）与片中一致，未改。
- 本轮改的是**外形**（原实现与片子明显不符）：
  - 灯室：`CylinderGeometry(16 边)` → `BoxGeometry`（方格，实测 x/z 尺寸 1.12 / 1.12，差 0）；
  - 窗棂：8 根深色竖条 → **5 扇玻璃 + 白色竖横棂 + 白外框**（片子里是白框不是黑框，玻璃偏蓝绿，夜里转暖黄）；
  - 屋顶：`ConeGeometry(16 段)` 暗红圆锥 → `ConeGeometry(4 段)` 橙红**四坡**（和屋顶同色 `#cf6a43`）+ 深色顶尖；
  - 平台：圆盘 + `TorusGeometry` 圆环栏杆 → 方形挑台 + 红唇 + **72 根立杆 + 四道扶手**；
  - 新增白色檐口（skirt）/檐板（lid）；所有灯室部件 `castShadow = true`。
- 仍缺：塔身本身的"红白分层"没有专门着色（靠下面楼体的调色板，命中时不一定刚好是红白带）；夜间光束已有，但片子里没演示到夜间，未做进一步核对；灯室玻璃在强光下偏白（片子里更蓝绿）。
