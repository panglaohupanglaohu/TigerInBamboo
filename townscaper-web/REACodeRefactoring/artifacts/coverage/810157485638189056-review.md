## 逐帧观察

- **构图**：俯视偏一点斜角，444×396，深灰蓝底 + 一条水平参考线。地面是一整片棕色块体，块体顶面能看见三角形剖分线（fan 三角网）与沿边缘的一圈白色小点（顶点/边采样）；边缘是圆角外凸的"团块"轮廓，属于典型的手搭城镇/墙体块布局。左下角一小片沙色地基，几根绿色小圆柱（树/灌木），一个蓝色箭头、一个红色锥体、几个彩色小方块。
- **0–6s**：黑色与暗红色小点聚成一片约 40×60px 的团，压在左下沙色地基与相邻台地上；同时有一条点串顺着台地颈部往上拖，点距 1–2px，形成连续的"点状线"。
- **6–12s**：点串整条换位置，出现在中上部台地，沿可行走区拐了几道弯；画面里换成另一组三轴 gizmo（红/绿/蓝箭头 + 绿色方块 + 白色圆圈）在中上部。
- **12–30s**：每 2–4 秒点串换一次落点，反复在左中、右上、中部之间跳动；相机极缓慢地绕行（块体朝向在 18–29s 之间持续偏转几度），构图不变。末帧（0509）点串回到中部偏左，gizmo 跟着走。
- 静止性检查：frame-0060 与 frame-0064 逐像素差 >20 的只有 2129 px（占 1.2%），暗色点像素 4277 → 4331 —— 点阵基本是**累积/静态**的，不是每帧重画的粒子流。

## 判定

**有机制，但片子里无法完全区分是哪一种**：这是一个编辑器内的调试/authoring 视图——棕色块体带三角剖分（说明底层是三角网格），点串沿可行走区域密集采样成一条路线，配合可拖拽的三轴 gizmo 标记。两种解释都与画面相符：

1. 沿可行走图**采样出来的移动路线**（点距 1–2px 的等距撒点，与 `path-samples.js` 的口径一致），gizmo 在拖路线端点/检查点；
2. 某个 agent 行走时**记录下来的轨迹**（点阵累积、不回退）。

两种都是「路线/轨迹在可行走图上的密集采样」，实现上共用同一套采样；差的是"手画"还是"录制"，片子没有 UI 文字可证。
