## 逐帧观察

- 帧 0–99：固定低俯角机位，绿色岛屿台地上两栋着火的房子。左屋（近、大）与右屋（远、小）各冒一根烟柱，风向右偏上。**每根烟柱都是一次从根部起、向外卷成弧形的粗团**，不是细长直柱。
- 帧 100–199：两柱都保持同一形态缓慢摆动；烟柱上缘是若干个各自鼓出的圆弧，瓣与瓣之间有凹口；根部与建筑接触处始终是深色饱和块。
- 帧 200–299：颜色分层很稳定——根部近黑（sRGB 40–55）、中段 85–100、远端 130–140，末端几乎融进天空（170）。
- 帧 300–302：与 299 一致（片尾静止）。

**frame-0250 的 4× 根部裁切（关键判读）**：贴建筑那一团是**整块近不透光的深灰团**，剪影完全闭合、内部透不出背景，边缘是圆滑弧；从它往上/往左才分成一个个圆弧瓣。**没有**出现「一串互不相连的小圆点」这种形态。
**frame-0250 的 3× 整柱裁切**：一根柱子上能数出 3–5 个大圆弧瓣，每个瓣的直径与柱宽同量级；远端（顺风方向）有一团明显脱离主体的球形烟，与主柱之间露出背景。

## 判定

有机制（两遍 + 描边 + mip 渐糊 + UV 滚动均已落地，见 review-r55）。本轮针对的是**根部实心度**这一条残余缺口：

> 原片根部是一整块近不透光的团（剪影闭合），本仓旧口径新生儿尺寸只有 0.11（≈ 1/4 个烟团）、且 age 0.55 起就整体淡出 → 渲染出来根部是一串带缝隙的小圆点，整条柱读起来「稀」。

这不是判读误差：本轮用同一台离屏渲染器量了掩码（见下），旧口径根部带箱内透空 13/19 箱、填充率 0.80，肉眼掩码同样是断续圆点。

## 代码落点与差距

落点：`src/life/smoke.js`（`Smoke` 类）。本轮（第 59 轮）三处改动，全部挂在新增的 `setSolidBase(on)` 之下，`setSolidBase(false)` 可完整回到旧口径：

1. **新生儿尺寸抬高**：`s` 的基数 `0.11 + age×0.38` → `0.30 + age×0.26`（age 0 时 0.26–0.37，age 1 时 0.54–0.70，柱长不变、根部不再稀疏）。
2. **尺寸离散度放宽**：种子因子 `0.88 + seed×0.34`（0.88–1.22）→ `0.78 + seed×0.72`（0.78–1.50），个别团明显顶出剪影 → 才是「各自鼓出的圆弧瓣」而不是均匀香肠。
3. **实心核心延长**：新增 uniform `uCore`（淡出起始 age），0.55 → **0.76**；基部发射间隔 0.20s → 0.15s。原片只有顶端一小截是虚的，中段仍近不透光。
4. 附带把 `uLobe` 的边界扰动幅度 1.35 → 1.55（只影响 lobes 打开时，关闭态 mix 到 1.0 不变）。

新增 `tests/smoke-solid-base-browser.cjs`：离屏 RenderTarget 只渲烟、PCA 主轴分 48 箱，量根部带（前 40% 轴长）的 `emptyBins` / `gapBins`（箱内垂向被烟包住但中间透空）/ `baseFill`，`solidBase` 开/关同机位对照。

## 仍缺（留给下一轮）

1. **远端独立黑烟团**：原片顺风端有一团明显脱离主柱、明度与柱身相近的球状烟；本仓是所有片走同一轨迹，末端只能靠淡出分开，没有单独建模的一团。
2. **瓣的尺度**：原片 3–5 个大瓣、每瓣直径≈柱宽；本仓 9 个偏小偏密的瓣（判据计数在区间内，但视觉颗粒更碎）。
3. 两柱之间那层弥散薄雾（低对比、模糊、压在所有团后面）本仓没有独立层。
