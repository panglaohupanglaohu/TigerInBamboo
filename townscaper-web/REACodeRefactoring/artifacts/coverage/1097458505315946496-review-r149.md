## 逐帧观察

- 0000（0.0s）：浅青灰海面 + 15 个左右的小岛图标（红/白/灰的城镇方块，带旗与细碎屋顶），画面里只有极淡的横向长直线，**还没有三角网**。这就是「散开的节点」底图。
- 0001（0.4s）：**黑色三角网**一次性压上来——岛心之间全是深色细线，三角形长宽比很不均匀，左/上边缘出现向画面外一点汇聚的长条细三角（= 原文第 1 步「triangulate with some added padding」，padding 点把最外圈拉成扇形细三角）。没有任何区域填色。
- 0002（0.8s）：同一张三角网**变淡成灰蓝细线**（调试层退到背景），岛上图标不变。三角形顶点都落在岛心，边中点也就是后面「走格边」的走廊。
- 0003（1.2s）：**第一条前线出现**——一条深墨色粗线（外一条更宽的浅描边）沿着三角网边走，绕过中间一片岛，从画面上缘进、下缘出；两侧没有填色，只有极轻的明度差。
- 0004（1.6s）：同一画面上**三条虚线墨线**并行（风格是长短相间的墨点线），每条都沿三角网边走、互不相交；三条之间海色略有不同（左带更灰、右带更青）。三角网细线仍在背景。
- 0005（2.0s）：三条线重新吸附规整，左带明显偏灰、右带偏青，边界就是那条最粗的墨点线；场内出现极淡的横向波纹短线（像海图等高线）。
- 0006（2.4s）：**padding 扇形被拍进来**——左侧有一大束细线汇聚到画面外一个点（三角网的 padding 顶点），说明这一步仍在调三角网；右侧是已经平滑的虚线前线。
- 0007（2.8s）：左侧区域变成"纸质"底（更灰、有隐约的小图标/花纹），右侧仍是青蓝海色 + 波纹；墨色虚线与 padding 扇形同时可见。
- 0008（3.2s）：去掉 padding 扇形，只看成品——左侧灰带 / 右侧青带靠一条墨色点划线分开，右侧海面有密集的横向波纹等高线，岛上图标清晰。
- 0009–0012（3.6–5.0s）：波纹铺满整张图，多条虚线前线（左粗右细）稳定，**尚无地名与箭头**。
- 0013（5.8s，终帧）：定稿地图——① 每个岛上方/下方有**手写体地名**（Bjornholm / Skuvoy / Herm / Koltur / Cantur / Fugloy / Darkrock / Graemsay / Skerry / Inchkeith / Ganinick / Otterton / Housholmur / Muck…），深墨色、略斜；② 岛与岛之间是**点线航路 + 箭头**（箭头落在两岛之间的空档，不压岛）；③ 前线是**墨色虚线**，旁边散落小号数字（7 / 8 / 9 / 10 / 12 / 13）；④ 海面有横向波纹等高线，两侧场色调不同（左灰右青）。

判定：这不是纯展示片，是**一步一条机制的建筑过程录像**：三角化（带 padding）→ 沿三角网边走到前线 → Bezier 采样 → 用 Bezier + 三角网把两侧的场细分出三角形 → 最后加墨（地名 / 阶段数字 / 航路箭头 / 场内纹样）。

## 判定

有机制，且四步 + 墨层都能拆成可检验的量。片中**没有**帧率/耗时读数，也没有 UI 面板。

## 代码落点与差距

- 第 1–3 步：`src/core/frontier.js#buildFrontier`（padding 矩形 + TriGraph 三角化 → 边中点图 → Dijkstra → `sampleFrontierBezier`），r55 就在，文件头署本片 ID。
- 第 4 步：`frontierFields`（用采样后的 path 把 padding 矩形切成 below/above 两个多边形 → ear-clip → 每个岛按其落在哪一侧分带）+ `buildFrontiers`（多条前线 + 交叉报错）。**旧 note 记的「两侧细分未实现」是过期账**（r55 G3 已落码，`tests/frontier-fields.mjs` / `tests/frontier-fields-campaign.mjs` 一直在跑）。
- 真缺口在**第 5 步的墨层**（本仓完全没有）与**页面的形制**：
  1. `campaign.html` 第 4 步填色用的是糖果色带（`BAND_COLORS` 绿/黄/橙/粉），片中两侧场是很淡的海水色差；第 5 步还挂着节点分带圆标（调试件），片中没有。
  2. 前线画成「深底 + 浅彩」实线，片中是多条**墨色虚线**并带小号数字。
  3. 片终帧的**地名、航路箭头、海面波纹纹样**在页面里一个都没有（第 5 步只有 64² 岛快照 + 点线航路）。

本轮补的（新模块 `src/campaign/map-ink.js`，机制主线一字未动）：

- `islandName(seed,id)`：按节点 id 索引导出地名（38 前缀 × 20 后缀，同图不重名），配 `Little/Great/Old/North/South` 风格前缀——片中手写体是美术资产，本仓只能程序化生成。
- `drawPlaceNames`：岛上方/下方交替 + 左右交替对齐，斜 0–3.6°（片中略斜的手写体）。
- `drawStageMarks`：沿主航路给每个阶段岛写小号墨色数字（片中 7/8/9/10/12/13 那类小数字）。
- `drawRouteArrows`：每条航路边在 62% 处画箭头（留出岛图标空档），方向按主航路。
- `drawFrontierInk`：每条前线「宽淡墨洗 + 细墨虚线」（`setLineDash([9,7])`）+ 线上一个步序号（1/2/3）。
- `drawFieldPattern`：在两侧场多边形内 clip 后铺横向波纹（片中那条海图等高线）。
- `frontier-overlay.js` 加两个可选参数：`palette`（填色带，页面传低饱和海色，节点标签仍用 `BAND_COLORS`）与 `curves`（第 5 步交给墨层画虚线，避免叠两层线）。
- `campaign.html`：`?ink=0` 可整层关掉做 A/B；`window.campaign().ink` 吐读数，`window.campaignBands()` 给每个带最大三角的重心（屏幕坐标），`window.campaignNames()` 给地名表。

如实口径（不计缺口）：原名是手绘美术，本仓是程序化音节 + 斜体字；片中小数字（7–13）在 560×420 原尺寸下判不出语义（既可能是阶段号也可能是岛号），本仓把「主航路上的阶段号 1..n」写在岛旁、把「前线步序 1..n」写在前线上，并在此写明这一口径；片中前线旁边还有 padding 扇形的一束细线（0006/0007），本仓只在第 2–4 步画三角网、第 5 步关掉 wire，未复现那束调试扇形；片中海面波纹是手绘等高线，本仓是正弦波纹。
