- 原文：To make Bad North even prettier, I'm adding some extra smoothing to the island using my voxel normals. It helps break up the grid and make it all look a wee bit more natural.

## 逐帧观察
- 0000–0169：近景小岛原地缓慢环绕。三层台地，崖壁是**连续渐变的明暗**（同一层墙面上没有逐面硬切），而每层台面的沿口仍是一条清晰的硬边；左侧坡面上有若干同心凹槽；台地中央有一个拱形洞口，洞口内部是暗的。
- 0170–0179：镜头急拉远（7 帧内从贴脸拉到全景），露出整座长条岛：多段城墙、四座塔、几处民居，下面是整片海面。
- 0180–0699：远景环岛，构图基本不动，只有极缓慢的位移/视差；岛的轮廓是**圆腹的曲线**，不是台阶状的折线。
- 0700–0779：镜头又拉回近景，回到起始的小岛视角，末帧与首帧构图接近。

## 判定
有机制：**用体素法线做额外平滑** —— 同一位置的三角形之间按法线夹角阈值平均，弯曲的崖壁变圆润、崖口（夹角大）保持硬边。片子里"墙面渐变、沿口硬、轮廓圆腹"三条特征都指向逐顶点法线平均，而不是加面/加倒角。

## 代码落点与差距
- `src/core/meshwriter.js`：`soft` 逐三角形标记 + `softAngle=55°`；`normals()` 按位置分组、只在软三角形之间按 `cos55°` 阈值平均，`outline` 另用全平均法线保证描边不裂。
- `src/terrain/terrainmesh.js:106-108`：崖壁 `w.quad(...)` 前后 `w.soft=true/false`，即**只有崖壁软、顶面硬**，与画面一致。
- 差距：片子里的圆腹轮廓还有一部分来自网格本身的松弛/倒角，本仓只做了法线平均（SILHOUETTE 仍是原始柱体），且没有"软/硬"对比开关页。
