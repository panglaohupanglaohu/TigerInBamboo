# 1664566546683899905「距离场浪裙」— buildShoreDistance API 移植（r211）

## 残差

- 原缺（r56 定案）：「真实双网格通过，独立原版buildShoreDistance API未迁移」。
- 性质：接口迁移而非片子机制 —— chamfer 距离场岸裙早已在共享 `src/water/shore.js`
  （内部 `distanceField`，按陆地顶点定界、支持 shape 形变、march 走
  `core/shore-profile.js` 的 `marchShore`）；缺的是原版 `engine/shorefield.js`
  导出的独立同名 API。

## 裁判定位

- `REACode/engine/shorefield.js`：`export function buildShoreDistance(town, grid, { res = 0.12, pad = 3 } = {})` → `{ sample, march, res, origin, size }`。
  - `rasterise`：格心采样 `(i+0.5)·res`，`index.at` 候选 + `town.top(cell)>0` + `pointInQuad`。
  - `chamfer`：Float32Array，两遍 1/√2 chamfer，末尾乘 res。
  - `sample`：双线性，界外 1e9。
  - `march`：步进 `res·0.75` 扫描 + 12 次二分，封顶 `maxTravel=4`。
- 消费方：`REACode/engine/waves.js:126` `buildShoreDistance(town, grid, { res: 0.14 })`，
  `field.march(x, z, nx, nz, target, width·1.4)`。

## 移植

- 新文件 `src/water/shorefield.js`，逐式移植裁判；返回面同形
  `{ sample, march, res, origin, size }`，另挂诊断 `{ w, h, land, field }`。
- 如实标注的差异（不影响输出逐值）：
  - 内部索引用 `core/spatial.js` `buildCellIndex`（桶 2、`at` 只回所在桶）替代裁判的
    桶 4 / 3×3 邻域——两者都返回含采样点全部格子的超集，pointInQuad 过滤后逐位相同。
  - `pointInQuad` 按 `pts.length` 巡边（裁判写死 4 角）；四边形上逐式相同，三角格也能算。
  - 本仓惯例补 `RangeError`（res/pad 非法、cells 空/未 decorate、budget 4M 与
    `shore.js` 内部场同口径）。
- 不融合进 `shore.js`：其内部场有 shape 形变需求与不同定界，保留原样；
  新模块 sample/march 签名与其内部场一致，可平替注入。
