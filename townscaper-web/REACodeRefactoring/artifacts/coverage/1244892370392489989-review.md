## 逐帧观察

- 0000–0100（0–3.0s）：红屋近景，木平台与塔楼。屋脊与坡面上停着一排海鸥：白身、短颈、小小一撮尾，**沿轮廓有一圈细的深色描边**；空中两三只白鸟飞过，白身**没有描边**，只有剪影与展开的翼形。
- 0100–0230（3.0–6.9s）：停着的鸟时不时小步挪位、原地转身（帧间位移很小但不为零），个别起飞加入绕飞；飞行路线是长的弧线，不是折线。
- 0230–0260（6.9–7.8s）：屋顶被玩家改成青绿色（画面里屋顶从红翻成绿色两次），鸟群受惊散开。
- 0260–0620（7.8–18.6s）：潮水上涨淹没台地，红屋只剩上半截，鸟基本都在空中或离开画面，水面出现建筑倒影。
- 0620–0690（18.6–20.7s）：相机推近红/白建筑，鸟回到新屋脊上排排停。
- 0690–0771（20.7–23.3s）：贴到白墙近景，画面开始飘雪；先前停着的鸟随屋顶翻色转移。

关键观察：**描边只出现在停着的鸟身上**；飞行中的鸟是纯白剪影（frame-0140 右上与中央两只），没有描边、也没有落在水面上的黑鸟影子。

## 判定

有机制，且五条都在：
1. 更像鸟：白身 + 头 + 短喙 + 尾 + 翼（不是简单方块/三角）；
2. 只有坐着才有描边：反向外壳描边只挂在坐姿几何上；
3. 会挪步：停着时小跳/转身/点头；
4. 有倒影：水面镜像一份；
5. 飞行更顺：长弧线 + 扇翅/滑翔，起落不瞬移。

## 代码落点与差距

- `src/life/birds.js`（503 行）：
  - `sittingGeometry()` / `flyGeometry()` 两套几何，飞鸟带 `aWing` 顶点属性控制翼展；
  - `outlineMaterial()` = `MeshBasicMaterial({ color:'#3a3833', side: BackSide })`，沿法线外扩 0.0038；
  - `this.sitOutline.instanceMatrix = this.sit.instanceMatrix` —— 描边只在坐姿上，飞鸟没有对应材质；
  - 状态机 `sit → takeoff → fly → land → sit`，坐姿里有 `hop/hopFrom/hopTo/yawTo/bob`（挪步）；
  - `mirror = new THREE.Group(); mirror.scale.y = -1;` 加 `sitRef/flyRef`（倒影）；
  - `fly.castShadow = false`（原片飞鸟不往水面投黑鸟影）。
- 差距：① 片中海鸥有明显「头颈转折」，本仓坐姿偏圆胖、喙很短；② 片中起飞时先跳一下再拉开，本仓 takeoff 只有短促抬升；③ 倒影只在水面网格可见角度下才看到，代码里没有单独的「鸟倒影强度」控制。
