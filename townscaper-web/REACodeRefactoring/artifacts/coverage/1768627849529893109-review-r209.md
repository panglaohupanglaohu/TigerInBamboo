# 1768627849529893109「put this on a sphere」r209 残差收口记录

原学习记录（sphere-relax-review.md）：229 帧全核验，原片 = 绿色球面陆地 + 曲折平滑海岸/窄水道 + 浅色陡崖。r205 已补「平面World→球面」接线层 world-sphere.js；队列残差「球面 World 的网格生成与编辑/保存恢复接线」（r205 复核注记：网格生成 = 贴球柱格的 mesh/产出，不是再画一遍姿态）。

## 残差判定

- a) **网格生成**：库里只有「平网格贴球」的映射（mapGridCells 给姿态）；没有「patch + 网格参数 → 带真 cell 拓扑的球面格」这一层——球面 World 需要的不是姿态摆放，是 grid.js 那种共享角点 + edgeNeighbors/edgeTwins 半边邻接的 cell 结构，角点贴球后逐位一致（接缝按构造闭合）。
- b) **编辑接线**：平面 app 的 applyAt 走「点击 → hit.cell/hit.level → world.setSolid/fill」；球面侧没有「球面 3D 点 → 落格 → 同语义编辑」的接线。
- c) **保存恢复**：world/save.js 只编码平面 World（3b 版本 + 2b 场景 + 6b 半径 + 游程）；球面 World 需要带上 mode/网格参数/patch 指纹的对应物。

## 本批落地（src/sphere/sphere-world.js，纯函数，不依赖 THREE）

- `sphereGrid(patch, {kind, radius, cellSize, seed, mode, y})`：网格生成——grid.js 四种生成器（quad/square/hex/mixed）出真拓扑，每格附 `pos`（格心 3D）、`pts3`（角点 3D，与平面 pts 对齐）、`pose`（modulePose 中心姿态）、`sigma/inRange`；`grid.coverage` 报 inRange/maxSigma。共享角点对象经同一映射 ⇒ 球面角点逐位相同。
- `makeSphereWorld(patch, opts)` / `buildSphereWorld(params, opts)`：{ patch, grid, world, index, mode, levelHeight, spec }；index = spatial.js 的 buildCellIndex（平面 XZ 落格）。
- `spherePick(ctx, pos)`：球面 3D 点 → unmapPoint → cellAt；贴不到格/对蹠折叠 → null；level = floor(y/levelHeight)+1（与平面 hit.level 同语义）。
- `sphereApply(ctx, hit, tool)`：`build`（点到的层空就填，否则叠柱顶）/`erase`（扣点到的实心层，上面的悬空保留，地形挖穿清河道）/`raise`/`dig`/`level`（整列改层）/`paint`，与 world/app.js applyAt 同语义；`sphereEdit` = pick+apply 一步。
- `encodeSphereWorld(ctx)` / `decodeSphereWorld(str, ctx)`：与 save.js 同风格（64 字符表 + 游程位流）。头 [3b 版本=1][1b mode][2b kind][8b 半径][12b cellSize×100][24b seed][24b patch 指纹]（R/center/up/e1/e2 的 float32 位折叠）；体素记录与 save.js v5 逐字段相同（12b solid/12b rock/5b 颜色+1/1b 河道 + 5b 游程 + 1b 继续）。校验全过才 world.restore，坏存档不动活数据（对应 decodeWorld 模型）。

## 测试（tests/sphere-world.mjs，5/5 PASS；浏览器红线未跑）

1. 网格生成：四种网格 kind 全部真邻接（每条半边有 twin 回指、边端点共享顶点对象）、球面角点逐位相同（接缝闭合）、全格 |pos|=R；'bend' 模式角点满足抛物面方程；同参数再生成逐位一致；非法 kind RangeError。
2. 编辑：球面点 → 落格 → build（点到的层/叠层）→ level（整列改层）→ raise/dig（岩石层）→ erase（扣点到的层留悬空/点柱顶之上扣顶）→ paint；点贴片外 null 无操作；编辑后 edgeNeighbors 逐位不变。
3. 保存恢复：混合体素态（地形/建筑/颜色/河道/悬空块）encode → decode 进同规格 World 后 solid/rock/color/river 逐位相等、再编码逐字相等；恢复后可继续球面编辑。
4. 拒绝项：patch 指纹不符 / kind/半径/cellSize/seed/mode 不符 / 截断 / 未知字符 / 尾巴数据，全部抛错且不动活数据。
5. buildSphereWorld 便捷入口、对蹠方向拾取 null 不抛错、非法参数 RangeError。

回归：tests/world-sphere.mjs 8/8、sphere-r55、sphere-stages、sphere-insert-c06、sphere-pole-guard、sphere-relax、module-group-fit、TigerMessenger capability-evolution 全 PASS。
