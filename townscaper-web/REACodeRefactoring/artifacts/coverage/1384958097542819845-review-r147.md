- **f0000–0010**：海面 + 零散小岛/灯标，一条细白线从画面左侧进入，末端停在鼠标处；线在**每个格的边界上折一下**，格心之间不是一条世界空间直线。
- **f0010–0060**：光标移动 → 线整条重算，长度/走向连续变化；f0020 是一条约 500px 长的横贯水面的线，光标在右端，线朝**两侧**同时延伸（说明是按「当前格 + 出口边」向正反两向追踪，不是单方向射线）。
- **f0060–0199**：开始同时出现**多条**线（互有交叉、部分共格），局部出现比格距还小的小闭环；同一屏里既有长直线也有闭环。
- **f0200–0299**：镜头缓慢环绕；线随光标在岛边缘游走，f0280–0299 出现绕着岛的**一整圈闭环**。
- **f0300–0399**：一条绕小岛的闭环稳定存在（f0300 原尺寸 + 4× 裁切：**连续 1px 白线，不是虚线段**；线在格边界上折，闭环在光标侧留一小截「尾巴」），远端还有一条长线。
- **f0400–0499**：2–3 条长线共存，小闭环随光标出现/消失（约每 10–20 帧换一次形态），线跨水面也跨屋顶。
- **f0500–0599**：1–3 条线 + 偶发闭环；镜头仍在环绕，线始终跟着光标那一格重算。
- **f0600–0615**：画面里几乎**没有**线（光标停在格上不动/未触发）。

## 判定

**有机制**：在整张不规则网格上追踪「拓扑直线」——以「格 + 出口边」为有向状态，从对边穿出、一路走到边界/三角格/预算用尽/回到同一有向状态；回到同一有向状态即为闭环。显示上**同时保留多条历史线**（一屏 4–5 条），线是实线、在格边界上折（所以「拓扑直」≠ 世界空间直线）。

## 代码落点与差距

- 追踪内核：`src/core/grid.js#traceStraightReport`（文件头署本片 ID）—— 有向状态 `cell.id + 出口边`、`reason ∈ {boundary,nonquad,loop,cycle,budget}`、真实入边/出边中点段；`traceStraight` 保留旧数组契约。
- 主场景层：`src/ui/game-ui-c06.js`（文件头署本片 ID）——
  `straightLineThrough`（向前 `traceStraightReport(cell, e)` + 向后 `(e+2)%n` 拼成整条线；闭环走单枝）、
  `stepCursor`（手柄十字键：上/下沿拓扑直线前进/后退一格、左/右换出口边，退出边 = 入口边的对边）、
  `paintLine`（把整条线每格 +1 层，进主场景真撤销栈）、
  `pointermove/pointerdown` 连刷（`state.tool==='line'` 时拖动即连刷）、
  `navigator.getGamepads` 轮询（十字键 12–15、A=0，`padPrev` 去抖）。
- 页面入口：`index.html?gameui=1&topoline=1`（工具条多出「拓扑直线连刷」格）；只读试验页 `grids.html?t=lines`。

本轮补的**三处真差距**（机制主线未动）：

1. **线型错**：原来用 `LineDashedMaterial`（dash .12 / gap .09），原片是**连续实线**（f0300 4× 裁切可数：1px 白线无间隔）→ 改 `LineBasicMaterial` 实线、opacity .95。
2. **只画一条**：原来只画当前光标这一条，原片 f0650 一屏 4–5 条 → 新增历史轨迹层 `topoline-trails`（`LineSegments`，最近 5 条、opacity .5、renderOrder 19 画在当前线下面；同一「格+出口边」不重复入栈）。
3. **对象不可定位**：线/轨迹对象加 `name`（`topoline-line` / `topoline-trails`），并给句柄加 `clearTraces()`，验收不再靠材质类型猜。

旧 note（r56 起挂）的两句核实结论：**「游戏手柄/连刷仍未接入」= 过期账**（r56 就在 `game-ui-c06.js`，只是从来没人从页面跑过），**「有向格/出边判环、停止原因、真实中点段已通过」= 成立**（`tests/topoline.mjs` + `tests/topoline-browser.cjs` 一直绿）。

## 如实口径（不计缺口）

- 手柄是**合成 gamepad**（本机无设备），但它走的是页面真实的 `navigator.getGamepads` 轮询分支（含 `padPrev` 去抖），不是旁路调用。
- 原片一屏 4–5 条线**同亮度**；本仓当前线 0.95、历史轨迹 0.5（差异是「看清当前条」的取舍，不是机制差）。
- 本仓网格是四边格（`scene=town&grid=quad`），原片是不规则四边/六边混合网；「对边穿出」在三角格上退化为 nonquad 终止（`reason` 有区分）。
- 片中作者只用鼠标移动看线，连刷/手柄是他自述的**计划用途**；本仓按他的说法实现并用合成输入验收。
