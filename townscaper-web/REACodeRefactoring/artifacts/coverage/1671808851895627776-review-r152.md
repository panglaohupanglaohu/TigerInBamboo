- **0000–0005**：整岛被压成纯黑剪影 + 下方一层海面/倒影，是转场用的「未着色 / 背光」首帧，无 UI、无文字。注意：此帧不是黑场，岛的轮廓（左上小屋、右侧塔楼）在黑色里仍可辨。
- **0006–0040**：黄沙台地岛 + 灰白岩体，镜头从低处起环绕；左侧悬崖顶一栋白墙黄顶小屋，岛心有细小的白色标记（镜头/图钉类图标，非 UI 面板）。
- **0041–0089**：继续环绕，岩体的层理与台地沿口清晰；地表是「黄沙坡 + 草绿顶」两色，岩体是浅灰带竖向纹。
- **0090–0149**：转到岛的另一侧，画面中央出现**蘑菇岩**雏形：一块宽大的灰色帽岩压在一根更细的黄褐色岩柱上，帽岩与柱之间是一圈**深色的朝下面**；帽子右侧与相邻岩壁之间留出一道可以看穿的缝（0130 原尺寸确认：缝里透出的是背后的浅色岩壁，不是黑色空洞）。
- **0150–0229**：镜头抬高后回落，蘑菇岩的帽檐底面时隐时现；地形仍是台地 + 缓坡混排（同一座岛上既有 1 层台阶也有竖直崖面）。
- **0230–0299**：低机位复现，帽檐底面变成一条明显的暗带，柱子比帽檐窄、柱子两侧都能看到背景；海面倒影出现，无 UI、无帧率读数、无建造过程。
- **0300–0302**：终帧仍是同一机位，帽檐底面可见，右侧岩壁占了画面右三分之一。

结论：全片没有 UI / 没有鼠标 / 没有第二机位，就是「原生生成结果 + 环绕镜头」在炫悬挑。

## 判定

**有机制**：悬挑地形（岩檐 / 帽岩）由生成器产出的 voxel 直接表达——同一列里「上面一块实体、下面若干层空气」，几何上必须画出**朝下的底面（soffit）**，且侧面留出可看穿的缝（柱间空洞）。片子里能看到的三件事都可数：①帽檐底面在画面里且是暗的；②帽檐与柱子之间的缝能看穿；③帽檐下方的空洞是空气（不是被填死的实体）。

**不是**「软坡/侵蚀缺失」：旧 note 挂的「原版软坡/侵蚀有效生成与完整接口待补（卡点·A 机制未做）」是**第 31 次同型过期账**——
`src/terrain/generate.js` 的 `softSlopes/drainage`、`src/terrain/soft-tops.js#softCorners`、`src/core/depression-fill.js#erodeHeights`、
`src/terrain/drainage.js#fillTerrainDepressions` 全在（r55），且 `tests/soft-slopes-overhang.mjs` 一直把「软坡 + 侵蚀无局部极小 + 悬挑 measure」
放在一起跑（本轮复跑：def 245/645 → soft 353/558 台阶/崖面互换、`localMinima` 0、`r.drainage.minimaAfter` 0、mixed/quad × 3 seeds 的
`overhang` 2–6 块、`caveDepth` 2–3）。

## 代码落点与差距

**落点**：`src/core/rock-topology.js`（`rockTopology` 数岩石区间/空隙列/暴露底面/level1 连通；`measureOverhang` 数悬挑体素、
朝下面、洞内空气与洞深）· `src/terrain/terrainmesh.js`（画悬挑侧壁与朝下底面）· `src/terrain/shape.js#guardDeformation`
（面积/边长/扇形三档保护，`minAreaRatio .3 / minEdgeRatio .35 / minFanRatio .2`）· 页面 `overhang.html`。

**本轮核实出的真缺口（不是机制缺，是验收缺）**：
1. `measureOverhang()` 自 r55 起**零页面引用**——`overhang.html` 只调 `rockTopology`，于是「洞内空气 / 洞深 / 朝下面」这套账从来没在页面上出现过；
2. 浏览器验收（`tests/mirror-overhang-browser.cjs`）只数「y=2 处 6 个朝下顶点、1 个空隙列、断开支撑报 1」，**从没证明过这些面真的在画面里、真的是暗的**；
3. 「柱间空洞」只在 World 层断言「level3 为空」，没有「射线能穿过去打到岩柱内壁」这种透气证明。

**本轮补的（页面只读探针 + 新测试，机制零改动）**：
- `overhang.html`：`#nocap`（去掉岩檐做像素 A/B）、`window.__overhangProbe()`（朝下面三角的投影/遮挡、空洞三层水平射线、
  柱剖面、相机与檐口高度）、`#status` 增加 `measureOverhang` 四项读数；夹具改成「单柱 + 单格外伸帽檐」（原来四周邻格也被填到 5 层，
  帽檐被埋进同一高度的台面里，画面上根本看不出外伸——这是旧「低机位仍受视角遮挡」的真因）。

## 如实口径（不计缺口）

- 夹具是「1 格外伸唇口 + 3 层空腔」，原片是整格帽岩压在细柱上——**比例未对齐**，本轮量的是「朝下面可见 + 空洞透气 + 底面是暗的」这三件事，不宣称同形制。

  不是缺机制；保护开/关的差是 1.7× / 3.5×。
- 原片是整岛生成 + 天空/海面反光，本仓夹具无植被与建筑（片子该岛也几乎没有建筑，只有左上一栋小屋）。
