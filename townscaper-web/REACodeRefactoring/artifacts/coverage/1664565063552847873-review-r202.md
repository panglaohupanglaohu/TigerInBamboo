## 逐帧观察

（第 198 轮已逐帧记过，本轮复核结论不变，摘要如下）

全片一条静止机位（缓慢推近），一座低矮岩台/小丘上叠着 plasma 假彩色场，无 UI、无文字。

- **f0000–0017**：色带满幅。左侧品红塌成一片，中部黄→绿，右下青，台上两处亮白斑（场值最高处）。
  小丘轮廓被色带整体包住 —— 不是在给地形上色，而是**一张连续的场按假彩色映射后铺在几何上**。
- **f0018–0049**：绿/黄交界线缓慢横移，青斑往左上收缩，品红略微变淡。同一帧内色带**连续**（没有等高线台阶）。
- **f0050–0079**：画面推近，黄绿交界**沿小丘轮廓弯折** —— 色带跟着地形起伏走，即场是在**几何表面**上采样的，不是全屏平板。
- **f0080–0116**：品红从右上渗回，黄色带变窄；末帧红黄斑集中在中下偏右。全程无闪烁/色块跳变。

## 判定

**有机制**：shader 平流场（连续标量场 + 假彩色可视化）。

片内能证明的只有「一个连续场在动、并且铺在表面上」；证明不了目标格式是 16F 还是 32F（色带连续只排除了 8 位）。

### 本轮新增（`src/world/float-bands.js`）

- 场 = `core/float-advect.js` 的 `advect`（固定涡旋、半拉格朗日、clamp-to-edge），每帧推进 1 步；
  `storage` 可切 f32/f64/f16/u8（CPU 侧模拟写入精度，不改 GPU 路径）。
- 初值 `seedField()`：正圆盘 `seedBlob` + 两个偏心斑 + 一道斜向脊。
  **这里踩到一个会把验收做成假绿的坑**：`seedBlob` 是同心圆盘，绕中心旋转是不变量 —— 直接拿它做「场在动」的断言，
  120 步后画面差 **4.3%、平均 1.38 级**（判据会假红），而实际场确实在转。换成偏心初值后同一口径差 **63.6%、平均 18.55 级**。
- 上传 = RGBA **float** `DataTexture`，`NearestFilter`，片元里四抽头手算双线性（对应「浮点目标不可线性过滤」的接法）。
- 贴面 = **克隆 `view.worldMesh.geometry`**（同一批三角、同一套世界坐标），逐片元按该片元的**世界 xz** 采样场 →
  色带随台地/崖壁弯折；天空不着色（不是全屏 quad）。
- 配色 = 5 段 plasma 近似，GLSL（`paletteBands`）与 JS（`paletteCPU`）同式，可逐点对表。

### `float-bands.html`

iframe 起 `index.html?scene=terrain&grid=mixed`，拿到 `rea` 后把色带层挂进 `view.scene`；提供量化档（连续/8 级/32 级）、
冻结时间、法线明暗开关，以及只读探针 `window.floatBands`（`stats / readPixels / probeGrid / isolate / stepTo / setQuant`）。

口径说明（避免下一轮误读）：

1. **「GPU 颜色 == CPU 孪生」是撒射线命中点对表**，不是格心：`probeGrid(10)` 从画布撒 10×10 条射线打到色带层，
   取**射线真正命中的世界点**算 CPU 色 —— 格心会被前方高格挡掉（第一版 29/60，全是遮挡，不是着色器错）。
2. **量之前必须 `isolate(true)`**：`view.scene` 里还有建筑/植被/水面/描边 23 个子对象会画在色带层上，
   不解耦的话「同状态噪声」永远不是 0（水面按真实 dt 在动）。
3. 量化档 A/B 只用于证明**连续性判据有分辨力**（8 级 → 色相档 18→10、离散色 2583→441），不作为机制证据。

### 仍缺 / 不等价（如实口径）

- **不是流体求解器**：速度场是固定涡旋，没有散度投影/压力泊松；片内看不出有没有（117 帧只有一张场）。
- **跨平台信任不可验**：`float.html` 的 16F/32F 读数只代表本机浏览器+GPU。
- 机位比片内近（片内小丘占画幅更小、天空更多），色带形制等价、构图不等价。
- 8 位对比只用合成量化，没有真 RGBA8 目标对照（那条在 `float.html` 的 GPU 表里）。
