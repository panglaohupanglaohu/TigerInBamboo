## 核实 r55 覆盖
r55 G1 `?shade=contrasttex`：World 格心扇形三角（2D）上 OKLab 松弛，结果画进世界 XZ 图，只上地形顶面（`shots-r55/g1-contrasttex-crop.png` 复看：台地顶按特征成连续色区、交界细暗线）。缺：① 只在 2D 格扇上解、崖面不参与；② 不是画进 UV 图集（片子顶部调试贴图是图集）；③ 没有"随机开始 → 逐轮迭代"的回放；④ 结果收敛成每特征均色，渐变没了（锚定把低频也拉平）。

## 本轮做了什么（与 1478114309263839244 同一套 UV 图集）
`src/core/uv-radial-atlas.js`：
- `meshContrastGraph`：真实 3D 网格（共享 World + terrainmesh）三角为节点、共享边为边；折痕 > 35° 或特征不同（各层顶面 / 崖面 / 底面）= 对比边。
- `contrastSimulation`：用 contrast-field.js 的同一个 `relaxContrastColors` 逐轮推进（可 step 回放）；随机初值上叠一层按三角中心位置的低频场、锚定调弱（0.002）——高频随机被抹平、低频起伏留下来，就是"表达连通性的渐变"。
- `paintContrastPage`：画进径向 UV 图集；顶点色按"同特征邻三角平均"插值，对比边两侧不混 → 图集里是硬边。
- `uv-radial.html?mode=contrast`：模型贴反差图集，片元按邻像素 UV 取样色差出一像素线（落到 gutter（alpha<.9）的不算，避免 UV 接缝假线）；顶部三张调试图（反差色 UV 页 / 对比边 / 棋盘 UV 页）；`?iter=` 或播放按钮从随机逐轮回放。
