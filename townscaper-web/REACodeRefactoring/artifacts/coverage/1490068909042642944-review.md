结论性观察：节点按「离根多远」被排进同心环，颜色按「根的第几个分支」分段成连续圆弧 —— 这是一张**邻接图的极坐标（径向）布局**，不是普通力导向图（力导向不会这样规整分环）。

## 判定

**有机制。** 机制 = 图布局：BFS 分层 → 每层一圈 → 环内按父节点角度定角 → 颜色按根分支分段。环半径要按节点数撑开，否则外圈节点会重叠（片子外圈最密但没重叠，说明半径是算过的）。

原登记 `ref`（当作"深夜神秘图"的纯参考图）不够，改判 `partial` 并补实现。

## 代码落点与差距

- 新增 `src/core/graph-layout.js`
  - `adjacencyComponents(ids, neighbors)`：并查集算无向连通分量，大分量在前、内部按 id 排序（确定性）。
  - `radialLayout({ ids, neighbors, root, ringGap, minArc })`：BFS 得深度 → 每深度一圈；环内按「父节点角度 → 父 id → id」排序后等角分布，整环旋转到首节点父角度上，于是每个根分支在最外圈投影成**一段连续圆弧**；半径 `r_d = max(r_{d-1}+ringGap, k_d·minArc/2π)`，节点多的环自动撑大；边按深度差分 `same` / `adjacent` / `long` 三类；只布 root 分量，其余进 `unreachable`。
- 新增 `grid-graph.html` 右栏：极坐标同心环图（画参考环 + 放射线、跨环边按分支色、节点是空心圈、半径随度数略增、根节点白圈标出），数据来自 `grid.js` 的 `buildMixedGrid` 的真实面邻接（`edgeNeighbors`）。
- 差距：片子节点半径是否还编码了别的量（面积/度数以外的）不可证；颜色语义只能确定是「分段」不能确定是分支还是分量（单连通时二者无法区分，故实现里两者都算出来并分开报告）；原片极坐标底网的刻度数字未复刻。
