## 逐帧观察

- 0–90 帧（sheet-00）：三个白色方块高地（城镇）在深色地面上，三处火源各在屋顶位置；火是**橙红外晕 + 黄白内芯**的一团，粒子边缘互相咬合成连续轮廓。相机极慢横移，火焰每帧只在顶部卷动，未见颜色"闪白"的帧。
- 90–200 帧（sheet-01）：相机继续转，火团保持同一亮度层次；重叠最密的芯部是**淡黄白**而不是纯白平片，外沿仍能数出 2–3 个半圆凸起——说明重叠处没有累加变亮。
- 200–295 帧（sheet-02）：这一段切到另一机位（更高、更俯），能看到整座城镇多处起火，火柱细长。虽然火源数量变多，单团火的内部层次没变：橙 → 黄 → 淡黄，边界依然融成一个轮廓。
- 295–379 帧（sheet-03）：回到第一机位，末帧三团火仍在烧，形状比开片更高更细，芯部仍非纯白。全片无 UI、无文字，纯效果展示。

## 判定

有机制：**火焰粒子的混合方程用 Max 而不是 Add**。Add 会把重叠粒子逐次相加，密集处必然过曝成白色平板；Max 取逐通道最大值，所以重叠只扩展轮廓、不提升亮度，颜色仍受控——这正是片子里"芯部淡黄白、外沿融成一条共用轮廓、没有闪白"的来源。
片中还能看出芯部比外沿更亮更黄，属于粒子自身颜色随年龄从亮黄转暗红 + Max 叠加的结果，没法从画面区分两者权重。

- 做到：Max 与 Add 可实时切换并被 GPU 读回证实；年龄按各粒子实际寿命归一；固定 900 粒子池。
- 缺：本仓火是 `Points` 软圆，不是原片的方片 + 噪声裁轮廓，所以片里那种"凸起花瓣状外沿"只能近似；没有火光对场景的照明（动态光照）、没有烟柱与火星。
