## 判定

有机制，且三件事是**同一句配文的三条**：

1. **无缝缓坡 + 锐利崖**：台地之间既有 1 层台阶被熔成连续斜面（0160 左侧），又有 ≥2 层的竖直崖墙（0160 右侧岩柱）；两种形制在同一个岛上连续过渡，中间没有一条直线拼缝。
2. **侵蚀后无局部低洼**：片子里看不出来（配文声称），只能靠页面读数验：填洼前本岛有 2 个局部低洼，侵蚀 + 填洼后 0 个，全部陆地格都能沿不升路径下海。
3. **方 + 三角两种 tile 兼得**：底色网格是方格（每格沿对角线切两片三角），0036 起的白线态里轮廓只沿格边不走对角线 —— 方格与三角片是同一张网格的两种用途。

## 代码落点与差距

落点（本轮核实，全部 r55 就位，**不是缺口**）：

- `src/terrain/soft-tops.js#softCorners`（文件头署本片 ID）：把「同层或 1 层差且两格都在缓坡省」的格按并查集分组、组内共用一个角高（层均值），得到连续折线坡面；≥2 层差或陡崖省仍保留竖直崖。
- `src/terrain/terrainmesh.js:60`（`world.softTops` → `softCorners`）+ `altered()`：**两角都被焊且共高时整条墙不画**（seamless），只焊一角时把墙拉成梯形（倒角）。
- `src/world/terrace-edges.js`（`soft: softCorners(...)` → `final.seamless`）：白线态只在没焊死的边画线，焊死的边不画 —— 与片中「有线处是台阶、无线处是坡」同构。
- `src/terrain/generate.js#slopeMask / limitSoftSlopes`：缓坡省按掩码分位数 p30/p58 划分，缓坡省相邻格压到 ≤1 层（只降不升、海岸轮廓不变），塔柱永远是陡崖。
- `src/core/depression-fill.js#erodeHeights / depressionFill / localMinima / drainedCells` + `src/terrain/drainage.js#fillTerrainDepressions`（`erosion` 选项）：整级 stream-power 侵蚀 + 优先队列填洼，返回 `minimaAfterFill`。
- 页面入口：`terrain-r55.html` 的 `soft` / `softrelax` / `erosion` / `edges` 四个开关（`?grid=quad|mixed|tri|hex` 都在）。

本轮新增（**只读探针，不改机制**）：`terrain-r55.html` 的 `__r55` 增 `soft`（缓坡台阶条数 / 焊死 / seamless / 拉伸 / 崖边借角 / 逐格型配对）、`walls`（把画出来的墙按「同一格边叠了几块=几层」分档）、`water`（minimaBefore/After/World、drained、raised）。这三块是量具，用来把「焊了几条、崖动没动」变成可数的数。

如实口径（不计缺口）：

- 本仓坡面是**逐格折线连续**（角高取层均值，两格共边），不是原片那种跨多格的平滑曲面；只能从画面判「有没有斜面、崖是否仍竖直」，不能反推原算法。
- 斜面占顶面 18.8%（mixed 24.9 / 132.5 m²）、steep 顶面 21.8 m² —— 原片这一比例量不出来（片中岛形/机位与本仓不同），只作量级对照。
- 缓坡省边界（掩码过渡带）仍会有 2 层崖，片中同样有「坡到崖」的突变，不作差异。
