## 逐帧观察

- **0000–0058**：青灰底的岛，顶面是**很大的**米黄/桃/草绿色块（单个色块动辄半座岛），边缘是柔和的宽带渐变，色块内部还有更浅的同心纹；崖面被压成米白，色块到崖肩就断，崖壁上一条色都没有。
- **0059–0062**：三帧纯黑剪影（换版/重编译），**0063** 起换成另一套观感（绿顶 + 白花点 + 米白崖），说明片中前后是**两版对照**。
- **0100**（原尺寸）：顶面一整块草绿大斑，边界是 20–30px 的软过渡、无硬台阶；斑块在崖肩处被整齐收住，崖壁纯米白，**没有任何色渗下去**；最关键的一点：斑块边界顺着格边界走，遇到崖肩/材质交界就停，不「穿过」重要边。
- **0140–0199**：环绕到岛侧，色块仍是大幅面，出现桃色/淡紫色，同样止于崖肩。
- **0200–0283**：近景环绕，斑块在顶面继续变大，崖壁始终干净。
- **0284–0287**：四帧黑剪影（第二次换版），**0288** 起又一套观感（白/粉崖缘 + 绿顶）。
- **0290**（原尺寸）：顶面绿/桃斑，崖肩处有一圈米白「台沿」，色块收在台沿上；深部崖面干净。
- **0300–0501**：终版观感环绕到末帧，斑块大小稳定、崖壁不再被色污染。

## 判定

**有机制**，而且与本片的两句话一一对应：① **更大的笔触** = 图集低频（世界空间尺度可调）；② **不越过重要边** = 崖肩距离场把顶面色块在崖肩前 `rimMask` 收住（`smoothstep(0.06,0.30,rimDist)`），崖面只在沿口极浅处才可能有一点（`bleedMask`），深部为 0；材质/崖肩这类「重要边」正是距离场的源点。

- 页面 `blotches.html`：本轮补「图集笔触＋受控渗漏」开关、**笔触尺度**滑杆（scale 越小 = 世界空间笔触越大）、强度滑杆与参数读数；旧噪声档保留对照。

**仍缺**：① 「更大」目前只有**图集尺度参数**这一档证据（6×6 顶面片扫描线边界 `.09 → 6 段`、`.045 → 0 段`），没有与原片同机位的笔触直径/岛宽比标定；② 原片终版的**配色**（白/粉崖缘）与**反射**未对；③ 与姊妹片共用的「受控渗漏深度」在画面上仍未量出来（见 `1696896119794479541-review-r169.md` 的竖直探针失败记录）。
