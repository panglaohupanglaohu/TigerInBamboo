## 代码落点与差距

- 落点：`src/ui/game-ui-c06.js`（文件头第一行就署本片 ID）+ 共享 `src/ui/icon-toolbar.js` / `src/ui/icon-ink.js`，主场景 `app.js` 的 `?gameui=1` 挂钩。
- **核实掉一条过期账**：旧 note 记的「撤销/重做/退出的真实命令要接主管线，单页实验验收不了」——
  命令其实早就接上了（`undo()/redo()` 走 `app.js` 的真栈、`setTool` 走真工具切换），真正缺的是**没人从页面上把这三项点过一遍**；
  另有一条**语义错**：第三个灰格被做成了「清空城镇」（`pushUndo + world.reset()`），而片中它是**叉 = 退出**。
- 本轮补的（全部在 UI 层，渲染/世界机制一行未动）：
  1. `app.js` 挂钩补 `undoDepth: () => undoStack.length` / `redoDepth: () => redoStack.length`（只多传两个读数函数）；
  2. `game-ui-c06.js` 工具格：每格自带底色 + 同色系浅色图形（`--ink`）、每格轻微倾斜（`--tilt`，-2.6°/1.8°/-1.4°）、选中格图形转**纯白**（原先只是换底色）；
  3. 下方三项改用 `icon-ink` 的 `DEFAULT_ICONS.undo/redo/close` 描边路径、灰底白图形；**可用态 = 真实栈深度**（每帧 `refreshActs()` 同步）；
  4. 第三个灰格从「清空」改为**退出**：摘掉 `#gameui-c06` 并把被隐藏的 `#tools`/`#topright` 还原（`dispose()`）。

## 如实口径（造型差，不计缺口）

1. **图稿本身没有源素材**：原片是手绘粗笔（指针/滚筒/漆桶/调色盘+笔，4 个工具格），本仓是折线几何替身且只有 3 个工具（建造/拆除/刷色）——图形形状与格数都对不上，这是素材差，不是机制缺。
2. 原片灰格里的撤销/重做/叉是**浅灰描边**（比底色亮一档），本仓是**纯白描边**，对比更硬。
3. 原片 4 个工具格的倾斜角各不同（目测 0–5°），本仓给了 -2.6/1.8/-1.4 三档，选中格额外 -4°（`.on` 的既有动效）。
4. 片中"灰"只说明不可用；本仓把"不可用"绑到真实栈深度（空栈即灰），默认场景进页面时两个都是灰，与片中一致。
5. 工具条**默认仍 `?gameui=1`**：默认 HUD 的 `#tools` 有同一套命令（建造/拆除/刷色 + 撤销/重做/回放），C06 这套是同一批命令的**图标皮肤**；
   换皮肤会连带隐藏 `#topright`（配色/光照/换种子）与回放按钮，属另一个片（`1260586697538113537` 回放）的取舍，不在本片范围。
