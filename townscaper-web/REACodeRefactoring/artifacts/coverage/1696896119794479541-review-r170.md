## 逐帧观察（本轮复看 + 沿用 r169 的分段）

- **0000–0139**：固定机位环绕。顶面是**大块圆角色块**（草绿 / 黄绿 / 桃色），边缘柔和、带极淡同色描边；崖面米白，只有细层理线。
- **0140–0253**：抽色只留几何（灰白崖体 + 黄顶小块），崖面出现沿口折线与层理。
- **0254–0299**：颜色回来，机位拉到岛侧。
- **0300–0399（本轮复看 sheet-03）**：近景崖肩。0300–0330 顶面大片桃色/米黄，左侧一小块黄绿；崖壁米白，水平层理清楚、**深部完全无色**。0355–0399 黄绿色块靠到崖肩线上，**沿崖肩外缘有一条窄的深色描边**，色只垂到很浅的一小段就平齐收住（目测 < 崖高的 1/6 ≈ 0.1 世界单位量级），崖壁其余处干净。
- **0400–0549**：镜头拉回全岛，色块恢复成大斑，末帧静止。

## 判定

**有机制**，且「controlled」= 三件事同时成立：① 只在崖肩附近有；② 只到固定深度（等深线）就齐平收住；③ 深部崖面一点不带。r169 已把 ①③ 与「顶面大笔触图集」量出来；② 就是本轮的攻坚点。

## 代码落点与差距

落点（r169 已接线、本轮修正）：
- `src/terrain/blotch-atlas.js`：`createBlotchAtlasData`（128² 可平铺图集）· `buildBlotchRimField`（崖肩 chamfer 距离场）· `blotchMasks`（rimMask 收边 / bleedMask 等深）· `blotchRimTint` + `BLOTCH_RIM_GLSL`。
- `src/terrain/blotch-tongue-c09.js`：翻崖舌头（`tongueWallMask` / `tongueTopMask` + GLSL）。
- `src/world/view-shading.js`：`?shade=blotchatlas` / `?tongue=1` 接主材质；`setBlotchRim` / `blotchParams`。
- `blotches.html`：图集 / 舌头开关 + 渗漏深度 / 笔触尺度 / 强度滑杆 + 读数。

**本轮修掉的两个真问题**（r169 三条断言 FAIL 的根因，各一条）：

1. **量具错（r169 自己的锅）**：竖直探针是 0.3×0.3 面片、取「最亮像素」。渗漏是**乘性压暗**，面片上没上色的那半截永远更亮 → `max` 恒等于未上色亮度 → drop 恒 0。改成：窄条 0.06 + 清屏 `alpha=0` 认「画到的像素」（lit≈110）+ 对这些像素取**均值**。
2. **真机制缺陷**：`below = G(本纹素顶面) − y` 在崖面必然出错。崖面片元的 XZ 压在台地边界上，纹素≈0.21 世界单位，双线性把**下面那一格**也掺进来 → 实测 15 个崖肩的 below 为 **−0.06 … −1.95**（其中 11 个为负），`bleedMask` 恒 0。改法：rim 场新增 **B 通道 = 崖肩顶面高度**（G 的 (2·2+1)² 邻域 max），CPU 与 GLSL 都改用 B 算 below；舌头原来「向墙内偏 0.18 取 G」的近似也一并换成 B。
   - 修后 CPU 与 GPU 在 15/15 个崖肩上一致：`cpuBelow == gpuBelow`（0.05/0.141/0.255/0.55/1.05…），`gpuTop` 与格顶同值（4.02 vs 4.00、3.01 vs 3.00 的 8 位量化误差）。

**尚差的一层（这就是两条片子仍 partial 的唯一理由）**：等深带在画面上**还没量成世界米**。
- 主场景「渗漏这一路」的隔离 A/B 已成立：同机位只改 `bleed` 0→.14 **3931 px**、`strength 0`（整条着色关）**5662 px**、同状态重渲噪声 **0** → 渗漏确实在改画面。
- 但「drop vs 深度」的 12 档曲线仍读出恒 0，且 `bleed=20` 与 `bleed=0` **逐像素相同**（0 px）——这两件事只能有一个解释：这条夹具的逐态 uniform 没有按预期落到位（不是渲染滞后：同状态重渲噪声 0；也不是状态粘住：`strength` 已按全量参数重写）。下一步换「每条状态 clone 一份材质 + 每帧回读 `uBlotchRimQ`」的夹具再量，本轮的合成窄条读数一律不进断言（测试里标 PENDING）。
- 原片的**配色**（桃/黄绿/米白）与**反射**仍未对；图集是程序化替身。

## 结论

机制与「顶面色块 / 笔触更大更少 / 崖肩收边 / 舌头」在运行时可验，等深带的**场**这一层本轮修好并 CPU≡GPU 对上；但「渗漏只到 0.14 世界深度就停」还缺一次可信的像素级读数 → **保持 partial**，下轮从夹具的逐态 uniform 落实入手（首选：每状态 clone 材质 + 回读 uniform）。
