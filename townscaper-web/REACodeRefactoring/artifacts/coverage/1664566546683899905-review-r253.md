## 逐帧观察

- 0000–0079：俯角 3/4 的淡黄岛体（无塔），水面是同一色相的青灰。贴着岸线有一圈**近白细带**，带外再一层更淡、更宽的晕（halo）。相机极慢地绕岛顺行，岛形几乎不动；晕在岬角明显收窄、在两处内湾明显变宽。
- 0080–0199：岛长高（出现白顶方塔、屋顶），裙带跟着岸线重算；外晕在内湾处**自己折过去**（叠成两层、局部被压成近乎零宽），岬角处则拉成一条离岸约一个建筑进深的外弧。水面整体仍是平色，没有碎浪/白冠（与配文 "calm waters" 一致）。
- 0200–0339：Townscaper 式的城墙/多塔，裙带沿更碎的岸线跑，白细带始终贴石脚，外晕在几处窄湾出现明显「剪口」（晕的两个边互相穿过）。全片无水花粒子、无泡沫遮罩扩散、无浪带推进 —— 只有静态裙带 + 极慢转镜。

## 判定

**有机制，且机制就是「距离场裙带」本身**：白细带 = 贴石脚的一圈（rim），宽带 = 远处淡晕（halo）。片里配文强调的正是「沿法线外推会在湾里折起来，距离场不会」。画面证据：内湾处外晕宽、岬角处窄；窄湾处旧实现会自交（见下）。

无机制的部分：无浪冠/碎浪/泡沫推进（那是作者说的「下次要做」的东西，不在本片）。

## 代码落点与差距

- 落点：`src/water/shore.js#buildShore`（`distanceField` 两遍 chamfer + `marchShore`；`rim`/`halo` 两条 ribbon；`skirtCoverage`/`skirtBreakGLSL` 分段）、`src/world/view.js`（`skirtStats`、`skirtWidth`、`setDebug`）、`waves.html`（裙带读数与开关）、`src/core/shore-profile.js`、`src/water/shorefield.js`（裁判 API 逐式移植，node 对拍 maxDiff=0）。
- **本轮查明的真缺口**：外圈（halo outer）一直是「岸→蓝线」矢量的 **1.35 倍等比外推**（`s + (b-s)*1.35`），蓝线本身只保证「march 到 0.775 再平滑 6 遍」；于是凹岸处相邻法线收敛、外圈自己翻过去。实测（真页面，mixed）外圈三角 **30/806 = 3.72% 绕序反向**，外推距离 min 0.568 / p50 0.922 / **max 2.835** / CV 0.474 —— 与片里「distance field 不会折」这句正相反。
- 改动（`src/water/shore.js`，默认开，`?skirtField=0` 退回旧档）：
  1. 外圈先沿平滑方向在场上 `march` 到**固定设计距离** `haloTarget = (reach+foot)×1.35×skirtWidth`（mixed 场景 = 1.0462），march 走不到目标（窄内港里场本身到不了）或撞栅格外侧（读数 99 → travelled 极小）时退回等比点，且场档统一 `min(hd, haloTarget)`；
  2. 再压一道**次序约束**（最多 32 遍）：外圈每条边的走向必须与岸线同向（cos ≥ 0.35），否则两端外推量 ×0.6，下限 0.35×设计距离。沿法线外推的曲线在凹岸必然自交，这一步就是把「距离对」变成「次序也对」。
- 仍未取的：原作精确场公式（配文未公开）与手绘晕的色调 —— 属定案，不是缺模块。
