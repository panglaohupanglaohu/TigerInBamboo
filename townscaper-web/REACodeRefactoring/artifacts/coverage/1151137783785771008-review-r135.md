## 逐帧观察

- **ff 0000–0044**：整屏深灰（#3c3c3c 附近），只有一个极小的十字准星落在画面中心，**没有任何格子**。这是「还没请求任何块」的空场景。
- **ff 0045**：中央突然出现一块**六边形状的网格团**（约一块块应有的范围），细白线 + 深色格心；团外一圈略亮的深灰环（未松弛拓扑），再外面是纯背景。团心有一个白点。
- **ff 0046–0286**：网格团**按块向外生长**，一次鼓出一整块（六边形轮廓的阶梯），块与块交界处**没有折痕、没有错位、没有明显疏密突变**。同期黄色焦点方块（带绿色向上箭头、红色向右箭头、蓝色第三轴）在画面上**游走**，新长出的块总是出现在焦点附近；外圈始终有一圈更暗的细网（未松弛拓扑，斜向对角线明显），最外是纯背景。ff 0286 时网格已占约 3/4 画面，可在上缘看到几处彩色记号（gizmo 轴与块边交汇处）。
- **ff 0287–0299**：网格**铺满整个视口**，边界从左向右推过整屏；此时背景环消失，只剩拼满的格子。
- **ff 0300–0430**：全屏网格，格子是**不规则四边形**（少数看上去像五/六边，多为相邻两格共边很短造成的错觉），大小相近但朝向各异；格子内部是均匀深灰，**没有任何块边界线、没有折痕、没有网格分区着色**。全片没有 UI 文本、没有进度条，也没有黑白双网（对偶只在另一条片子里出现）。
- **ff 0431–0448**：镜头**连续放大**，格子从约 12.5 px 边长放大到约 25 px，放大过程中格子形状与疏密关系不变（同一张网，只是看近了）。

## 判定

**有机制：按焦点流式生成的不规则四边形网格** —— ① 画面从「空」到「一块」到「一块块长满」而不是一次开满窗；② 生长跟着黄色焦点走；
③ 块边界无缝无形变；④ 终帧整屏格子大小相近、朝向各异（非周期、非规则），且看不出块的分区。这三条正好对应
`createInfiniteStream`（按需生成块 + 块松弛 + 6 个三块簇松弛 + 三表示重心插值）与 `streamWindow`（焦点窗口 + `evict` 丢弃）的语义。

## 代码落点与差距

**落点**

- `src/core/infinite.js#createInfiniteStream`：`finalPatch(q,r)` 只在被请求时生成块拓扑（`patch`）→ 块松弛（`relaxQuads`）→ 6 个三块簇松弛（`cluster`）→ 三表示插值；`counters{patches,patchRelax,clusterRelax,finalized}` 记真实生成量；`evict(keep)` 丢远处缓存（结果只由 `(q,r)` 决定，丢掉再要逐位重算）。
- `src/core/infinite-c06.js#streamWindow`：按焦点半径算 finals（最终化）/raws（圈外只生成未松弛拓扑），`evict` 只留焦点邻域；页面 `infinite-stream.html` 有指针拖动焦点、半径滑杆、自动巡游、黑网（对偶）开关。
- 本轮新增 `src/core/infinite-c06.js#densityStats`：块内疏密均匀度量具（面积比 p10/p50/p90、p90÷p10、CV、边长 CV，以及**块均值离散 vs 块内平均离散**），页面把读数写进状态面板并暴露 `window.infStream.density`。

**旧 note 两条「仍缺」的核实结论**

1. 「真流式加载（页面一次最多 19 块）」→ **过期账**。`createInfiniteStream` + `streamWindow(evict)` + `infinite-stream.html`（拖动焦点 / 自动巡游 / 半径滑杆）r56 C06 就落了，`tests/infinite-stream.mjs`、`tests/infinite-c06.mjs` 一直绿 —— 缺的只是**没人从页面上拖过一遍**（r121/r122 同型：模块 + node 测试 + 页面都在，没有 `-browser.cjs`）。
   注：旧 note 说的「一次最多 19 块」是 `grids.html?t=infinite`（`buildInfinite({rings:2})` 的窗口版，19 块），不是流式页；本轮把 `where` 指向流式页。
2. 「块内疏密均匀度指标」→ **真缺口**（没有量具），本轮补上并给出两边同口径数据。

**新缺口**：无。**如实口径（造型差，不计缺口）**：① 原片的彩色记号是三维 gizmo 轴（绿=上、红=右、另有蓝），本仓只画黄方块 + 两根轴；
② 原片圈外的未松弛拓扑画成更暗的**细斜对角线**，本仓画 raws 的外轮廓（暗网）；
③ 本仓格子大小差比原片大一档：同一口径（洪水填充量格心面积，格子面积中位对齐到 ≈156 px²）**原片 CV 0.216 / p90÷p10 1.83 vs 本仓 CV 0.272 / 2.14**（几何口径 p90÷p10 = 1.48）。
