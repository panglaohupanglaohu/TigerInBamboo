## 判定

有机制，且是网格层的：

1. **完美环**是入口条件（原文 "perfect loops I've scattered across the grid"）：拓扑直线绕回起点的那一圈才算；
2. 环内区域**整片抬升**离开水面，底面生成**船壳**（厚度随岛体规模），
3. 船壳下挂**极细、等距的支撑腿**，竖直落到水面，落脚一圈涟漪。

片子只给了"结果"（已经在飞的岛），没给"从平地变飞岛"的过程，所以抬升曲线只能按"边沿贴水、圈心最厚"的形状近似。

## 代码落点与差距

- 环判定：`src/core/grid.js` 的 `traceStraightReport`（`seen` 里回到起点 → `reason:'loop'`、`closed:true`）。本轮实测 `buildQuadGrid({radius:10,hexSize:0.62,seed:1337})` 有 1306 格、**3 个不重复的完美环**（最大圈住 119 格 / 面积 8.99 / 折线 42 点，另两个各 28 格）。
- 新增 `src/core/loop-lift.js`：
  - `loopPolygon(report)` 环 → 中心线折线（首尾闭合，去重复点）；`pointInPolygon` / `distanceToPolygon` / `polygonArea`；
  - `loopRegion(grid, report)` 环 → 圈内的格（按格心判）；
  - `findLoops(grid)` 扫全网格求环并按"圈的格集合"去重、面积降序；
  - `liftField(region,{peak,rim})` 抬升场：`h = rim + (peak-rim)*smoothstep(d/dmax)`，`d` = 格心到环的距离 → 船壳边沿贴水、圈心最厚（实测峰值 2.4、最低 0.02，且随 d 单调不减）；
  - `hullDepth(area)` 船壳厚度 `0.30*sqrt(area)`，夹在 0.3–1.2（面积 8.99 → 0.90）；
  - `supportLegs(region,{spacing,depth})` 沿环等弧长取点，腿从船壳底 `-depth` 竖直落到水面 `y=0`，带 `radius`/`splash`（最大环 11 条 / 间距 1.10）；
  - `buildFlyingTown(grid,{startCell,edge})` 一体化，非闭环回 `closed:false`（边界直线不会被当成飞岛）。
- 新增实验页 `loop-lift.html`：左平面（环蓝色、环内格按抬升高度上色、腿落脚点）、右侧视剖面（岛体切片、亮黄船壳带、腿落到水面带涟漪），可调 `peak` 与腿距。
- **缺什么**：① 飞行操控（片子里没拍，玩法层根本不存在：没有"选中环 → 起飞 → 平移/悬停"的状态机）；② 船壳外沿那圈白色小蝶形构件（片中疑似小螺旋桨，看不清，未做）；③ 镇上建筑没有跟着抬升（本仓建筑不在网格几何里，抬升场只作用于格与船壳）；④ 环内抬升后的悬崖面/侧壁没有按层生成，剖面是逐格切片近似。
