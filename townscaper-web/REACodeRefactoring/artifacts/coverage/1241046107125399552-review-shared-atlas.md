## 原版裁判（REACode，只读）

`REACode/src/texelsnap.js`：
- `bakeAtlas({size:128, corner:32})`：植物区 = 右下 32² 角，`x0 = y0 = size − corner = 96`。
- 采样方式（原文 "every-other-pixel-is-a-line"）：UV 按 2 texel 周期做**分段连续**
  重映射（speed past every 2nd pixel）+ 双线性；画面实测轮廓 10–90% 过渡宽中位
  1.0px（点采样级锐度），关键在采样方式不在分辨率。
- 画面未打开 atlas 本体 → atlas 内容布局为机制层裁判（尺寸/角落/采样），
  叶纹图案属原片美术资产。

## 本轮改动（REACodeRefactoring/src）

- `core/leaf-atlas.js`：布局与 motif 单源化——`PLANT_RECT`/`SKIN_SIZE`/`writePlantCorner`
  全部引自 `core/town-skin.js`（全城 TownColor 128² 图集的唯一来源），消除两份
  独立实现的漂移可能；新增 `sharedLeafAtlas()` 进程级单例与 `leafPatternCPU()`
  （leafPattern GLSL 的 CPU 镜像）。
- `life/leaf-surface.js`：新增 `sharedLeafTexture()`——整个进程一份 DataTexture；
  `makeLeafSurface()` 全部改绑共享纹理（`shared:true`，dispose 只放开引用不销毁）；
  GLSL 的角落常量改由 PLANT_RECT/SKIN_SIZE 模板生成（96.0/32.0/128.0）。
- `life/vegetation.js`：注释标注 leafSurface 为全场景共享单例。
- `town-skin-layer.js` 原有绑定路径实测：`set(true)` 时 `leafSurface.uniform`
  指到全城同一张纹理对象，关闭时还原。

## 程序近似与缺失原资产（分开记录）

  原作植物贴图与全部植物种类未迁（卡点·B 美术资产）。
- 采样机制（分段连续 UV 重映射 + 双线性）为本地重建，原作确切公式未公开。
- TigerMessenger vendor 为 B 批换血快照；本批只改 REACodeRefactoring/src，
  vendor 侧同步留待下一换库批（apostles/morris 多 Vegetation 实例届时自然
  共享同一纹理对象）。
