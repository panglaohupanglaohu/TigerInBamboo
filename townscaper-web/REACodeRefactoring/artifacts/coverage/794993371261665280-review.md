## 判定

有机制：**体素化幽灵预览**。先把目标模型采样成"将要占据的格"（黄点），再把同一批格换成线框占位，最后按顺序逐格实体化；三态重叠出现，不是"整体淡入"。填充顺序自下而上。

## 代码落点与差距

- 新建 `src/world/voxel-ghost.js`：
  - `rasterizeBoxes()` 盒子集合 → 体素占位（并集去重、`hollow` 只留壳，对应片中空心中庭）；
  - `voxelOrder()` 三套装配序：`scan`（自下而上）/`radial`（由中轴向外）/`shuffle`（定种子打乱）；
  - `previewState(order,t)` 每格四条时间线：hidden → point(0.02+0.12h) → ghost(0.16+0.20h) → solid(0.28+0.72·i/N)，所以**已实心的格恒为装配序前缀**；
  - `isoProject` / `cubeFaces` / `depthOf`：等轴测投影与画家序。
- 新建 `voxel-ghost.html`：主画布实时三态 + 进度滑杆/播放/装配序切换，底部三联对照（点铺满 / 线框+开始实体 / 全部实体）。
- 做到哪：949 格模型，t=0.13 全点、t=0.34 线框 780 + 实体 80 共存、t=0.62 实体 449、t=1 全实心。
- 缺什么：① 本仓模型是自建盒子体素塔，不是"任意网格体素化"（没有 UV 采样、没有内部空腔剔除）；② 片中逐层粉/紫/绿材质分组没有做，只按底板/实体两套配色；③ "Go!" 按钮那种一次触发后才开始填的交互没接。

### 判定
**「每 3 层换一档、6 色循环」说过头了**。逐段圆均值色相（外表面 frame-0060 / 0150，每 25px 一段）：
- 0060：154 170 189 191 189 190 194 208 205 199 194 191 181 166 156 157 °
- 0150：155 170 187 190 189 189 197 207 200 202 197 185 174 157 160 °
饱和度中位**恒 12–15%**、明度 56–73% → 是**连续漂移**（中段偏青 190–207°、上下偏绿 155–170°），
没有六个离散色档；帧里也量不出「层带边界」（相邻 25px 段色差 < 10/255）。
真正有明显偏色的是**进塔后的内侧**（0120：中段 H≈355° 玫瑰），那不属于外表面的层带。

### 代码落点与差距
- `src/world/voxel-ghost.js`：`LAYER_PALETTE` 从 6 个鲜明色（粉/紫/青绿/蓝/黄绿/蜜桃）
  换成实测色相族 `#b4d1c5 #b0cfc8 #b8d4d4 #abc5cc #abbdc9 #bcd6d2`（H 156–204°、S 12–16%、V 79–84%，
  略高于成片是因为材质色还要过光照与雾）；色槽机制（每 3 层一档）不变。
- `voxel-ghost.html`：**删掉页面里抄的第二份旧色板**，改成 `import { LAYER_PALETTE }`，
  否则改模块色板页面不跟着变（本轮第一次跑截图就是旧色，正是这个原因）。
- 仍缺：① 内部玫瑰墙（H≈355°）没有建模；② 层高（每档几层）在片里量不出来——外表面没有可见的层带边界，
  所以 `bandHeight=3` 仍是估计值，别再声称已标定。
