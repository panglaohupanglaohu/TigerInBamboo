判定要点：
1. 「视角 alpha」的证据不是某一帧的透明度数值，而是**换视角后冠的轮廓与内部遮挡跟着变**（掠射角处叶簇透出来）；
2. 0250 的线框是一次**全局调试视图切换**，一直保留到结尾 —— 这是用来展示「冠是球面三角 + 叶纹」的诊断视图，不是资产；
3. 冠的厚度感来自叶片 alpha 与球面贴图，不是高模几何。

## 判定

有机制：球面坐标系叶片贴图 + 视角（掠射角）调制的 alpha + 边缘墨带；线框只是调试视图。

## 代码落点与差距

- `src/life/leaf-surface.js`：`sharedLeafTexture()` 单例 128² 图集（植物角 96,96,32,32）；`leafCoverage()` 按视角+叶纹出 alpha，`LEAF_SURFACE_GLSL`；
- `src/life/vegetation.js#swayMaterial`：`uLeafy>0.5` 时 `rim = 1-|dot(n, viewDir)|` → `leafCoverage` → `discard` + 墨带；`leafyOn` 开关；
- `src/life/leaf-depth.js`：树冠 `customDepthMaterial` 与彩色材质同源（阴影端同 alpha 判据）；
- `src/life/leaf-impostor.js`：远树交叉面片替身。

本轮补的页面入口（此前 `leaf-surface.html` **不能改视角**，而这条片子的机制恰恰只在换视角时才看得见；也没有线框档）：
