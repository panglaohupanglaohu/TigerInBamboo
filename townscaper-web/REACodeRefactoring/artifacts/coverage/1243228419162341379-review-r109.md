## 逐帧观察

- **frame 0–99（联系表 00，0–5.9s）**：机位压得很低、几乎平行水面，小镇整排躺在画面下沿；上方 2/3 全是**成团的层云**——
  靠上的一片大而实、靠下的几片小而碎，云体从左向右缓慢平移、同时有缓慢的竖向隆起，6 秒内轮廓换过一轮。
  云与云之间是淡青灰色的天光，没有硬边阴影落在屋顶或海面上（这一段是阴天照度，云影是软的、幅度小）。
- **frame 100–488（sheet-01…04，沿用 r55 全片）**：镜头缓慢横移转到另一侧；近处一团云被塔楼遮住（说明云在建筑后面，
  深度分层成立），远处云更淡更糊（深度越大越淡越糊）；240 帧原尺寸回看仍只见"青绿/粉红塔楼 + 低处浅云带 + 高处大云体"。
- **本轮回看**：0 / 230 / 240 / 250 / 488 五帧原尺寸，画面与联系表一致；片中**没有**出现"云的轮廓在地面/水面上一一对应"的硬证据，
  只有整体照度随云层厚薄起伏，所以云影强度按"弱、软、空间上不严格对应"实现，不追像素等价。

## 判定

有机制：三层深度云体（远/中/近，越远越淡越糊、飘得越慢）+ 云影投到接收面 + 首页独立开关。
没有体积散射、没有原作逐层烘焙。

## 代码落点与差距

- `src/light/cloud-shadow.js` · `CloudShadow` + `CLOUD_SHADOW_GLSL`：按接收点世界坐标沿 `sunDir` 求交云平面，采样图集 alpha 取 max。
- `src/world/cloud-deck-layer.js` · `CloudDeckLayer`：三层圆柱带云体（`uBlur` ∝ depth）、近/中层团块喂给 `CloudShadow`。
- 本轮新增：
  1. **水面接云影**（`src/world/view.js` 的 `#setupWater` 片元里 `col *= cloudShadowTone(vWorld)`，
     `Object.assign(this.waterUniforms, this.cloudShadow.uniforms)` 共用同一批 uniform 对象）；
  2. **远层单独弱档**：`uCloudPuffsFar[24]` + `uCloudCountFar` + `uCloudFarRatio=0.42`，
     `cloudShadowTone` 里远层用更宽的 ramp（`smoothstep(.02,.92)`）单独相乘，云越高影子越淡越散；
     `CloudDeckLayer.update()` 把 deck 第 0 层团块半径 ×1.6 喂进去。
- **仍缺**：
  1. **植被接收未证明**：`src/life/vegetation.js` 的 `swayMaterial` 已注入 `cloudShadowTone(vCldW)`（uniform 与主材质同一批对象，
     `customProgramCacheKey` 带 `-true`），但本场景（30 丛灌木 + 5 朵花，画面仅 133px）差分**恒为 0**，像素级未通过 → 不算接上。
  2. 反射/倒影、单位影子仍未接（`reflection`、`unit-shadow-batch` 都读不到这份 uniform）。
  3. 原作是逐层烘焙的云影，本仓是"沿太阳射线求交 + 图集软斑"，云影与云体的**一一对应**是近似。
