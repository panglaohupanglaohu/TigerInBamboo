## 判定

有机制：流场/影响场的**第三项数据继承 = 兵种**。原片表现就是「同一屏内不同颜色并行」，颜色 = 该格继承到的最近单位的兵种。

本轮把它量出来了（此前只到「代码里有 type 字段」）：
- **继承正确性**：386 个图上节点，`atNode().source` 与「三源独立 BFS 最近源」对账 **386/386 一致**；继承到的兵种与最近源兵种 **386/386 一致**；方向 382/386。
- **上色不再并色**：场景本身三支守军（步兵/矛兵/弓手各 8 人）→ `flowColorBy='type'` 下 `flowTypeColors = 3`，
  图例逐兵种计数；r70 的旧 bug（表外兵种 `TYPES.indexOf → -1 → max(0,-1)` 全并成第一种色）已不复现。
- **LOD**：维持「不适用」（本片固定机位整岛入画，第三次否证，不再排期）。
