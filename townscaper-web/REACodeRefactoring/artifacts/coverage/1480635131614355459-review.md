- 原文：More experiments in procedural texturing of procedural islands. Still very early, but I do like these big paint blotches. They hide the polys well and they would be hard to achieve with other means. Definitely need a proper lighting system though. And probably some outlines.

## 逐帧观察

- 0000–0030：灰白模型岛（小镇 + 两座塔 + 三栋房子）在深青背景里，镜头绕岛小幅推进；地面几乎无颜色，只有极淡的黄绿。
- 0031–0120：色彩一层层"铺"上来——先是草面的黄绿，再是更亮的淡黄斑；房子依次有白墙、棕红屋顶。色斑不是逐像素噪声，而是**大块低频色域**，跨过若干三角面仍在同一色域内。
- 0121–0225：继续绕行到岛的背面；右上角有 minimap（岛的正交截图 + 几行小字），说明这是编辑器实录。全片没有阴影投射、没有描边：这正是原文"need a proper lighting system … and probably some outlines"的自述状态。
- 0226–0228：硬切（黑两帧）。
- 0229–0340：第二段是**纯地形岛**（无建筑）：先灰褐，随后绿色斑块从高地往下蔓。灰岩台地始终不被上色。
- 0341–0427：第三段回到有房子的山谷：绿斑 + 棕红屋顶 + 白墙，色斑同样跨面连续。

## 判定

有机制：程序化地面着色 = **世界坐标低频域扭曲噪声 → 连续色阶的柔和色斑**，只作用于朝上的草色面；岩壁/屋顶/河床不上色。
关键量化（这是本轮改代码的依据）：

- 4× 最近邻裁切看斑块边界：过渡带宽 20–30 px（原片 640 px 宽），**没有硬台阶**，色阶连续（亮度直方图是 20 左右范围的多峰宽分布，不是 3 根窄尖峰）。
- 掩码证据：灰色岩壁、棕红屋顶、白墙在所有帧里都没有色斑；只有草绿面有。

## 代码落点与差距

`src/terrain/blotch-pattern.js` `blotchTone()` + `src/world/view.js` 的 `uBlotch` 注入（`vUp>0.8 && vField.z∈(0.5,1.5) && 绿>红*0.82` 才乘 tone）。

本轮改动：

- 原来默认分支是**量化三档**（0.80 / 1.00 / 1.14 硬切），与片子的柔和大斑不符——硬边会在多边形上留下"色带棱线"，恰恰是"hide the polys"要避免的。
- 新增 `uBlotchStyleMode = 2`：一个低频域扭曲场 + `smoothstep(.34,.66)` 宽带渐变，tone 在 0.84–1.12 连续过渡，spatial scale 0.55（约 1.8 世界单位一块斑）。`setBlotchStyle()` 允许 mode∈0..2。
- 缺：原作的 atlas/受控跨崖采样、配色随生态变化、以及"色斑是否随镜头移动"无法从本片证明（本片是绕岛，无法区分世界坐标 vs 屏幕/UV 坐标，本仓取世界坐标）。
