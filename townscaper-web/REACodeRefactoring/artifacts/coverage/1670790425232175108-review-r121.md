## 判定

**有机制**：同一套地形生成管线在**纯方格 / 纯六边 / 纯三角**三种格型上各生成一座完整岛 —— 这正是原文那句「generator also output pure triangle/hex and square grids」的全部主张。

## 代码落点与差距

- `src/core/grid-kinds-c08.js`（r56 C08，文件头署本片 ID）：`PURE_GRIDS = { hex: buildHexGrid(radius 9, cellSize 1.15), square: buildSquareGrid(radius 15, cellSize 1.1), tri: buildMixedGrid(mergeRate 0) }` —— 三档都是**共享** `grid.js` 的构建器，不是第二份生成器。
- `src/world/app.js:40`：`if (['hex','square','tri'].includes(params0.get('grid'))) Object.assign(GRIDS, PURE_GRIDS)`；`app.js:99` 的 `buildSceneBar()` 把 `GRIDS` 全表铺成网格切换按钮 → 主场景页 `index.html?grid=hex|square|tri&scene=terrain` 就是页面入口（默认 quad/mixed 不变）。
- `src/core/grid.js`：`buildSquareGrid` 是真正交方格（旧「纯方格」= `buildMixedGrid({mergeRate:1})` 会残留三角，已改名「合并菱形」）；`buildHexGrid` 走 `finishGrid(..., kind:'hex')`。
- **note 里连挂的「独立六边地形/原模块仍缺」是过期项**：C08 已把纯六边接进主场景，但那批只出了 node 级测试（`tests/grid-kinds-c08.mjs`），**没有一支运行验收**，所以 `learn/data.js` 一直停在 partial。本轮补的正是「从真实主场景页跑出来并量出来」。
- **如实记形制差异（不计缺口）**：原片的六边岛是**软坡 + 六棱柱体素**（frame-0242 / 0440），本仓六边岛走主场景的**台地阶 + 白色格线**（六边台地）。原文的主张只有「格型输出」，不含美术；而「软坡 / 柱体形制」属于同组 `1669315384619540487`（[054] 另一条）已在挂的「完整软坡/模块联合生成」续项，不在这条片子上重复计。
