## 判定

**有机制，但全片只在编辑器本体上，没有「贴到模型」这一段**：

1. 节点式调色图：节点（可拖）/ 矩形 / 三角 / 色带四种图元；
2. 每个图元内部被**离散成小三角面片平涂**（相邻面片不同色、面片内恒定）；
3. 取色三档：RGB / LAB(OkLab) / HSL(OkHsl)，每档三个滑条 + 数值；
4. 右键菜单 `New node` / `New gradient` / `New triangle`；
5. 色带的色彩空间菜单 `OkHsl` / `OkLab` / `Srgb`；
6. 底部 12 段带缝隙的色带条。

旧 note 的「全材质接入仍待补」**按片中没拍到的机制不记缺口**（r127 先例）：全片无 3D 场景，故不把「贴到墙/屋顶」当欠账；本仓 `ground-palette-map.js` 的 `wall` 通道仍保留为可选扩展。

## 代码落点与差距

- `palette-editor.html` 第 56 批 `#pg` 段：`paletteGraph` 探针（`stats()`）、拖点、右键菜单、三档滑条、色带/面片空间下拉、导出/导入、`#pgApply` → `attachGroundPaletteMap`。
- `src/core/palette-graph.js`：`facets/quadFacetAt/triFacetAt/moveNode/addNode/addTriangle/addGradient/gradientColors/swatches/exportGraph/importGraph/colorWorldByGraph`。
- `src/core/okhsl.js` / `src/core/oklab.js`：三档换算。
- `src/world/ground-palette-map.js#setCellColors({top})`：应用到实景顶面。

本轮三处**真形制差**（不是过期账）：

1. **画布被 flex 拉伸**：`#pg canvas` 只写了 `max-width:none`，画布被拉到 1213×1434（原 440×520，2.76×）→ 面片发虚；且 `offsetX` 是 CSS px、命中判定用属性 px，**点节点要点到 2.76 倍远处**。改 `#pgCanvas{width:440px;height:520px;flex:none}` → 1:1。
2. **色带条被拉成 1px 连续带**：原来把 156 色 palette strip 画在 1px 高、再 `width:100%` 拉伸 → 片里的 12 段带缝色块看不见。改成按 `gradientColors()` 逐段 12px + 2px 缝隙绘制（12 段，实测块宽 11–12px、缝隙 2px）。
3. **导出只写 8bit hex** → 往返调色板只重合 142/156（91.0%，面片色被量化后 hex 漂移）。`exportGraph` 增写浮点 `rgb`（6 位），`importGraph` 优先取浮点 → 往返 `maxNodeErr 4.7e-7`、调色板重合 **156/156**。
