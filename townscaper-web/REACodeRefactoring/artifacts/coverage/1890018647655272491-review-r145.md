## 逐帧观察

- 0000–0083：与 1897 同一个内转角的**黑白版**：无底色、只有墨线；纹样明显更密（同一块板上小件/圆点/眼睛的密度更高），且**左右镜像**（拱门在画面左上，彩色版在右上）。窄竖带仍在（下圆点上三角）。
- 0084–0119：相机贴近白门，画面上半是门框花边带与门上方对称板，下半是白门（矩形门芯两块）与深灰的走廊侧壁；这一段能看到「门洞两侧是深灰、门是白色」的对比。
- 0120–0150：拉远，护墙板顶线在楼梯段**斜上**最清楚；墙板纹样在护墙板之上，斜线下方是纯白竖纹。
- 0150–0199：绕行到另一侧，图腾式对称脸（中线大件 + 两侧对称花瓣/眼）排成一列；纹样跨转角连续。
- 0200–0242：回到转角正面，门在中间偏左、右侧是密纹板；0216 之后拱门再次完整入画（扇窗放射格 + 花边带），末帧 0242 与 0000 构图接近。

结构小结：与 1897 同一套版式（两面墙 + 内转角 + 圆弧 cove + 分区板/窄竖带 + 竖纹护墙板 + 拱门 + 楼梯），差别是**黑白 + 纹样更密 + 左右镜像**；全片没有第二种房间或 UI。

## 判定

有机制（同一走廊生成器的黑白档）。note 里挂的「完整室内/弧顶、门口版式及参考纹样复杂度」核实为**过期账**：弧顶（cove）、门口版式（门位独占一跨 + 拱带 + 门上方对称板）、密度（`density` 1.35）都在 `doodle-hallway-layout.js` / `doodle-hallway.js` 里，缺的是运行验收。

## 代码落点与差距

- `src/core/doodle-hallway-layout.js` 的 `planHallway({mirror, density, seed})`：本片 = 同一 plan，`mirror:true`、`density:1.35`（`makeHallway({gray:true})` 自动给 1.35）。
- `src/build/doodle-hallway.js#paintHallwayTexture({gray:true})`：底面全白 + 墨线合成时 `grayscale(1) contrast(1.6)`。
- 差距（如实）：黑白版的「更密」只是同一套纹样的密度乘子，不是原作那种换了一套更细的图样；纹样本身仍是程序化替身，属美术差、不计机制缺口。

## 如实口径

- 原片 243 帧 / 27.46fps 明显比彩色版采样更密，但两片拍的是同一处走廊的两个版本；本仓用同一 plan 的两种贴图对应。
- 「更密」的判据是同一纹样库 + 密度乘子；原片 0060 那种「一格内塞满小眼/小豆」的观感本仓能达到，但线条粗细与手绘抖动不同。
