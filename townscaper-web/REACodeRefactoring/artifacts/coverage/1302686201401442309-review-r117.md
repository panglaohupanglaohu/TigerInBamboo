## 判定

有机制：这是「无限、确定、无缝的松弛四边形网格」管线（`1151137783785771008` / `1151770831619534848` / `1332410042784641026` 三片的实现）在 **松弛阶段** 出的问题，要落到的就是这条管线的两块：**格子的松弛目标**与**验收度量**。

## 代码落点与差距

- `src/core/infinite.js`：块 = 三角点阵上的六边形；每块 / 每三块一簇各自松弛、**外圈钉住**（`relaxGroup`）；顶点最终位置 = [所在块, 最近两簇] 三个版本按重心坐标插值。因为钉住边界且各自松弛，本仓**不会翻折**（`verify().flipped == 0`）。
- `src/core/grid.js#relaxPolygons`：拟合目标 = 各角相对形心的偏移反向旋转后取平均（= 最佳拟合正 n 边形），再按 0.45 / 0.3 的步长拉。
- `verify(inf, mode)`：查四件事 —— 翻折格数、相对**本格原始点阵**的拉伸/收缩倍率（`maxStretch / minShrink / maxEdgeStretch`）、块边界两侧是否同一点（`seam`）、非法点。
- **上一轮记的真缺口**：「还缺把面积拉回点阵的松弛权重（现有 14 格收缩到 0.46×）」。根因就是上一条 —— 拟合半径取「当前偏移的均值」，格一旦被邻格/边界挤小，就**照着更小的半径继续拟合，面积只丢不还**；这正是原片第二症状（邻格被拉长）的对偶面。
- **本轮补上**：`relaxPolygons(polys, verts, passes, areaPull)` —— `areaPull > 0` 时把目标半径朝「与该格**原始点阵面积相等**的正 n 边形」拉
  `R_want = √(2·A_raw / (n·sin(2π/n)))`，`vx,vz *= 1 + (R_want/fitR − 1)·areaPull`。外圈仍钉住 → 边界位置一点不变、接缝照样 0。
  `buildInfinite` 默认 `areaPull = 0.85`（`areaPull: 0` 逐位复现旧行为，留作对照）；`bugPatches` 演示块**不施加**面积拉回（那是故意复现原片翻折 bug 的）；`createInfiniteStream` 同口径透传（否则流式与窗口版不一致 —— 第一版漏传，`infinite-stream.mjs` 立刻报 0.0516 偏差，已修）。
- `verify()` 的报告里带上 `areaPull`，页面 `grids.html?t=infinite` 的面板可直接读到。
