## 判定

有机制（天光柱 + 单位柱），机制已实现（r91–r100）。**本轮唯一的目的是给「峰值 α=1.0」找一个独立证据，
结论是：证不出来，而且大概率不到 1.0。**

r100 的 1.00 来自 `tools/beam-alpha-slope.py` 的 `cal_alpha=1.0`（标定假设），属循环论证。本轮新写
`tools/beam-transmission.py`：用**柱后背景剩余对比度**反解 α（`spread_in ≈ (1−α)·spread_flank + noise`）。

- 自检（以 0278 为背景合成已知 α 的柱再反解）：α=0.10 测成 0.54、0.30→0.61、0.70→0.81、0.85→1.00，
  **最坏误差 0.442 → CALIBRATION FAILED**。原因两条：柱内残余对比度与平坦区噪声底同量级；
  spread 比值在高对比背景上不线性。
- 实拍（诊断值，非结论）：0288 柱内残余 **11.98** / 柱外 **44.55** / 噪声底 **5.12** → τ=0.174 → α≈0.83；
  0289 τ=0.266 → 0.73；0286/0290–0292 出现 τ>1（柱内比柱外还花，说明柱已移出窗口）。
- 4× 裁切目视复核 0288：柱带压过岩体时，**岩顶的斜坡边与白色裂纹仍隐约可见**（278 帧则完全没有柱）。
  这与「α<1」一致，与「α=1.0」不一致。

**判定：峰值 α 落在 0.7–0.85 区间（含 ±0.15 估计偏差），明确小于 1.0。r100 的 1.00 应作废，
改记为「标定假设值」。** 天光柱的 α 绝对曲线在此素材上已到上限：400×400 / JPEG q≈88，
残余对比度与噪声底只差 2.3×，任何 α∈[0.85,1.00] 都给不出统计显著差异。
