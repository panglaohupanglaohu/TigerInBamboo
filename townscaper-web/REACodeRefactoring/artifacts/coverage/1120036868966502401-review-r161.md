- **0380–0399**：视角转到岛体侧上方，补丁与 gizmo 仍在，红/蓝细线是沿格边走的**选择轮廓**（红 = 跨多格，蓝 = 单格）。

## 判定

有机制，且本条的主体在第 94–98 轮已落地：等距格网 + 贴面 + 外缘回字环 + 三角分组色 + **「选中态 → 包围盒 → 窗口补丁」**
（`quad-lattice.js#boundsForCells/mergeBounds/selectionBounds` + `view.setGridWindowForSelection/builtCluster`）。

**本轮收掉的是最后一层**：note 从第 98 轮起一直挂着 `仍缺与真编辑器撤销/多选联动`。核实（先核再动手）：

- 主场景 `src/world/app.js` 有**真撤销栈**（`undoStack/redoStack`、`pushUndo/undo/redo`、60 条上限、`sceneStart`），
  但**全仓没有「选中」这件事**：`grep -n "sel\b|selection|selected|多选" src/world/app.js` 零命中，
  `grep -rn "多选|multiSelect|multi-select" src *.html tests` 零命中；`grid-debug.html` 的选中是**另一页**
  （NDC 反投影点拾取），主编辑器里根本没有入口 —— 所以这不是过期账，是真缺口。
- 另外发现：HUD 那排工具按钮（▲▼■）**只有 title、没有 onclick**（点了没反应），
  且左下角被「重构版·最新进度」信息条（z-index 100）与进度折叠面板 `#coverage-progress`（z-index 7）压住，
  连原有的撤销/重做也点不到 —— 所以「页面入口」必须先修成真能点的。

## 代码落点与差距

新增（纯逻辑，node 可测）：

- `src/core/cell-selection.js` · `CellSelection`：有序去重 id 集合（`add/remove/toggle/set/clear/has/ids/size`）、
  `prune(valid)`（Set / 数组 / 谓词三种口径，谓词抛错当无效剔掉）、`toSelection(resolve)`（→ `{cells,ids}` 或 null）、
  `snapshot()/restore()`（撤销栈旁路只记 id）；非法输入一律抛 `RangeError/TypeError`。

改（接线，只动编辑器层）：

- `src/world/app.js`
  - **工具**：`setTool` 增加 `select` 光标；给 HUD 的 `.tool[data-tool]` 补 `onclick`（原来点不动）；
    键盘 `S` 切选择、`Esc` 取消选中。
  - **选中**：`pointerdown` 新增 `tool === 'select'` 分支 —— 无修饰 = 单选替换，`Shift/⌘/Ctrl` = 加减（多选），
    点空 = 取消（多选时点空不清）；`pointermove` 在选择工具下**不画建造幽灵块**。
  - **窗口联动**：`applySelectionWindow()` 走 `view.setGridWindowForSelection({cells})`；
    等距档没开（`gridLatticeStep=0`）时只留选中态、不抛错。
  - **撤销/多选联动**：新增平行账本 `undoSel/redoSel`（不把 id 塞进 `world.snapshot()`，所以 `snapshot-replay`、
    `game-ui.undoDepth` 的口径**逐字不变**）；`pushUndo` 同时压入选中的快照，`undo/redo` 同时弹出并 `restore` 选中态；
    60 条上限时两条账本一起 `shift`。
  - **世界变了先 prune**：`endStroke()`（编辑完）、`loadScene()`（换场景）、`clear` 按钮与 `C` 键（清空世界）、`undo/redo` 之后
    都先 `pruneSelection()` 再重算窗口；`selectionApi.stats()` 给出 `windows/prunes/prunedCells/undoRestores`。
  - **页面入口**：`?gridwin=1` 打开「等距格 + 窗口补丁」调试层（**必须放在学习面板/环境面板挂载之后** ——
    面板会重放 `setDebug`，提前打开会被改回 `false`，本轮第一版就踩到：几何在、画面一根线没有）；
    `window.rea.selection` 暴露只读探针（ids/size/has/window/bounds/stats）。
- `index.html`：工具条加「▣ 选择（S）」格；底部信息条改 `pointer-events:none`（链接单独 `auto`），不再吃掉左下角点击。
- `src/ui/hud.css`：`#tools` 从 `left:16px;bottom:16px` 挪到**底部居中**，避开信息条与 `#coverage-progress`。

与片子的差距（如口径，不是「缺口」）：补丁最大 8 格（`maxCells`）是第 96 轮按原片 7–8 格定的；两格相距 >8 格时
窗口会被裁到 8 格内（本轮测试据此选 3.0 格间距的一对）。多选来源是「点选 + 修饰键累加」，片中是否有框选/快捷键
无 UI 可证（片里没有工具栏、只有鼠标指针），不据此立新缺口。
