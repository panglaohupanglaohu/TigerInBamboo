## 逐帧观察

- **0000–0055**：整屏是 Unity Inspector（标题 `Col Vol Test (Script)`），左列五个折叠行 `Grass / Roof / Cliff / Beach / Flowers`；右侧同一高度上是五条横向色带（一特征一条，每条十几格，颜色沿条渐变）。没有 3D 场景、没有游戏画面。
- **0056–0115**：`Grass` 展开 → 三行滑条 `H 5 0.51 … 0.90` / `S 3 0.31 … 0.63` / `L 3 0.44 … 0.59`。**每行第一个数是该轴格数，三个轴可以不同（H 5、S 3、L 3）**；滑条下方出现 5 块小色格（每块里是 3×3 左右的格点色）+ 一条多格色带，色带随滑条移动实时改色。
- **0116–0299**：鼠标在五行标题上来回移动/折叠（0255 起 `Roof` 高亮），五条色带始终在位；这一段没有新的数值编辑，只有行的开合。
- **0300–0399**：回到全折叠态，`Grass` 行标题被悬停；五条色带颜色与首帧一致（草绿 / 红橙 / 青灰 / 沙米 / 洋红）。
- **0400–0450**：`Cliff` 展开 → `H 4 0.06 … 0.25` / `S 3 0 … 0.52` / `L 3 0.47 … 0.79`。**Cliff 的 H 轴是 4 格，与 Grass 的 5 格不同** —— 逐轴、逐特征格数都被片内数值坐实；滑条下方这次是 4 块小色格 + 色带。
- **0451–0514**：`Roof` 那条色带整条变成紫色系（原来红橙），`Grass` 色带首格变成紫灰；末帧停在五行全折叠态（`Grass` 首格紫灰、第二行紫、其余行颜色也有偏移），说明编辑即时反映到色带上。

## 判定

**有机制，且机制就是面板本身**：每个特征一条 H/S/L 三段范围 + **逐轴格数**（H 4/5、S 3、L 3），配一条该特征的色带；改任一段/任一格数，色带与下方小色格立刻重画。片里**没有**地形三轴/八角点色容体的证据，也没有 3D 场景 —— 全片只有 Inspector。

## 代码落点与差距

存量（前轮已落）：
- `src/core/color-volume.js`：`makeColorVolume`（H/S/L 范围）、`sampleColorVolume`（`steps` 离散吸附）、`colorVolumeStrip`（12 格色带）、`colorVolumeTerrain`（8 角点预览）；
- `src/world/view-shading.js`：8 角点 **GPU** 路径（`uShCVC` 40 个 `vec3` + `uShCVMap` 320²），`setCorner(feature,index,hex)` 逐角点改 uniform 不重烘；`src/ui/shading-panel.js` 五特征 × 8 角点取色器面板（r55 G1）；
- GPU 输出侧验收：`tests/color-volume-features-browser.cjs`（mode-3 三桶零串色 / steps 阶梯 / 确定性）。

**真缺口（本轮核实）**：
1. `sampleColorVolume` 的 `steps` 只能三轴同一个数 —— 片里 H 4/5 与 S 3/L 3 不同，这一层形制做不出来；
2. 片里那个「五行 × H/S/L 三段 + 逐轴格数 + 12 格色带」的**作者面板没有任何页面入口**（`color-lab.html` 只有 ground 一条 H 起/止；`grep -rn "setCorner" *.html` 零命中）；
3. 该面板从未有过运行验收（此前只有输出侧 GPU 验收）。

本轮补齐：
- `src/core/color-volume.js`：`steps` 支持 `[h,s,l]` 逐轴格数（单数字路径逐位不变，向后兼容；`n===1 / 非整数 / 长度≠3` 仍抛 `RangeError`）；新增 `colorVolumeTerrainHSL(w,h,vols,{steps})` —— 与 `colorVolumeTerrain` **同一分类器**（Beach hh<.13 / Cliff slope>.55 / Flowers wob>.90&&hh>.30 / 其余 Grass），取色改走面板形制，`steps` 可按特征各给一份，并返回逐像素 `feature` 掩膜；
- `color-volume-lab.html`（新页）：五行 × （H起/止、S起/止、L起/止、格数 H/S/L）+ 每行 12 格色带 + 左侧 300×300 实时预览；默认值与片内一致（Grass 5/3/3、Cliff **4**/3/3、其余 5/3/3）；
- `tests/color-volume-hsl-panel.mjs`、`tests/color-volume-author-browser.cjs`。

## 如实记录的形制差异（不构成机制缺口）

- 片里每条色带的格数比 12 多（同一行内是连续多段），本仓固定 12 格（与 `colorVolumeStrip(vol,12)` 同口径，原版 `strip(vol,12)` 也是 12）；
- 片里只有 Inspector、没有 3D 场景；本页左侧地形预览是本仓自加的可视化，不是片内要求；
- 3D View 侧仍是「8 角点 OKLab + 3 桶 HSL」两条路径（已有 GPU 验收 `tests/color-volume-features-browser.cjs`），本面板驱动的是预览与色带，不直接改 3D 场景 uniform；面板的 8 角点版仍留在环境面板（`src/ui/shading-panel.js`）。
