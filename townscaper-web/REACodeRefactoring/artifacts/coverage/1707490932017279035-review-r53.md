## 逐帧观察

- 0000–0039（sheet-00 前四行）：两层台地小岛的近景，机位几乎不动，只有轻微位移。崖顶边缘一圈鲑橙色带，厚约 20–30px（420 画幅），外轮廓是小圆齿/扇贝波，内缘贴草面那侧有一道更深的细描边。带宽沿边不等：有的边整段没有（被低频噪声断开），有的边宽到盖住约三分之一格面。
- 0040–0099：画面推近到一座带白墙红顶小楼的圆台，灌木带绕台顶一圈，在建筑落地处断开。带内能看到比底色更亮的小团块（受光感），但几何三角线框直接穿过带身 → 没有独立几何，就是顶面着色。
- 0100–0139：继续推近，出现更矮的一级台阶。矮台地边上的带宽明显窄（约 10–14px），与 0165 那种高崖（约 30px）对比是 1:2 量级，方向与「崖越高带越宽」一致。
- 0140–0199：转到高台地（落差目视 6–8 层）。高崖顶的带最宽、且出现了两三级并行的台阶边，每条边各有一条带；崖壁本体是奶油色/浅米色，带淡淡的水平沉积细线，看不到独立的「粉橙 / 土黄 / 灰绿」三档竖向变色——粉橙只出现在灌木带本身和沙岸上。
- 0200–0256：拉远成全景，整岛台顶一圈鲑橙带，草面偏灰绿，水面青绿。带在沙岸（贴海那一圈）是空的。

## 判定

**有机制**：灌木 = 顶面上「到崖边的归一化距离 × 阈值」刷出来的一条带，不是几何、不是广告牌；带的外缘高频噪声成扇贝齿，带内侧有一道窄阴影与小描边制造体积感；带宽随崖高变化、并受低频噪声随机断开。

## 代码落点与差距

- `src/terrain/terrainmesh.js`：顶面扇形逐顶点写 `edgeTri`（崖边 0 / 格心 `centreE = 1/min(1.8, 1+0.35*(maxDrop-1))`），崖越高格心值越小 → 同一宽度阈值盖住更多格面。实测量化档：落差 1 → 1.000、落差 2 → 0.741、落差 3 → 0.588、落差 ≥4 → 0.556（1.8 倍封顶）。
- `src/terrain/shrub-texture.js` 的 `shrubApply`：低频宽度 + 高频锯齿 + 内侧 `shW` 小阴影 + 内缘描边 + 亮团，与片子的四条特征一一对应。
- **本轮修掉的硬伤**：`src/world/worldmesh.js` 的 `ChunkRouter` 只代理了 `fieldFrame` / `soft`，**没有代理 `edgeTri`**。地形生成器写的是 `w.edgeTri = [...]`，值落在这个路由对象上、到不了真正的 `MeshWriter`，于是活的世界网格里顶面 `aEdge` 恒为 1.000（浏览器探针：8628/8628 顶点 = 1.000）→ **灌木带在任何页面上都从未画出来过**，第 47 轮记的「同机位开关差 24562px」是别的画面变化。已补 `set/get edgeTri`（并在 `at()` 换块时带上），实测活几何变成 0（1468 顶点）/ 0.556 / 0.588 / 0.741 / 1（5752），`scaledShare` 0 → 0.163。
- 仍缺：① 片上带更饱和、更厚，本仓偏浅偏薄（受光乘 1.14 后仍偏灰）；② 带的外缘圆齿频率偏低，近看更像直条；③ 崖壁本体没有「粉橙/土黄/灰绿」三档竖向变色——本轮原尺寸复核认为片中崖壁只是奶油色 + 水平沉积细线，粉橙来自灌木带与沙岸，因此**不按上一轮的猜测硬加三档色**，改为在 note 里记下这个判读修正。
