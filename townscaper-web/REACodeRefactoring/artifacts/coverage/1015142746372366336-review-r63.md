## 逐帧观察
- 全片固定机位（400×400），岛上两处火源，烟整体向右上方吹斜、越往上越淡；0000–0099 与 0200–0299 的柱形几乎一致，说明是持续的稳态发射，不是一次性爆发。
- `smoke-r63-crop150b.png`（frame-0150 中下部 3 倍）：柱子从烟囱口出来时是一段粗细≈烟囱宽的实体，往上立刻分成 4–5 个**直径≈柱宽的大圆瓣**，瓣与瓣之间只有一道浅缝（不是一串小圆点）；每个瓣的轮廓是圆滑的弧、外侧有一圈深色描边。
- `smoke-r63-crop150.png`（同帧更上方 3 倍）：柱身到某一高度**断掉**，上面另有一团独立的深色烟（直径约等于柱宽，边缘同样清楚），两段之间有一条能透出背景天空的缝。
- 同帧右侧（背风侧）另有一大片**没有任何硬边**的浅灰雾，横向铺开约画面宽的 1/3、纵向只有柱高的 1/5 左右，亮度只比天空暗一点；这正是「两柱之间的弥散薄雾」。
- 描边在两瓣交界处仍然连续（第 55/59 轮已核的两遍做法），本轮不改描边。

## 判定
有机制，且原片口径比我仓上一版更「粗」：**每 0.24s 一片、每卡一个大瓣（噪声尺度 0.14–0.36）、瓣径≈柱宽**；柱顶的断开来自**发射分组**（长周期静默窗在高度上留真空），不是靠 alpha 淡出分开；薄雾是**独立的一层低 alpha 扁卡**，不参与两遍描边。

## 代码落点与差距
- 落点：`src/life/smoke.js`（第 63 轮 native 化，不再依赖 `smoke-c01.js` 的外挂近似）
  - `LOBE_STYLE` 两条口径：`fine`（旧观感，回归用）/ `big`（本轮原片口径：interval 0.24、subs 1、uv 0.14–0.36、spread 0.68–1.64、jitter 0.24）；`setLobeStyle()` 切换。
  - `setTopBreak()`：每源一个分组相位，`3.50s 发射 + 1.10s 静默`；静默期不吐片、`acc` 夹到一档（避免恢复时连环爆）→ 柱高上留出 ≥1 个卡径的真空。
  - `#buildHaze()/setHaze()`：8 张大扁朝镜头软卡（sx 3.2–6.0、sy 0.75–1.65），`pow(1-r,2.2)` 软衰减 ×(0.045–0.12) alpha，无阈值化所以永远无硬边，renderOrder 5 在所有烟之下；源没动时整层跳过重铺（否则每帧抽 random 会闪）。
  - `smoke.html`：`大瓣 / 顶端断开 / 弥散薄雾` 三个勾选框从 `smoke-c01` 改到这三个 native setter。
- 仍缺：
  1. 原片的顶团是**独立的一团**（尺寸略大、边界同样清楚），本仓只是「发射断口」，断口上方那组烟与柱身同尺寸同淡出曲线；
  2. 薄雾的密度/模糊半径没有标定（原片横向 8–14 单位、纵向 0.8–1.2 单位；本仓按单位猜）；
  3. `src/badnorth/battle-c01.js` 仍走旧的 `smoke-c01` 外挂层（隐藏每 3 片 + 放大 1.32），主管线未切到 native；
  4. 默认口径仍是 `fine`（页面勾选框才切 `big`），主场景没有默认切。
