| 面板 | 结构 | 量到的数 |
|---|---|---|
| ① 法线 | 平涂色块拼接、块间有细缝；大块（绿）占 20.5% | 色桶 ≥100px 的 25 个，合计占 55%；最大块 3442px（20.5%）；25 块平均 371px → **等效块宽 19.3px，块宽/图宽 = 0.15**；`RGB→n` 反解倾角 p10/p50 = 43.7°/88.4°（倾角很猛） |

| ③ 六向 AO | 8 列 × 4 行左右的小格图集，每格一块暗斑（每片 chart 一幅） | 列峰 22 处、行峰密集，格宽 ~32px；暗斑覆盖率按格不同（正/负轴向不同） |

## 判定

**有机制**，且三件都在本仓落地并有运行读数：

1. **大笔触程序法线**：`src/core/paint-normal.js`（r56 迁原版 paintnormal.js：抖动 Voronoi 块、一块一个随机倾角、1–2px 软边、切线空间 RGB）+ `src/world/view-shading.js` 的 `?shade=paintnormal`（主材质按主轴平面投影采样并扰动**着色**法线，顶点不动）。
2. **3D SDF**：`src/core/voxel-distance.js`（各向异性三轴加权平方欧氏距离变换，体素中心精确；射线走「中心距离 − 偏移 − 半对角线」的保守下界 + DDA 兜底）+ `src/light/lightvolume.js` 的 `distanceField` 开关。
3. **±X/±Y/±Z 六向 AO**：`src/light/voxel-ao.js` 的六向距离衰减 AO（单轴近似），页面六切片可看。
4. 原文没写但片子隐含的「贴图 → 光照」闭环：`src/light/megatexture-gi.js`（SDF 的 RG = 最近表面在 mega texture 的 UV，B = 距离；六向光体积对 SDF 球步进、命中处按 RG 取 mega 纹素，逐轮反弹）。

## 代码落点与差距

| 落点 | 做到哪 | 差距（如实口径，非未实现） |
|---|---|---|
| `paint-normal.js` + `view-shading.js` | 块数 25、块宽/图宽 **0.20**（原片 0.15，1.3×）、块内倾角离散 **1.1°**（一块一倾角）、倾角上限 26°（原片测得 43–88°，更猛） | **布局不同**：原片那张图是**网面 UV 图集**（色块形状跟着面的 UV 展开走，块缝即 chart 边），本仓是世界平面**周期平铺**的 Voronoi（r56 迁的是原版 paintnormal.js 的口径）。平铺在几何上重复，UV 图集不重复。这是形态差，不是缺机制。 |
| `voxel-distance.js` / `lightvolume.js` | 中心 EDT 精确、保守步进与 DDA 逐项一致（`tests/lightvolume-distance-browser.cjs`） | 是**体素中心**距离，不是连续三角网表面的 SDF；原片那 16 张切片同样是体素体积（软斑边缘可见格状），属同类近似。 |
| `voxel-ao.js` | 六向距离衰减、0–1，六切片可看 | 单轴近似，不是原作的多射线半球积分；原片 AO 是烘进**每片 chart 的图集**（8×4 小格），本仓是可切的体积。 |
| `megatexture-gi.js` / `texel-owner.js` | 984 片 chart / 9256 纹素 / 图集 172×164；SDF-UV 命中「精确穿越面」**82.5%**（69094/83777）；反弹相对变化 122.9% → 5.50% → 0.97% | 纹素 = 体素面（不是三角网 UV 展开）；命中率余下 17.5% 是粗格 SDF 的量化误差。 |

**页面假账修正**：`lightvolume.html` 顶部原写「尚未复现形变 SDF/mega-texture 反馈」，实际 `megatexture-gi.html` 早就有这三张图与读数（r114/r122 同型：页面提示语本身是过期账），本轮改成指向 megatexture-gi.html 的实际口径。

## 账

`--status done` 的理由：原文点的三件（笔触法线 / 3D SDF / 六向 AO）与片子隐含的 mega 反馈，**四件都有模块、有页面入口、有本轮真实运行读数**；旧 note 的两条「仍缺」（笔触法线贴图、SDF 命中 UV/mega 反馈）均为**过期账**（r56 已落码，本轮补的是运行验收）。剩下的都是形态/近似口径差异，已逐条写在上表，按项目口径记为如实口径而非缺口。
