## 逐帧观察

- **0000–0180（固定机位，高崖岛）**：外海几乎不动，只有岛脚一圈白带在变。白带**不是**一条从头到尾的连续线 —— 岸线被切成几段，段内是实心白、段间是水体直接贴岩脚（sheet-00 全页可见，段边界随帧移动）。
- **f0180 原尺寸**：岛体左下沉岩脚处有三四条约 8–12px 的白色短弧，贴岩脚，外缘软；岛底缘是一段较长的白带；其余岸段只有一条极细的浅色水线。
- **0190–0244（镜头绕过高崖 / 海蚀洞）**：机位转过约 90°，可见另一侧岸段同样「有浪才白」；转场期间白带不跟着相机走（是世界空间里沿岸移动）。
- **f0300 原尺寸**：岛脚三处白块（中左下大块 ~40×14px、中下小块、右下patch），块与块之间约 20–60px 的岸段**没有白**，水直接压到岩脚；块的外缘有一层淡色晕散进水里（skirt halo）。
- **0244–0544（固定机位）**：白块的**位置沿岸滑移**、宽度来回胀缩（有的时刻只剩 3 段、有的时刻 5–6 段），同一岸段不会一直亮 —— 即「分段展开 / 聚散」。全片无 UI、无帧率、无建造操作。

## 判定

有机制，且机制 = **沿岸白带的分段 + 缝隙漂移与胀缩**（外加 r56 已做的全局岩石泡沫遮罩、窄湾浪带防穿岸）。

本仓原状：`shore.js` 的静态裙带（rim + halo）沿**全岸 100% 常亮**，浪带（K 条）虽然分段，但只在 0.07–0.24 世界单位宽的一条细带上走，且被常亮裙带盖住 → 片内「有浪才白 / 段间留缝」的形制在画面上不存在。

## 代码落点与差距

- `src/water/shore.js`
  - `buildShore()`：裙带每个岸点烘 `aArc`（弧长相位 0..2π，每条闭合岸线各自从 0 起算）。
  - 新增 `skirtCoverage(u, time)`（JS 孪生）与 `skirtBreakGLSL`（GLSL，逐式同源）：整数谐波 `3u`/`7u` 保证绕一圈接缝连续；`amp = 0.34 + 0.16·sin(0.55t)` 让白段宽度随时间呼吸（聚 / 散），相位项 `-0.35t`/`-0.62t` 让缝隙沿岸扫过。
  - `makeSkirtMaterial()`：uniforms `uTime/uSkirtBreak/uSkirtDrift/uSkirtGap`；`vCover = mix(1, mix(gap,1,cover), uSkirtBreak)`，rim 的 alpha 从 `vA²` 变成 `vA²·vCover`，halo 的 tint 同步乘 `vCover`。
  - **顺带修掉一个真缺陷**：裙带材质原来是 `FrontSide`，而环向绕序让这层薄条的法线朝下 → 从上往下看绝大部分三角形被背面剔除。同机位离屏实测：单面可读像素 **2170**，双面 **35481**（6%）。改 `DoubleSide` 后「静态白边 + 淡晕」才真的沿整圈画出来。
  - 新增 `skirtStats(geometry, time, thr, drift, brk)`：按 `aArc` 回放亮段 / 缝隙（段数、缝隙占比、最长缝角度），供页面读数与测试。
- `src/world/view.js`：裙带共享 `waterUniforms.uTime`；`view.skirtStats(t)` 探针。
- `src/world/app.js`：`?skirt=plain` 回旧档（默认分段）。
- `waves.html`：新增「裙带分段」开关 + 「泡沫遮罩＋防穿岸」（`&c10=foammask,shoreclamp`）开关 + 逐帧读数「N 圈 · 亮段 M 段 · 缝隙占 X% · 最长缝 Y°」；页脚原来写的「全局泡沫遮罩、窄湾浪带交叠与全路径防穿岸仍待补」是过期账，改为指向 `foam-mask.js` 与开关。

## 如实口径（不构成缺口，记清楚）

- 白带是本仓程序化替身（整数谐波 + 呼吸），不是原作手绘；片内白块外缘更「毛」，本仓是软边。
- 主场景这一格岛的岸线在陡崖下很短，真场景截图里白带只有几个像素宽；离屏单层图（`-skirt-on.png`）才看得清分段 —— 这是取景尺度，不是带宽缺口（0.18 世界单位 ≈ 岛宽 2%，与片内 ≈2% 同量级）。
- 「浪带之间互相遮挡/合并」核实为已被标准 alpha over 合成正确处理（K 条浪片叠同一带时是 `a1+a2−a1a2`，不是加法过曝），不另立缺口。
