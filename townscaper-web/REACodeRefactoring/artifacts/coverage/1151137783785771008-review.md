## 判定
有机制：地形网格 = 六边形"块（Patch）"拼贴，块内是按种子合并/细分出来的不规则四边形；块与相邻三块组成的"簇（Cluster）"各自松弛（外圈钉住），顶点取"所在块 + 最近两簇"三个版本的重心插值——所以块边界两侧算出来是同一个点，接缝为零。区域是一圈圈往外长的。

片中"aperiodic"这一点，画面本身并不支持：拉到最远时能清楚看到同一朵花纹在重复，本仓同样是"确定性地重复同一块"，不是无周期拼贴。

## 代码落点与差距
- `src/core/infinite.js`：`buildInfinite({N,L,rings,passes})` 生成块中心（六边形点阵 DIRS）→ `quadPatchTopology` 用 `hash(q,r)` 当种子生成块内四边形 → `relaxGroup()` 对块、对簇各松弛一遍（边只属于一个组的点钉住）→ `blendAt()` 按（块中心、簇1中心、簇2中心）重心坐标插值；`verify()` 查翻折、拉伸、块边界两侧重合。
- `grids.html`「无限网格」页签：本轮新增**环数 0/1/2（1 块 / 7 块 / 19 块）**三档，用来对照片子里"一块块往外长"的过程；原有 未松弛 / 只按块 / 只按簇 / 块+两簇插值 四档保留。
- 做到：blend 模式下 19 块 3946 格，翻折 0、非法 0，块边界 330 个点共 378 对表示最大差 **3.7e-15**（7 块时 9.9e-16）；拉伸最大 1.83×、最小 0.46×，超 2× 的 0 格。
- 缺：① 页面是**有限环数**（最多 19 块），片子是真正无限（拉远后铺满取景框、并随镜头继续长），没有流式加载/LOD；② 本仓按块上色 + 红色块边界线，片子是统一灰、只留格线，所以"接缝看不见"这件事本仓其实是被调试色破坏的（关掉调试色才等价）；③ blend 把 14 个格子压到 0.46×，片子里块内格子大小差没这么极端；④ 无周期没有复现（见上）。
