## 判定

**有机制**，且是「生成网格 → 局部替换成手制规则模板」这一件事，三件子能力：
1. 单块补丁：从现有共享网格取一块星形/带洞的封闭区域，**复用原边界顶点对象**，内部改成规则环带（同心环 + 辐条）；
2. 多块补丁：同一张网格上撒多块，互不重叠、各自编号可溯源；
3. 已有世界迁移：把已建好的 World 搬到打过补丁的网格上（外部格逐列照搬，补丁格按最近源格重采样），而不是「只对新网格生效」。

片子本身没有展示「随机撒」的自动流程，也没有参数面板；0106 那一帧只是编辑器里选中模板的高亮 + 操纵轴。

## 代码落点与差距

- `src/core/radial-patch.js`（文件头署本片 ID）
  - `insertRadialPatch`：星形孔洞 → 原边界顶点复用 → `rings` 圈环带 → 中心 `N/2` 扇形；拒绝非星形/带洞/边界接触/翻折。
  - `insertTemplatePatch`：`PATCH_TEMPLATES = ['radial','block','rhombus','courtyard']`（r55 手工模板库）；courtyard = **带洞边界**，洞内原格原样保留。
  - `insertRadialPatches`：多补丁（重叠即 RangeError）+ `sourceCellOf` 溯源 + `patches[].cellIds`。
  - `migrateWorldToPatch`：已有 World 迁移（copy / resample 两路，返回计数）。
- `src/core/grid-gems-c06.js#sprinkleGems` + `app.js:50`：主场景 `?gems=N`（默认关）在建 World 之前换网格。
- `gridpatch.html`：单块补丁页（quad/mixed、模板切换、顶点对偶、中央塔编辑）。
- **本轮补的入口**：`gridpatch.html` 原来把 `radius:3 / rings:2 / holeRadius:1.3` 写死 —— 原片那块补丁是「**约 5 环 + 中心留一小片原格**」，页面上根本到不了这个口径。现已支持 `?rings= ?radius= ?hole= ?inner=`，并把 `rings / boundaryN / holeBoundary / edgeRatioP50 / slivers / minEdgeRatio` 写进 `#report` 读数，加了「原片口径」深链。

### 量出来的差距（同一口径：辐条数 / 环数 / 补丁格长宽比）

| 口径 | 辐条数 | 环数 | 补丁格长宽比中位 | 细长格（min/max 边长 < 0.35） |
|---|---|---|---|---|
| 原片 0035/0106（像素射线计数：径向穿越 7–8 条线、一圈 21–27 段） | 21–27 | ≈5 | — | 中心是小多边形，不是单点扇 |
| 本仓 radial 旧默认（rings 3 / radius 3） | 56 | 3 | 0.366 | 90 / 196 |
| 本仓 radial 5 环 / radius 1.9 | 32 | 5 | **0.544** | 31 / 176 |
| 本仓 courtyard 5 环 / radius 1.9 / hole .8 | 32(+洞 14) | 5 | **0.257** | 151 / 197 |

结论：**「环数」与「辐条密度」靠新入口已经能对上原片**（radial-5：N=32 vs 原片 21–27、5 环 vs ≈5 环、长宽比 0.366→0.544）；**中心形态也对上了**（courtyard 的洞内 7 格原格原样保留 = 原片中心那簇小多边形，不是单点扇）。剩下的是**细楔**：courtyard 把星形外边界逐点径向投影到每一条环（`insertTemplatePatch` 里 `target = boundary.map(p => 径向投影 R)`），星形尖角处每环都被压成细楔，长宽比中位只有 0.257；原片是**等角**分环（radial 模板那条路径 `target = phase + i·2π/N` 才是等角的），所以原片 5 环里没有这种细楔。

## 仍缺（一句话）

courtyard 模板把星形外边界**逐点径向投影**到每一条环，星形尖角处被压成细楔（eP50 0.257、细长 151/197）—— 应改成 radial 那条**等角目标环**（`phase + i·2π/N`），保留洞边界只在洞内侧拉链；radial 模板中心仍是 `N/2` 扇形汇聚到一点，原片中心是小多边形（courtyard 已做到，radial 未做到）。
