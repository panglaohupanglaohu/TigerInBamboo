## 逐帧观察（沿用 r55/r109 两轮全片核验，本轮不重排）

- **frame 0–99**：机位几乎与水面平齐，小镇压在画面下沿；上方 2/3 是成团层云，靠上的大而实、靠下的碎而淡，
  云体自左向右缓移并缓慢竖向隆起。云与云之间是淡青灰天光，**没有**硬边影子落在屋顶/海面（阴天照度，云影是软弱信号）。
- **frame 100–488**：镜头横移到另一侧；近处云团被塔楼遮住（云在建筑之后 → 深度分层成立），远处云更淡更糊。
- 240 / 488 帧原尺寸回看：只见「青绿/粉红塔楼 + 低处浅云带 + 高处大云体」，无云的轮廓与地面一一对应 → 云影按「弱、软、不同严格对应」实现。

## 判定

有机制：三层深度云体（越远越淡越糊、飘得越慢）+ 云影投到接收面 + 独立开关。无体积散射、无原作逐层烘焙。

## 代码落点与差距

- `src/light/cloud-shadow.js` · `CloudShadow` + `CLOUD_SHADOW_GLSL`：按接收点世界坐标沿 `sunDir` 求交云平面，采样图集 alpha 取 max；远层 `uCloudPuffsFar/24 + uCloudFarRatio=0.42` 走宽 ramp。
- `src/world/cloud-deck-layer.js` · `CloudDeckLayer`：三层云带，近/中喂 `CloudShadow`，远层单独弱档。
- 接收端（第 112 轮清点，四条全部在位）：
  1. 地形/建筑主材质 `view.js` `outgoingLight *= cloudShadowTone(vWPos)`（r108 就有）；
  2. 水面 `#setupWater` 片元 `col *= cloudShadowTone(vWorld)`（r109）；
  3. 植被 `vegetation.js` `swayMaterial` → `gl_FragColor.rgb *= cloudShadowTone(vCldW)`（r109 注入，r112 首次证明）；
  4. 倒影 `src/water/reflection.js` —— **r112 新接**：`makeReflectionMaterial({…, cloud})`，`Object.assign(uniforms, cloudShadow.uniforms)` 后再注入 `CLOUD_SHADOW_GLSL`；
     镜像网格 `scale.y=-1`，所以取样点写 `vCldW=vec3(w.x,-w.y,w.z)` 还原成原几何高度（否则会在水下方取到错误高度、恒 `c.y<=p.y` 判定失败）。
     `view.js`：`makeReflectionMaterial({…, cloud: this.cloudShadow.uniforms})`。
- **r109「植被已注入但差分恒 0」的真因是本轮查出来的**：不是着色器没接，是**夹具口径错** ——
  r109 的夹具把云片放在 deck 中心（y≈30 / 宽 90），而 `cloudShadowTone` 的取样点是 `p.xz + sunXZ*((c.y-p.y)/sun.y)`，
  对这个高度的云要沿太阳射线平移 ~36 世界单位，落点直接跑出云片 uv（`uv` 越界即 `continue`）→ cover 恒 0。
  本轮把云片压到被测物体正上方（y=+6 / 宽 80）后，植被 11838/11919 px（quad）、12300/12470 px（mixed）变暗，平均变暗 **0.333 / 0.327**（= strength 0.35）。
  同一测试里做了**反向对照**：把云片挪回 y=30 / 宽 90 → 变暗像素 **0**（`highCloudDark`），复现 r109 的现象，坐实「口径错不是机制缺」。
- 单位影子不接这份 uniform 的口径：`UnitShadowBatch` 画的是**遮挡贴片**（alpha 混合的暗盘），不是受光面，
  且本片（"Some moody clouds"）全 489 帧无任何单位，只有小镇 + 云 → 不再作为本片缺口。
- 仍属**声明过的近似**（非缺口）：本仓是「沿太阳射线求交 + 图集软斑」，原作是逐层烘焙，云影与云体的一一对应是近似；
  片子里本来也量不到硬对应（见逐帧观察）。
