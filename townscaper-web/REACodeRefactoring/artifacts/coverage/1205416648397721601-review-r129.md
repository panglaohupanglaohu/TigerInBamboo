- 原文：New prop placement system! It tries to place as many props as it can without overlap. I use it for doors and windows too, which means they are no longer skewed when placed on skewed tiles, which means skewed tiles now look less awkward.

## 逐帧观察

- **0000–0030**：空岛起步，右侧常驻色板列（绿 / 蓝 / 红 / 黄四档 + 灰）；岛心一栋绿顶小屋，镜头缓降。
- **0030–0060**：房屋沿格生长成排屋，墙色在 绿 → 蓝 → 黄 → 红 之间逐栋切换；镜头持续下降靠近。
- **0060–0100**：彩色排屋群形成，出现一座红塔；右侧露出一层灰色码头平台（后院所在的那一层）。
- **0100–0140**：镜头越过塔身，露出被墙四面围合的**后院/露台**（灰色石板地），光标在墙上点选编辑。
- **0140–0190**（3× 原尺寸 frame-0180 看清）：后院地面上是**沿墙一列长凳**、**一张圆桌 + 四把椅子**、一只红色花盆、两丛灌木、一盏灯；道具都落在格内的浅色地块上，**彼此不叠压、也不插进墙里**。窗框在斜着的红墙 / 绿墙上仍是**竖边竖直的正矩形**（不是跟着墙倾斜的平行四边形）。
- **0190–0260**：换角度继续加层，院落变成明显的**歪斜梯形**（格子被拉斜）；门窗依旧正矩形（frame-0250 的斜墙两扇窗、右下红墙三扇窗都是正框）。结尾 0260 全岛收束。

## 判定

有机制，两件，都在同一句配文里：

1. **尽量多放 + 互不重叠**的道具放置器（凸格内贪心 + 占位矩形不重叠）；
2. **门窗复用同一套放置器** → 在**斜格（skewed tiles）**上框仍是正矩形，不跟着格子歪。

## 代码落点与差距

- `src/core/opening-footprint.js#placeProps`（凸格内随机贪心 + `propOverlap` SAT 不重叠 + `frame:'std'` 刚性正框 + `obstacles` 预占 + `coverage/rejectedEdge/rejectedOverlap/frameDevMax` 台账）、`openingFootprint`（门窗用同一套，含 1.6× 窗台外缘）。
- `src/build/buildings.js:589–604`：`world.yardProps` 把 `placeProps` 接到**真实后院格**（`c.pts` 就是形变后的格多边形），树冠先占位；`opening()`/`tryPlace()` 用同一套逻辑排门窗（同层排斥 + 拐角余量）。
- `src/build/yard-prop-art-r56.js`：按同一 footprint 换画法（桌 / 木箱 / 盆栽）。
- `openings-r56.html`：`flags=yardProps,yardPropArt` 开关；**本轮新增只读探针 `window.r56propProbe()`**（不读 build 日志：直接拿 footprint 逐对 SAT、逐角量到格边余量、量格歪斜角与框的直角偏差；再只改 `yardPropTries` 重跑同一 World 量饱和曲线；门窗量「框水平边与墙边夹角」并给两个反向对照）。

**如实口径（造型差，不计缺口）**：① 原片道具是长凳 / 椅子 / 灯 / 花盆，本仓是木箱 / 桌 / 盆栽（程序化替代，原版道具美术未迁）；② 本仓 town 场景后院只有 5 格，道具落在草坪块上，没有原片那种「沿墙一长排长凳」的成排感；③ 杯子大小的椅子没做。
