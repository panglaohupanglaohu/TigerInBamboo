## 逐帧观察

- **0000–0100**：固定机位、只有很小的下降/右移。红砖多层塔群立在一块浅色地台上：左端粉色塔、右端青色塔、中间一栋黄色小塔（三色附属体块），每层砖塔**顶面是平的挑台**，临空边有矮墙/栏杆，屋檐下一道白色腰线；塔身开着双扇小窗（白框），旁边有两道**外挂石阶**从地台爬上一层挑台。水面倒影可见。
- **0100–0200**：结构在被编辑——右侧青塔加高一层、左侧粉塔加顶盖，中间塔的挑台向右伸出一块木面平台。镜头持续小角度右移，**没有任何生物群**；紫色球簇（左上、右侧屋顶）始终长在**树干上**（4× 裁切：球簇下有柱状树干、球体大小分层），随楼体一同出现/消失，整段不位移。
- **0200–0300**：塔长到 5 层，出现跨楼木梯与拱形门洞、白门；地台边缘与挑台边缘的白色栏杆带随楼层增多而增多；青色塔被替换成粉色塔，地台加了一圈石砌护岸。
- **0300–0343**：最终形态= 5 层砖塔 + 两段外阶 + 三个彩色附属体块 + 若干树。无点群、无移动小点、无 UI。

## 判定

- **「群体寻路」前提撤销**：原文那句是作者的猜测（"could possibly be crabs"），片中紫球是**树冠**（有树干、叶簇分层、随楼体增删、全程不位移）。r56 据此建的 `life/crab-swarm.js` 属本仓扩展，不该再记成该片的缺口。
- 真实机制：多层砖塔的**平挑台 + 临空边栏杆**逐层出现、外挂石阶连层、拱洞门、三色附属体块。

## 代码落点与差距

- `src/build/buildings.js`：栏杆只在 `h === 1` 的地面院落收集（`railings.push` 位于 `runTop && lv === h && h === 1` 分支内），绘制段 `const y = L` 固定在一层高 → **多层挑台的临空边没有栏杆**，与片内「每层平台都有栏杆」不符。
- 屋顶系统（`buildRoofs`）只出坡顶/山墙，**没有平屋顶平台**这一档 → 片中的平挑台（每层砖塔顶面）在本仓无法表达。
- 试验过一条改法（在 `runTop && lv < h` 的挑台处按 `tops[nb] < lv` 补栏杆 + 加只读 `railings` 账）：`?multitile=3&mth=6` 塔夹具只出 **1** 条（level 2），开/关像 **0 px** —— 因为塔柱是实心、几乎没有挑台，改法的覆盖面在夹具里量不出来，无法据此断言落地 → **改码与试跑测试已回滚**（`git checkout src/build/buildings.js`，临时测试文件已撤），仓库默认行为未变。

## 验证

- `index.html?grid=mixed&multitile=3&mth=6` 与 `grid=quad`：塔 22 格 / 75 体素 / 跳过 3（列 25）/ 最高 7 层（含 2 层岩台）；`worldMesh.build` 报告 `railings 1（level 2）`、`openings 152`、`facadeRuns 0`；0 console error。
- 截图：`/tmp/probe-tower-mixed.png`、`/tmp/probe-tower-quad.png`（ViewImage 看过；塔为灰泥 + 橙坡顶，仅在低层挑台看到 1 段栏杆）。
- 试跑 `tests/multistory-terrace-railing-browser.cjs`（本轮临时新增，已撤）：mixed/quad 均 FAIL —— `upper=1`、`diffPx=0`、同状态噪声 0（时间轴已冻）；即「改法在真实塔夹具上无可观测效果」。
- 结论：**仍 partial**。缺的是「多层平挑台 + 逐层临空栏杆」这一层形制（要动屋顶系统，出平顶平台档），不是缺验收。
