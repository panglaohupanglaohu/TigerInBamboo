- 原文（README 第 14 行）："A fluffy cloud shader. It is using the same impostors as the trees"。
- 片子机制（235 帧联系表 sheet-00..02 复看，原尺寸回看 150）：球面小世界四周一圈厚白云；云是菜花状鼓包、底部灰蓝；前景大云遮住半边画面，远处云带贴着地平线，树梢上有小云团；镜头拉近/平移。
- 原缺：原蓬松云形、前景云层次（以及共享 ImpostorField 只认世界 +Y，云和树都放不到球面上）。
- 本轮：
  - `src/life/impostor-c09.js`：`localUpImpostorField()` 用共享 `ImpostorField` 建材质，再把顶点着色器的"上方/方位/俯仰"三处换成实例自己的坐标系（instanceMatrix 的 Y 列 = 径向）；球面云不沿世界 X 漂。`fluffyCloudGeometry()`：9 个大鼓包 × 3 个小鼓包（共 36 球）的菜花云，平底，光照和"底部灰蓝 → 顶部暖白"烘进顶点色；`useUnlitVertexColors(baker)` 让共享 Baker 用无光照顶点色材质烘（不然 Lambert 会把顶点色照成全白）；`bakedColor` 片元改写直接用烘出来的颜色。
  - 云和树走**同一个** `ImpostorBaker`、同一张 2048² 图集、同一个 `ImpostorField` 类（"same impostors as the trees"）。
  - 新页 `impostor-planet-c09.html`：程序化星球（worldmap.js 的 3D 噪声海陆），三层云：远处云带（R×1.075）、树梢小云（R×1.06）、镜头前下方的前景大云（R×1.12，`front=N`）。
  - 共享 `impostor.js` / `atlas.js` 没改，默认画面不变。
- 测试：tests/c09-life.mjs PASS（另跑 atlas / atlas-crossleaf / rectpack-compat / impostor-pitch / impostor-bend / uv-bake 均 PASS；全量 302 个 tests/*.mjs 全部通过）。断言：改写后的着色器含局部上方、不含 parentYaw；云底偏蓝更暗（b/r 与亮度对比）；云底压平；落点确定性。
