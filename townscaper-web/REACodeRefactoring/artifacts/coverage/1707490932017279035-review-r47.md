## 逐帧观察
- 0000–0014（0–1.4s）：贴近台地崖边的近景巡览。崖壁分三段：上沿一条粉橙色斑点带（灌木）、中间土黄色岩层、底部灰绿草面。斑点带是**贴图**，边缘吃进岩层的法线明暗里，没有任何独立草丛的剪影或投影。
- 0015–0027（1.5–2.7s）：镜头拉远，整岛白模+崖边灌木带一起入画；带子沿崖沿断开（低洼处没有），断开处的岩层颜色完整。
- 0028–0057：绕着岛转，灌木带始终贴在同一高度带上，随崖线起伏，没有一个个凸出的球簇。
- 0058–0099：继续转到大俯角，带子在最外侧崖沿消失，草面与岩层直接相接。

## 判定
有机制：崖边灌木是**纯纹理**（顶点 aEdge 沿崖沿衰减 → 着色器里叠带/扇贝齿/内侧小阴影），不是实例化草丛。这与 r46 的实现口径一致。

## 代码落点与差距
- `src/terrain/shrub-texture.js`（`shrubApply` / `SHRUB_LAYER_FRAG`）· `src/terrain/terrainmesh.js`（`aEdge` 顶点属性）· `src/world/view.js`（`uShrub` + `onBeforeCompile` 注入 `color_fragment`）· 入口 `index.html?scene=terrain&on=shrubtex`。
- 做到哪：`aEdge` 顶面崖沿 0 / 格心 1，着色器按 `vEdge<0.999` 出灌木带、带内做簇状断开与内侧压暗。
- 缺：原片灌木带在崖壁上是**竖向分层的三档色**（粉橙 / 土黄 / 灰绿），本仓只有一档斑点带；带宽不随崖高变化（原片高崖带宽），且不带投影。
