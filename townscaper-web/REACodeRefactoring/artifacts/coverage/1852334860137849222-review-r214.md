# 1852334860137849222 · r214 残差补全（裁判云风材质 + 前景深度层 + 蓬松云烘焙）

## 原文
"A fluffy cloud shader. It is using the same impostors as the trees, in case that isn't obvious."
画面（r56 已核，235 帧）：星球四周一圈菜花状厚白云，底部灰蓝；前景大云遮半屏、远处云带贴地平线、树梢小云。

## 旧残差 → 本轮落点
- 「完整风材质未复现」→ REACode `engine/impostor.js` 顶点着色器的云起伏（`uWindAmt` 树 0 / 云 0.6，相位 `ph = centre.x*0.13 + centre.z*0.17`，三轴异频 sin·0.11 / sin·0.15 / cos·0.09，幅度 y×0.25、z×0.6）函数化移植到 `src/core/cloud-motion.js`（`cloudWindBob` CPU 镜像 + `CLOUD_WIND_BOB_GLSL` + `CLOUD_WIND_AMT`），`ImpostorField` 新 uniform `uWindAmt`（默认 0，零侵入），CLOUD 非 HORIZON 分支接入 `center += cloudWindBob(uTime, im[3].xyz, uWindAmt) / cd`。
- 「前景云层次仍缺」→ `ImpostorField` 新 uniform `uCloudParallax`（默认 0）：`cd = mix(1, max(1,aCloudDepth), uCloudParallax)`，漂移与起伏同除 cd（与 clouddeck `v∝1/depth` 同口径）。`vegetation` 近云按离岛心半径 `nearCloudDepth(r,R)` 分层（内缘 1 → 外缘 1.8），一团一深度。
- 「原蓬松云形未复现」→ 近云 `cloudField` 换 `impostor-c09.js` 的 `fluffyCloudGeometry(7)`（菜花鼓包、平底、顶点色烘灰蓝底/暖白顶，`useUnlitVertexColors` 防 Lambert 二次光照，`patchBakedCloudColor` 片元直用烘焙色）。远景阴云仍共用旧 `cloudGeometry`。原片真实云形为美术资产（卡点·B），此为更贴近的程序近似。
- `light/cloud-shadow.js` CPU 镜像同步：puff 位置同除 cd 并加 bob，定点迭代可解（|∂bob/∂p|≈0.06 收缩）。
- `impostor-c09.js` 锚点 DRIFT_SRC 更新覆盖新两行位移（球面云仍无世界轴漂/起伏）。
