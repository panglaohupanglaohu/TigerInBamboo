- 0050–0080：回到正常。
- 0081–0089：再一次只看贴图。
- 0090–0146：正常。
- 0147–0162：**只看光照**。整座城变白模：没有瓦片/砖缝/配色，但檐下、拱洞里、塔身侧面层次分明，影子与 AO 都在（原尺寸 frame-0155）。
- 0163–0174：正常。
- 0175–0188：只看光照。

即：先示范 texture-only，再示范 light-only，两者与正常模式交替，每种各出现 3 次左右。

## 判定

有机制，而且是**两个正交视图**：
- texture-only = albedo（贴图 + 顶点色）直接当结果，丢掉一切光照；
- light-only = 丢掉 albedo 变白模，保留光照 / 投影 / AO。
片中两种都不是"调低某个强度"，而是整条光照链被短路（texture-only）或整层颜色被抽掉（light-only）。

## 代码落点与差距

- `src/world/view.js`：原本只有 `case 'lightonly'`（`material.vertexColors=false` + 材质色改暖白），texture-only 完全没有；且两者都不在任何面板里，只能代码里调，等于不可发现。
- 本轮改：
  - 新增 `textureOnlyOn` uniform，注入 `#include <opaque_fragment>` 前一行 `if(uTextureOnly>.5) outgoingLight=diffuseColor.rgb;` —— albedo 直接出屏，光照/投影全部短路；
  - `case 'textureonly'` / `case 'lightonly'` 互斥（开一个自动关另一个），并记录 `lightOnlyOn` / `textureOnlyOn` 状态；
  - `src/ui/environment-panel.js` 把「柔和投影 / 只看光照 / 只看贴图」三个开关放进场景面板，`sync()` 里补上真实状态映射。
- 仍缺：texture-only 只对共用的 town 材质生效，树/海鸥/水面影子接收层还是照常吃光（掩码内仍有 13.9% 像素随投影变化）；light-only 下灯塔灯室、植被也没跟着变白模（所以主体饱和度掉到 0.208 而不是 0）。
