## 逐帧观察

画面是左「青绿场景视图」+ 右「深色 Unity Inspector」的两栏结构，全程无镜头运动。

- **0000–0019（0.0–0.9s）**：左栏停着 Toggle 按钮与一块白底 "Moving!" 标签（y≈267），另有一个 10px 小白方块停在下方（y≈527）。右栏从上到下是 RectTransform / Canvas Renderer / Image / Shadow 与四个脚本块：
  `Float Select Node`（On False **226.9** / On True **−33.8** / Condition ☐ / Output **226.9**）、
  `Float Lerp Towards Node`（Target 226.9 / Speed **20** / Output **226.9**）、
  `Vector 2 Compose Node`（In 0 **−5** / In 1 226.9 / Output X −5 Y **226.9**）、
  `Vector 2 Event Node`（UnityEvent → `RectTransform.anchoredPosition`）。
  四个脚本块之间用**弧形连线**画出了端口连接（输出圆点 → 输入字段），这是原片里最像"节点图"的东西。
- **0020–0039（0.9–1.7s）**：光标点到 Toggle。Condition 由 ☐ 变 ✓，Select Output 跳到 −33.8；Lerp Output 不再是整数，出现 **−32.17935** 这类中间值，逐帧朝目标单调逼近；白方块同步上移到 y≈267，白标签反向落到 y≈527。位移量 **≈260px = 226.9 −(−33.8)**，与 Select 的两档取值严格对得上。
- **0040–0054（1.7–2.3s）**：Toggle 被再点一次，Condition 回 ☐，Select Output 回到 226.9；Lerp Output 此刻读到 **189.6505**（正从 −33.8 往回走），说明**回程同样逐帧逼近**，没有瞬移。
- **0055–0089（2.4–3.8s）**：再次点上，Condition ✓，约到 0072 时 Lerp/Compose 都稳定在 **−33.8**（stall 住，不冲过、不回弹），两块白元素各停在另一端。
- **0090–0129（3.9–4.8s）**：画面基本静止，Inspector 数值不动（settled 状态），鼠标在面板上停留。
- **0130–0133（4.9–5.9s）**：收尾又切回 ☐，Select/Lerp/Compose 全部回 **226.9**，两块白元素回到起始两端。

要点：整条链的语义是「bool 资产 → 两档常量里选一个 → 每帧限速逼近 → 拼成 Vector2 → UnityEvent 写回 anchoredPosition」，且**中间每一站的数值都在 Inspector 里实时显示**；动画之所以"慢半拍"，就是 LerpTowards 的 Speed 20 在起作用，而不是 UI 动画曲线。

## 判定

**有机制**：节点式数据绑定（bool 资产 / FloatSelect / FloatLerpTowards / Vector2Compose / Vector2Event）。原片展示的是**Inspector 形态**的节点链（组件 + 端口连线），不是图形化节点画布 —— 画布形态是本地等价物。

## 代码落点与差距

- `src/core/node-graph-runtime.js`：端口 + 有向边、拓扑序求值、`lerpTowards` 每帧最多走 `speed·dt`、`sink` 只在值变化时回调、`serialize/fromJSON/NODE_REGISTRY`。
- `src/core/node-graph-editor.js`（模型）：`move / connect / disconnect / add / remove / parameter / undo / redo / snapshot / load`，每次编辑走「快照 → 校验 → 整体重载」的事务，拒绝时旧图不变。
- `src/ui/node-graph-editor.js` + `node-editor.html`（画布）：`pointerdown` 抓标题移动 / 抓输出圆点拉线 / 点连线删除 / 参数表单 / 撤销重做 / 导出载入 / 运行预览。
- `node-graph.html`：原链对照页（每帧重画的连线图 + Inspector 读数）。

**本轮核实结论（r61 记的缺口已过期）**：`next` / `note` 里写的「仍缺可拖拽的真实节点编辑器」，在 r61 之后已被补上 —— `node-editor.html` 与 `src/core/node-graph-editor.js` 都在（2025-11-12），且模型层有 `tests/node-graph-editor.mjs`。缺的**不是机制，而是「真的用鼠标拖过一遍」的运行验收**：此前没有任何测试驱动过指针事件，`move/connect/disconnect` 只在 node 里被直接调用过。
