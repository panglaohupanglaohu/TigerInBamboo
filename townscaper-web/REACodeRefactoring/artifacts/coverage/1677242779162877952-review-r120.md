## 判定

有机制：**增量插点的通用三角图 + 流形/近似 Delaunay 压力测试**（每加一点改动的边短暂染色，外轮廓随之扩展）。画面**不能**证明严格 Delaunay、无重叠、无孔洞（原文只说 "delauney-ish"、"making sure the graph stays manifold"，画面只有线框），这一条按原样记在口径里，不当作缺口。

## 代码落点与差距

- `src/core/trigraph.js`：Bowyer–Watson 增量插点（`add`，坏输入/重复点/域外点拒绝且不占序号）+ `locate / edgeMap / clone / flip / legalize / check(Infinity)`。
- `src/core/trigraph-edit-c08.js`（本轮核实的关键一条）：**「局部编辑接口」就在这里** —— `addTracked`（插点并返回新增/删除边差分）、`removeVertex`（取星形环 → 耳切重三角 → Lawson 合法化）、`moveVertex`（删+插，失败用 `clone` 回滚）、`checkLive`（把已删点排除后的同口径流形/Delaunay 体检）。
- 页面入口：`trigraph-c08.html`（`?steps=N` 预插 N 点、`?edit=del|move` 直达编辑态；改动边绿→黄→青淡出，每 10 步全图复检；`window.trigraphC08` 暴露 `step/edits/hot/audit`）。旧的 `trigraph.html` 只做「加 25 点 + 坏输入拒绝」，不承载局部编辑。
- **差距（note 过期项）**：`note` 里挂的「局部编辑接口待补」在 r56 C08 就已补上（文件头直接署本片 ID），但 `learn/data.js` 的 `implementationVerified / runtimeAccepted` 一直是旧值、证据文件末尾也只写了一句「判 done」而没有可复核的运行断言。本轮把它补成可复核的：页面读数 + 新浏览器验收。
- 仍然成立的口径（不是缺口）：本仓检查是**浮点外接圆容差**诊断，不是精确谓词；「外轮廓几乎不动」的原注释不采用（本片轮廓明明在扩）。
