- 原文：However, if you are more careful in providing structural support you'll get curvy brick arches instead and you can build these neat airy cathedral structures

## 逐帧观察
- 0000–0012：一座实心绿砖方楼 + 橙瓦屋顶，立在蓝色水面/空底上，镜头缓推。楼底只有墙角、没有开口。
- 0013–0035：**楼底那条边的墙被"抬开"了**：从两侧支撑之间空出一条圆头洞口，洞口下方直通到底，上方仍是实心绿墙 + 屋顶（拱肩）。这一下是"多了支撑 → 变成拱"，不是"挖了个门洞"：洞口顶是一条连续平滑的曲线，两侧脚正好落在相邻体块上。
- 0036–0075：同一座楼再补支撑，多出第二、第三条拱；拱脚处仍是实心墩。3× 放大（/tmp 临时图，源自 frame-0060）能看到**拱圈上有一圈圈跟着曲线走的砖缝**，拱腹比外墙面暗一档。
- 0076–0199：体块被反复加减，只要两侧对边都有支撑就出拱，缺一侧就退回平底 + 钢架（片子里能看到细钢柱）。
- 0200–0359：越搭越高，出现"细柱 + 拱"的飞扶壁式结构：柱顶之间连拱，拱上再压一层墙和屋顶，整体镂空、通透（作者说的 airy cathedral）。
- 0360–0446：镜头拉远，成片的拱廊；拱的高度与跨度大致成 0.6–0.7，比半圆更扁一些，拱圈砖色与墙同色。

## 判定
有机制：**支撑决定底面形态**。格子悬空时，如果它下面一层的"对边两侧"都有实心支撑，就把这块底面做成跨在两侧之间的拱（拱腹曲线 + 上方拱肩墙保留 + 拱脚落在两侧体块上）；只有一侧或没有支撑，就退回平底 + 钢架。拱是"结构性后果"，不是贴片装饰。

## 代码落点与差距
- `src/build/buildings.js` · `underside(c, lv, wall)`：取 `axis = [0,1].find(i => solid(nbr(i), below) && solid(nbr(i+2), below))` —— 只在**四边格**上、且**对边两侧**下一层都实心时才做拱（三角格无对边 → 平底 + 钢架），与片子的触发条件一致。
- `src/core/arch-floor-budget.js`：`crown = base - slab`、`rise = min(0.75*(base-floor), 0.8*storey, crown-floor)`、`spring = crown - rise`。
- `src/core/arch-profile.js`：`archProfile(span, rise, {tolerance})` 生成椭圆拱（x = -span/2·cos t, y = rise·sin t），按弦高误差自适应分段（误差 ≤ tolerance），`archClearance()` 给净空查询。
- 实测（arches.html，桥洞示例）：`archCount 1`、`archSegments 16`、`archBudgets = [{level 4, base 1.5, floor 0.5, crown 1.45, rise 0.4, spring 1.05, slab 0.05}]` → 跨度约 1.0 时 rise/span = 0.40，与片子目测的 0.6–0.7 倍跨高（含直腿）同量级；跨底 0.95 高（floor 0.5 → crown 1.45）可通行。
- 差距：① 片子拱圈上有**跟着曲线走的砖缝**（一轮轮砖），本仓拱腹是一整片 `wall × 0.72` 的纯色、没有砖缝；② 片子拱更扁更宽（开口高/宽 ≈ 0.65），本仓开口比接近 0.95（直腿段更长）；③ 片子有"细柱顶连拱"的柱廊/飞扶壁，本仓只按格算底面，柱是 `postSeen` 的钢柱，没有砖柱 + 柱头 + 多跨连续拱；④ 拱高预算受层高/楼板限制，`0.8*storey` 这一项在层高很矮时会把拱压得很扁，且没有做碰撞/导航复验（页面写明"未改变导航碰撞"）。
