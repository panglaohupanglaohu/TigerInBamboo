## 判定

有机制：**指挥官能力键（三颗圆钮）+ 选中态（黄圈 + 上方名牌）+ 非法目标提示（顶部黑条）**。
片里没拍落地过程，故「跃击本体」按本仓可实现口径近似（跃起 → 落地白环 → 范围伤害），不冒充原版数值。

## 代码落点与差距

机制早在 `src/badnorth/battle-c03.js`（文件头署本片 ID，`C03_FLAGS` 里的 `plunge`）：

- `#ensureHud()`：三颗 58px 圆钮（SVG），`.cd` 冷却弧（`stroke-dasharray 169.6`）、`.hl` 高亮环、`.tag` 名牌；
  只有 Plunge 可点（Volley/Brace 为灰占位，`opacity .45`）；
- `arm()` / `castPlunge()`：`range 3.6` 内无敌人 → `#toast('No valid targets')` 且**不进冷却**；有 → 全队跃起
  （`c03Leap`，0.62–0.72 s）→ 落地白色冲击环 `ringGeo` + `b.applyHit()` 范围伤害；冷却 10 s；
- 页面入口早就在：环境面板 `c03 · 北境·玩法与演示` 下的「指挥官跃击」勾选框（`input[data-scene-control="plunge"]`），
  URL `?plunge=1` 同效；`?scene=badnorth` 主战场即生效。

**旧 note 的「能力系统（Plunge 本体/冷却环/非法目标提示）仍空白」是过期账（第 52 次同型）** —— 三件都在，缺的只是运行验收。
本轮核实后另补三处**真形制差**（片内一眼可数）：

1. 名牌原来常驻在钮**下方**；片里是挂在亮键**上方**并带朝下小三角指针，且另两颗钮没有牌 → 改 `column-reverse` + 牌默认隐藏、`armed` 时才显示；
2. 亮键没有**黄色高亮环**（原来只靠冷却弧变白来暗示选中）→ 补 `.hl` 圆环（r 27.5 / `#ffd34d` / 3px），`armed` 时 opacity 1；
3. 「No valid targets」原来只在**点地面**时才提示；片里黑条与黄圈**同帧**出现 → `arm()` 里就地校验
   （`plungeHasTargets()`，与 `castPlunge` 同口径 `range 3.6`），无目标即出条并计 `stats.noTargets`。

另加两处稳健性：能力条容器 `pointer-events:none`（只有可点的键收事件，不再吞掉页脚工具条点击）、
`bottom 18px → 72px`（本仓 `index.html` 页脚本来有一条白色工具条，压在它上面会读不清也挡点击）。
