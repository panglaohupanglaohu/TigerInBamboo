## 代码落点与差距
- 落点：`src/terrain/shrub-texture.js`（`uShrubStyle.x` = 带宽）、`src/world/view-c11-shrubband.js`（`?c11=shrubband`，
  `width = (.13 + .06*bfm) * cover`）、`shrub.html`。
- 本轮新量（新工具 `tools/shrub-band-measure.py`：局部对比度而非全局色阈 —— `R>=195 & R-G>=50` 且 2px 内有强梯度，
  厚度取四方向游程最小值，避免近水平台沿把带量成一条长条）：
  - frame-0100 带宽 P50 2px / P90 4px / 均值 2.47px，带像素占画幅 1.84%
  - frame-0250 P50 3 / P90 4 · frame-0420 P50 2 / P90 3 · frame-0560 P50 3 / P90 5
  - 同片等距格顶点间距（FFT 基频，`--lattice`）：**26.6px**（257 片同法 30.4px，两片缩放不同）
- 差距：带宽 ≈ 2–3px / 26.6px ≈ **0.08–0.11 个顶点间距**；现实现 0.13–0.19 世界单位（若顶点间距 = 1 世界单位 → 约 2× 偏宽）。
  「顶点间距 = 一格」仍未证死（扇形三角化的角点/格心交替会让 FFT 周期落在 0.707 格），故本轮不改码。
- 另一条硬约束：改带宽要连动 `meshwriter.triC` + `shrub-band` / `shrub-wide-band` / `shrub-cliff-drape` 三条回归，须独占一轮。
