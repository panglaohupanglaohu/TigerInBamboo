## 判定

有机制：① 显式**半边**结构（next / prev / twin 遍历）；② 用半边追出「剩余区域」的**边界环**（片里那些彩色描线）；③ 顶点**扇**；④ 把剩余区域用**三角网**填满（间隙 Delaunay + 约束边）；⑤ 对已经成形的网格做**局部编辑**（把四边格切成两个三角）。

## 代码落点与差距

- `src/core/halfedge.js`：`buildHalfEdge(cells)` 在任意多边形格集合上建 `{origin,dest,cell,next,prev,twin}`（边界 twin=-1），并给 `boundaryLoops`（沿边界半边串环）、`vertexFan(v)`（绕顶点出边扇）、`euler`；`checkHalfEdge` 校验 next/prev 成环互逆、twin 互反、扇覆盖全部出边；`splitQuads(cells,{share,seed})` = **局部编辑**（四边格沿对角线切两个三角，角点对象共享）。
- `src/core/halfedge-patch-c08.js`（文件头直接署本片 ID）：`scatterGroups`（圆内撒旋转方格块，互不重叠留缝）→ `fillGaps`（方格顶点 + 间隙抖点 → `TriGraph` Delaunay → Sloan 式强制翻边把块轮廓插成约束边）→ `gapLoops`（**只用间隙三角**建半边，`boundaryLoops` 就是片里的彩色环）→ `fullMesh`（方格 + 三角合成一张网格，应单边界环、Euler=1）。
- 页面入口 `halfedge-c08.html`：`?t=` 分阶段（0 撒块 → 1 追环 → 2 填三角 → 3 合成网格）；本轮新增 **「切四边形」按钮 + `?split=<share>`**，把 `splitQuads` 这条编辑接口从「模块里有」变成「页面上能跑、有读数」：切完重建半边并报 半边数 / 边界环 / Euler / 一致性错误 / 面积 Δ，`window.halfedgeC08` 一并暴露 `splitCells / splitEdges / splitEuler / splitLoops / splitErrors / splitAreaDelta`。
- **差距（note 过期项）**：note 里的「显式半边环/扇及编辑接口待补」三项**全在**（环/扇在 `halfedge.js`，编辑接口是 `splitQuads`，页面此前没入口、`data.js` 也还是 `implementationVerified:false / runtimeAccepted:false`）。本轮补页面入口 + 运行验收。
- 口径差（不是缺口）：原片把相邻方块组的轮廓并进同一条环、并给不同环不同颜色；本仓 `gapLoops` 追的是「间隙三角网的边界」，得到「圆 1 条 + 各块轮廓 13 条 = 14 条」，颜色按环序号轮转。语义相同（每个未被占住的区域一圈），只是环的合并粒度/配色规则不同。
- 仍然成立的口径：从画面不能推断「彩边 = 具体哪条半边指令」，本仓只按「结构 + 可校验量」对齐，不冒充逐指令复刻。
