## 判定

**有机制**：
1. 三态时间线（点 earliest → 线框 → 实体，逐格独立），已由 `previewState` 实现（r61 核过，本轮不重复改）；
2. 材质 = **每 bandHeight 层换一档色槽**，色相段间连续漂移（外表面灰青 H156–208°、S12–16%）；
3. **房间内墙是暖玫瑰色**（只有透过门洞/进到里面才看得见）——旧 note 的「内部玫瑰墙（H≈355°）没建模」就是这一条。

## 代码落点与差距

- 旧的 `LAYER_PALETTE` + `layerMaterials(bandHeight:3)` 保留（r97 已按原片逐段色相标定，本轮不动常数）。
- 新增 `cavityCells(voxels)`：从包围盒外泛洪，剩下的空格 = **完全封死**的空腔（演示模型的塔身空腔 18 格）。
- 新增 `interiorFaces(voxels,{reach:16})`：**房间墙**判据 —— 沿格面法线（+x / +z）逐格步进，穿过 ≥1 格空气后在 reach 格内撞到实体 ⇒ 这个面就是「对面有墙」的房间内壁，上 `INTERIOR_TONE`（`#e3cad7`，按 0110–0130 帧取样）。演示体量上判出 **134 面**（+x 96 / +z 38）。
- `voxel-ghost.html`：`?interior=0` 关档 A/B；HUD 显示「内腔 N 格 / 内墙 M 面」。
- **踩过的坑（写清楚，别下次再踩）**：第一版画的是**背面**（−x / −z）——背面永远背对机位，内腔开/关像素差只有 5px，等于没画。透过门洞看到的墙法线是**朝着机位**的（+x / +z）。第二版改用「封闭腔 / 凹龛（≥4 面被围）」也不行：片子里房间通着门洞，泛洪能到；演示体量又是一整间大开间，中心格六面全空。只有「对面有墙」这条射线判据同时成立。另外 `reach` 一开始给 8，演示体量进深 14 格，−z 墙那侧全漏（134 → 只判出 12 面）。
- **还缺**：内墙是单色，原片是随进深变化的室内反射光（有梯度）；层带边界的实测值仍量不出（1× 与 2× 上带界都被光照抹平），bandHeight 保持 3 层不变；露台灌木/花盆属植被资产。
