- 0020–0040：人群整体成**一条有头有尾的宽带**沿下层台地向右流，前端已上坡，尾端还在原地；带子边缘不是直线。

## 判定

有机制。机制 = **在导航面（凸多边形）内连续的流向场** + 群体分离；片中关键判据有三条：
①同一时刻各人方向平滑（不是逐格 8 向）；②过面 / 过坡时流向不跳，所以队形是带宽连续变化的弧带；
③只在坡道 / 台阶口换层。

## 代码落点与差距

落点：`src/world/navmesh-flow.js`（`buildVertexField` 顶点多源 Dijkstra、`flowAt`、`stepCrowd`、`moveOnMesh`）、
实验页 `navmesh-flow.html`。

本轮补的缺口（第 47 轮新发现）：「流向是逐面常量 → 过共面边整段换向，队伍有折线感」。
实现 **共边带混合**：`buildFaceDirs()` 预算每面单位流向；`flowAt(..., fd)` 在距共享边 `band=0.35`
以内把邻面方向按 `0.5·(1-d/band)` 混进来，两侧到边时同为 `0.5·(d_p+d_q)` → 过边连续；
崖边（`nb = -1`）与面心（`d ≥ band`）保持逐面精确。

**走过的死路（重要）**：先做了「顶点梯度（面积加权 + Laplacian）+ 均值坐标插值」，跨面差确实做到 **0.000°**，
但临崖顶点把「顺着墙拐向坡口」的切向分量平均掉了 —— 崖脚 100 人里卡 1 人，`x` 顶在 7.000、`vz≈0.015`，
40s 走不出（位置贴着 x=7 的崖边，插值方向 `[1, 0.01]` 直指崖体、切向≈0 → 沿边滑行无位移）。
加「一步走出导航面就退回逐面梯度」的退避分支也救不回来（贴着的是**已连通**的邻面边，不是崖边，探测不触发）。
结论：不能为了「跨面差为 0」牺牲崖壁处的切向，共边带混合是正解。

仍缺（写进 next）：
1. **未接进 `battle.js`**：主场景仍是 `badnorth/flowfield.js` 的格心多源 Dijkstra，导航面流场只在独立页跑；
2. 通口前视（给人群一个「先看到口子」的预瞄角）没有；
3. 导航面仍由 `navMeshFromTerraces` 的规则地形手搓，共享 World 的分层导航自动生成没接；
4. 片中 0478 抵达后收成方阵的「到位摊平」只是分离力自然结果，没有显式队形约束。
