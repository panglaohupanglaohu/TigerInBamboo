**本轮修掉的真缺陷（与 A 片同一处）**：`BLOTCH_RIM_GLSL` 的 `bleedMask` 少了「bleed>0」闸门 →
`bleed=0` 时 `smoothstep(0,0,below)` 退化成除零区间（GPU 钳成 1）→ **bleed=0 等于无限深**，与 CPU 相反，
这也是「bleed=0 与 bleed=20 逐像素相同」的根因。补 `step(1e-4,uBlotchRimQ.x)`，并在 `tests/blotch-atlas.mjs` 加 GLSL 文本断言。

**夹具修正**（r170 记的「怀疑共享材质」不成立，真因是坐标口径 + 探针位置）：
`readRenderTargetPixels` 第 0 行在下、NDC y=+1 在屏幕顶部（两处都要换算）；探针从「0.85 台地内侧」挪到扫出来的崖肩线（rimDist 0）。

**如实口径**：真实地形上 0.14 世界单位在 480×360 全景里约 2px，逐点采样读不出可信带宽（只作读数，未进断言）；
等深带的世界米读数由合成崖肩窄条（真 uniform + 真距离场）给出，真实地形用整帧阶梯与近景 A/B 作证。原片配色与反射未对，图集为程序化替身；0284–0287 的黑场是原片自身的版本切换，本仓不复现。
