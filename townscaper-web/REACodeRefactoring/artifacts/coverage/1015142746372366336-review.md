## 逐帧观察

- 0–99（0.00–4.95s）：固定机位俯视一座小镇，左中一栋烧黑的房子冒一股浓烟，右侧另一处屋顶冒第二股。烟柱整体向右上方飘、被风压成斜带；靠近烟源的一段是密的深灰团块，往上越来越散。
- 100–199（5.01–9.27s）：机位完全不动（前后帧背景逐像素一致），两股烟持续抬升。约 145–165 帧中间空档冒出一小股新烟并很快被并进主柱——说明是连续发射，不是分段重播。
- 200–299（9.33–13.59s）：构图不变，烟柱顶端已飘出画外半截；同一根柱子由十几团互相错开的小团叠成，团与团之间能看出深浅两层。
- 300–302（13.62–13.70s）：结尾与前面连续，无跳切、无 UI、无调试线框。

原尺寸（0150，4× 裁切）看清楚三件事：
1. **每团有一圈深色描边**：团块内部是中灰（约 sRGB 110–130），边缘一圈明显更暗（60–90），且这圈描边贴着不规则的凹凸轮廓走，不是方片直角。
2. **底部比顶部实**：烟源上方 10–20px 处近乎不透明（最暗采样到 (47,47,52)），到柱顶变成能透出天空的青灰薄纱。
3. **烟与楼体的遮挡关系正确**：近处的楼檐压在远处烟上，同一团烟在楼前楼后没有出现「远处烟盖住近处楼」的翻转。

量化（frame-0150 烟柱区，天空 lum≈155）：烟区 lum p5=104 / p25=116 / p50=149（含大量天空像素）；暗于 120 的像素占 29.3%，暗于 90 的只占 2.5% → 烟体主体 104–130，描边 60–90。

## 判定

**有机制**，而且原文写得非常具体：两遍绘制。第一遍纯黑、底部满 alpha；第二遍更浅、底部更透明、阈值往里收 1 像素 → 露出第一遍那一圈 → 形成「清楚的轮廓」。原文那句 "z-depth and draw order" 说明：两遍并不等于免排序，团与团之间仍要按相机深度从远到近画。

## 代码落点与差距

- `src/life/smoke.js`：两个 InstancedMesh（`back` = PASS 0 黑底遍、`front` = PASS 1 浅色遍），`renderOrder` 6/7 保证两遍先后；`#if PASS == 0/1` 两套 alpha；第二遍的 smoothstep 起点是 `px`（fwidth 一个像素）→ 内收一像素。
- `src/core/smoke-order.js`：`smokeDepthOrder()` 按 `viewMatrix` 第 3 行算相机空间深度，由远到近排，同深度按 `serial` 稳定；两遍共用同一排序、同一实例矩阵（`smoke-browser.cjs` 校验 `back.instanceMatrix` 与 `front` 逐元素相等）。
- `smoke.html`：真 World + 真 Smoke，可选两遍开关、UV 滚动、mip、网格类型。

**本轮改了什么（明度）**：原实现两遍颜色是 `0.08`（黑遍）与 `0.24→0.42`（浅遍），实测合成后烟区 lum 均值 **152.7**，几乎等于天空 155 → 烟柱成了比天空还亮的一团白雾，片中那种深灰烟柱 + 黑描边完全读不出来。按片中实测改成黑遍 `0.03`、浅遍 `0.10→0.22`（乘 0.9+0.2n），重测 lum 均值 **116.0**、p1=66（描边）、p50=120、p95=137，落在片中的 104–130 区间内；只留黑遍时 p1/p50=43.7/51.0，与片中最暗 47–52 一致。

**还缺什么**（如实记）：
- 轮廓仍然糊成一条光滑带。片子里一根烟柱能数出十几团各自凸出的凹凸团，本仓所有团沿同一条轨迹单调放大，联合轮廓就是一个放大的圆盘弧。本轮试过「每团横向漂移 + 每团尺寸抖动」，截图上看不出凹凸（见下），已回退，只保留明度修正。
- 阈值内收用的是 `fwidth` 导数近似，不是原文那种「精确一像素」；描边随视角变宽/变窄。
- 相交方片仍是透明体积近似，不是顺序无关透明。
