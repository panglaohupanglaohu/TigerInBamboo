## 观察与推断

- 9064：0–1.2 秒紫色多孔岩岛旋转，之后白色单位在中央平台和洞口附近活动，约 4.2 秒后的转向又露出另一侧洞口。洞口、平台与上层实体同时存在。视频能支持“多孔结构上导航”的目标，不能据此推断作者的具体数据结构。
- 7971：前约 2.3 秒模块从空台上逐步构建，2.4 秒后白色点状单位沿内部层与外侧路线移动；约 7–10 秒转动镜头能看到不同高度的活动点，约 14 秒后从另一角度继续展示。单一柱顶不足以表示这些活动位置。
- 8808：两支蓝色军旗小队被反复选择、交换目的地。约 10–13 秒的山间窄口与约 15–18 秒的阶梯通道尤其清楚，两队能交错通过。原文明确是左行；帧中 UI 高亮不应误读为导航算法本身。通道检测和偏移的具体公式是我们的实现选择。

## 原版与重构差距

- 原版 voxelnav.js 为规则 x/y/z 体素枚举节点，但其竖直空气邻接不能代替真实台阶转换，也把 y=0 无条件当作地面。原版 holenav / cheesenav 还有独立洞口与演示。
- 重构 navgraph.js 只保存每格一个地表高度，因此同柱的洞底与洞顶无法共存。
- 新 layerednav.js 直接读取共享 World，按每个实心层上方的净空枚举多层可站点，按任意多边形边邻接生成通道，验证台阶与净空，排除海面假地板。保留旧地表导航，避免改变现有战斗和楼梯接口。
- 原战斗“左行”对应的移动表达式偏移为 `0.0`，实际只有碰撞排斥。新增稳定左车道目标，并按目标多边形内切距离限制横向幅度。
- 流场此前绕过 navgraph 的楼梯限制；现在反向搜索复用实际导航边代价，也保留河流顺逆方向。

## 验收与边界

`tests/navigation.mjs` 验证洞内穿行、洞顶隔离、身高净空、封洞断路、双向台阶、无海面假节点、混合多边形、反向车道及有向流场。运行截图另存在本目录。

新增 `navigation.html` 提供同一 World 的多层 / 仅柱顶对照、两层身高开关、混合 / 四边形网格及路径动画。

尚未把北境战斗的所有单位高度、拾取与攻击接入多层图，也未重建任意预制模块内部的精细 portal。对应模块仍标为部分覆盖，不能宣称洞内战斗已全部完成。
