## 判定

**有机制**，且帧里的三件事都能对上：

1. **球极投影 + 按半径插入序**：点按「到极点的弧距」排序 = 原文的 sorted vertically → radially；
2. **平面 Delaunay（Bowyer–Watson）**：超级三角可见、逐点插入、中心密外圈薄；
3. **抬回球面 + 松弛重三角化**：收尾是闭合球网的平面展开（F=2n−4），松弛段与姊妹片 1338825080844021760 共用同一套快照。

中心暗面是**球体实体的遮挡**（不是空洞、也不是「极点处网格塌陷」），这一条是本轮按 r116/r117 的教训把关键帧放大到数得清笔画之后才定的 —— 缩略图里它长得像一个空洞。

## 代码落点与差距

- `src/sphere/planet-town.js`：`stereoProject` / `stereoUnproject`（极点 = +Y，r=cot(θ/2)）、`sphericalDelaunayViolations` / `flipToDelaunay`
- `src/sphere/stereo-insert-c06.js`：`projectionOrder` → `createInsertionReplay`（超级三角 bound=1.15·maxR、逐点 `TriGraph.add`）→ `liftToSphere`（平面三角 + 凸包连极点 = 闭合球网，并量 `roundTrip`）→ `relaxRetriangulate`（按三角形重心松弛 + 每轮整体重三角化，返回每轮改边数）
- 页面：`sphere-insert.html`（插入进度可拖、超级三角/半径/往返/改边全读数）、`planet.html?stage=tri` / `?stages=1`（真快照三阶段：随机点 → 散开 → 三角化按半径揭示 → 松弛 → 翻边修复）

**本轮真缺的只有一件**：**极点鲁棒性**。旧路径把极点固定成「最北点」、不做任何角距检查：

- 极点上有重合点时 `stereoProject` 直接 `RangeError`（1−p.y<1e-12）；
- 次北点离极点 1e-4 rad 时 r=cot(θ/2)≈2.0e4，超级三角 bound 跟着到 2.3e4，Bowyer–Watson 的「坏三角」判定退化成巨型薄三角。

## 本轮改动（第 118 轮）

`src/sphere/stereo-insert-c06.js` 新增 `poleGuard(points, {minSin, topK, mergeSin, maxTilt})`：

1. 极点仍优先取最北点；当它的最小角距 sinθ < `minSin`(1e-3) 时，在次北的 topK 个点里挑**角距最大的**当极点（限 tilt ≤ 0.7 rad，保住「vertical ≈ radial」的排序语义），并把坐标架转成极点朝 +Y —— `basisFor()` 构造 `z = x×axis`，保证 **det(R)=+1 是真旋转不镜像**（镜像会翻三角朝向，外接圆判据直接反）；
2. 落在极点方向上的、以及互相重合的点合并（`merged[]` 记 into/why），不参与三角化（否则退化成零面积三角）；
3. `liftToSphere` 用 `Rᵀ` 反旋后再比原点，所以 `roundTrip` 仍是同一个几何量；
4. `?minSin`/`?fat=1` 页面入口 + `window.sphereInsert.guard` 读数（`rotated / minSin / merged / maxR / bound`）。
