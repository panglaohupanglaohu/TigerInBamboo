## 逐帧观察

全片是一条**循环四遍的生成过程**，每遍「点点 → 从中心长格 → 满格 → 转白并细分 → 鼓成穹顶 → 淡出」，四遍分别落在 0000–0265、0266–0535、0536–0801、0802–1067。

- 0000：白线框 + 黄色顶点点的六边形满格（上一遍的终态被当成第 0 帧）。
- 0001–0049：镜头拉开，格子全没，只剩深底上一片很暗的顶点小点。
- 0049–0100：从一个很小的黄色菱形开始，逐圈向外长出方格，约 0090 铺满整个六边形。
- 0100–0150：整片黄色方格网（每格约 5–6px），格与格接缝略有错位、不是正交方格。
- 0150–0199：黄色逐片转白，同时画面出现透视——六边形变成一块「三面可见的箱体」，网格贴在前后左右面上，格数比上一段明显多（细分了一层）。
- 0200–0265：白网格继续加密，六边形外轮廓由直线变成微微外鼓的弧（像被吹起来），格子在鼓面处被拉大；0265 起整体淡出。
- 0266–0310：又只剩点点。
- 0315–0399：第二遍生长，仍是从中心黄色菱形起、逐圈外扩到满格。
- 0400–0440：满格后转白，右侧一小片保留黄色（选区/未松弛区的标记）。
- 0440–0535：白网格箱体细分，黄色片逐渐消失，0535 淡出。
- 0536–0582：点点。
- 0583–0700：第三遍生长→满格→0680 起转白。
- 0700–0801：白网格细分、格数继续涨，0801 淡出。
- 0802–0850：点点。
- 0851–0930：第四遍生长→满格（黄色）。
- 0930–0999：转白，右半先白左半后白。
- 1000–1067：白网格细分并鼓成穹顶状，片子在穹顶状态结束，没有回到点点。

## 判定

有机制，且是三重机制叠在一条时间线上：

1. **不规则三角网 → 合并成多边形**（底色格错位、"方又带六边形味道"就是合并后的菱形）；
2. **每个多边形细分/切分成四边形**（格数在转白时翻倍，正是"每个 n 边形 → n 个四边形"，多边形顶点处的价数就是原文 Todo 里说的 6 价顶点问题）；
3. **松弛成"相当均匀"的四边形**（格子在鼓面/边界处被拉大、内部趋于等积，正是 relax 到最佳拟合正方形的效果）。

## 代码落点与差距

- `src/core/grid.js`：
  - `buildQuadGrid({radius, hexSize, seed, mergeRate=0.92, relaxPasses=80})` = `latticeAndMerge()`（点阵 + 按 mergeRate 合并三角成多边形）→ **逐多边形切成 n 个四边形**（每条边取中点 `mid()`、每条多边形加形心 `c`，四边形 `[cur, mid(cur,next), c, mid(prev,cur)]`）→ 统一正绕向 → `relaxPolygons(quads, verts, 80)` → `finishGrid(kind:'quad')`。
  - `relaxPolygons()`：每个面求"最佳拟合正 n 边形"（把各角相对形心的偏移反向旋转 i·2π/n 取平均），逐 pass 拉角；n=4 时即最佳拟合正方形，外圈顶点 pinned。
  - `buildTriangularSubgrid(source)`：把 tri/quad 再细分成三角子格（四边形的对角交点取中心，4 个子三角），带 `owners`（sourceCell/sourceEdge）和 `groups`。
- 对应关系：片子的"合并→切四边形→松弛"三步与 `buildQuadGrid` 完全同构；"格数翻倍"对应四边形细分后 1 格变 4 格。
- 缺：
  - ① 原文 Todo #1「消除 6 价四边形顶点」的启发式**没有**：`grid.js` 里没有任何 valence / 价数统计或改写（grep `valence|6度|六度` 全空），当前只靠 `mergeRate` 概率性回避；
  - ② 没有把这条时间线做成可播放的页：`grids.html` 只显示静态成品（kinds 页签），看不到"从一格长满 + 转白细分 + 鼓成穹顶"的过程；
  - ③ 片子末段的**穹顶外鼓**（外轮廓由直线变弧、边界格被拉大）在本仓是 pinned 外圈顶点，不会鼓。
