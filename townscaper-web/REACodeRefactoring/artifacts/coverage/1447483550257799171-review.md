## 逐帧观察

整片是一条 44 秒的循环 showreel，反复"着色岛 → 切黑 → 线稿逐笔描出 → 回到着色岛（另一座）"：

- **0000–0152**：彩色岛。暗色岩块（灰蓝、深绿分层）压在浅蓝海底上，表面有蓝色线状河网/等高线纹理，几个尖塔状岩柱；相机缓慢环绕，无 UI。
- **0153–0197**：整屏切黑，只剩白色细线。线**从零散几段开始**（0153 只有 3–4 小段），到大写 S 形、再到 0160–0197 连成完整的岛轮廓草图；0453 之前的多轮都是这个过程。原尺寸 frame-0405 看得很清楚：黑底上散布着互不相连的白色折线段，段端点都是"画到一半"的截断，不是整体淡入。
- **0198–0257**：彩色岛回来，但换成另一座（山脊更高、岩柱更靠中），相机换了角度。
- **0258–0273**：又一轮线稿从零长起，0273 闪一帧彩色，0274 起再切回线稿。
- **0330–0396**：彩色岛多角度环绕（第三座，三根岩柱并列）。
- **0398–0453**：线稿 + 线网阶段，白线更密，出现三角形共享边的结构。
- **0454–0486 / 0487–0564**：彩色岛（第四座），缓慢旋转并把镜头拉远。
- **0570–0580**：线稿再起（第 N 轮）。

每轮岛的形态、岩柱数量、海岸线都不一样 → 不是一段预渲染动画，而是**连续生成不同的岛**。

## 判定

**有机制**，两件事叠在一起：

1. **程序化岛生成连续出图**：同一个生成器连续产出不同形态的岛，每座都不同。
2. **线稿逐笔描出**：黑底上把轮廓/网格线一笔一笔画出来，每条笔画开始时刻错开、画完的时刻也错开，画完停一会再换下一座。

## 代码落点与差距

- 落点：`src/terrain/generate.js`（高度场 → 塔柱 → 峡谷 → 河道）、`src/core/contour.js`（`marchGrid` 2D 等高线）、本轮新增 `src/core/stroke-reveal.js`（逐笔描出的排期与按弧长裁剪）。
- 差距：① `generate.js` 是"一次性生成"，没有"连续换岛 + 逐座展示"的循环演示页；② `marchGrid` 只服务世界网格的 2D 等高线叠加（`src/world/contour-overlay.js`），没有接"岛轮廓草图"这条线；③ `stroke-reveal.js` 已经能画，但还没接到地形管线上（目前只在独立的 `stroke-reveal.html` 里演示）。
