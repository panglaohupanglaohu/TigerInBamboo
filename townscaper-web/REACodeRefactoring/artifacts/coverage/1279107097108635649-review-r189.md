## 逐帧观察

- 0000–0007：镜头贴地掠过平铺场，场上是一排排**单格构件**（墙块、坡顶、平台），底色为灰蓝网格地面；块按族群成行。
- 0008–0050：镜头抬高后沿行列飞。每个构件由三类几何组成：**墙身立板**（蓝/紫/绿）、**坡屋顶**（绿/暗红/浅褐）、**基座/底裙**（绿/棕/青）；构件之间是**白/浅灰细边**（框条、檐口、栏杆）。
- 0051–0092：低空掠过粉/紫族群；同一行的块颜色一致，跨行换色 —— 对应"同一种邻接签名同色"。
- 0093–0115：镜头撞上一座**多层竖塔**：同一格上逐层叠放，每层各一个颜色（层间签名不同 → 颜色不同），塔顶仍未上色前是原屋顶色。
- 0116–0145：成片绿/蓝/粉团聚块，块与块之间贴边、留缝，缺口处露出白细边。
- 0146–0168：一整片**青色平台群**（铺地/矮墙连成一片）+ 白色立板，说明基座/铺地这一族也在按签名分色。
- 0169–0199：近景木栈道样构件：蓝墙 + 棕板 + 绿底，白细边不上色。
- 0200–0255：俯视拉远，整场几十上百块被同一套签名色覆盖（大片深蓝 = 同一签名族），镜头持续平移至结束。

结论（形制）：**平铺的每一块按"部位 × 邻接签名"分色** —— 墙身、屋顶、基座/铺地各一族色，同一签名同色；白细边（框条/檐口）保持不上色。

## 判定

有机制，且本仓已有 `src/build/module-catalog-r56.js`（签名公式 + `usedSignatures` + `allSignatures` + `buildPiece` + `catalogLayout`）与页面 `module-catalog-r56.html`。

**旧 note 的两条"仍缺"逐条核实：**
1. 「没有零件目录页」= **过期账**（第 66 次同型）：`module-catalog-r56.html` r56 就在（`?grid=quad|mixed`、`?mode=used|all`、飞行巡览 + 俯视、`window.r56cat` 探针）。
2. 「只给墙身上色（底座/屋顶/窗饰仍原色）」= **真缺口**：`buildings.js` 里只有 `wc = debugModules ? sigColor(sig) : wall` 这一处吃调试色；基座走 `K.stone/K.stoneDark/K.band`、屋顶走 `K.roof/K.roofAlt`、山墙走 `wallColor(c)` → 目录页上永远只有墙在分色，与片里"基座绿/棕/青、屋顶绿/暗红"的形制不符。

## 代码落点与差距

本轮（r189）落地：

- `src/build/buildings.js`
  - `buildBuildings(w, world, { …, debugModules = false, debugParts = true })`；`debugParts` 只在 `debugModules` 打开时生效。
  - 新增三族签名色：`partSigs = {wall, roof, base}` + `sigColorFor(kind, sig)`（色相盐 `SALT = {wall:11, roof:977, base:613}`，同签名同色、定种子可复现）；旧 `sigColor(sig)` 保留为 `sigColorFor('wall', sig)`。
  - `plinth()`：`dbgBase = sigColorFor('base', moduleSig(c, 1))` → 基座四段石带 + 三道压顶/铺地改用基座签名色（`dbgBase ?? K.stone/K.band`）。
  - `buildRoofs(..., { dbg })`：屋顶面 `dbg.roofColor(c) = sigColorFor('roof', moduleSig(c, tops[c.id]))`；山墙三角 `dbg.gableColor(c)` 归墙族；`skeletonRegionRoof` 同步（region 级）。
  - 统计：`buildStats.moduleParts = { wall, roof, base, quads:{roof, base} }`（族色数 + 实际画出的屋顶片数/基座面数）。
- `src/build/module-catalog-r56.js`：`buildPiece(..., { debugParts })` 透传，返回 `parts`。
- `module-catalog-r56.html`：`?parts=0` 关档（回到"只给墙身分色"）；`window.r56cat` 增 `partsOn` / `scenePartColors` / `piecePartColors`；页脚 URL 提示补 `&parts=0`。

**如实口径（未冒充）**：
- 本仓签名按「格 × 层」计：本场景 27 种、四边网格理论 60 种、混合网格 88 种；原作 545 是按角点对偶模块 × 更多状态计，**口径不同**，不冒充 545（`module-catalog-r56.js` 文件头一直这么写）。
