## 逐帧观察

- 0008–0012：一块地基落进水里，格脚冒出一圈白色泡沫，边缘锯齿不规则；水面同时有白点飞沫。
- 0130–0160：连续补块，每次只在「与水接触的那一格」出水花；陆地/屋顶上的增删没有任何水花。
- 0330–0343：拆掉临水一块，泡沫呈**贴着墙的不规则白斑**（不是干净圆环），外面还有 2 圈很淡的同心波纹。
- 0381–0391（本轮 4× 裁切，0384 最清）：**冠状竖直水帘**竖起 —— 一条条上宽下窄的白色竖片围成一圈，高约 0.5–0.7 个格高，
  几乎不外抛；裁切里正面能数到 5–6 根（透视互相遮挡，绕一圈约 10 根）；空中 2–3 颗圆白飞沫（另有更小的碎点）。
  水面上 2 圈环已经展开（内圈在格脚、外圈约 1.2 倍格宽）。
- 0400–0414：竖片塌落，飞沫落回水面即灭；环继续外扩、变淡。
- 0415–0435（末帧）：水面仍留 2 圈很淡的环（事件后约 3.2s），未完全消失。

## 判定

有机制。一次落水/拆水事件 = ① 冠状竖直水帘（约 10 根，0.35s 到顶、0.9s 前塌落）；② 3 圈同心泡沫环（末帧 3.2s 仍在，约 3.8s 才淡完）；③ 9–12 颗偏竖直的飞沫。

## 代码落点与差距

**核实（先核再动手）**：旧 note 的两条「缺冠状竖条 / 缺多环长寿命」是**过期账（第 41 次同型）**——
`src/life/splash-c07.js`（文件头署本片 ID，r56 C07）早就是 `CROWN_STRIPS = 10` 的冠状竖条 + `RING_DELAYS = [0, 0.22, 0.5]`
三圈 + `RING_LIFE = 3.8` + `10 + floor(random*3)` 颗飞沫，node 测试 `tests/c07-look.mjs` 一直绿。
真缺口是**它只挂在 `?c07=splash` 上**：主场景默认仍是 `effects.js` 的一圈 1.1s + 26 颗外抛飞沫，而且这套形态从没在页面上跑过一次。

本轮（A 类收口，机制零改动）：

1. `src/life/effects.js`：构造时建 `CrownSplash`，默认 `splashStyle='crown'`（`?splash=plain` 退回旧档做对照）；
   `#splash()` 在 crown 档直接 `crown.spawn(cell, t)`；`update()` 每帧 `crown.update(dt)`；补 `setSplashStyle()` / `splashStats()`。
2. `src/world/view-c07.js`：`?c07=splash` 不再自己 spawn/update（否则与默认档双份），改成 `fx.setSplashStyle()` 切形制。
3. `src/life/splash-c07.js`：补只读探针 `stats(t)`（条数 / 高度 / 各圈半径与 alpha / 飞沫），`spawn()` 的 log 记下 `scale`。渲染未改。

已知差异（不构成「仍缺」）：环仍画在格心，片子 0330–0343 的「贴墙白斑」是同一圈环被墙裁切后的样子，本仓同样由几何裁切产生，没有单独的贴墙形制。
