- 原文：I've shipped two whole games with orbital cameras and not once have I previously though about adding motion blur smear. What a fool I am.

## 逐帧观察

- **0000–0037 慢转**：单一岛屿（台地 + 粉色岩层 + 绿顶 + 几片淡黄/白斜面）悬在一整片纯绿背景（studio 无天空、无地面网格）。逐帧差分 0.10–0.12，画面锐利（岛内 lap95 69.4）。
- **0038–0079 快转段**：帧间差分峰值 18.08（f38）、17.72（f69）、16.48（f70），岛内 lap95 掉到 47–51。原尺寸看 `frame-0041`：轮廓与屋顶交界出现 2–4px 的柔化过渡，暗描边被"抹开"成一条较宽的灰带；`frame-0039→0042` 四连帧同一区域，暗描边宽度逐帧变化（旋转越快越宽），色块本身没有分成几份。
- **0080–0169 快慢交替**：0090（diff 7.66）、0110–0139 一段快转（0118 diff 17.92，lap95 46–53），0150–0169 几乎静止（diff 0.13，lap95 61.0）。
- **0170–0239 二次快转**：0180–0195、0227–0232 两个快段（diff 6.3–11.0，lap95 39.7–52.1），中间 0210–0225 放慢。
- **0240–0299 慢转**：diff 0.5–8.7，画面回到锐利（lap95 60–62）。
- **0300–0336 停镜**：diff 0.02–0.06，lap95 恒定 62.2；把 `frame-0306`、`frame-0311` 与快转帧对比，停镜帧的左下轮廓是 1px 硬边，**没有**前一位置的残留副本。
- 全片无 UI、无参数面板、无帧率读数、无建造过程；镜头只做绕竖轴的环绕 + 轻微俯仰，中心几乎不动。

## 判定

**有机制**：环绕相机（orbital camera）的运动模糊拖影。三条可从画面判定的性质：

1. **只在快转段出现**：差分峰值的帧同时是 lap95 最低的帧（69 → 47），慢转/停镜帧恢复到 61–62；
2. **是单帧拖抹，不是历史累积**：停镜后 0300–0336 连续 37 帧差分 0.02、无任何前一位置的半透明副本 —— 若是「上一帧按 alpha 叠上来」的做法，停镜后必然留一串衰减重影；
3. **方向性**：暗描边被抹开的方向随位置变化（左/右轮廓处偏竖直、画面中部偏水平），符合「位移 = ω × (p − c)·dt，切向且 ∝ 半径」的模型；外圈比中心糊。

## 代码落点与差距

- 落点：`src/world/view-post-extras.js` 的 `?fx=smear`（`ORBIT_SMEAR_CENTER_GLSL.orbitSmearAt`：单帧 6 次三角权重采样、圆心取相机 target 投影、`screenOmegaDt` 按 ω·sin(俯角)·固定快门 1/60 换算）+ CPU 孪生 `src/core/camera-motion.js#smearImage/orbitVelocity/smearLengthPx` + 页面入口 `?fx=smear&spin=`。**旧 note 的两条「仍待补」全是过期账（第 32 次同型）**：方向性轮廓拖抹、速度场、指标接口都在，缺的是页面运行验收。
- 核实为**真缺陷**（本轮修）：拖影合成着色器同时带 `#include <tonemapping_fragment>` 与 `#include <colorspace_fragment>`，而场景渲进 `smearRT` 时 TONE_MAPPING 已经生效一次（RT 的 `texture.colorSpace` 是线性的，只缺编码）→ 开拖影整帧被二次 ACES 提亮。实测 `omegaDt=0` 时全屏平均亮度 **130.14 → 143.75**、平色样本 +13 级。修法：合成通道只留 `colorspace_fragment`。
- 一并补的接口（`stats.smear`）：`omegaDt / screenOmega / shutter / taps / maxPx / outerPx / center`（旧版只有 `omegaDt/outerPx/center`）。
- 未做的（如实口径）：实时路径用**固定快门 1/60 + maxPx 24 截断**，原片的快门角度无法从 640² 画面反推；`View` 原有的 `setDebug('motionblur')` 历史叠加通路保留未动（两者各自开关，本片只验收解析拖影）。

新测在同一机位做「开 / 关」A/B（冻结动画：`__orig(0)` 渲染，同状态噪声 0），量到：

- **变软**：岛内 lap95 **34.49 → 9.64（−72%）**；0.5× / 1× / 2× 角速度 = 13.15 / 9.64 / 9.84（2× 已在 maxPx 24 截断，故不再下降）；
- **方向 = 切向**：dy/dx 各向异性 左带 **1.017 → 0.749**、右带 **1.381 → 0.890**（左右带切向≈竖直 → 竖直梯度被抹平），画面中部 **1.216 → 1.280**（切向≈水平 → 不该降，实测不降）；
- **∝ 半径**：岛内像素按半径分带，0–0.15R 带差分 10.00 < 0.15–0.3R 带 12.98；`outerPx = |omegaDt|·min(w,h)/2` 三项实测 4.26/8.52/17.04；

- **不偏色**：五个平色取样点开/关逐值相同（回归守卫，旧版 +13 级）；
- 实时画面（`?fx=smear&spin=6`）`outerPx 23.24`、0 console error。
