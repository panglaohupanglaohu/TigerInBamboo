# 长矛对移动目标的连续检测

## 承接学习
重读903647529203634176的README原文，续用已复核全部654帧及spear-review.md。本轮回看末段600–653帧，新增学习帧0。视频说明长矛实现复杂，没有公开精确算法；本轮连续检测是针对本地代码遗漏的改进，不能归为原作者算法。

## 实现
上一轮只检查目标当前坐标，快速横穿时两端都在矛外会漏击。现在每次攻击保存目标上次位置，固定矛轴和原点，假设每个更新区间内目标线性移动、矛尖线性伸出。将相对坐标投影到矛轴，分别求轴身矩形的线性不等式交区间、原点圆帽及移动尖端圆帽的二次方程最早接触，取最早有效时间。命中按时间及轴向距离排序，仍使用每刺独立Set。暂停零dt不更新快照；长dt超过攻击余时，只取目标轨迹对应的有效前段，避免结束后追补伤害。

真实Battle在攻击启动时提供目标坐标快照，仍保留异队、离船、非坠落和已有canMelee的高度/遮挡筛选。原版只读，其他会话编辑保留。

## 验证
spear-thrust.mjs验证30/60/120Hz的目标跨轴、两个端点均未命中仍被截获、尖端伸出与目标时间耦合（防止以整段最终矛身错误追溯命中）、圆帽边界、到期截断及原有去重/暂停契约。120条固定随机轨迹与每条4001点的独立点到线段距离参考对照，排除临界容差区后吻合。

spear-sweep-browser.cjs在真实北境四边形/混合网格，保留上一轮多目标、侧向/另层排除、每刺去重/重置和中断测试，再让受控目标从轴的一侧快速移到另一侧，两帧端点均在轴外，仍通过实际Battle命中路径扣一次血。JSON报告spear-sweep-browser.json，截图spear-sweep-{quad,mixed}.png已查看；截图只是受控测试结束时近景，连续路径由量化断言证明。

## 限制与下一步
只覆盖水平固定轴及目标线性移动，不支持旋转矛身、移动持矛者、目标跨帧高度变化的连续碰撞、盾格挡或刚体推挤。Battle高度及环境遮挡仍按本次更新末态保守筛选，未实现接触时刻3D遮挡；新进入候选列表的目标没有历史路径，首帧只按当前点。大兵种、精灵受击动作及时间窗对应武器动画仍待续。未同步游戏副本、未认证TigerMessenger实景。
