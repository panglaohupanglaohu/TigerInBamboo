## 判定

有机制，且只有一件事：**单位脚下的接触软影**（灰模地面无贴图、无明暗渐变，能看出来的"暗斑"只可能是脚下那块影子）。
其余内容（选点框 / 路径点 / 挥砍 / 血 / 尸体）本仓 `src/badnorth/battle*.js` 早已有并有更早轮次的验收，不是本片新增。

## 代码落点与差距

- 两条片子（8213 / 8216）共用同一句缺口，机制与修法完全一致，按「一条缺口 → 两条片」记。
- 机制：`src/core/unit-shadow.js#unitShadow`（blobshadow：`0.36·h` 沿 `LIGHT_DIR` 偏移、坡向 `1/cosθ` 拉长 + 横向压短、`groundAt` 逐顶点贴地、`measure()` 指标表）；
  批处理 `src/life/unit-shadow-batch.js`（跨格拼片 / 楼梯踏面 / `groundSampler` 射线拟合）；接线 `src/badnorth/battle.js:70` + `#draw` 每帧 `update()`。
- 第 130 轮已修的真缺口：`UnitShadowBatch.enabled` 默认 `false`（只有 g3 的 `shadowFit` 会置 true）→ 默认战斗一片软盘都不画；改为默认开、`?unitShadows=0` 关档。
- 本轮收掉最后一层：**在画面上确认盘子可见**（钉机位 + 冻时间轴 + 俯视台地顶层），并排掉「实心台地把盘埋掉」的疑点：
  24 片盘面最低点全为 `floor*L+0.008`，画面压暗 12%–22%，无一片被埋。
