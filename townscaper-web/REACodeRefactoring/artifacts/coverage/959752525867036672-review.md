## 逐帧观察

全片一个静止机位（无转镜、无 UI、无鼠标），画面 = 一座多级台地的绿色小岛：
上层平坦草台、中层台地、下层草坪与池塘，岛上几栋白墙绿顶小屋、成片灌木/树冠。

- **f0000–0002**：对偶线网满尺寸铺在台地面与草坪上 —— 每个顶点一圈近乎闭合的白色小环，
  相邻环之间的中段用细直线相连；台地边缘的环被地形切断，只留在新层上。
- **f0003–0010**：白线像素数单调下降（3011→2367），即**每个环连同连线段一起向自己的源顶点收缩**，
  环与环之间开始出现明显空隙。
- **f0011–0015**：收到最小（f0013 = 2154，相对 f0000 的 71%），环变成顶点周围的小团，
  连线只剩短短一截，簇与簇几乎不相接。
- **f0016–0025**：开始反向涨回（2195→3038），到 f0025 基本回到起始大小。
- **f0026–0030**：略过冲（f0027 = 3153 = 起始的 104%），随后稳定在 3120 左右。

结论：不是镜头在动、也不是材质在闪 —— 同一机位下白线像素数按余弦节律在 2154↔3153（±19%）之间走，
是**几何在缩放**（面积 ∝ 线性² ⇒ 线性峰谷比 √(3153/2154) = 1.206，拟合周期 1.296s）。

## 判定

**有机制**：三角网格的**对偶顶点格**（每个顶点一圈的对偶多边形 = 落植被的候选位），整体做周期性脉动。
片内没有别的机制（没有植被真的长出来 —— 原文只说 dual 是 "a suitable place to start with foliage placement"）。

## 代码落点与差距

- `src/core/vertex-dual.js#vertexDual`：扇形三角 → 重心对偶（每个顶点一个闭合对偶格，边界格在源顶点收口，
  不向无穷外推）。这是**本仓自选口径**；原作的中心规则未公开，画面也反推不出来（卡点仍记在这里）。
- `src/core/vertex-dual.js#DUAL_PULSE / dualPulse(t)`（本轮新增）：脉动曲线**按片内量的**，
  不再写死。旧写死 `.72 + .28·(0.5+0.5cos(3t))` = 峰谷比 1.39、周期 2.09s，比片内深且慢。
  新值 `{min:0.829, max:1, period:1.3}`：峰谷比 1/0.829 = 1.206（片内 √(3153/2154) = 1.206），周期 1.30s（拟合 1.296s）。
- `src/core/vertex-dual.js#dualFoliageSites`：候选点（按面积比/间距筛，悬崖/河/已建格裁掉）—— 片内不出现，属原文所说的"起点"。
- `src/world/vertex-dual-overlay.js`：shader `mix(aOrigin, position, uPulse)` 做缩放，`update(t)` 改调 `dualPulse(t)`。
- 缺口（口径差，非机制）：对偶中心规则是本仓重心近似；候选点尚未替换全局植被/导航（片内也没拍）。

## 验证

1. `node tests/dual-pulse.mjs` → PASS。测试里嵌了逐帧白线像素序列，先做 a·cos+b 最小二乘（扫 0.6–2.5s 找最小残差），
   再断言 `DUAL_PULSE` 的峰谷比在 0.03 内、周期在 0.08s 内与拟合一致 —— 常数和片内量测绑死，改常数就红。
   实测 period 1.296 / rms 31.5 / ratio 1.206；单调段、周期性、非法输入抛错、对偶格面积比（√(aMax/aMin)=1.206）均通过。
2. `node tests/radial-dual.mjs` → PASS（accepted 25 / rejected 23 / dualCells 640，面积守恒与对偶闭合不变）。
3. `node tests/dual-foliage.mjs` → PASS（quad/mixed 候选点确定性、间距、悬崖裁边不变）。
4. `node tests/dual-pulse-browser.cjs` → PASS。gridpatch.html?grid=quad 上开对偶叠层，冻结到峰/谷两档：
   线段总长按 uPulse 线性缩（geoRatio 1.206 = 片内 1.206）；同帧两次 readPixels 差分 48646 px（overlay 真的动了）；
   截图 `artifacts/coverage/dual-pulse-quad-peak.png` / `-trough.png` 已用 ViewImage 看过：峰档环与环几乎相接、
   谷档环缩小后彼此留出空隙，两档都贴在台地面/草坪上，0 页面报错。
