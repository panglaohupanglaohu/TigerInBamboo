## 逐帧观察

- **0000–0099**：小岛俯瞰，岛上有几座屋子；青绿色和品红色的小方块（两队守军）在岛上来回移动，岸边有白色小船。这一段的机位很高，流场线看不出来，只能看见单位在走。
- **0100–0199**：镜头绕岛并压近；单位继续移动、换位；0170 之后画面开始飘白色雪粒。
- **0200–0299**：最近的一段。地上能看清**细的粉红/亮青折线**：沿格子中心一格一格连成锯齿状的路径，一路指向目标点；线的颜色按小队分（品红一队、青绿一队）。格心上还有白色的小箭头/刻线（"≫" 形状），指示该格的流向。单位在动、线也跟着重算。
- **0300–0499**：镜头继续环绕，雪一直下；同一座岛，单位在滩头与内陆之间往返，地上的折线断续出现（被单位和建筑挡住）。
- **0500–0536**：仍是环绕，没有字幕卡、没有 GDC 标题，片子直接结束——所以这是演讲配的实机录屏，不是幻灯片。

## 判定

有机制：**流场寻路**。能判出来的细节：
1. 路径是格心到格心的折线（不是欧氏直线），说明是格子图上的场；
2. 线按小队上色，两支队伍各走各的场 → 多源流场，每队一份；
3. 格心有不动的白色方向标记，说明每格除了「往哪走」还存了方向向量；
4. 场在单位移动时被重算（线会整体变形）。

## 代码落点与差距

- `src/badnorth/flowfield.js`：`buildFlowField(world, nav, sources)` —— 所有守军同时作源做一次 Dijkstra（多源），得到 `dist / parent`，查询 O(1)；分层地形按层代价算，跨层边有额外代价。
- `src/badnorth/battle.js` `flowLines`：按 `parent` 链画「格心 → 父格心」的线段，按小队（unit 档）/ 兵种（type 档）着色，`depthTest:false` 贴地叠在上面。
- 实验页 `flow-color.html` 三档配色（unit / type / 关）+ `fields.html` 看单场。

差距：
1. 片子里的线是**亮粉/亮青**，在雪地和草地上对比度很高；我们 unit 档的线偏淡绿黄（见 `flow-color-unit.png`），在亮草地上几乎看不清 —— 配色对比度不够；
2. 片子里每格有不动的白色方向箭头，我们没逐格画（只有选中的路径点和窄道点）；
3. 片中地面上还有一种很淡的格网（三角/四边混合网格的线框），我们实验页没画网格底；
4. 三角网格的流场只在逻辑测试里验过（父链完整），没在页面上做过三角网格的截图验收。
