## 逐帧观察

- 0000–0009（0.0–3.9s）：深蓝底（带极淡同心等高环）单人肖像，硬切。0000 额头有雀斑、眉细、眼圆睁、鼻长且鼻头粉、嘴一条线、两耳外露带耳廓螺旋；0002 起是侧分深棕发、0003 短寸、0005 光头（顶上有浅色高光弧）。
- 0010–0029（4.3–13.2s）：清一色「正面半身头」构图，唯一变量是脸形（宽卵 / 窄长）、发型（侧分 / 寸头 / 光 / 后撤）、眉粗细则、眼睑厚薄、鼻长短、嘴开合、有无雀斑。色板只有四种：皮（米白）、发（深棕/褐/橙红）、鼻头（粉）、背景（蓝）。
- 0030–0059（13.7–27.2s）：继续硬切，出现橙红发（0018/0037/0050/0056/0064）、后撤发际线（0040/0045）、更大的耳朵（0042）；每帧只有一张脸，没有并排对照、没有文字标签、没有转场动画。
- 0060–0087（27.7–40.3s）：同构延续，末帧 0087 为窄长脸 + 顶端一撮褐发 + 两侧鬓角 + 厚眼睑。整片没有相机运动、没有 UI、没有数字。
- 全程：一帧 = 一个显式身份，切帧即换身份，返场不会再出现同一张脸（88 帧无重复组合）。

## 判定

有机制，且是**内容无关的槽位表走表器**：一张有序槽位表（背景→头→耳→发→眉→眼→鼻→嘴→装饰），按 seed 抽样逐个变体派发；换一张表就换内容。片子只给 5 个示例、构图层级一致，正好对上「content agnostic / similar hierarchy」。

旧 note 挂的「完整 spec / 数据接口 / 剪影 IoU 仍缺」经核实是**过期账（第 53 次同型）**：`src/core/part-random.js` 早有
`PORTRAIT_SLOTS`（9 槽，`needs/provides` 依赖）、`sampleSlots(seed, slots)`（可换表 = 内容无关）、`portraitSilhouette`、`silhouetteDiversity`（成对 IoU）、`partSeed`（格位身份与列数无关），
`src/ui/slot-portrait.js` 的 `slotGeometry` 与 `portraitSilhouette` 共用同一套几何，`ui.html?t=face&portrait=slots` 早把 `slotStats()` 的 `canvasMaskIoU` 打在页面上。
缺的只是**运行断言**：这套数据接口与 IoU 从来没有在真页面上被数值化验收过（`tests/part-random.mjs` 只测 `withRandomState/mirroredRandom/partSeed`）。
