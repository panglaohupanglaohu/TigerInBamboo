## 逐帧观察

- **0000–0139（0.00–4.17s）**：固定斜视的雪岛（粉白墙体、台阶地块、屋顶与墙顶一层白雪、粉色小丛顶雪帽），空中散布细小雪点（514px 下 1–2px 亮点，亮度不一）。地面白覆盖在这 4 秒内基本不变，变化全在空中的雪点位置。
- **0140–0147（4.20–4.41s）**：一个亮帧（转场），随后机位切近：岛体变成更近的俯斜视，可见墙体立面与壁架的雪层边界。
- **0148–0317（4.44–9.54s）**：近机位继续缓慢环绕/推进，雪点仍持续从画面上方进入并向下落，岛体遮挡处（墙体后、台阶下）没有雪点堆积，雪点也不会穿进墙体。
- **裁切放大（frame-0000 右上天空 300,40–520,260）**：雪点是**圆点/软边小点**，大小与亮度都不一致（有几颗明显更亮更大）；没有任何「方块点阵」特征。同区域还能看到粉色小丛上的白色雪帽（美术资产）。
- 片中无法逐粒追踪单点身份（1–2px + 33fps），所以「绕岛流动」只能从「雪点不进入岛体、迎风面密度与风向一致」这类统计特征看，不能从单粒轨迹断言。

## 判定

有机制，且机制就是片名这一句：**雪点由共享风场推进（风向/风速/障碍绕行），并在贴地处衰减**。

- 风场：`Atmosphere.rebuild` 逐层算占用（`world.isSolid(cell, lv+1)`，隧道上方有顶不等于下方实心），两遍盒式模糊后按占用梯度把「撞向障碍」的法向分量减掉、贴边加速、`vy = b*0.55` 上抬 —— 这正是「flow around the island」。
- 雪点：`update(dt)` 里逐粒 `sample(x,y,z)` 取风场三线性值 + 每粒相位不同的 flutter，`(v*0.9, v.y*0.6-0.32, v*0.9)` 积分；端点若落到实心体素/出界/落地就 `#spawn` 重新从上风边进来（所以雪点不会停在墙里）。
- 形制：片元 `length(gl_PointCoord-.5) > .5 → discard` + `smoothstep(.5,.28,r)` 软边（不是方点）；`aSize` 每粒 0.55–1.45、`aAlpha` 走 `particleContactAlpha(离支撑面高度, 离岛心距离)`（贴地更淡、离岛越远越淡）。
- 地面：`uSnow` 在 `smoothstep(0.55,0.85,vUp)` 上把朝上面混成 `(.93,.95,.98)` —— 片中的「屋顶/墙顶积雪」在本仓是**朝上面混白**，不是几何雪帽。

## 代码落点与差距

- 落点：`src/life/atmosphere.js`（雪 Points + `#seedSnow`/`#spawn`/`update` 的风场积分与体素端点碰撞；`rebuild` 里逐层占用 → 法向绕行 + 上抬）、`src/core/wind-flow.js#particleContactAlpha`、`src/world/view.js`（`setDebug('snow')` → `atmosphere.showSnow` + `uSnow`）；页面入口 `flow.html`「共享风场雪片」勾选 + `index.html?scene=*` 场景能力面板「飘雪与表面积雪」。
- 本轮唯一改码：`atmosphere.field` 增加只读 `res`（世界跨度 = 格数 × res，测试不必再猜常量），**零行为变化**。
- 旧 note 的「Points 方点 / 统一大小与亮度 / 软片、接触 AO 仍未复现」= 过期账：软圆片 + 逐粒尺寸/透明 + 接触衰减都在（见下读数），缺的只是运行验收。
- 残差（美术/口径，不是机制）：片中的雪帽是**几何厚帽**（墙顶/丛顶一团），本仓只有朝上面薄层混白；空中雪点密度与单点尺寸档比片内小（3000 粒铺 ~7×7 世界单元）；`uSnow` 不上立面。

## 验证
