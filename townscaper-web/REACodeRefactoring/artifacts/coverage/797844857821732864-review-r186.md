## 判定

**有机制**，本轮两件事：
1. **屋顶小件是几何体，不是贴图**：天线/栏杆齿/树都站在屋顶格上（上方无实体），圆盘挂在朝外的立面上；
2. **室内光按进深渐变**：同一面内墙的颜色由「它面前那格空气离最近的洞口几格」决定，越深越暗 ——
   这就是原片「环境光从洞口灌进去、深处只剩反弹光」的表现。

## 代码落点与差距

改码（`src/world/voxel-ghost.js`，只加不删旧口径）：

- `roofProps(voxels, {seed, antennaRate, maxDishes, maxTrees, minY, postGap})`：
  - 屋顶格 = `y>=minY` 且上方无实体；露台 = 8 邻全是屋顶且最靠上的格。
  - ① 天线：屋面散点（散列 <6%），高 0.55–1.35 格、宽 0.045 格，部分成对（同基格 +0.14/+0.09 的第二根）；
  - ② 圆盘：只在「上部 6 层内、至少 2 个屋顶邻格、+x 或 +z 面朝外」的格上，半径 0.24–0.34；
  - ③ 栏杆：每条「屋顶格 → 同层空格」的沿口，每 0.25 格一根短齿（高 0.13–0.19）；
  - ④ 小树：只长在 8 邻全屋顶的平整露台，彼此至少隔 2.5 格，尺寸 0.86–1.04。
- `propStats(voxels, …)`：件数 + `floating`（基格不是实体、或上方压着实体）= 0 才算过。
- `airDepths(voxels)`：从包围盒边界上的空气泛洪，空格 depth = 到外部空气的步数（洞口那格 0/1）。
- `interiorFaces(...)` 的值由 `true` 改成 **进深数字**（`has/size` 语义不变）；`interiorTone(depth,{ref:9})`
  = `INTERIOR_TONE_NEAR #f2e4e9 → INTERIOR_TONE_DEEP #b891a3` 按 `1−exp(−depth/9)` 插值。

页面（`voxel-ghost.html`）：两个开关 `#props` / `#grad`（默认开）+ URL `?props=0` / `?grad=0`；
小件与格子走同一套 painter 序（depth +0.35，画在自己那格之后、更近的格子之前）；
内墙面按 `interiorTone(depth)` 取色 × 面明暗；HUD 出「屋顶件 天线 12/栏杆 320/碟 2/树 2」与「进深 4–16 格」；
只读探针 `window.voxelGhost.props / .propList(kind) / .gradient / .interiorProbe()`。

**做到哪**：两件事都有页面入口、运行断言与截图；四类小件逐件核过基格，进深色阶在画面粉色像素上可量。
**差距（如实）**：① 原片是整栋「每格一个窗槽 + 每段沿口一排齿」的极高密度，本仓演示体量只有 305 个屋顶格、
320 根齿；② 直线上更明显的差是**近景的进深渐变在同一机位里读不出一整条色带**——演示塔的可见内墙基本在同一进深档，
画面里只有「浅档（206 级）/ 中档（180）/ 深档（171）」三档散点，色带靠离屏读数（见验证）而不是靠一张截图；
③ 天线/圆盘/树的**形状**是体素替身（圆柱/球/细杆），不是原片那套小模型，属美术差，不记机制缺口。
