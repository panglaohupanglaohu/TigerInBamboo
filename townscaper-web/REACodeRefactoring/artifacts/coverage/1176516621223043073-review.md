## 逐帧观察
- 0000–0099：密排小镇俯瞰，橙红瓦屋顶 + 米色/砖红/青绿墙体，水是深蓝。镜头慢慢推近某一栋，屋顶的瓦纹很清楚，墙面是**单一平色**，没有任何噪点/渐变脏迹。
- 0100–0199：（原尺寸 frame-0100 + 4× 放大）窗是**接近正方的小窗（宽:高 ≈ 0.93）**：白色窗框、深色玻璃，中间有一道**白色十字**把玻璃分成四格；个别小窗只有一道竖档（两格）。窗下有一条比窗框略宽的白色窗台。每面墙每层 **1–2 扇**，贴在墙中间偏上，不与墙角相碰；同一栋同一层窗高一致。
- 0200–0281：镜头横移扫过整排房子：两栋不同颜色的房子相接时，颜色在**共用的竖直棱上直接换色**，没有渐变、没有污渍过渡，只留一条暗缝。红/绿/米三色并列时尤其明显。
- 全片：没有 UI，没有选中框，只有一个白色菱形光标（建造工具）在中间飘。

## 判定
有机制：窗是沿墙边放置的**正矩形贴片**（不随格子歪斜），尺寸/间距由每层一张"已放置列表"控制（互不重叠、离墙角留边）；窗型至少有"十字四格"和"只竖档两格"两种。不同颜色的房子在共用棱上硬切换颜色。

## 代码落点与差距
- `src/build/buildings.js`：`opening()` 画窗框 + 玻璃 + 竖档 + 窗台；本轮**补了横档**（`cross` 参数，`wm ± 0.005`），并把默认窗从 0.085×0.14（1:1.65 窄条）改成 **0.09×0.095（≈1:1.06 正方）**，窗高位置从层高 40% 抬到 35%；`window2`（tall 型）保留竖档单窗，高 0.13。`tryPlace()` 用 `openingFootprint` + 每层 `placed` 列表保证不重叠、离墙角 ≥0.035；`windowStyle()` 按"建筑连通组 + 层"取三种窗型。
- 换色：`wallColor(c)` 按格取 `world.color`，同格同色；不同格在共用棱上直接换色（与片一致），勒脚/檐带是另一层色。
- 实测（`building-components.html` 默认小镇，开启 六类墙饰）：
  - 露出墙面（每层"已建格 + 邻居该层非实心"的边数）：L2 148 / L3 72 / L4 16 / L5 8 / L6 4；
  - 实际放置开口：L2 129 / L3 66 / L4 12 / L5 5 / L6 5 → **每面每层 0.63–0.92 扇**，即"每层每面 1 扇为主、长墙 2 扇"，与片子的 1–2 扇吻合；
  - 窗型分布：window 152 / shutter 48 / window2 13 / arch 2 / door 2，`decoFailures = 0`。
- 差距：① 片子里**看不到百叶窗**，本仓在"六类墙饰"模式下会成对出现 48 扇（来自 `surface-decoration.js` 的 WFC；片源未验证，属额外风格）；② 片子的窗台是白色薄板、几乎与框同宽，本仓 `WINDOW_SILL_SCALE=1.6` 明显更宽；③ 片子玻璃是"深蓝灰 + 白十字"，本仓玻璃走顶点色 + 反弹光，近景里会偏亮（截图里四格仍能分清）；④ 窗型选择仍是"连通组+层"哈希，不是片子所说的独立小 WFC 求解器。
