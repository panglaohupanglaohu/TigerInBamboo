## 判定

**有机制**：真平面倒影，三条硬性质 ——
1. 倒影紧贴岸脚、随岛体轮廓镜像（不是贴图/模糊）；
2. 只在**水面**上出现，被岛体挡住的地方没有倒影；
3. 越远越淡。

## 代码落点与差距

**本轮改了实现（r181 判定的真缺口在这里收口）**：

- 新增 `src/water/planar-reflection.js#PlanarReflection`：镜像相机（绕 y=0 反射位置/朝向/up）+ 斜近平面裁剪（oblique frustum，只留水面以上）+ `bias·P·V` 的 world→uv 矩阵；RT 清成 **alpha=0**，没有几何的地方 alpha 0，水面按 alpha 混色（不会把天空色二次铺到水色上）。
- `src/world/view.js`：水面 uniform 加 `uRefl / uReflMatrix / uReflStrength / uReflTint`，片元里 `ruv = (uReflMatrix·vWorld).xy / w`，按 `refl.a * strength * edge` 混入 `mix(refl, 水色, 0.45)`（= 1215 说的 flat coloured mid point）；`render()` 在主渲染前画反射图（隐藏水面/影接收面/裙带/浪带/旧倒影层）；`setDebug('reflection')` 改成控制反射强度；`?refl=0` 关档。
- 旧「镜像双网格」`reflection.js` + `view.js` 的 `scale.y=-1` 网格保留但**主场景常隐**（只给 `reflection.html` 实验室），并修真 bug：`cloudShadowTone()` 只在传了 cloud uniform 时才注入 GLSL，没传就整支 shader 编译失败 → r181 记的 `tests/reflection-browser.cjs` 红（`below:[0,0,0,0]`）就是它；现在 shader 按有无 cloud 分两版，该测试 **PASS**。
