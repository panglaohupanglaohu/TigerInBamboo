## 判定

**有机制，且机制已在本仓落地（旧 note 的「任意轮廓插入 / 周边重网格仍缺」是过期账，第 39 次同型）。**

- 任意（可凹）轮廓拼进共形三角网：`src/build/splice-polygon-c09.js#spliceFootprint`（文件头署本片 ID）—— 受影响三角并 R 向外扩到边界是**单环** → R\poly 带洞桥接 + 耳切（不丢共线点）+ 约束 Lawson 翻边（外环边/占地边不翻）。
- 落到真实地形：`prepareFootprintSplices`（同层、裸露、非河、非旧拼的格顶扇形按共享角点 id 合成）→ `src/terrain/terrainmesh.js:105` 准备、`:230` 跳过被替换的扇形、`:314` 写新三角 + 墙 + 四坡顶。
- 半边绕顶点：页面用 `src/core/halfedge.js` 的 `vertexFan` 逐个顶点走扇。
- 已有 node 测试：`tests/c09-terrain-c.mjs`（面积守恒 / 半边一致 / Euler / 环数 / 真实台地）。

**真缺口 = 从来没有页面运行验收**：`splice-c09.html` 早在（探针 `__c09splice`），但全仓没有一支浏览器测试跑过它，也没人看过截图；因此不敢标 done。

## 代码落点与差距

- `splice-c09.html`：本轮补 ① `?on=0` 关档（同机位 A/B）；② `window.__c09ctr`（占地中心 + 地面层，两档都写，供测试钉相机）；③ 探针扩到 24 个字段（扇角合 `fanMinDeg/fanMaxDeg/fanFull`、`baseErrors/baseLoops`、`srcTris/kept/removed`、`polyVerts/concave/fillRatio`、`cellsHit`、`roofTris/walls/houseTop/levelHeight`）。渲染逻辑一行未改。
- 差距（如实口径，不计缺口）：① 混合格拼接处最小角 **0.68°**（四方格 1.26°）—— 一个薄三角，卡在约束边（外环/占地边不许翻）上，肉眼不可见，半边/面积/闭合三项都精确；② 房子是「6 面墙 + 12 个屋顶三角」的直骨架四坡顶替身，没有原片那栋的烟囱与多段屋顶 —— 原文说房子本该来自预建 tile，本模块只负责「按占地拼进去」，故不据此立缺口；③ 整帧 A/B 不可用作判据：开档整帧（连天光）比关档亮 ~20 级，故 A/B 只数中心裁切。
