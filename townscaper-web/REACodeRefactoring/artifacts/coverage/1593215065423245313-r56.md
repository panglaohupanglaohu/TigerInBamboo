## 第 56 批（C09-A）

- 原文（README 第 65 行）："a lil dynamic sprite packer, able to add and remove sprite allotments at runtime … the sprites are baked live from meshes. So I guess it's basically impostors"。
- 片子机制（164 帧联系表 sheet-00/01 复看，原尺寸回看 120）：深灰板，球 / 方块 / 胶囊 / 花 / 球团 / 雪人等白模现场烘成大小不一的精灵；每个分配区有编号，存活的描黄框；一批批加满再一批批删；删掉处留暗淡旧图（调试残影）直到被新分配覆盖；有的分配区里是同一网格的多个视角（"1" 号是 4 个方块）。
- 原缺：单视角分配区与编号 UI、释放残影、自动扩容/重排、原素材、完整 SpriteAtlas 接口。
- 本轮：`src/life/sprite-pack-c09.js`
  - `SpritePackPlan`（纯逻辑）：分配走共享 `Atlas.place`（候选 + 跨叶，key 释放）；单视角或 2×2 视角；编号递增；`remove(id,{residue})` 记残影；新分配盖到的残影删除；满板且开 `grow` 时调用共享 `Atlas.grow()` 整批重排扩容，返回新旧位置映射。
  - `LiveSpritePacker`（GPU）：清整个分配区 → 按视角烘焙；释放时把 RGB 和 alpha 一起乘 0.38（透明处仍透明，精灵成暗淡残影），或清透明；扩容时新建 RT，把存活分配区原样（NoBlending 拷 RGBA）搬到新位置。
  - `spriteMeshes()`：球、方块、胶囊、圆柱、花（5 瓣）、球团、雪人、扭结、毛球白模（程序化替代原素材）。
  - 新页 `atlas-live-c09.html`：自动"加满 → 删空 → 再加"循环，叠加层画空闲叶深色框、存活黄框 + 白编号、残影灰编号；`grow=1` 满板扩容，`residue=0` 改为清透明。旧 `atlas-live.html`（8 视角 Baker）不动。
- 测试：tests/c09-life.mjs PASS（另跑 atlas / atlas-crossleaf / rectpack-compat / impostor-pitch / impostor-bend / uv-bake 均 PASS；全量 302 个 tests/*.mjs 全部通过）。断言：编号、2×2 子格在分配区内、残影记录与覆盖清除、放不下返回 null、扩容后搬运不改尺寸且记录跟随、2000 次随机增删每 100 步无重叠、残影永不与存活区重叠。
