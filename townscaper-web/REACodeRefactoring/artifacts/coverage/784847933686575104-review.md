## 逐帧观察

紫红纯色底，一个灰白（无贴图、单色）的球面壳体在画面中央缓慢自转，同时**从一小片长成整个球**。

- 0000–0010：只有一小片薄片（约 2–4 格），立在中上部；片边缘是断口，能看到往下落的侧壁。
- 0011–0030：沿断口边缘一格格往外长，长成一条弯曲的壳带；开始出现**圆柱状小柱**（只有一格宽、比周围高出 2–3 层的塔）。
- 0031–0060：壳带围成 C 形，中间镂空，能直接看到壳体**内壁**（说明是薄壳，不是实心球）；缺格处露出背景色。
- 0061–0100：补到半个球，表面出现明显的**台地分层**：等高的一圈圈台阶，台面边缘有竖直侧壁，形状是五边形/六边形的不规则格。
- 0101–0180：继续铺，缺口缩成几个多边形空洞；球面大部分已是台地格子，柱子零星分布。
- 0181–0267：铺满整球，之后只剩匀速自转，表面不再变化（末帧 267 与 240 帧结构一致）。
- 量化：非背景像素占比 0.5%（0000）→ 12.5%（0020）→ 20.7%（0100）→ 41.6%（0267），峰值 42.6%（0260）。是"长出来"的，不是"换个角度看同一团东西"。

## 判定

有机制：**球面胞元壳的逐格装配生长**。
1. 球面被切成胞元（五/六边形），每格按高度量化成台地，格与格之间高度差处生成竖直侧壁；
2. 装配不是一次成型，而是从一个起点沿邻接前沿一格格铺开，未铺到的邻格按 0 层处理，于是前沿出现"一路落到海平面"的断口侧壁；
3. 铺满时断口侧壁消失（等于把切口补上）。

## 代码落点与差距

`src/sphere/planet.js`（球面 Delaunay → 对偶胞元 → 台地 → `planetMesh` 顶面+侧壁）原本已有 1、3 两件事，**缺 2（装配时间轴）**。本轮补：

- `assemblyOrder(planet, {mode:'frontier'|'height'|'shuffle', seed, root})`：frontier 模式从起点沿邻接前沿生长，序列的每个前缀都连通；陆地不连通时按最小优先级补种，起点数恒等于陆地连通块数；同种子同序。
- `assemblySlice(planet, order, t)`：进度 → 已出现格集合。
- `planetMesh(planet, at, {only})`：只出已装配的格子；被隐藏的邻居按 0 层处理，前沿自动出断口侧壁；`only=null` 与旧行为逐值相同。
- `planet.html`：装配滑杆 + 装配播放（6s 一遍）+ 白模 + 薄壳（无海核）四个入口，状态进 `window.planetDemo` / `window.planetAssembly`。

做到哪：装配顺序、断口侧壁、白模、薄壳都对上了片子；页面实测铺满 618 格。
还缺：① 片子的生长起点是一处随机位置，页面固定用"最高格"，`root` 参数已留但没做 UI；② 片子里同一层内还有更细的裂缝/碎屑（片子表面那些细碎的凹坑），本仓只有整格级别的台地，没有格内细分；③ 单色光照用的是固定方向光，片子里明暗更硬（近乎环境遮蔽），未对齐。
