## 判定

有机制，且与原文一一对应：块（Patch）为松弛单位、块边界共享、顶点被多个表示插值后仍严丝合缝。片中的明暗差是调试可视化（当前块高亮），不是地形/材质。

## 代码落点与差距

- `src/core/infinite.js`：`buildInfinite()`（块 = 六边形 patch，`quadPatchTopology` 生成内部四边形，块/簇各自 `relaxPolygons`，外圈钉住）+ `verify()`（翻折 / 非法 / 相对原始点阵的拉伸）× `grids.html` 无限网格页四种模式（未松弛 / 只按块 / 只按簇 / 块+两簇插值）。机制本轮未改、未发现偏差。
- 本轮补的是**片中调试视图的两件东西**（原来完全没有）：
  - 「顶点圆点」开关：把每个顶点画成 1.35px 圆点（片子里整片点阵是显式画出来的）；
  - 「高亮 1 块」开关：把一块的四边形全部重涂成 `#f6f2e6` 并描白边，用来盯住"同一块在松弛前后 / 被邻居拉走"的情况。
- 仍缺：片子是**斜视 3D**（近处块被压扁、远处收敛），本页是 2D 俯视，透视压缩看不出来；片中"高亮块短暂消失再回来"的闪烁节奏没有复刻；簇没有单独上色（片中也没给，属推测）。
