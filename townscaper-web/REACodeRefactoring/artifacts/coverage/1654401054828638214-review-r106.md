- 原文：An quaint island being procedurally generated

## 逐帧观察

- **0000–0030**：空场里先出现两三条黄绿细线，交点只有一个 —— 三角网的种子。
- **0030–0120**：线一条条接上去，包住的圆盘越来越大，全程**没有填色**，交点从十来个涨到上百个。
- **0120–0123**：线网最后一次加密后**在同一帧里换成灰面**（sheet-01 的 0123→0124 那一格）：边还在，但面开始有灰度了。
- **0124–0222**：整片是**灰底的体块**，面与面之间靠灰度差分开（frame-0150 / frame-0200 原尺寸：台顶最亮，大岩体右侧的背光面暗一档，岩体下缘与地面之间的凹缝最暗），外加一层线框叠在上面 + 一圈白色岸线。**没有材质颜色**。
- **0223**：单帧纯黑剪影（阶段切换空档）。
- **0224–0229**：颜色一次性上来（沙滩 / 草绿 / 岩灰白 / 浅黄屋顶），形状在这一帧之后仍在变。
- **0229–0260**：中间那块台地**继续被抬高、加宽**（frame-0260：中央岩体更高更宽，右侧多出一段崖面），左下角出现塔状岩柱 —— 这段不是"换种子重铺"，拓扑没变、颜色没重随机。
- **0230–0343**：形状基本稳定，只有极轻微的相机漂移。

## 判定

有机制，三段管线：**增量三角化 → 同一张网抬成 3D → 先灰模（带 AO/软阴的明暗）再上色**；上色**之后**还有一段"按笔刷改高度"的地形微调（台地扩张）。

> 口径纠正（本轮）：r56 记的"暗灰阶段带环境光遮蔽与软阴影"在本片是**弱信号** —— 灰模主体是灰底 + 线框 + 白色岸线，灰度差只有一到两档（台顶 vs 背光面 vs 凹缝）。所以本地做的 AO/软阴是**比原片更强**的实现，不追求逐像素等价；能对上的是"凹处暗、背光面暗一档、边缘是渐变不是硬边"这三条定性关系。

## 代码落点与差距

- 已有（r56 起）：`src/terrain/pipeline-stages.js`（`delaunay` Bowyer–Watson、`liftHeights`、`stagePlan`/`StageRunner`、`buildIsland`）+ `terrain-stages.html`（主画布 + 四张阶段缩略图）。
- 本轮补齐（原登记的两条剩余缺口）：
  1. **灰模 AO 与软阴** → 新模块 `src/terrain/clay-ao.js`：
     - `vertexAO()`：半径 2.6 内按距离加权累 `(h_j - h_i)/levels`，凹心被压、台顶为 1；
     - `sunShadow()`：沿太阳水平方向步进 14 步，射线高度 `h + t·tanSun`，撞到更高顶点即记一次遮挡，返回**被挡比例**（0..1，所以是软的，不是二值）；
     - `shadeFactor()`：`(1-aW + aW·ao) · (1 - sW·shadow)`，下限 0.34；`triShade()` 取三点均值给页面。
     - 页面：`bakeClay()` 在 `make()` 里算一遍并用 `WeakMap` 按三角形数组对象取回 shade；`paint()` 把原来的常数量 `0.04 + slope*0.03` 换成 `0.04 + slope*0.02 + (1-sh)*0.62`；侧栏加「灰模 AO 软阴」勾选框（可 A/B），读数栏出 `AO 0.612–1.000（97 档）· 软阴均值 13%`。
  2. **生成后地形微调** → `pipeline-stages.js` 新增 `tweakTerrain(points, heights, {cx,cz,radius,delta,levels})`（半径内余弦 falloff、整数层、夹 0..levels）+ `terraceArea(points, tris, heights)`（三顶点都在水上的三角形面积和）。
     页面加按钮「生成后微调（抬台地）」，**不换种子、不重算 Delaunay**，只改高度 → 重烘 AO → 重画，读数栏记台地面积与微调次数；`window.terrainStages.tweak()` 返回 `{before, after, changed, steps}`。
- 差距（明确不追求）：原片是 Unity 实时拾取渲染 + 白光照射的灰模，本仓是 canvas 等距投影的平面填色 —— **不是视觉等价**；片中的白色岸线（等值线）本仓在 `contour.html` 有独立实现，本页没叠。这两条属于"表现层不同"，不再是"机制没做"。
