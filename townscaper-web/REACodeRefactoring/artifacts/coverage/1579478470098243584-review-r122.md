## 判定

有机制。机制 = **对 cell 做笼形变（cage deformation）**：每个格在每一层切面上是不同形状的多边形，
竖向角点段被拉弯、崖面内收/外凸/出洞口，并且这套形变必须是"可碰撞的"（原片崖面上没有直柱可贴）。
所以这条片子的 done 门槛是两问：① 形变壁面**内部**（不只是角点）能取到点；② 形变后的岩体有 3D 包含/推出。

## 代码落点与差距

- `src/terrain/cage-c09.js`（r56 C09-D，文件头就署本片 ID）：
  `cageWallPoint(shape,a,b,lv,u,v,L)` 壁面**内部**任意 (u,v) 点、`cageSlice` 连续层截面、
  `insideCage` 3D 包含、`cageCollider` 的 `wallsAt/cellAt/solid/wallDistance/pushOut` 形变后碰撞。
- `src/terrain/shape.js` `shapeTerrain`：连续层高采样（分数 `s` 插值相邻切面）+ 崖顶收分/噪声/Taubin。
- `src/terrain/terrain-strokes-c09.js#cageSegments`：原片那种"每层多边形 + 竖向弯笼边"的线，直接由 `shape.at` 取。
- `src/world/build-reel-c09.js` preset `cage` + `island-build-c09.html?mode=cage`：主场景同一个 World/WorldMesh 上
  播 `wire → hold → color`（着色时笼线还叠着，overlay 6s 后淡出）+ 转镜。
- **本轮补的两件（原来是旧账）**：
  1. `cage.html` 新增「笼碰撞探针」——`cageWallPoint` 与 terrainmesh **实际发出的墙四边形**在 5×3 网格上逐点对账，
     并把塞进岩石 0.08 的探针用 `cageCollider.pushOut` 推出来（红=原位置、绿=推出位置、青点=壁面采样），
     读数写进 `#probeStatus` 与 `window.cageProbe`。**旧提示语「未实现任意扭曲壁面内部插值/形变后精确碰撞」已删**（r114 教训：页面提示语也会变成假账）。
  2. 新测 `tests/cage-deform-browser.cjs`：页面级运行验收 + `?mode=cage` 的成片时间结构。
- 差距（如实，不计机制缺口）：原片形变"radical"，本仓 `shape.js` 的顶点水平位移量级只有 **0.066**（弯曲量），
  视觉上比原片保守；原片公式未公开，强度只能由现有分层平滑/崖顶收分给，属**美术强度差**，不是机制缺。
