## 判定

有机制，四件事都能在本仓落到具体模块（不是纯美术摆拍）：

1. **两队混战**（蓝守军 vs 红/粉维京人、掉血、尸体、草地血渍）→ `src/badnorth/battle.js` 的 `#hit` / `#bleed` / `#step`；
2. **小屋失守 → 烧 + 黑烟 + 屋体炭黑** → `battle.js` 的门口燃烧计时（4s）→ `view.effects.fireSources` + `view.smoke`（`setFireCoupling`）+ `battle-c01.js#charStep` / `house-char.js#charHouseVerts`；
3. **屋周焦痕 + 余烬** → `battle-c02.js#scorch`（`C02_FLAGS.scorch`，屋基 + 门口各一片不规则焦黑斑）+ `embers`；
4. **两队旗**（旗杆 + 贝塞尔旗面 + 白徽 + 风场飘动）→ `battle.js#flag` / `#updateFlag` + `life/banner.js`（`FLAG` 三色：浅蓝 / 橙 / 薄荷）。

## 代码落点与差距（本轮核实）

旧 note 的「仅判读未做运行时对齐」成立；`【卡点·A 机制未做】` 是**过期标签**（r56 已把 houseFx 落到 battle-c03，本片 ID 还署在 `house-char.js` / `battle-c03.js` 文件头）。但复核发现**一处真接线缺口**：

- `charHouseVerts` 只把**屋体顶点**压黑，不铺地；焦痕贴片在 C02（`scorch`）与 C03（`houseFx`）各有一份，**两处默认都关** → 主战场「黑屋有了、屋周焦痕没有」，与片里 0060/0299 的暗红焦痕带不符（片里焦痕是原片默认观感）。
- 本轮修法（照 C01 `houseChar` 先例）：`battle-c02.js` 新增 `C02_DEFAULT_ON = ['scorch']`，构造时先开后解析 URL；`?c02=-scorch` 关档。其余 C02 开关维持默认关。`tests/c02-bn-fx-b.mjs` 的「默认全关」不变式同步改成「只有 `C02_DEFAULT_ON` 里的开」。
- 顺带记一条探针陷阱：`effects.showFire` 是**只写 setter**（`src/life/effects.js:197`），读回永远是 `undefined`，真值应读 `effects.fire.visible` —— 本轮读数里 `showFire:false` 是这个原因，不是火没开。
