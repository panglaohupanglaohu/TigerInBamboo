## 第 56 批
- 原缺：反弹反馈用平均 RGB / 逐格反照率；没有 SDF 的 RG→UV、没有 mega texture、六向体积不按命中 UV 取纹理。
- 本轮新建 `src/light/megatexture-gi.js`（与 lightvolume.js 同口径的共享 World 体素化，不另建格子）：
  - mega texture：每个暴露体素面 = 1 纹素，按 (法线方向, 层) 平面再 4 连通拆 chart，货架装箱（terrain 岛 9256–9849 纹素、927–984 片、填充 32%）。每纹素存位置 / 法线 / 反照率 / 直射 / 间接 / 出射。
  - SDF 体积：RGBA Float32，A = voxel-distance.js 有符号中心距离，RG = 最近表面纹素在图集里的 UV（贴面空格多源 BFS 传播）；查纹素时真按 UV 回查图集。
  - 六向光体积（粗格 2×）：每空格每轴 1 lobe × 5 条射线（轴向 + 4 条 40°），对 SDF 球步进（lowerBound 大就跳，近表面 DDA），命中时取「命中前最后空格」SDF 的 RG → UV → 纹素，读 mega texture 当前出射光；朝上逃逸 = 天光。命中缓存一次，每轮只重做 gather。
  - 照亮 mega texture：出射 = 反照率 × (太阳 N·L·SDF 可见 + Σn²·lobe)。
  - 量化：SDF-UV 纹素 = 精确穿越面 82.5–82.9%（RG 是「最近纹素」，不总是射线真正穿过的那张面——这是原作编码本身的近似，单独统计）；SDF 步进与纯 DDA 1251/1251 条随机射线命中同一格。
- View：`?c11=megagi`（src/world/view-c11-megagi.js，经 view-c11.js 分发，默认关不加载）把实例 bakeGI 换成 mega 烘焙，写同一 aGI/uGI；太阳/World 变了走原防抖重烘；关闭还原。
- 演示页 `megatexture-gi.html`：三张贴图（SDF / 六向体积 / mega texture，可切出射/反照率/直射/间接）+ 同一共享 World 主场景、太阳方位、反弹数、慢放。
- 判定：done。机制（SDF 存距离 + UV、体积对 SDF 射线、按命中 UV 采 mega texture、照亮 mega texture）全部在共享系统复现。差别写明：纹素 = 体素面而非原作三角网 UV 展开；SDF 为体素中心 EDT 而非连续形变表面 SDF；CPU 烘焙（~0.3–0.4 s）。
