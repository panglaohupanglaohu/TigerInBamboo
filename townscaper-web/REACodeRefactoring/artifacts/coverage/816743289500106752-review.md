## 逐帧观察

- **场景**：504×356，灰白"石膏/黏土"材质的多层台地岛（Townscaper 那类模块化体），台地边缘是圆角，等高线式的层叠——能看到 3–4 级高度，台地之间用斜坡/台阶连接；岛缘有一圈白色水线（泡沫）细带，水下部分渐隐。
- **单位**：成群的小人偶——白色/骨色头盔 + 深蓝身体（海军兵），高约 8–10px。初始帧（0000）三块台地上各有一团约 40–80 人，排成 3–4 排的密集方块，队形整齐、朝向一致。
- **0–8s（frame 0–130）**：三团开始拉长。中上部那一团先沿台地边缘拐一个直角，前端顺着斜坡往下走，队尾还留在原地，形成一条弯折的"长蛇"（frame 0120：一条队从上台阶绕过拐角再下到中间平台，另一条在右侧台地拐弯），路径上能看到一串白色小点（引导点）。
- **8–16s（frame 130–270）**：长蛇走到下层台地后重新收拢成方块；右侧台地那一团同时往下走，形成第二列。frame 0240 是两队并行、一队在上层台地贴边走、一队在斜坡上排成竖列。
- **16–26s（frame 270–430）**：各队陆续回到"方块"状态，位置比初始帧更靠下、更靠右；末帧（0430）仍是三团方块，队形间距均匀，没有掉队、没有互相穿插。
- **相机**：全程固定等轴测视角（不推不转），地形一帧都没变——片子在演示单位，不是演示地形生成。

## 判定

**有机制**：成列行军 + 集结。落点很清楚：

1. 单位以**列队**方式沿一条路径走（前后间距恒定，队列整体贴着路径弯，不是各自独立寻路）；
2. 队列能**跨台地层**（上台阶、下斜坡），身体高度跟着地面走，脚不悬空；
3. 到达后按 3–4 排**重新集结成方块**，间距均匀；
4. 路径在画面上有白色引导点串（调试视图），与 `path-samples.js` 的等弧长撒点口径一致。

不是纯展示：画面里没有 UI、没有美术包装，就是灰模 + 单位在验证队形与跨层行走。

## 代码落点与差距

- 已有：`src/badnorth/battle.js`（单位、`paused`/`update`）、`src/core/unit-ground-height.js`（踩地高度）、`src/core/unit-tier.js`、`src/core/nav-visibility.js`、`src/core/path-samples.js`、`src/badnorth/landing-plan.js`（登陆编队）。
- 缺：
  1. **成列行军**：现有单位是按各自目标点移动，没有"沿同一条路径按固定间距排队"的队列（列宽、前后间距、拐角处内圈减速都不存在）；
  2. **跨层列队**：上台阶时队列没有被拉成竖列的处理（片中 frame 0240 斜坡上明显变成一列），现有 `unit-ground-height` 只保证单人贴地；
  3. **到达集结**：没有"列队走完后展开成 3×N 方块"的落位逻辑（`landing-plan.js` 只算登陆点，不算方阵排布）；
  4. 路径引导点串的调试渲染（白点）没有入口。
