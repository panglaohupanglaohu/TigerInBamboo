## 第 56 批

复核：624 帧 sheet-00..06 全部逐格看过，原尺寸回看 0200（左上 RGB/LAB/HSL 三个页签 + 三条滑条，选中节点在矩形外单独一个色块）、0305（右键菜单 New node / New gradient / New triangle）、0550（矩形 + 白收束三角 + 底部色带，色带菜单 OkHsl ✓ / OkLab / Srgb）。矩形与三角内部都是小三角面片平涂（菱形格），角节点可拖（0100–0110 矩形被拉歪）。

原缺（r53/r55 记录）：白三角只是预览；OkHsl/OkLab、自由拖点、色带编辑、导出、离散三角网都没有。

本轮做了什么：
- 新 `src/core/okhsl.js`：Ottosson OkHsl 参考实现移植（compute_max_saturation + Halley 一步、find_cusp、find_gamut_intersection、get_ST_mid、get_Cs、toe），和 `src/core/oklab.js` 同矩阵；纯红 = 29.23°/1/0.568 与参考一致，2 万色往返误差 1.3e-3。
- 新 `src/core/palette-graph.js`：共享节点 + 矩形 / 三角 / 色带三种图元，各自细分数与插值空间（okhsl/oklab/srgb）；`facets()` 离散面片（矩形 n×n 格交替对角线两三角、三角 n² 子三角，取质心色）；`quadFacetAt/triFacetAt` 与画布同一规则（实景取样用）；`swatches/paletteStrip` 去重调色板条带；`exportGraph/importGraph` 往返一致；`colorWorldByGraph` 把真实 World 每格（u=格 hash，v=归一高度，高处进白收束三角）映射到离散面片色。默认面片 OkLab（片中矩形内部是发灰过渡，OkHsl 会绕出鲜紫）、色带 OkHsl（0550 菜单勾选项）——这是对画面的推断。
- 新 `src/world/ground-palette-map.js`：链在 `view.material.onBeforeCompile` 后（不改 view.js），每格离散颜色栅格成世界 XZ 图（Nearest），片元在 emissivemap 前写地形顶面 / 建筑顶 / 岩壁；默认关。
- `palette-editor.html` 只在页尾追加「节点式调色图」：拖节点、右键菜单三项、RGB/LAB/HSL(OkHsl) 滑条、色带空间与面片空间菜单、细分数、导出 JSON+调色板条带、导入、「应用到实景顶面」。原四角编辑保留不动。

判定：done（片中每项机制都有：自由拖点、右键 New node/gradient/triangle、三套滑条、离散三角面片、白收束三角、色带 + OkHsl/OkLab/Srgb；另接实景）。原 Unity 工具内部公式未知，细分规则与 HSL 页签用 OkHsl 是本地选择。
