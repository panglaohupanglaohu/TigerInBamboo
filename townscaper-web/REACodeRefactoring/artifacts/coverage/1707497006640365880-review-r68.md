## 逐帧观察

- 0000–0039：一座小岛逐层抬升；橙粉色灌木带压在**每条台地边缘与崖顶**上，带宽约当层高度的 8–12%；岛前另有一小块独立圆盘台地。
- 0010（原尺寸 + 2.4× 裁切复看，本轮关键帧）：孤立圆盘顶面**整整一圈**橙带——连朝向沙嘴的那一侧也在（不是只盖外侧）；圆盘内部是深浅两层粉褐颗粒面，外圈是近白细沙裙。同帧岛体草地直接临水的那圈边也压着橙带。
- 0043–0046：整帧黑（相机穿进岛体，无内容）。
- 0050–0552：地形长高，带宽随该边落差变化；有的边明显粗（多层崖），有的边只有一条发丝。
- 0560–0599：整片台面**几乎被橙粉铺满**，只剩零星浅色草斑——带宽是低频噪声大幅调制的，同一座岛可以窄成发丝、也可以宽到盖满整格。

## 判定

有机制：灌木是**纯纹理**（三角线框直接穿过灌木，没有几何、没有广告牌），沿「东西的边」上色；带宽 = 低频噪声 × 该边落差，**能一路涨到整面覆盖**；外缘是小圆齿扇贝边；灌木内侧草地上有一道窄阴影。

第 68 轮量出来的两处差异：
1. 本仓 `shrubEdgeFlags` 的门控是 `og >= 1 && og < g`（不含临水），原片圆盘与临水崖边**都有**橙带 → 360° 环被切掉一侧；
2. 本仓 `setShrubStyle` 的 width 上限 0.6，乘着色器里的 `(.55+.9*bfbm)*mix(.5,1,cover)` 最多到 d≈0.87，永远盖不到格心 → 0560+ 那一档渲不出来。

## 代码落点与差距

- `src/terrain/shrub-edges-c09.js` `shrubEdgeFlags()`：门控改为 `og < g`（沙岸不长是因为**本格自己是 sand**，已在 `terrainmesh` 的 `shrubby` 里排除，不是「邻居是水」）。
- `src/world/view.js` `setShrubStyle()`：width 上限 0.6 → 1.2。
- 实测（`tests/shrub-ring-browser.cjs`，活世界 + 真模块）：临水边 0/67 → **67/67**；孤立台地整圈 5/7 → **7/7**；`setShrubStyle({width:1.15})` 由抛 `Invalid shrub style` → 通过，俯视截图显示台面接近整面覆盖。
- 仍缺：带宽现在能盖满，但**没有「按落差自动选档」的规则**（原片窄/满两种状态是地形长高过程中自然出现的，本仓要手动调 width）；齿距在大幅覆盖时的密度未再标定。
