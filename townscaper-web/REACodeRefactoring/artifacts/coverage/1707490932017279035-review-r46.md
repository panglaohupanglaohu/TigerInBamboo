## 逐帧观察
- 0000–0044：近景俯视，线框模式。黑色三角线框**直接穿过**鲑橙色灌木带 —— 灌木没有自己的几何，就是低模顶面上的颜色。灌木沿台地边缘一条带，宽窄不一（局部变宽成团、局部断开），外轮廓是一串小圆齿 / 锯齿。
- 0045–0060：镜头拉远转向，可见红顶小屋；同一种灌木沿各层台地边缘出现，崖面本身不长。
- 0060–0256（frame-0200 原尺寸）：岛的另一侧，带状沉积纹的圆柱崖；灌木在崖顶沿与下一层台地沿，靠**格心一侧的草地上有一道窄的深色小阴影**，灌木身上有亮一些的团块；靠海的沙岸一圈没有灌木。

## 判定
有机制：「纹理灌木」= 顶面着色，按到边缘的距离 + 噪声定出一条带，外缘扇贝齿、内侧一道小阴影 → 看起来有体积。不是广告牌、不是几何。

## 代码落点与差距
- `src/core/meshwriter.js`：新增 `aEdge` 顶点属性（`edgeTri` 由调用方给，翻绕序时同步交换），`toGeometry()` 输出；`src/world/worldmesh.js` 分块拼接 / 哈希带上 `edge`。
- `src/terrain/terrainmesh.js`：顶面扇形每顶点写到崖边的归一化距离（边外侧是更低的陆地台地且本格是草 / 干草 → 该边两端 0，格心 1）；沙滩、河道、临海边不写（原片沙岸无灌木）。
- `src/terrain/shrub-texture.js`：`SHRUB_GLSL.shrubApply`：低频覆盖率（有的边断开）、低频宽度、两层噪声锯齿（扇贝齿）、`[宽, 宽+阴影宽]` 内侧小阴影、内缘细描边、受光亮团。
- `src/world/view.js`：uniform `uShrub / uShrubStyle / uShrubColor`、`vEdge` varying、只作用于顶面（`vField.z==1 && vUp>.8`）；开关 `shrubtex`（`index.html?scene=terrain&on=shrubtex`）；`setShrubStyle({width,ragged,shadow,coverage,color})` 带参数校验。
- 缺：没有沿屋墙根 / 房基的灌木（只做台地边）；阴影方向固定朝格心，不随太阳方向偏移；没有原片线框调试叠层的同屏对照。
