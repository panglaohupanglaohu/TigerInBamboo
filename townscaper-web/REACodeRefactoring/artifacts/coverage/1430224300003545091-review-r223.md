## 实现（src/tools/objexport.js 追加，geometryToOBJ/downloadOBJ 不动）

- `geometryData(geometry,{matrix})`：摊平 THREE 风格几何（有限值/索引/整三角校验照旧）。
- `bakeInstances(mesh,{base,color})`：InstancedMesh 烘成普通网格——实例矩阵 ×
  mesh 世界矩阵（自带 4×4/逆转置法线，不引 three）；逐实例色取
  `instanceColor → aColor → aCardColor → 顶点色`；退化/越界照旧抛。
- `sceneToOBJ(parts,{name,mtl,precision})`：mtllib + 每对象 `o`/`usemtl` 分节 +
  跨部顶点去重；默认精确值（与 geometryToOBJ 同口径，显式 precision 才量化）；
  同步生成 .mtl（每 newmtl 一个近似 Kd：town=白留顶点色、water=片元同一 0.55
  中点混色、植被=逐实例色均值）。
- `sceneParts(view)` / `downloadSceneOBJ(view,basename)`：收集 town/water/植被
  六组（墨线外壳 shrubInk/crown ink 与远景 impostor/farFields 面片替身不导），
  一次点击真实下载 .obj+.mtl 两文件。
- UI：index.html `#exportscene`（⇊）+ app.js 一行接线。

## 关键修复

混合「有/无顶点法线」部位时，`f v//vn` 的 vn 索引必须和 v 一一对应——首版只给
有法线的顶点写 vn，Blender 导入直接报 Invalid normal index（索引整体错位）。
改为缺法线顶点补一条永不引用的占位 vn 0 0 1，复测零警告。

## 如实边界

水面噪声/平面反射/云影与植被风摆是运行时着色器表现，不进几何文件；瀑布/水花/
烟/旗帜等特效与墨线外壳、impostor 面片替身不在导出范围；.mtl 每对象一个近似
Kd（逐顶点 RGB 扩展仍在），不声称与原作 mesh exporter 同格式、原片只展示过
灰白主体。
