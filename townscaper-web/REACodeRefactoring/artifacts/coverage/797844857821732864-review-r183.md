## 逐帧观察

- 0000–0007：纯底板。一块米色方形薄板悬在暗色背景上，无任何体素。
- 0008–0035：**一根竖直点柱**从板心往上长（塔的中轴），高度一路到板面上方约 3/4 画幅；板面尺寸、位置不变。
- 0036–0043：点柱两侧开始出现同高的点，柱体变粗；此时仍只有黄点，没有几何。
- 0044–0050：**白色细线立方框**成片出现，叠在已经实心的下部体量之上（0050 的 2× 里能同时看到：下部实体墙、中部线框格、顶部还是点）。
- 0051–0099：实体自下而上推进，线框层随之被吃掉；建筑出现拱洞、外挑楼板、屋顶栏杆。
- 0100–0116：机位**绕塔转**（0107 起能同时看到两个立面，0116 时正面几乎正对镜头），并轻微推近；**竖直棱始终竖直**——0116 右轮廓在 253 行内水平漂移 <1px（最小二乘斜率 −0.0024 px/行），所以是**正交环绕**，不是透视推轨。
- 0116 的 2× 放大（逐格细节）：每格外墙上都有一个**内凹的小竖槽**（宽约 0.3 格、居中略偏上，深色）；塔顶有两根细天线、一个圆形碟、一段栏杆；一处露台上有一丛小树；一层有贯穿的拱洞，从洞里能看到内壁。

## 判定

**有机制**，分三条：
1. 装配序 = 先中轴竖柱、再横向铺开（`voxelOrder('spine')` 已经在做，r61 已核）；
2. 机位 = 正交投影 + 绕 Y 轴方位角转动 + 推近（旧 note 写「缺真三维环绕镜头（本仓等轴测无透视环绕）」：前半句对，后半句错——原片本身没有透视收聚，缺的只是方位角这一个自由度）；
3. 外立面 = 逐格内凹窗槽 + 屋顶小件（天线/碟/栏杆/树）。

## 代码落点与差距

- `src/world/voxel-ghost.js`
  - 新增 `rotateY(x,z,deg)`、`isoProject(v,{azimuth})`、`depthOf(v,{azimuth})`、`cubeFaces(v,{azimuth,back})`：方位角进投影，竖直棱恒竖（正交）；
  - 新增 `windowSlot(v,{seed,density})` / `windowStats(voxels)`：逐格窗槽的「有/无 + 格面归一化矩形」，定种子可回放，开窗率 81.4%（613/753 非底板格）；
  - 新增 `cavityCells(voxels)` / `interiorFaces(voxels,{reach})` / `INTERIOR_TONE`：房间墙（见 7949 证据）。
- `voxel-ghost.html`：加「窗洞 / 内腔玫瑰墙 / 方位角滑杆 / 环绕」四个控件 + `?azim= / ?orbit=1 / ?punch=0 / ?interior=0`；`orbitAt(t)` 在 t>0.35 后把方位角从 0° 推到 26°（片尾绕塔），`dollyAt(t)` 保留 1.22× 推近；投影包围盒按方位角缓存重算（否则转 30° 模型顶出画面）。
- **做到哪**：环绕机位、逐格窗槽、房间内墙暖色，三件都有了运行验收。
- **还缺**：屋顶小件（天线/圆盘/栏杆/露台小树）仍是美术资产，未建；层带色只按 6 槽近似（见 7949）；内墙暖色是单色，不是原片那种随进深渐变的室内反射光。
