## 逐帧观察

- 0000–0099（0–3.0s）：俯视四边格小岛，高台上蓝旗部队静止，画面上只有台地轮廓的**连续**白线与水面，无点线；镜头几乎不动。
- 0100–0199（3.0–6.2s）：镜头开始绕岛缓慢环绕，台地两级结构逐渐露出，仍无点线，蓝旗单位原地不动。
- 0200–0299（6.2–9.3s）：机位降到侧面，上层台地与下层滩地之间的窄坡道露出；坡道上开始出现成串小圆点，但缩略图下只是一条浅色细带。
- 0300–0399（9.3–12.4s）：侧面近景（frame-0320/0330）。可清楚看到点线沿**窄坡道/崖沿的可行走通路**蜿蜒，一条从下层滩地上坡进入上层台地，另一条沿上层台地的崖沿外侧走。点线是断开的圆点，不与台地的连续轮廓白线混同；全程没有选中单位、没有命令路径箭头、也没有交战。
- 0400–0499（12.4–15.4s）：镜头继续绕到岛的另一侧，点线仍贴着同一批通道，位置随地形固定（不是屏幕空间贴图），转角处在坡面上一路爬升。
- 0500–0599（15.4–18.3s）：背面视角，能看到同一批通道的另一段点线；台地顶面轮廓线是连续实线，点线只出现在上下层之间的连接处。
- 0600–0623（18.3–19.1s）：末帧（frame-0620）停在正面偏左，至少三条点线链：左侧从滩地爬上中台、中部绕崖肩下行、右侧沿湾口窄脊下行到水边。全程无 UI 面板、无文字、无战斗。

点线量测（原尺寸 frame-0320，420×420）：圆点直径 1.5–2px，点中心近纯白（≈250），间距 4.5–5px，即**点距 ≈ 2.2 倍直径**；点落在深色坡面上，与背景差 ≈ 90–100 灰阶。

## 判定

有机制：**常驻的「窄通道」点线标示**——不是选中单位后的命令路径，也不是台地轮廓线。判据：

1. 全片没有选中单位（无选中圈、无路径箭头、无 HUD），点线却始终存在；
2. 点线只出现在「上下层之间的连接处/窄脊」这类瓶颈通道上，台地顶面与开阔滩地没有；
3. 镜头绕行一周点位不变，说明是世界空间里的固定标注，不是屏幕空间覆盖层。

## 代码落点与差距

- `src/world/traffic.js`：`narrowCells()` 从与移动同一套 `buildNav` 图上判「度 2 且无绕行替代」的格；`passageMarkers()` 把窄格与 `nav.stairs` 的楼梯连接都算作通道，每条无向边只处理一次，段内按 `spacing=0.16` 等距撒点（中点采样避免节点重复）。
- `src/badnorth/battle.js`：`refreshPassages()` 生成后向下射线投到真实形变地形与楼梯几何（避免线性高度插值把点埋进崖壁），单个 `THREE.Points` 批量渲染；`setPassagesVisible()` / `setDebug('passages')` 开关；版本变化或几何重建时重算。
- 本轮修补（原实现能算对但**看不出来**）：原材质 `#fff7e4` / size 4.5 / 16px 精灵 + `alphaTest .4`，实测 277 个点里只有 42% 超过 +20 灰阶，中位对比度 14.5/255、峰值亮度 210（不是白）。改成 8px 精灵（与屏幕尺寸近 1:1，避免双线性缩小糊掉）、纯白、`size 7`、`alphaTest .3`、`toneMapped:false` 后：中位对比度 14.5 → **43.1**，可读点占比 0.383 → **0.704**，峰值中位 210 → **225.6**，点位直径 ~2px → ~5px。
- 仍缺：本仓最后一道 composer 色调映射把「白」压到 ≈226，因此点线在浅色草地上的对比度（≈43）仍低于原片深色坡面上的 ≈95；原片点距/直径比 2.2，本仓 ≈1.6（略密）；点线目前只在北境 `battle` 里，未做成任意场景可用的调试层；不跟随迷雾/遮挡做淡出。
