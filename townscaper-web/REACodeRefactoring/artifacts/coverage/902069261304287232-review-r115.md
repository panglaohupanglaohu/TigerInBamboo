## 判定

有机制：**流场/距离/影响场的数据继承可视化** —— 每格记 dist（到最近源）、parent（往源走的方向）、src（继承来的源 = 兵种/队伍），
画面 = 格边骨架 + 每格往父格的短流线 + 按继承源上色。**不是**单纯距离场贴色。

本轮补的量（此前只到「模块在、页面能开」）：
1. **三项继承逐节点对账**：真实导航图层 386 个节点，`atNode()` 返回的 source 用「三源独立 BFS 跳数」独立核对 → **最近源 386/386 全对**；
   继承兵种 386/386；继承方向（parent 比本格更靠近该源）**382/386 = 98.96%**；距离全部有限非负。
2. **三色不再靠场景凑**：场景本来就是 步兵8 / 矛兵8 / 弓手8 三支守军 → 按兵种上色实测 **flowTypeColors = 3**，
   图例「流场配色 · 按兵种 步兵·8 矛兵·8 弓手·8」。r70 记的「第三色要等矛兵上场才量得到」由此关闭。
3. **LOD 维持不适用**（r75 已用实景页三档量测否证，本轮不重开）。
