## 逐帧观察
- 0000–0012：一块巨大的方形装饰图（四角卷草 + 中心十字纹），铺满视口，只看得见**一个**图元；底部 Photoshop「Inspector · Orientation 7」面板。
- 0013–0059：同一块图元被缩小（手柄与变换读数 −2750.9 / −528.4 可见），从"一个图元铺满"退到"面板中央一块"，四周是空画布。
- 0060–0120：图元尺寸缩到画布内一格，开始出现 2×2、3×3 的阵列；对照画面中央的虚线参考线，**相邻格互为镜像**（左右、上下都对称），没有硬接缝。
- 0121–0247：继续缩小 → 4×4…6×6，重复肉眼可辨；Orientation 由 7 变 3。
- 0248–0299：图案换成 Orientation=3 的另一种排布（大块深色三角 + 四角卷草），重复周期变短。
- 0300–0369：Orientation=4，整幅变成"大斜纹 + 卷草角"的另一种拼接，仍是镜像铺贴。

## 判定
有机制：**同一张 UI 装饰贴图，绕面板中心对折镜像铺贴**（相邻格互为镜像，避免硬接缝），配 8 种朝向（旋转 0/90/180/270 × 镜像）任意尺寸都能用；面板越长，重复次数越多，"拉太长就看得出重复"。

## 代码落点与差距
- `src/core/mirror-uv.js`：`fold` / `orientUV` / `mirrorUV` / `GLSL`（`foldMirrorUV` 即 `1-abs(mod(p,2)-1)`），`src/ui/ornament.js` 已在用它。
- `textures.html` 的 deco 页签原本自己写了一套**逐格翻转**（按左右上下半区 flip），和模块的"绕面板中心对折"口径不一致。
- 本轮改成 `decoPanel()`：格索引 k 的奇偶决定该格是否镜像（等价 `foldMirrorUV`），并把 deco 页签扩到 4 个子模式「只镜像 / + 8 向 / + 几种设置 / 拉太长」。
- 仍缺：贴图本身是程序化 48px 小图（`decoTile`），不是片子里的巴洛克卷草图集；九宫格边框拉伸仍未做。
