## 判定

有机制，且是「已实现但默认关」这一类（第 2 次同型于 r243 的 `houseFx`）：

1. **火团抛射**（片 ③）：`battle-c03.js#torchStep` r56 就落了「维京人贴近小屋 1.3 内、层差 ≤1 → 每 2–2.8s 抛一枚球体（内核 #ffb340 + 加法混合辉光 #ff7a30 + 火星拖尾），命中 `burn += 1.1` 并爆一小团火」，但 `torches` 一直**默认关** → 主战场开打期间屋顶根本不烧，只有失守后 `houseFx` 爆一次。
2. **奖励飘字**（片 ④）：`battle.js:1500 #damagePopup(v, KILL_VALUE, 'kill')` + `damage-numbers.js`（金色、同池上浮），`tests/kill-popup-browser.cjs` / `tests/damage-numbers-kind.mjs` 已覆盖 → 不是缺口；片内 +6/+12/+192 与本仓「1 血 = +4、击杀 = +10」是本地词汇差，不列缺。
3. **层间指令 / 阶梯支援**（片 ①②）：逐人层高 + 楼梯下坡在前几轮已验收，本片只做画面复核，不重开。

## 代码落点与差距

- `src/badnorth/battle-c03.js`：`C03_DEFAULT_ON` 由 `['houseFx']` 改为 `['houseFx', 'torches']`，`?torches=0` 关档（沿用 `?houseFx=0` 的显式关循环）。
- `tests/c03-battle.mjs`：默认档断言同步「只开 houseFx + torches」，并在用例里 `set('torches', false)` 复位，不影响其余用例。
- 新测 `tests/torch-fire-main-browser.cjs`（16 项）：默认开 / 真抛 / 抛物线 / 连抛 / 命中加燃烧 / 关档负对照 / 橙色像素 / mixed 复跑。
