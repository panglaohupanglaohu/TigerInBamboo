## 组合路径（全是真实机制，无布景/状态注入）

- 冬景：`#environment-theme` select 派发 change → `applyBadNorthTheme(view,'winter')`
  （与面板同一条路）→ bnTheme.sky #c4c7cb、场景背景换冬色、`frostVegetation` 挂霜。
- 雪：`[data-environment="snow"]` 复选框派发 change → `view.setDebug('snow',true)`
  → atmosphere.snow.visible + uSnow=1（表面积雪混白）+ 3000 粒。
- 船群/士兵/血：`battle.update(0.05)` 按真实 26 秒波次推进——长船 planLanding 靠岸、
  维京人下船、近战 `#hit`→`#bleed` 留血泊、击杀留尸体，全部自然发生。
- 黑烟：小屋 burn 机制要求「维京人在门口 4 秒且无守军邻近」。守军默认布防 target=屋门
  → defNear 恒真 → 实测 600s/24 波 0 屋失守。本轮 t=20.1s 用**玩家移动令同款机制**
  （`squad.goal=cell`/`goalFloor`，与 onPointer 同一字段路径）把三队守军重定向到
  导航可达、离所有门最远格（cell 671，门距 5.74），维京人随后真实占领门廊烧屋。
