# 长矛：654帧与固定轴伸出命中

## 素材
先读903647529203634176的README原文：Spears are so weird to implement. I can see why most games don't use them。全部654帧已查看，7张联系表、原尺寸帧及时间戳在同ID目录（0–653，0–19.979秒）。开头两支蓝队调整阵位；约120–250帧敌船靠岸、敌人沿岸接近；260–335帧接敌及红色战斗痕迹，337帧换机位；第二段左侧敌人靠向蓝队，约483帧再换到崖边，后段队伍在窄岸交战。能看到长杆武器、队列和成片的命中反馈，但不能从画面证明原作是胶囊扫掠或每次攻击的伤害规则。参数和下面算法是本地设计。

## 静态对照及实现
原版combatfx.thrust按静态轴投影筛选，spear.id每次调用自增并写入目标；若持续调用即会重复命中，不同矛的局部数字ID还可能冲突。重构Battle此前只有0.44范围内最近敌人即时扣血。保留既有小队、武器、美术和命中效果，本轮core/spear-thrust.js增加固定轴向前延伸的胶囊：0.18秒逐步伸到0.44，每次攻击持有独立Set，按目标对象去重，同一刺击只命中一次；新刺击可以重新命中。同帧按轴向距离排序。

真实Battle矛兵启动攻击后保持原点和方向，期间不走动；候选必须异队、离船、非坠落并通过已有分层canMelee高度/遮挡检查。受击中断、坠落和在船状态取消刺击，暂停不推进。零距离重叠使用朝向兜底，避免零向量异常。其他近战和弓箭保留现有路径。

## 验证
spear-thrust.mjs验证30/60/120Hz两名轴向目标各一次、侧向/身后排除、独立攻击Set、重复输入目标去重、外部遮挡谓词、暂停、斜向和无效参数。spear-browser.cjs在真实四边形及混合北境，用受控固定小队验证0.18秒攻击窗口、同刺两名正面目标各扣一次、侧面和另层不扣血、暂停、下一刺重置、眩晕取消。下一刺测试重置目标位置/坠落以隔离击退行为；不是整场战斗录像。量化报告spear-browser.json和截图spear-{quad,mixed}.png已查看。stun-browser及combat-state逻辑回归通过。

## 尚未覆盖
这是固定轴伸出，目标按每次更新位置检测；没有跨帧高速移动目标的连续相对扫掠、旋转矛身扫掠、盾格挡/实体堆挤与精确推力。武器暂沿用现有静态实例几何，尚无与时间窗同步的伸缩动作。大兵种与精灵受击动作仍待续，combatfx继续标部分覆盖。未同步TigerMessenger副本，未认证游戏实景。
