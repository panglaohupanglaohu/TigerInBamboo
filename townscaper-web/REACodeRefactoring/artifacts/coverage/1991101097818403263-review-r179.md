## 判定

有机制，且正是原文说的三件：① **循环顶点着色器**（不是模拟，没有主海面）；② 数据**生成时烘入**（每顶点 in 方向 / out 方向 / 时间偏移）；③ 浪「弹回来」——片子里能看到浪爬到岸线后**退回一点点**。

## 代码落点与差距

- `src/water/shore.js`（文件头署本片 ID）：`buildShore` 逐顶点写 `aIn`（岸→海的位移）、`aOut`（`bakeWaveMotion` 的镜面回弹）、`aPhase`（`k/waves + 0.14·sin(2s) + 0.05·sin(5s)`）、`aPeriod`（0.90+0.22·hash）、`aCrest/aWidth`（`waveCrest`，整数谐波 7/13 保证闭环无缝）；顶点着色器 `t = fract(uTime/(uPeriod·aPeriod) + aPhase)`，`center = aShore + aIn·cycle.x + aOut·cycle.y`，`cycle` 来自 `src/core/wave-cycle.js#waveCycleGLSL`（t<0.68 进浪 f:1→0，t>0.68 退浪 0.22·sin）。
- `src/core/wave-cycle.js#waveCycleGLSL` 两端透明度归零（t=0 → a=0，t→1 → a→0），所以 loop 回绕无缝；`waveCrest` 用 s∈[0,2π] 的整数谐波。
- 「碰撞」一侧的落点：`src/water/foam-mask.js#clampWavePaths`（穿岸顶点收回、`aIn/aOut` 同比缩放）+ `src/world/view-c10.js` 的 `?c10=shoreclamp`；泡沫 `?c10=foammask`。
- 旧 note 的「完整浪形」属原片美术（浪的细碎形状/颜色），不列为本轮缺口；「碰撞」本轮收口。
