- 0300–0305：稳态（草皮 + 绿篱 + 灌木），镜头继续环绕。

## 判定

**有机制**，而且是两条不同的时间曲线：

| 事件 | 片内读数（33.01 fps） | 形状 |
|---|---|---|
| 出现 | 1 帧到稳定值的 **1.372×**，4 帧 = **0.121 s** 单调回落到 1 | 过冲后指数收敛（back-out） |
| 消失 | **1 帧**塌掉（绿像素 7077→86），0225–0227 只剩 1% 残影 | 单帧塌陷，无过冲 |

**错峰（stagger）片子里证不出**：每次切换整组同帧完成。本仓的 `spread` 错峰标为「本仓扩展、无原片依据」。

## 代码落点与差距

**r190 记的「代码仍缺稳定道具键 / 保留消失几何 / 逐道具缩没 / 原 CPU 接口」是过期账** —— 四项在 r55/r56 就落了，且文件头署本片 ID：

- `src/core/prop-anim.js#PropLifecycle`：稳定 key（`cell:edge:kind`）+ 重建不重放 + 消失期保留槽位几何 + 每槽 `(x,y,z,scale)` 记录表；
- `src/world/prop-anim-layer.js#PropAnimLayer`：合并网格 + `aPropSlot` 属性 + 记录 DataTexture + 顶点着色器绕根点缩放（`propScaleGLSL`），World 变了只写新生槽位；
- `src/world/prop-anim-yard-r56.js`：后院真树/灌木接进来（`?yardanim=1`）；系缆桩走 `?propanim=1`。

本轮核实到的**真缺口**两条：

1. **曲线不对**：默认走 r53 的弹簧（ζ=.6 → 只有 9.5% 过冲、0.35s 才收；消失 outLife 0.35s），与片内 1.372×/0.121s、1 帧塌陷差得很远 —— 页面看得出「弹一下」，但过冲量只有片内的 1/4、消失慢 11 倍。
2. **没有运行验收**：`reviewStages.runtimeAccepted` 一直是 false，`tests/prop-anim-browser.py` 需要 python playwright，本机没跑过。

### 本轮改动（第 192 轮）

- `src/core/prop-anim.js`：新增 `PROP_TIMING`（`appearPeak 1.372 / appearRise 1 帧 / appearSettle 0.121 / vanish 1 帧 / slotHold 3 帧`，全部来自上面的片内读数）、`appearAt`、`vanishAt`、`timelineScale`；`PropLifecycle` 增加 `timing` + `curve: 'clip' | 'spring'`，**默认 clip**，`outLife` 默认 `slotHold`（0.091s，对上 0225–0227 残影）。旧的 `springValue/scaleAt` 原样保留，`curve:'spring'` 可整体回退。
- `src/world/prop-anim-layer.js`：透传 `timing/curve/outLife`；新增 `probe()`（曲线档 + 计时 + 缩放极值 + 正在出现/消失件数），页面探针与浏览器测试共用。
- 页面入口：`index.html?scene=town&yardanim=1`（后院真树）/`?propanim=1`（派生木箱/系缆桩）。**默认档仍为关**：开档会让 162 支按静态像素基线的浏览器测试整体位移，属口径选择，不是机制缺口。
- 测试同步：`tests/prop-anim.mjs`、`tests/prop-anim-layer.mjs`、`tests/yard-props-r56.mjs` 里「+0.05s 仍在收缩」的采样点改到半帧（+0.012s），因为片内塌陷只有 1 帧 —— 断言本身改成「半帧在收缩 / 一帧后为 0 / 槽位再留 3 帧」。
