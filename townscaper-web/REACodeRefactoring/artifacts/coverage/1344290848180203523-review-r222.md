## 本批实现（src/core/qa-replay.js，不引 three 依赖）

- `exposedWallFaces(world, L)`：枚举「已建层且邻格同层非实心」的外露墙带（与 buildings.js 出墙同一条件）；
  默认镇 quad 362 带 / mixed 332 带。岩石层走地形崖壁、顶面/屋顶另属顶盖，均不在此清单。
- `auditSurfaceCoverage(world, geometry, {L, index, strict})`：每带 3 沿边 × 3 高度共 9 个采样点，
  要求被一张三顶点都在墙面薄板内、竖直向的三角形的 (t,y) 投影覆盖。
  薄板 = 内 ≤ min(.10,.45·len)、外 ≤ max(.02·len,.13)（含基座外鼓 .085×1.35 与门窗凹进）；
  整带缺面与局部破洞都会被抓；strict 任一采样未覆盖即 invalid。实测默认镇两网格 9/9 全满。
- `floatingVoxels(world, L)`：本层实心、下一层空的已建体块，kind 按 underside() 同规则
  （方格且一对对边下层有支撑 = arch，否则 flat；flat 逐角按 vertexCells 共享占用判应立钢柱）。
- `auditUndersideSupport(world, geometry, {L, index})`：arch 核格内 footprint 下方拱腹朝下三角；
  flat 核 yBase 平底朝下三角 + 每个应立钢柱角点有一根整跨柱侧面三角
  （三顶点都在柱轴 .055 内、y 贯通 yFloor..yBase——w.beam 把每根柱画成一根跨越整段的方柱，
  侧面三角质心落跨中，按「空档层中点采样」会漏报，已改为顶点贯通判定）；
  world.steelFrame 时钢柱另走 emitSteelFrame，只核平底。
- `triangleIndex(geometry, g)`：三角形 XZ 均匀桶索引，供两条核查共用。
- `runWorldQA` 16 步回放逐步带两条核查（surfaceAudit 可关）；`runMonkeyQA` 每个核对点与最后一步同核。
  漏面/失支撑即抛错，finally 仍全量还原体素/色槽/河道/配色。
- `qa-replay.html` 状态行报墙带覆盖与悬空支撑计数。

## 验证

- `tests/qa-replay-r222.mjs`（node 真 WorldMesh，关烘焙）：双网格默认镇 3258/2988 采样点全覆盖、
  悬空 3 体块（quad 拱1/平2柱3，mixed 平3柱2）全有底；删一整带 / 抽平底 / 抽钢柱 / 拆拱腹
  四个反例分别被判 uncovered 或 unsupported(flat-bottom/post/arch-soffit)；
  runWorldQA 16 步逐步核查全过、四数组还原；runMonkeyQA 60 步 6 个核对点未覆盖 0 / 失支撑 0、结束悬空 9。
- `tests/qa-replay-r222-browser.cjs`（真页面 http://localhost:8769/qa-replay.html，swiftshader）：
  双网格 16 步 uncovered 0 / unsupported 0（峰值墙带 354/384、悬空 10/7）；
  页内手工拱（quad n=4 两对边支撑 → arch，mixed 同法）与孤立平底钢柱配置 audit 全过；
  注入异常后 finally 还原通过；控制台零 error。截图 qa-replay-r222-{mixed,quad}.png。
- `qa-monkey.html` 真页面实跑：quad 种子 7 在第 40 步曾报 `underside unsupported (cell 1969 lv 5 post)`。
  复现定位：buildBuildings 确实在该角画了钢柱（w.beam 整跨 0.5→2.0），误报原因是核查按
  「无邻墙空档层的中点高度」采梁面质心，而 w.beam 把整根柱画成一个跨 yFloor..yBase 的方柱、
  侧面三角质心恒在跨中——邻墙挡掉低层采样带时全落空。已改为顶点级判定（三顶点贴轴且 y 贯通整跨），
  同状态复跑 unsupported=0。修复后真页面全量 120 步（种子 7）双网格各 12 个核对点全绿：
  quad 墙带峰值 494·悬空峰值 21、mixed 墙带峰值 432·悬空峰值 21，未覆盖 0 / 失支撑 0 / 退化 0，
  增量=整体 12/12、还原摘要一致、结束悬空 15。（页内 afterStep 的 setTimeout(60) 在 headless
  被定时器节流拖慢，验证改以页面内直调 runMonkeyQA 跑同一 api/render 路径。）
