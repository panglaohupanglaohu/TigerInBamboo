## 判定

**有机制**（与 1707490932017279035 同一套）：灌木是顶面着色带，沿「到崖边的归一化距离」刷；每级台地边各一条，带宽随该级落差变大，被低频噪声随机断开；不覆盖沙岸（贴海那一圈是空的）。

## 代码落点与差距

- 同一处落点：`src/terrain/terrainmesh.js`（`edgeTri` 的 `centreE` 按 `maxDrop` 缩放）+ `src/terrain/shrub-texture.js`（`shrubApply`）。
- **本轮修掉**：`src/world/worldmesh.js` 的 `ChunkRouter` 不代理 `edgeTri` → 活的世界网格顶面 `aEdge` 恒 1，带根本不出现。修后活几何里同时出现 0 / 0.556 / 0.588 / 0.741 / 1 五档，正好对应「落差 1 窄、落差 2–3 中、落差 ≥4 宽」，也就是片子里**每级边各一条、落差越大越宽**的关系。
- 仍缺：① 片上多岛连续生成（黑剪影过渡 + 换岛），本仓页面是单世界、换岛要重载；② 带色偏浅；③ 水面倒影里没有灌木的暖色（本仓倒影只取地形色，灌木是纯着色阶段，不进倒影缓冲）。
