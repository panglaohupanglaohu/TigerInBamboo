关键判读：画面里是“点一个构件 → 工具标出它的边界 → 同时列出能与之拼接的候选”，即**用网格几何自身（面/边）做邻接签名，再查候选**，不是靠命名约定；候选只以线框呈现，不显示几何拼接结果，因此无法从画面推出容差、签名格式或完整匹配算法。

## 判定

有机制：几何邻接抽取（mesh edge 焊接 → 边签名 → 拟合表）+ 候选面片查询工具。

## 代码落点与差距

- `src/core/adjacency.js`：迁移 `meshEdges` / `edgeSignature` / `buildFitTable` / `whichFits` / `gridEdgeSlots` / `selfCheck`。空间桶按欧氏距离焊接，代表点固定（不链式传递）；报告退化三角、非流形边、绕序冲突；候选只取网格边界，排除三角化内部对角线；以绝对点积判平行 + 真实长度容差判等长（避免逐分量 abs 把正反斜边混为同轴）。
- `adjacency.html`：边选择、绿色候选、灰色内部边、两种网格审核；`wfc.html` 求解前调用几何核验。
- 做到：147 格 / 510 条半边、206 格 / 824 条半边全量审核，初始声明不符 0，注入错误边界检出 1。
- 缺：候选只允许平移、不自动旋转；平行等长不代表完整面轮廓/法线/实体碰撞正确；非流形输入只返回诊断，拒绝策略留给调用方；演示用的三角网格是只读模块库，未接真实建筑多格 tile。
