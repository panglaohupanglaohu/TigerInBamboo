## 逐帧观察（第 238 轮结论，本轮沿用）

- f0000–f0099：紫岩厚岩台地静置，相机缓慢环绕，层间两三处**深色拱洞**，洞内空。
- f0100–f0199：镜头压低露出岛底浅海与礁石，右侧出现小船（船身 + 白桨）；单位散在台面与洞口外侧。
- f0200–f0299：单位成排在台面上移动，一队贴洞口外沿走；f0230 原尺寸：洞是**贯穿的暗洞**，
  洞里有单位（暗部里的亮蓝点），洞内顶面是实心岩，台面上两处白屋 + 右侧一处拱门。
- f0300–f0499：战斗段，火光与白烟，烧黑的屋子；部分单位在洞口附近聚集，洞内多个亮点叠在暗部里。
- f0500–f0724：收尾，烟稀、单位减少，相机回环，船停在岸边。

本轮要核的两处画面口径（与代码对齐）：

1. **洞内比洞外暗一档**：f0230 / f0280 原尺寸看，洞口那一圈还留着天光，往里一步就沉下去，
   洞底的单位是「暗底上的亮点」而不是同亮度；洞顶岩体表面与外面台面同亮度。
2. **船只是静物还是联动**：f0100–f0190 只见船停岸边，**没有**拍到上下船的动态 —— 所以「上下船联动」
   在片内不可证，只能按代码与真实岛回归核。

## 判定

有机制（三条，逐条落定）：

- 洞穴岛穿山隧道 + 分层导航（r56/r214 已落，r238 复验帧证据）。
- **洞内光照**：原片可证（洞内暗一档 + 洞口渐变），本仓 r56 起只有体素 AO，洞身中段与洞口差不出
  一档、洞口无渐变 → 本轮补实现。
- 船只靠岸 + 卸人：片内只能看到「船在岸边」，动态不可证；代码侧 `#launchWave`（planLanding →
  steerBoat 靠泊 → crew 逐个 `onBoat=null` 上岸 → `state='out'` 离港）是完整链路，
  `tests/bncaves-island-battle.mjs` 真岛回归本轮复跑 `landed:1`（quad/mixed 各 1）→ 旧 note 的
  「上下船未联动」记为**过期账**（第 36 次同型）。

## 代码落点与差距

新增 / 改动：

- `src/light/cave-light.js`（新）：`planCaveLight` 从 `world.bnCaves` 建计划 —— 洞口识别（端格贴洞外同高地面）、
  沿轴弧长（隧道会拐弯，首尾连线不能当轴）、`smoothstep(s/ramp)` 渐变、两端洞口取 `min(s, len−s)`；
  `caveShadeAt` 按「顶点 y 落在洞空腔 `(floor·L, (floor+2)·L)` 内 + 到洞轴横向 ≤ 半宽」判洞内；
  `applyCaveLight` 只乘顶点色不动 pos/normal；`caveLightReport` 出洞口/洞身/洞顶上方三个系数。
- `src/badnorth/island.js`：生成后 `world.caveLight = planCaveLight(world)`（默认开，`?cavelight=0` 关档）。
- `src/world/worldmesh.js`：bake 之后对坏块调 `applyCaveLight`（仅 `world.caveLight` 存在时；其它场景空转），
  并把被压暗顶点数记到 `worldMesh.caveShadeVerts`。
- `src/world/app.js`：`window.rea.caveLight()` 只读探针（report + shadedVerts）。

读数（真页面 `index.html?scene=badnorth&bncaves=3&cavelight=1`，单页内切档重建做 A/B）：

- 计划：3 条隧道 / 7 个洞格 / 全部 `mouths=2`；洞口系数 **1.000**、洞身 **0.540–0.5416**、
  洞顶上方 **1**（strength 0.46、ramp 1.6，短隧道 ramp 按半长夹到 0.2–0.57）。
- 几何 A/B（同世界只摘 `caveLight` 重建，按沿轴弧长分 4 桶取洞内顶点平均亮度）：
  桶0 **0.165 → 0.165（ratio 1.000）**、桶2 **0.100 → 0.140（0.714）**、桶3 **0.100 → 0.130（0.769）**；
  被压暗顶点 **234**。→ 洞口不变、越往里越暗，符合「暗一档 + 渐变」。
- 逻辑测试 `tests/cave-light.mjs`：quad/7、quad/11、mixed/7、mixed/11 四个真岛组合
  （每组合 3 条隧道）逐条断言：洞口 ≥0.995、沿轴最大步进 <0.06（无硬边）、两端对称差 <0.02、
  最暗 = 1−strength±0.02、洞顶上方 / 地板以下 / 横向洞外恒 1、`applyCaveLight` 只压中洞身那 1 个顶点且不动 pos。
