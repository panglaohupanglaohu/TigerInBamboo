## 残差判定

库里已有：planet.js 对偶柱群球面（球面三角化→五/六边形格→台地量化）、planet-town.js（球面 World=对偶格）、planet-smooth-c08.js（对偶柱群各层边界的球面 Taubin 平滑）。这些都不是「平面 World → 球面」的接线——queue 的 nextAction 明确不许用它们顶替。真残差三层：

- a) **平面 World/模块 → 球面映射**：grid.js 的不规则/方/六边形格、multicell、module-patch-commit 全部工作在 (x,z) 平面；没有「柱格 → 球面位置/切向/up」的映射层。游戏实景（TigerMessenger apostlesReacode.js）的做法是锚点切平面 frame + 抛物面下弯 y−(x²+z²)/(2Rw)，但游戏侧是定制实现，库里没有同口径纯函数。
- b) **平滑岸线（球面）**：water/shore.js 的黄线/蓝线机制（traceShoreLoops → sampleShoreline → 距离场外推 → 平滑）只在平面；贴球后岸线连续性、法线搬运、外推蓝线、平滑全部缺。
- c) **模块视觉球面姿态**：模块摆放到球面的位姿（径向 up + 切向基 + 局部 yaw）无实现。

## 本批落地（src/sphere/world-sphere.js，纯函数，不依赖 THREE）

- `makeSpherePatch({R, center, up, e1, e2})`：锚点 = center+up·R = 实景 seaAnchor；e1/e2 缺省确定性派生（e1,up,e2 右手系，与平面 (x,z)·y向上 手性一致），显式传 (X,Z) 即复刻 apostles frame。
- **'bend' 模式**（与实景逐式同口径）：`mapPoint` = apostlesReacode `toWorld`（pos = water + x·X + (y−(x²+z²)/(2Rw))·Y + z·Z）；`bendDrop` = 抛物面下沉；`bendCoefficient` = uBend = S/(2Rw)（格单位）；`bendNormalLocal` = 帽面法线 normalize([x/Rw,1,z/Rw]）。
- **'sphere' 模式**：方位等距（azimuthal equidistant），锚点→点沿测地线 σ=d/R 严格上球；`unmapPoint` 双模式逆映射。两模式一阶一致（主导差 = 弦收缩 O(d³/6R²)）。
- **柱格/模块姿态**：`localFrame`（up=径向/抛物面法线；right/forward=测地平行搬运基）、`modulePose`（+切平面 yaw）、`mapCell`/`mapGridCells`（共享角点映射逐位相同 ⇒ 接缝按构造闭合；coverage 报 inRange/σ）。
- **球面岸线**：`shoreLoopOnSphere`（平面点串贴球，按等距切向伸长 σ/sinσ 折算在平面细分，相邻角距 ≤ maxStep；法线平行搬运到径向切面）、`worldShorelines`（复用 traceShoreLoops + sampleShoreline 同 buildShore 口径 → 可选 Taubin 平滑 `smoothSphereLoop` → `pushOutSphere` 测地外推蓝线）、`shoreReport` 连续度报告。

## 测试（tests/world-sphere.mjs，8/8 PASS；浏览器红线未跑）

1. patch 构造/校验（派生基右手系、非法基拒绝）。
2. bend 与实景逐式同口径：toWorld 参考式逐点相等；uBend=S/(2Rw)；帽面法线；两模式近锚点差 < d³/6R²+ε。
3. sphere：|pos|=R 严格、测地距离 = √(x²+z²)、unmap 往返精确、抬升 y→半径 R+y、bend 往返 y 由抛物面方程还原。
4. 柱格：全格 inRange、共享顶点映射逐位相同（接缝）、同高角点共球面（'sphere' |p|=R）/共抛物面（'bend' 满足 y+d²/2R 方程）、edgeNeighbors 共享映射边。
5. 模块姿态：基矢单位正交、'sphere' up=径向、yaw=0 与搬运 e1 同向、yaw 不动位置。
6. 岸线：方片+内塘 2 条闭环、相邻角距 ≤ maxStep、法线切径向、蓝线弧长=reach 同半径、平滑后仍在球面。
7. 粗折线强制细分后 maxStep 达标；星形环 Taubin 后最大转角 116.7°→69.0°（boundaryTurning 同口径）。
8. 确定性（整管线两次逐字节同）；南/北极锚点不炸；对蹠点 inRange=false 不抛错；非法输入 RangeError。
