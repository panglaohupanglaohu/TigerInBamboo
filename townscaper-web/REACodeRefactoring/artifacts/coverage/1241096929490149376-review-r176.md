- 原文：It has been brought to my attention that not all of you are familiar with my every-other-pixel-is-a-line tech. I make the UVs speed past every 2nd pixel before sampling. It's core to my art style and what lets me get away with one 128² texture and crisp antialiasing up close.

## 逐帧观察

- 0000–0136：同一固定机位贴着一排房子（左橙砖墙、上红瓦屋顶、右石灰台地、中绿墙 + 石阶 + 铁栏）。墙面的砖缝**是 1px 的深色细线**（3× 裁切里砖缝与砖面的差约 8–10% 亮度，不是硬黑描边），台地石块的边同样只有 1px；细线在整段里偶尔"变粗 / 变细"一次（0160 前后、0240 前后各一次）——这不是镜头在动，是同一套纹样在两种采样状态间切换。
- 0137–0240：镜头拉远到整座岛（橙墙 / 绿墙 / 红瓦 / 灰台地成片）。这个距离上**砖缝仍然看得见**（台地石块的缝、墙面的砖列都在），但没有摩尔纹、没有闪烁的高频噪点，也没有"糊成一片纯色"——这是缩小端已经走 mip 的样子（对应本仓 `town-skin` 的色格内 box mip 链）。
- 0241–0301：镜头推回同一机位，砖缝重新变成 1px 细线，收尾静止。全片无 UI、无帧率读数、无建造过程，只有一个机位的近景 ↔ 远景往复 + 细线粗细切换。

## 判定

有机制，且机制就是原文那一句：**图集里每隔一个像素是"线像素"，采样前把 UV 重映射，让线像素在屏幕上始终只占约 1 像素**；放大端靠连续重映射 + 线性过滤得到抗锯齿的 1px 线，缩小端必须另有 mip，否则"跳线"会把线整条跳掉。

## 代码落点与差距

- 机制本体：`src/core/texel-skip.js#skipTexel` / `TEXEL_SKIP_GLSL`（文件头署本片 ID）。
- 建筑 + 植被共用一张 128² 图集：`src/core/town-skin.js`（`buildSkinAtlas` 8×8 色格 + 右下 32² 植物角；`skinPattern` 每 4 行一条暗缝、砖列错位；`buildSkinMips` 四级 box mip 打包进同一张 128²）、`src/world/town-skin-layer.js`（`c07Level`：k<0.5 走 `skipTexel` 重映射，k≥0.5 走打包 mip 并按导数两级插值；`set('townskin')` 同时把 `vegetation.leafSurface.uniform.value` 指到这张图）。
- **核实结论：旧 note 的两条"仍缺"有一半是过期账** ——「建筑/植被 atlas 未全面接入」不成立（`town-skin-layer.js` 已把建筑墙格与植物角的叶纹接进主材质，`tests/c07-skin-decal-browser.cjs` 一直在跑）；「缩小仍缺 mipmap」对**主场景**也不成立（`buildSkinMips` + `c07Level` 就是这件事）。
- **真缺口（本轮补）**：本片自己的页面入口 `textures.html` 的「隔像素一条线」页签只用了**玩具贴图**，且只有最近邻 / 连续重映射两列，既没有真实图集、也没有 mip 档与可读回的量具 —— 也就是说这条片子的"缩小端"从来没在页面上被验收过。

## 本轮改动（机制零改动，只补页面入口 + 量具 + 断言）

- `textures.html`「隔像素一条线」页签改成吃**真实 128² 图集**（`buildSkinAtlas` 八个色格 + 右下 32² 植物角，与主场景同一张），三列并排：左 = 最近邻、中 = 只做连续重映射、右 = 再叠 `buildSkinMips` 的打包 mip（`texLevel` 与 `town-skin.js#c07Level` 同口径：k<0.5 走 `skipTexel`，k≥0.5 按 `log2(fw)` 两级插值）。
- 新增只读量具 `window.texelSkip`：`atlas()`（色格数 / 植物角矩形与标准差 / 第 4 级 mip vs 色格盒滤波均值的最大误差）、`measure({mag,mip,show,cell})`（画进离屏 FBO 后 `readPixels`，返回相邻像素差 `mad`、暗缝占比 `darkFrac`、暗缝连续段 `runP50/runP90`）、`set()/state`。
- URL 可钉：`?zoom=` / `?mip=0` / `?show=0|1|2` / `?cell=gx,gy`（探针默认挑 `[1,0]`：本页只填了 `SKIN_SLOTS[0..7]`，gy≥1 的格子是空的）。

## 验证

- 新测 `tests/texel-skip-atlas-browser.cjs`（见 `artifacts/coverage/texel-skip-atlas-browser.json`）。
- 图集本体：128² / 60 色格 / 植物角 `{96,96,32,32}` 亮度标准差 **0.2495**（叶纹真的在同一张图里）；打包 mip 第 4 级 vs 色格 16² 盒滤波均值最大误差 **1.06 级**（纯四舍五入）。
- 放大端（mag 8 / 4）：mip 开 / 关四项读数**逐项相同**（lod 钳到 0，mip 不改放大结果）。线宽 mag=12 时最近邻 `runP50 = 12px`（暗面积 0.3323）、连续重映射 `runP50 = 2px`（暗面积 0.0508）—— 屏幕上一像素级的线，正是原文那句。
- 缩小端：mag 0.35 时 `mad` 无 mip **0.01136** → 有 mip **0.00564**，暗缝占比 0.284 → 0；mag 0.12 时 0.00631 → 0。截图 `texel-skip-minified-r176.png` 目视一致：左/中两列是密密麻麻的混叠网格，右列收敛成均匀色。即：无 mip 是"跳线"后的高频采样（相邻像素差更大、暗缝占比在不同倍率间乱跳 0.284/0.298），有 mip 收敛成平均色且随倍率单调收敛。
- 主场景（`index.html?scene=town&c07=townskin`）：`aC07Cell` 就位、`stats` = 36555 顶点 / **skinned 36555** / 26 槽 / overflow 0 / mismatch 0 / 16ms；植被 `leafSurface.uniform.value === skin.tex`（**建筑墙格与植物角共用同一张 128²**）；关档 A/B 整帧差分 **6595 px**、再开回位 **0**、0 console error。
