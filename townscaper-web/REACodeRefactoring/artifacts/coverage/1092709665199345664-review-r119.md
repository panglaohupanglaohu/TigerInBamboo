## 逐帧观察

- **0000–0077**：贴海斜俯视。中央灰白崖台，台上一排**蓝盾**单位，台顶横一条红底白字横幅「k-pow !!」+ 白色小人图标，两端带锯齿。左侧一大团黑色翻滚的烟（表面鼓包、边缘有硬剪影线、往上被风吹斜）。海面白浪线、滩地草丛都在。
- **0078–0095**：崖脚海面炸开。先是一点白光，2–3 帧膨成一团亮黄白火球，内核过曝、外缘橙黄、边不规整带火舌；**火球正下方出现一片半透明红色圆斑**（焦痕/受击范围贴片）；同时左上烟团里迸出成串橙色火星（带小拖尾）。
- **0096–0189**：火球迅速收缩变暗（白→黄→橙），烟继续翻、体积变大，火星落尽；横幅、地形不动。0110 帧可见**红盾维京敌兵**站在崖台上、灰烟从左侧台地升起。
- **0190–0203 / 0301–0330 / 0425–0445 / 0455–0470**：又四次爆破，位置沿崖脚换点；每次都是「白光一点 → 火球 → 收缩 → 红斑留在原地」。0316 帧的火球与红斑关系最清楚：红盘就压在火球底缘正下方。
- **0331–0473**：烟堆积成更大黑团遮住部分崖体，单位小步移动；片尾停在烟最浓、横幅仍在的一帧。

爆破峰值约在 0085 / 0195 / 0310 / 0430，间隔 110–120 帧（≈3.5 s），是一段循环播放的爆炸演示。

**本轮纠正一处误读**：0100–0140 帧崖台上那几块「鲜红色不规则块」不是残留焦痕，是**红盾维京敌兵**（0085 帧同一位置是蓝盾玩家兵）。真正的焦痕只有火球正下方那片半透明圆盘。

## 判定

**有机制**，拆成五件事：①一点白光 → 膨胀成亮黄白火球 → 收缩变暗；②火球正下方半透明红斑，2 s 内转焦黑并留在原地；③橙色火星上抛 + 重力落尽；④黑烟从火球顶部接上、持续数秒；⑤崖顶红底白字「k-pow !!」横幅 + 小人图标。

## 代码落点与差距

- `src/badnorth/battle-c03.js#explodeAt()`（文件头就署了本片 ID）：`t=0` 内核 `scale .02` → `0–.16 s` 缓出膨胀到 `r` → 之后收缩到 `5% r` 并淡出；`core` 颜色 `(1,1,.9) → (1,.55,0)`；`life=.75`。
- `#scorch()`：贴地 `CircleGeometry` 圆片，`y = groundAt + .012`，颜色 `(.88,.29,.24)` → 2 s 线性到 `(.16,.12,.12)`（焦黑），`opacity .55 → .65`，不消失（上限 48 片）。
- 火星：`sparks[]` + `sparkPoints`（`#ffab3d`, 900 点池），`vy -= 3.2·dt`，`drawRange` 跟数量。
- 烟：`#smoke()` 把源推进 `view.smoke.sources`，`smokeLife` 到期摘掉。
- 横幅：`#ensureBanner()` 画 256×80 canvas（红底锯齿 + 白字 + 小人图标），贴在**最高台地**上方 `.75`。
- 周期：`afterDraw` 里 `kpowT` 到 0 就在随机岸边格炸一次并重挂 `3.5 s`。

**结论：note 里记了 6 轮的「缺 explodeAt 时序编排与焦痕贴片」已过期** —— 缺的只是页面运行验收与量具，本轮补齐，无改码。
