### `src/build/steel-frame-edit.js`（新，~260 行，纯函数/确定性）

- **`collectSteelJobs`**：与 `buildings.js` underside 同口径——本层建筑、`lv>1`、下层空（runBottom）→ 钢架 job；方格一组对边邻居在下层都实心 → 拱，排除（三角格无对边恒入）。测试断言 job 数与 `buildBuildings` 的 `steel.blocks` 逐场景相等。
- **`steelFramePlan`**：记录式 writer 复用 `emitSteelFrame`（steel-r56，不重写算法）→ 杆件清单 `segments{kind:column|beam|tie|brace|ladder-*,a,b,r}` + `boxes{joint|pad}` + 同源统计。杆件类按 emitSteelFrame 的既定半径定。
- **`planSteelReveal`**（原片 f22 行为的判定层）：编辑步先在暂存列校验/推进，逐步 diff 出显露/隐藏杆件——`kind: reveal|hide|mixed|none` + 按类计数「露多少」。纯预览不动 World。
- **`commitSteelReveal`**：整组事务——`commitModulePatch(fit, mapping=被编辑列)` 先过 socket 边界 + 周围 `solveWithPrefab` 补网 + `findWFCConflicts` + stale-version（任一失败 World 原样）；再原子写楼层体素；`withdrawModulePatch` 回执快照整组撤回（楼层回来、钢架藏回）。**边界如实**：fit 事务层不写模块格体素（`placeModuleVolume` 只增不减、`tileColumn` 跳模块格），楼层写在本层原子段；撤回由先于一切写入的回执快照保证（fit restore = 字段整列还原）。
- **`frameCollisions`**：碰撞清单口径审计——杆件穿实心体素内部才报，端点贴支撑面（柱脚落屋面/码头顶）不算穿；命中报 `walkable`（顶面岩石=可走面，与 `columnState` 同口径）。
