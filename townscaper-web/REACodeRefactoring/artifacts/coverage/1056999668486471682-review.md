## 逐帧观察
- 0000–0099：**白天**、固定斜俯视机位（无位移、无剪辑）。两座台地上各一栋白色小房：左上那栋屋脊上冒出一柱火，右上那栋同样；前景台下第三栋房顶也在烧。火柱高约房高的 0.8 倍，柱体是**淡黄到奶白**，外缘一圈**粉色/珊瑚色光晕**，光晕边缘柔和、能透出后面的天空与草地。
- 0100–0299：火柱不长大也不熄灭，只有内部**团块在上下窜动**：每次有新的团块从底部冒上来、老的团块上移并碎成小块（顶端能看到 0.5–1 个身位大小的碎片）；房子本身不焦黑、没有烟柱。
- 0300–0434：同上，三处火一直在烧，形状/大小稳定，说明这是"稳态燃烧"而不是"起火过程"。结尾 0434 与开头 0000 的构图、火柱高度基本一致。
- 关键判断：白天背景下，火不是**一片白**——能清楚分出"奶白核心 / 黄 / 橙 / 粉边"四档，且相邻团块之间的边界可见（说明叠合时没有被加亮到饱和）。

## 判定
有机制，机制就是原文说的 **Max 混合**：每颗粒子的颜色乘以自己的软遮罩后与背景做逐通道取大（`blendEquation = MaxEquation`，`src = dst = OneFactor`）。取大只会"保留更亮/更暖的那个"，不会像相加那样把重叠处累加到全白；所以白天也能保住火焰的内部色阶与轮廓。

## 代码落点与差距
- 落点：`src/life/effects.js`
  - `this.fire`：`THREE.Points` + `ShaderMaterial`，`CustomBlending / MaxEquation / OneFactor`（第 115 行）；
  - 着色器：`gl_FragColor = vec4(c * m, m)`，`c` 按年龄在 `hot(1,.93,.6) → mid(1,.55,.18) → cool(.85,.2,.12)` 之间插值，`m` 是 `1 - smoothstep(.55,1,r)` 的软圆遮罩；
  - `setFireAppearance({blend})` 可在 `max` / `add` 之间切（`add` 只作对照诊断，默认 max）；
  - 粒子 900 个（`fireN=900`），出生尺寸 `0.13`，寿命 `0.6–1.3s`，`fsize = 0.13 * (1-age)^2`（二次收缩，来自 1056992291108413446）。
- 已等价：① 白天靠 max 混合不炸白（下面 GPU 读回实测：两颗粒子完全重合时 max 的像素差 **0**，add 差 277924）；② 火焰按年龄分段变色（核心→橙→红）；③ 顶端随年龄收缩碎成小块（片子里也能看到碎片）。
- 差距：① 本仓火柱偏**细而散**：粒子半径 0.13 世界单位、同源只有 300 颗，远看是一串点而不是片子里连成一片的火舌；② 片子里火柱外缘那圈**粉色光晕**很宽（约火柱宽的 0.4 倍），本仓软圆遮罩只有 `0.55–1.0` 的过渡带，光晕更窄；③ 片子里火烧在屋脊/屋顶面上，本仓火源固定在烟囱口一点（`chimneys`），贴附形状没做。
