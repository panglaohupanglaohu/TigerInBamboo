## 逐帧观察

- 0000：深棕底，橙色线框已经覆盖大半屏，左上角有一小段绿色钩状折线。
- 0010–0100：线框铺满整个圆盘。**橙色是四边格**，格心还有一串红点（四边格的对角/中心记号）；**青色三角**成条带状横穿格子，条带两侧是**亮绿色**轮廓；最外圈是**深绿岛缘**。绿色带不是散的，是几十格连成的一条蜿蜒长带。
- 0108–0110：整片清空成暗底，只剩左中几块橙色小碎片——重铺开始。
- 0110–0135：从碎片重新长出一整片新格子，形状与上一轮不同（补丁边界换了位置）。
- 0140–0259：多块朝向不同的补丁，紫/蓝/黄的小方块出现在部分格心；绿色带把补丁围起来。
- 0260–0262：又一次整体清空重铺（第三座）。
- 0263–0388：绿色收缩成一条横穿全盘的 "S" 形长带，两侧橙色四边格朝不同方向，带上三角密布。
- 0389–0400：清空重铺；0426 附近再清空一次。
- 0420–0532：补丁 + 彩色格心小块，绿带围出封闭环。
- 0533–0540、0594：又是两次清空重铺。
- 0595–0608：最后一轮铺开，画面在绿带最长的状态结束。

结论性观察：**每 40–60 帧整片清空重铺一次**，每次的补丁位置、绿带走向都不一样 —— 这是生成器的调试视图（换种子重新生成），不是渲染资产。

## 判定

**有机制。** 机制是「不规则四边格 + 保留下来的三角形」这套混合网格：三角形没法再细分成四边格，所以它们就留在原地，形成一条条过渡带；过渡带两侧的四边格阵列朝向不同，等于把整片格子切成若干补丁。片子里橙/青/深绿三种颜色分别就是四边格边、三角边、岛缘。

原登记 `na`（早判为与技术无关）是错的，改判 `partial`。

## 代码落点与差距

- 新增 `src/core/grid-wireframe.js`
  - `classifyWireframe(grid)`：逐条边按两侧面型分类为 `quad`（四边↔四边）/ `tri`（三角↔三角）/ `seam`（四边↔三角，即过渡带轮廓）/ `rim`（只有一面，岛缘），并给出面型计数、每顶点度数、流形检查（>2 面共边记为 nonmanifold）。
  - `seamBands(wire, { grid })`：把 seam 边串成带子；岔口按「最接近直行」继续（用顶点坐标算夹角），因为原片里的带子是横穿整片的长条，不会在岔口断掉。返回角点序列 + 闭合标记，按长度降序。
- 新增 `grid-graph.html` 左栏：按面型着色的线框（橙/青/亮绿/深绿），伪倾斜俯视投影，格心小点（四边橙、三角青）对应片子里的红点层；「换一座岛」按钮复现片子的周期重铺。
- 复用了 `src/core/grid.js` 的 `buildMixedGrid`（三角形合并成菱形 → 细分成四边格，剩下的三角形保留），未改它。
- 差距：片子格心里的紫/蓝/黄彩色小块语义不可证（可能是补丁 id 或调试通道），未实现；原片是透视 3D 视角，本页用俯视 + 倾斜近似；尚未接 `world.js` 的实景网格。
