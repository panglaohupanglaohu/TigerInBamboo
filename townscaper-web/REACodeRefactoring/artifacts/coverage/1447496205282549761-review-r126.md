## 判定

有机制，机制就是**底图本身**：一张不规则三角网（顶点抖动、格子大小不一、四边格只切一条对角线），岛是在同一张网上生成的（白格线越过岛体范围继续画这一条是硬证据）。
本片**没有**房子 / 模块 / 预制 tile（0349–0382 全岛只有地形与植被），所以 note 里挂了几十轮的「预制 tile」在这条片子里根本不存在。

## 代码落点与差距

- 落点：`src/core/grid.js#buildMixedGrid`（不规则格：四边格 + 三角格，`relaxPolygons` 抖动顶点）、
  `src/terrain/generate.js#generateTerrain`（软坡 `softSlopes` + `world.softTops`、河道 `carveRivers → riverFlow`、
  湖 `lakes`、河道 BFS 缓坡 `riverRelax`）、`src/core/grid-kinds-c08.js#PURE_GRIDS.tri`、`src/world/app.js ?grid=tri`。
- 本轮补的**页面入口**（这才是真缺的那一层）：
  1. `grids.html`：新增 `?kind=tri|square|rhombi|mixed`、`?wire=1`（只画格线，深底白线 = 原片那种底图）、
     `?tri2=1`（四边格沿 pts[0]–pts[2] 一条对角线切两片），并把「只画格线 / 四边格切对角」做成可点的按钮；
     新增 `gridLab.kindsReport`（格型 / 顶点共用 / Euler / 格面积离散度 / 对角线数 / 切完的三角数）。原来这个页面只能看填色格、也无法深链到某一种底图。
  2. `terrain-r55.html`：`grid` 参数原来只透传 `quad|mixed` → 三角底图上根本跑不了软坡/河道；现在接受 `tri|hex`，
     并在 `__r55` 台账里加 `gridSides / cells / riverCells / riverReaches / riverMouths / land / levelCount / softTops`。
- 差距（如实口径，不计缺口）：
  1. 原片三角更接近等边：像素口径 `P²/A` 的 p10–p90 = **35.6–39.7**（136 个格全是三角形）；
     本仓不规则底图（mixed 三角化后 486 个三角）同一量具 p10–p90 = **35.1–66.8**，有细长三角（原片没有）。
  2. 原片格面积 p10/p90 = 287/592px（**2.06×**，含透视），本仓不规则底图面积 CV **0.4165** / max÷min **5.79×** ——
     本仓的格子大小差得更开（相当于把原片的抖动幅度放大）。两者都是「不规则三角网」，造型差一档。
  3. `?grid=tri`（纯三角）是**规则**等边格子（面积 CV = 0），它对应的是另一条片（1670790425232175108「why I'm going for my mixed approach」），
     不是本片的不规则底图 —— 判这条时别拿它当落点。

| 对象 | 格数 | 面积 CV | 面积 p10/p90 | P²/A p10–p90 |

| 原片 frame-0020 | 136（全三角） | 0.2615 | 287 / 592（2.06×） | 35.6–39.7 |
| 本仓 mixed+tri2 | 311（全三角） | 0.4165（模块级） | — | 35.1–66.8 |
| 本仓 纯 tri | 254（全三角） | 0（模块级） | — | 35.2–36.6 |
