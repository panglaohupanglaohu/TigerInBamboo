## 判定

## 代码落点与差距

本仓 `src/ui/` 下没有任何 i18n / locale 层（`environment-panel.js`、`icon-toolbar.js`、`walkthrough.js` 等全部硬编码中文），也没有语言切换控件。

差距：若要做，最小落点是 `src/ui/i18n.js`（`{key: {en, zh, ja…}}` 表 + `t(key)` + 语言环游指针）与一个胶囊控件；但本仓所有实验页是中文说明性页面，没有面向玩家的可翻译 UI 文案，加 i18n 只是空转，故本轮**不实现**，维持 ref。
