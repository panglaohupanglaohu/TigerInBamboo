# 浮点渲染目标：117帧与实际能力探测

先读1664565063552847873的README，原文讨论shader fluid对32位浮点目标、跨平台、可调风格及CPU反馈的顾虑。已检查0–116全部117帧（0–6.960秒），sheet-00/01覆盖无遗漏，原尺寸回看0、58、116帧。可见固定机位岛形线框，周围青/洋红/黄等连续色场移动并绕过地形；结合文字可以识别流体实验，但不能仅凭颜色确定速度/密度通道。

原版floatprobe已有格式探测和平流实验，本目录此前缺少实际探测。新增world/float-probe.js，用临时独立WebGL2上下文测试RGBA16F/32F的FBO完整性、写入[1.25,-0.5,0.125,0.75]并FLOAT回读，以及2×1左右0/1纹理中点线性采样。三个能力分开报告，不能以扩展存在替代实测。所有资源清理并释放自有上下文，不触碰游戏渲染器状态。float.html为可重新运行的本机诊断入口。

tests/float-probe-browser.cjs在headless Chrome SwiftShader实测：两格式均FBO complete，HDR/负值回读正确，过滤值0.50196，重复运行通过，pageerrors[]。报告float-probe-browser.json，截图float-probe-browser.png已查看。当前环境不是设备/平台兼容性矩阵。

代码验收只覆盖格式/回读/过滤；未搬运原版60步平流质量与CPU参考误差实验，也未将GPU流体接入主水面。跨GPU/浏览器矩阵尚缺，所以模块继续部分覆盖。原版与游戏副本未修改。
