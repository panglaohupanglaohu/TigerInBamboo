## 只读裁判参数（REACode/src/levelflora.js，本仓未改一行）

直接 import 原版模块原样跑（tests/level-flora-layers.mjs 第 1 节实测）：

| 参数 | 裁判值（buildFlora/measure 实测） |
|---|---|
| 每格成丛概率 | d = density·(0.55+0.45·h)，默认 density .55 → 实测 presence .40 |
| 丛内个体 | 4–9 个（实测均值 6.68） |
| 丛半径 | .20–.46 格（实测均值 .337，spread 0.98 格） |
| 个体缩放 | .55–1.25（实测均值 .897） |
| 物种指派 | 每层 2 物种、层间不共用、丛内统一一个物种 |
| 可量化指标 | sharedSpecies / levelFromSpecies / cover / meanSpread / edgeDensity / innerDensity |

本地近似（与裁判参数分开记账，不冒充原作规则）：
- 表面型密度系数 SURFACE_DENSITY = shore 1.2 / edge 1.0 / interior .8
  （原片「顶层草、墙根草、水边草各自成群」的方向性近似；裁判本身无表面项）。
- 雨生态 RAIN_COLORS / RAIN_CROWN：帧 109+ 紫树冠、灰白直立地被的色组近似；
  同一批物种键/形状只换色，属「生态切换」的色组层，不是完整第二生态。
- FLORA_SHAPE_SCALE：草丛广告牌的各向异性缩放（dots 贴地、blade/fan 高、conifer 最高），
  opt-in `vegetation.levelFloraShapes`（默认关 → 实例矩阵与旧版逐字节一致）。

## 落地

- `src/core/level-flora.js`：FLORA_JUDGE 裁判参数表、FLORA_SURFACES/SURFACE_DENSITY、
  FLORA_SHAPE_SCALE、FLORA_ECOLOGIES/RAIN_COLORS/RAIN_CROWN；

  口径成丛计划（presence 闸、4–9 items、半径 .20–.46、缩放 .55–1.25，独立 hash 全确定）。

  levelFloraShapes opt-in；雨生态下树冠换 RAIN_CROWN；setTimeOfDay 加 'rain' 挡（.62）。
- `src/life/flora-species.js`：非 dual 落丛改走 levelFloraCluster（每格至多一丛、

  veg.floraEcology）；rows 带 surface/items，stats 带 absentCells/ecology。
