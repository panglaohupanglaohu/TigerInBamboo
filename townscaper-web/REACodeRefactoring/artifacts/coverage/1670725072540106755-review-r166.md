## 逐帧观察

**三档的分界（用左上角标签做模板匹配，164 帧逐帧判）**：`no` 0–64、`dumb` 65–119、`hierarchical` 120–163。
画面左上角是 Unity 风格的小标签，原文那三个词就写在上面：`no smoothing` / `dumb smoothing` / `hierarchical smoothing`。
两个切点是 64→65 与 119→120，切点处整岛在画面里上下移 ~7px（换面板时取景略变），此后每档内部机位固定、只有岛体在动。

**0–64 `no smoothing`**：同一座岛，侧视略俯视，岛填满画面；岸线由一段段直边组成，转角尖锐（水面与陆地交界是折线，不是曲线）；
台地侧壁是直柱，台面边界是硬折直线；红色粗线（模块/格边界）与紫色细线（材质边界）在岛面上穿过；草皮/岩檐的边带完全贴着折线走。
沿底岸线量二阶差分 `mean|d2| = 1.012`、最大单步跳变 `14px` —— 这就是"没平滑"的锯齿基线。

**65–119 `dumb smoothing`**：地形开始形变，但形变是**无差别**的：台地边界从直折线变成**外凸/内凹的波浪**，岸线出现小台阶与不均匀鼓包；
草皮带往上爬的高度沿边不一致（同一段崖壁这头高那头低），台面被拉圆、岸线内缩。
同样的底岸线量具：`mean|d2| = 1.025`、最大单步跳变 **47px**（是 no 档的 3.4 倍）—— 原片说的 jankyness 就是这一段。

**120–163 `hierarchical smoothing`**：台地边界**仍然是直边**（输入的方形 tile 的意图被保留），只有转角被均匀抹圆；
岸线是一条连续曲线、没有 dumb 那种小台阶；草皮/岩檐的带状边缘与台面平行，宽度均匀；崖壁侧柱仍直立（没被拉弯）。
底岸线：`mean|d2| = 1.025`、最大单步跳变降到 **19px**（no 14 / dumb 47 之间，且没有孤立的深缺口）。
末段（0150–0163）镜头略拉远，三档对比结束在 hierarchical 档。

**三档共同的、与实现无关的部分**：整片没有 UI 操作、没有建造、没有颜色/光照变化；红/紫两条粗线在三档里都在（那是下一片 1670720537662836736 讲的黑/红/蓝分级），

## 判定

**有机制**：三档平滑（无 / 普通 / 分层）是同一套形变代码的三个模式开关，不是美术资产差异：
- `none` 完全跳过平滑与笼形形变，顶点在全部切面上回原坐标；
- `dumb` 每遍把所有轮廓点按**全部**邻居拉平（无视边类型）→ 台地意图被吃掉、海岸内缩（片里 12.84% 面积漂移）；
- `hierarchical` 按 rank（钉住 > 崖顶 > 崖脚 > 材质 > 自由）只让「同级或更硬」的邻点相拉，且只沿同级边走 → 直边保住、转角圆滑。

## 代码落点与差距

- 落点：`src/terrain/shape.js#shapeTerrain(world,{mode})`（文件头 5–10 行就署了本片 ID 与原文），mode 三值 `hierarchical|dumb|none`，非法值抛 `RangeError`；
  `none` 走 `if (mode === 'none') continue;` 完全跳过平滑，`dumb` 走 `dumbStep()`（所有邻居、忽略 rank），`hierarchical` 走按 rank 的 Taubin 拉普拉斯；
  量具 `smoothingMetrics(world, api, s)` 给 `kink(rank)` / `areaDrift` / `regularity`。node 测试 `tests/edge-hierarchy-modes.mjs` 从 r56 就在跑三档对照。
- 真缺口（本轮补的）：**页面入口**。`hierarchy.html` 原来只有「显式硬边 / 平滑开关 / 约束边近景」三个控件，页脚还写着「完整无/普通/分层三模式仍待补」——
  也就是说机制、node 测试都在，唯独没有从页面上切过档、也没跑过运行验收。
- 本轮改动（渲染路径零改动）：`hierarchy.html` 加 `#mode` 三档选择器（选项文字就是原片那三个词）+ `#modes` 三档读数区（崖顶转角 / 面积漂移 / 正则度 / 位移采样 / 最大位移 / 钉住违例 / 逐采样差分）
  + 探针 `window.hierarchyModes`（`setMode / table / shapes / rebuild`）；`shapeOptions.mode` 随选择器走，`window.hierarchyReview` 的旧字段（pair/slice/shape/baseline/error）保持不变。
- 如实口径（不等于原作）：本仓的分级是「钉住 / 崖顶 / 崖脚 / 材质 / 自由」五类，是**本地近似**；原片的黑=硬边、红=模块边界、蓝=材质边界是完整 mesh 边类型，
  那部分（1670720537662836736）仍只做了硬边与材质边两档，不声称等价。原片是**三块并排面板**，本仓是同一 World 上切档（更能证明"同一座岛只换算法"）。
