## 逐帧观察

- f0000–f0299（sheet-02）：城镇小岛（黄色地块 + 灰色建筑）在斜俯视下缓慢转台；岸外是一条**极窄的白裙**紧贴方块轮廓，裙边随岸形起伏、在每个凸角与塔基处略微加厚，湾里略薄甚至断成细线；水面上没有成片泡沫。
- f0300–f0599（sheet-05）：机位继续环绕到更低的角度，白裙保持贴岸、宽度稳定，四角塔基与窄水道处出现「白裙对穿」——两侧裙边在水道中间几乎要接上（原片后期修的就是这件事）。
- f0500 原尺寸：可以看清白裙不是一条画上去的线，而是**从岸脚放射出去的细三角带**（水面上能看到一圈根根细丝/spokes），外面还有一条更远的虚线环；地的三角剖分用黄线画在同一张画面里。

## 判定

**有机制**：岸裙 = 岸脚一圈放射三角带（distance-field-like skirt），白度随浪相位进出；窄水道里两侧裙带会在水中间交叠（原片博主本轮正在修的就是这种交叠）。原片只说「refined version」，没有给距离场公式，所以本仓用 chamfer 栅格近似——这条差距（独立 `buildShoreDistance` API）在第 340 帧那条片上已按 C 定案，不重复计。

## 代码落点与差距

- 岸裙/浪带本体：`src/water/shore.js`（`buildShore` 的 skirt / waves / shoreLine / seaLine）+ `src/core/shore-loops.js`（按左侧陆地转向、自接闭环分解）+ `src/world/townDemo.js` 接管小镇水面。
- 本片遗留的两条缺口（`note` 原文「蓝线窄湾交叠/泡沫mask仍缺」）：
  - **泡沫 mask**：`src/water/foam-mask.js#buildFoamMask` + `view-c10.js#FoamMaskLayer`（`?c10=foammask`，噪声切碎的碎斑，非整圈实心白边）；
  - **窄湾蓝线交叠**：`foam-mask.js#auditWavePaths`（量）+ `clampWavePaths`（修：碰陆顶点收回、`aIn/aOut` 同比缩放）+ `view-c10.js#clampShore`（`?c10=shoreclamp`，每次岸浪几何重建后跑，`stats.shoreclamp` 出 before/after）。
- 两者 r56 就在码里、入口也在 `app.js:523`，但**全仓没有一条浏览器测试跑过它们**——缺的是运行验收，不是机制。
- 如实差距：残余穿岸 0.92%（quad）/2.23%（mixed），来自 0.04 栅格边界余量；泡沫是单通道遮罩近似，淡雾色 `#f4fbfa` 未按片内白裙的冷白重标。
