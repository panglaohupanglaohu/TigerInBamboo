## 判定

有机制，正是原文说的"矛很难写"的三件事：

1. **待机斜举 / 刺出压平**：静止时矛杆斜向上（约 40°），只有刺击那一下才压到水平前指，收矛再抬回斜举；
2. **够得更远**：矛兵射程比步兵长，先出手；
3. **单次刺击的独立命中集**：一次刺击只结算一次，中途被打断则刺击作废（片中被击中的单位立刻僵住、矛停在半途）。

## 代码落点与差距

- `src/core/spear-thrust.js`：`beginSpearThrust` / `stepSpearThrust`，刺击带 `age/duration/length/dx/dz/targets`，每次刺击独立命中集，`canHit` 过滤；`tests/spear-thrust.mjs` 用 120 条种子轨迹对稠密几何参考。
- `src/badnorth/battle.js`：`reach = u.squad?.pike ? 0.44 : 0.28`；`if (stunned) { u.thrust = u.spearRecovery = null; continue; }`；`mSpear` 实例矩阵 `weapon.compose(pos, q.setFromEuler(e.set(-pitch, angle, 0, 'YXZ')), s.set(1,1,length))`。
- **本轮改动**：原来 `e.set(0, angle, 0)` 只给偏航，矛永远水平。改成 `YXZ` 绕序（先按朝向偏航、再绕自身 X 抬矛，否则换朝向会朝侧面倒），待机 `pitch = 40°`，刺击 `pitch = 0`，收矛按 `1 - remaining/duration` 线性抬回。
- 缺（仍未做）：① 片中的**粉红放射状命中/方向细线**（本仓只有血斑，没有以命中点为中心的放射线）；② 伤害飘字与"本次刺击命中集"仍是两处实现，没有联动；③ 旗面不随队伍换纹章。
