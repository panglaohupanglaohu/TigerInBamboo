## 逐帧观察

整片是深色全屏工具窗口，机位不动，只有面板/节点在动，没有 3D 场景：

- **f0000–0016**：画面只有几个小色块；f0006–0016 左侧浮出一块灰面板，主色块缓缓放大。
- **f0017–0100**：主体是一个**四角节点矩形**（左上绿、右上橙、左下蓝、右下紫四个 16px 方柄），
  内部是大面积平滑渐变；左上角浮着小面板（几行小方色块 = 颜色槽）。
- **f0101–0200**：镜头右移，右侧露出**矩形下方的三角**：三角以矩形底边两角为两顶点、向下收到一个**白色方柄**，
  三角内是**离散小面片**平涂（菱形/三角拼版，能看见缝）。f0134–0160 底部横条出现（一排小方块 = 调色板条），
  f0160–0178 收起，f0178 起左上角换成带标签页的面板（RGB / LAB / HSL 三页）。
- **f0201–0266**：矩形被拉大占满画面，f0251–0260 露出**内部面片缝的斜线**（面片被画出来的那几帧），f0261 起又填实。
- **f0267–0332**：底部黄柄 + 白色指针在动；f0323–0332 主体下端逐渐收成尖，三角成形。
- **f0333–0400**：三角面片平涂，f0378–0390 左下浮出一块带彩色格子的白面板（新建节点/选色的调色板网格），
  随后三角尖端多出一个**白色方柄** —— 即"新建节点并接成三角"。
- **f0401–0500**：白柄被拖动（三角形状随之变），f0422–0460 底部调色条开/关切换；f0480 起右下角浮出面板。
- **f0501–0600**：保持"矩形 + 三角 + 底部调色条"，调色条颜色随编辑实时重采样（f0600–0613 右端偏蓝）。
- **f0601–0623**：末态 = 四角矩形（8×8 面片）+ 收口三角（4 段）+ 底部条带（红→橙→绿→青→蓝→紫的离散色块）。
  条带在 f0614 后变成橙红主段 + 蓝块，说明条带是从当前图里重新采样的，不是固定图。

结论：全片只有"节点式调色图"这一件事 —— 四角矩形/三角离散成小面片平涂、节点可拖、
节点颜色用 RGB/LAB/HSL 取、底部条带按图采样。没有任何"把调色板贴到场景材质"的镜头。

## 判定

**有机制**：节点图（矩形 + 三角 + 色带）→ 重心/双线性插值 → 离散面片平涂 → 去重调色板条带。

旧 note 的四条"仍待补"里有三条是**过期账**（第 54 次同型）—— 它们在 `palette-editor.html` 第 56 批段里已全部落地并一直在跑测试：

| 白三角仅预览 | `#pgMenu` 的 `New triangle` → `addTriangle` 建真三角面片（f144→160，nodes 7→9，tris 1→2） |

真差距只剩一条，而且**片内没拍**：调色板只接到世界**顶面**（`setGroundPalettePatch` / `ground-palette-map` 的 `{top}` 通道，
facetsUsed 104），没有接到墙/屋顶/悬崖等全部材质。原文只说 "palette authoring tool"，片内是纯工具画面，
所以按片口径它不是缺口；列在这里当**本仓自选的外延**。

其它口径差（非机制）：本仓是页面里的一块面板（外景 + 面板上下排布），片内是全屏深色工具；面片数 8×8×2+4² 是自选细分。
