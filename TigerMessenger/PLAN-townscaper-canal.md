## 0. 截图差距（为何「差很多」）

| 维度 | 原版 | DeepSeek 现状 | 差在哪 |
|---|---|---|---|
| **体块单元** | 带石砌分缝的「户」立方；转角有柱、檐口、窗套 | 光滑大方块 + 棕色门片 | 没有 Townscaper **模块件** |
| **网格** | **扭曲大网格**（顶点扰动，手工歪斜） | 严格正交，像 Minecraft | 缺 distorted grid 观感 |
| **配色** | 饱和 15 色：红/蓝/绿/黄/紫/白撞色竖柱 | 灰白墙 + 统一褐瓦 | 像工地模型，不像玩具城 |
| **屋顶** | 橙红陶瓦、人字坡、四坡、退台花园 | 统一棕色四棱锥「帐篷顶」 | 屋顶分类失败 |
| **悬空** | **黑铁细柱 + 交叉斜撑**（flying buildings） | 长条灰走廊悬空、无支架语言 | 缺 stilts 模块 |
| **水岸** | 海面包围、岸线咬合、倒影 | 运河直角切堤，建筑骑在土坡上 | 不是「水上岛城」 |
| **点缀** | 露台灌木、栏杆、拱、窗、鸟 | 几乎没有 | 规则没长出细节 |
| **构图** | 高低错落、退台、穿洞、叠户 | 两三座塔 + 一条平走廊 | 布局算法是「摆房子」不是「点格子」 |

结论：DeepSeek 做的是「在运河边堆方盒子」，不是 Townscaper 的 **点格 → 邻接选件 → 自动长成房屋**。

## 1. 调研结论（算法要对齐什么）

来源：
- [How Townscaper Works（Game Developer / Tommy Thompson 访 Stålberg）](https://www.gamedeveloper.com/game-platforms/how-townscaper-works-a-story-four-games-in-the-making)
- [Wikipedia · Townscaper（distorted grid）](https://en.wikipedia.org/wiki/Townscaper)
- [mxgmn/WaveFunctionCollapse README（Stålberg = WFC + marching cubes on irregular grids）](https://github.com/mxgmn/WaveFunctionCollapse)
- [BorisTheBrave · WFC Explained](https://www.boristhebrave.com/2020/04/13/wave-function-collapse-explained/)
- Stålberg 谱系：Brick Block（类 marching cubes）→ Bad North（3D WFC 瓷砖）→ Townscaper（不规则网格 + 邻接模板）

**原版流水线（要对齐的不是「抄 WFC 求解器」，而是这条混合管线）：**

1. **玩家只点占用格**（有/无 + 颜色）。不选屋顶、窗、拱。
2. **不规则/扭曲网格**：逻辑仍是格子，几何顶点扰动，所以街区「歪」但不裂缝。
3. **邻接模板 / 类 marching-cubes**：每个 occupied voxel 看 6 邻，从预制件里选墙/窗/拱/柱/栏/屋顶。
4. **屋顶二次分类**：条带→人字坡；孤立→四坡/尖塔；围合平顶→花园；L/十字→教堂。
5. **悬空规则**：下空 + 侧有撑 → 拱廊；完全飞出 → **黑铁 stilts**。
6. **水**：未占用且连通外海 → 水；岸线自动出防波堤/码头。
7. **配色**：15 色盘；**竖柱同色=一户**；屋顶瓦色独立、不跟户色抖。

本地 `citadelTown.js` 已有规则骨架（15 色、户、屋顶分类、拱、花园、支架），但：
- 色盘过灰、过墨；
- 运河交汇默认 **空地基**，DeepSeek 手摆成灰白盒；
- 支架是木褐细柱，不是原版黑铁交叉骨架；
- 扭曲网格幅度不够「积木歪」。

## 2. 建筑单元清单（向原版拉齐）

每个 occupied 格应能长出这些 **独立低模单元**（不是一个 Box + 一个 Cone）：

| 单元 | 原版角色 | 本地动作 |
|---|---|---|
| 户墙体（色 + 石缝） | 主体 | 加强分缝/檐口，禁止光盒 |
| 窗 + 窗台 + 过梁 | 立面节奏 | 已有，加「临街密、背街疏」 |
| 门 | 底层临空 | 已有 G / 户门 |
| 人字坡 / 四坡 / 尖塔 | 屋顶分类 | 去掉「所有顶都是帐篷锥」 |
| 退台栏杆 | 晒台 | 已有围栏，加转角柱 |
| 屋顶花园（草+球树+盆） | 围合平顶 | 已有，运河种子布局要真用上 |
| 黑铁 stilts + X 撑 | 飞楼 | 材质改铁黑，交叉更明显 |
| 拱 / 水门 | 悬空、临水 | 已有，岸线多种 |
| 岸石防波堤 | 贴水底圈 | 运河交汇要一圈咬水 |
| 灌木 billboard | 露台点缀 | 第二期 |
