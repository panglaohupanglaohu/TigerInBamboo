# PLAN — 高山圣城「城堡层」Townscaper 全模拟（配色 → 构建规则）

> 目标：参照 Oskar Stålberg《Townscaper》（城镇叠叠乐）的机制，把高山圣城的
> 「城堡层」搭建系统从配色到构建规则完整模拟一遍，并保持与既有系统的兼容
> （编辑器拾取 / 裁剪闭环 / 台地湖开关 / 静态合并 / 夜间窗口 / 夜间潜入）。

## A. Townscaper 机制研究笔记

来源：[城镇叠叠乐百科](https://baike.baidu.com/item/%E5%9F%8E%E9%95%87%E5%8F%A0%E5%8F%A0%E4%B9%90/59661495) ·
[知乎：TownScaper 的研究](https://zhuanlan.zhihu.com/p/499198786) ·
[GameRes：Steam 游戏《TownScaper》技术分析](https://www.gameres.com/877989.html) ·
[PCG Towns](https://summit-2324-sem2.game-lab.nl/2024/02/28/pcg-town-scape/)

### A1. 网格与体块
- 逻辑上是规则方格网格，顶点做轻微扰动获得「手绘感」（本作 25×25 网格保持逻辑规则，扰动作为可选项在几何层做，不影响拾取）。
- 左键点击 = 加一块（自动落到该柱底面/承重面上）；右键 = 删一块；无任务目标。
- 块可无限向上叠（本作限制为 5 层，与五台地 × 5 城堡层一致）。

### A2. 邻接模板系统（Townscaper 的核心）
每块的外观由**上下左右邻接状态**决定，从预制模块库里挑模块：
- 四邻皆实 → 内芯块（无立面细节）；
- 一侧开敞 → 立面墙（可带窗/门）；
- 顶面无块 → 屋顶模块（类型由顶面形状决定）；
- 底面悬空且两轴支撑 → 拱；
- 空地被建筑围合 → 石板广场；
- 底层夹道（与外部水面相通）→ 水道。

### A3. 屋顶分类规则（Townscaper 原版）
| 顶面形状 | 模块 |
|---|---|
| 1×1 孤立块（四邻同层皆空） | 四坡尖顶；柱高 ≥4 层加旗杆+旗 |
| 1×N 条带（单向邻接、两侧开敞） | 人字坡屋顶（沿条带轴向） |
| L 形顶（两段条带转角） | 教堂：转角处出尖塔（steeple） |
| 十字形顶（四臂条带交汇） | 教堂：中心出尖塔 |
| 2×2 方块顶 | 平台晒台（边缘栅栏）或尖塔 |
| 大平顶（≥2×2 连通、贴更高墙） | 花园：草地 + 栅栏 + 树 + 花圃 |
| 3×3 全屋顶中心（本作特色保留） | 黄金穹顶（现有） |

### A4. 广场 / 水 / 点缀
- 广场：底层空格被建筑围合 → 石板铺装（Townscaper 的 road/plaza）。
- 水：岛缘海面（本作 = 护城河/梯湖）；夹道 → 水道 + 拱形水门（现有）。
- 点缀：屋顶花园树、水面小船/灯笼、高塔旗杆、鸟（本作已有台地鸟群，城堡层加轻量静态点缀即可）。

### A5. 配色系统
- Townscaper 15 色盘；每块在基色上做**明度微抖**（hash 格坐标），避免大面纯色呆板。
- **竖柱同色 = 一户**：一条垂直柱使用同一颜色与同一组窗/门随机种子（户概念）。
- 屋顶色统一（红瓦），不随柱色变化。

## B. 现状审计（对照 `citadelTown.js` / `citadelEditorPanel.js` / `citadelSceneEdit.js`）

已实现（保留）：
- 体块放置/删除（`applySceneEdit` / `supportsCell` / `dropTarget` / `trimCitadelGridToTerrain` 裁剪闭环）
- 3×3 全屋顶中心 → 黄金穹顶（规则 1）
- 1×1 孤立高柱（≥3 层）→ 金顶（规则 2）
- 条带坡顶 / 孤立尖顶（规则 2.5）
- 城垛 / 围栏（规则 3）
- 拱窗（夜灯可切换材质）、悬空拱、正门门廊（规则 3）
- 水道 + 拱形水门（规则 4，洪水填充）
- 屋顶贴墙随机 32% 绿植（规则 3）

缺失（本轮新增模拟）：
1. **15 色配色盘**：现只有 4 色 `W/L/B/D`。
2. **明度微抖**：现无。
3. **竖柱同色入户 + 户级窗/门随机种子**：现窗密度全盘一致。
4. **屋顶形状分类**：现无 L 形 / 十字形 / 2×2 判定。
5. **教堂尖塔（steeple）**：L 转角 / 十字中心。
6. **旗杆+旗**：高细柱顶。
7. **花园**：现为随机 32% 灌木 → 改为「围合平顶判定 + 草地铺装 + 树 + 花圃」。
8. **广场铺装**：底层围合空格。
9. **点缀**：水面小船/灯笼；屋顶鸟（轻量静态）。
10. **编辑器 15 色调色板** + 2D 染色 + 3D ghost 同步。

## C. 设计目标（模拟到位的边界）

1. 玩家在 5 台地 × 25×25 × 5 层的编辑器里任意摆块，城堡层自动「长」出
   与 Townscaper 一致的屋顶/教堂/花园/广场/水门——**规则驱动、零手工建模**。
2. 15 色调色板完整可用，旧存档（W/L/B/D）无损迁移。
3. 所有既有验收不回归：3D 拾取（faceToCell）、隐藏高层、撤销重做、
   裁剪闭环、台地湖开关、静态几何合并、夜间窗口、夜间潜入路线、性能。

## D. 实施步骤（按依赖排序）

### D1. 配色系统（先行，其他规则引用颜色）
1. `citadelTown.js` 定义 `CITADEL_PALETTE`：15 色（Townscaper 同名色系，
   适配水墨 toon 明度）——白 / 米白 / 沙黄 / 柠黄 / 橙 / 砖红 / 陶土 /
   褐 / 深褐 / 蓝灰 / 石板灰 / 蓝 / 藏青 / 青 / 松绿。
2. 存档 char 集扩展：`.` 空 + `0-9 A-F`（15 色）+ 兼容旧 `W/L/B/D` 迁移映射。
3. `buildCitadelTownAssembly` 材质表由 4 材质 → 15 色 `makeToon` 材质
   （按 char 索引查表），窗口/水门/屋顶仍走专用材质。
4. 明度微抖：`color.clone().offsetHSL(0, 0, hash(ix,iz,char)*0.08-0.04)`，
   材质按 (char, 抖动档) 缓存（抖动档取整到 5 档，控制材质数）。

### D2. 编辑器调色板
1. `citadelEditorPanel.js`：`PANEL_CHARS` / `CHAR_NAMES` 扩到 15 色；
   调色板按钮 `1..9,0,-,=` 或 `1-9 + Shift`；沿用「保存才落盘」。
2. `citadelSceneEdit.js`：`CHAR_COLORS` 同步 15 色；ghost 材质跟随 activeChar。
3. `townscaper.html` 独立编辑器同步（同 palette）。

### D3. 户概念（house）与立面规则
1. 竖柱同色入户：扫描每根柱 (ix,iz)，柱 = 户；户种子 = hash(ix,iz)。
2. 立面模块决策树（替换现有「每面必窗」）：
   - 四邻皆实 → 无立面细节；
   - 外露面 → 墙 + （iy≥1 且户种子<窗密度）拱窗；底层门（户种子决定哪面开门）；
   - 悬空底面 + 单轴支撑 → 拱（保留现有）。
3. 窗材质保持 windowDark/windowLit 夜间切换（现有 `refreshCitadelWindowLights` 不变）。

### D4. 屋顶形状分类（核心新规则）
1. 顶层连通分量（同层四邻）→ 形状签名：
   - 大小 1 → 孤立尖顶 / 旗杆（柱高≥4）；
   - 1×N 直线条带 → 人字坡（保留）；
   - L 形 → 两段人字坡 + 转角教堂尖塔；
   - 十字形 → 四段人字坡 + 中心尖塔；
   - 2×2 → 平台晒台（栅栏边缘）+ 可选尖塔；
   - 大平顶（≥5 格连通）→ 花园（围合）或晒台。
2. 教堂尖塔几何：四坡锥 + 小十字顶饰（复用 `buildHalfDome` 风格，toon 描边）。
3. 旗杆：细柱 + 三角旗（`MeshBasicMaterial` 双面），高细柱判定 = 柱高 ≥4 且顶层 1×1。

### D5. 花园 / 广场 / 水
1. 花园：大平顶且至少一面贴更高墙 → 顶面铺草色薄板（0.06 厚）+
   边缘栅栏 + 1-3 棵树（复用 `buildShrub`/`buildTopiary`，位置哈希）。
2. 广场：`iy=0` 空格四邻全实（或 ≥3 邻实且贴边界）→ 石板铺装薄板
   （浅灰，拼缝线 2 条）。
3. 水：保留现有水道+水门；水面格随机小船（1×0.4 盒子+帆）或灯笼。

### D6. 点缀与户顶统一
1. 屋顶瓦色统一（红瓦 `roofTile`），不随柱色。
2. 屋顶鸟：花园/晒台顶概率出 1-2 只静态低模鸟（复用 `birdVortex` 的
   小鸟几何或简化三角鸟，避免新增资产过大）。

### D7. 兼容与集成回归
1. `mergeCitadelTownStatic` skip 名单补新模块（草板/铺装/船/旗可合并，
   窗口/水门仍 skip）。
2. 裁剪闭环 `trimCitadelGridToTerrain` 与色盘无关，回归即可。
3. 台地湖开关（cascadePoolsEnabled）与广场铺装共存：铺装只落在台面格，
   不与湖面重叠（湖区由 `citadelTerrainPointSupported` 放行时铺装让位）。
4. 夜间潜入：台面 surface 判定不变；巡逻点仍用 `patrolSurfacePoint`。

### D8. 测试
- **node 单元**（纯函数）：屋顶形状分类（1×1/条带/L/十字/2×2/平顶）、
  教堂尖塔落点、花园判定、广场判定、配色迁移（旧档 W/L/B/D → 新盘）、
  明度抖动档缓存、裁剪闭环与新规则的兼容。
- **无头 e2e**：调色板 15 色编辑 → 3D 重建颜色正确；摆 L 形 → 教堂尖塔；
  围合 → 广场；回归 `citadel_editor_e2e`（3D 直编辑/隐藏高层/导入导出）、
  `terrace_loop_e2e`（裁剪+湖开关）、`night_infiltration_e2e`、
  `accept_tiger_messenger`。
- **性能**：圣城视角帧耗时 + 网格数探针（新增模块合并后 draw calls 不升）。

## E. 风险与回滚
- **存档迁移**：旧 `W/L/B/D` 字符在 normalize 时映射到新盘前 4 色，双向兼容；
  导入导出面板沿用 ASCII，新增 char 集白名单。
- **拾取回归**：屋顶/铺装/点缀全挂层组下、faceToCell 映射不变；e2e 兜底。
- **色调不和谐**：15 色先在 node 渲染截图（shot harness）比对 toon 风格，
  再进真机调。
- **性能**：新模块全部纳入静态合并；点缀尽量共享几何/InstancedMesh。
- **回滚**：每步小提交（git），测试全绿才进下一步。
