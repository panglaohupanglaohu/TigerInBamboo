## 六、诚实的四条限制（本轮更新）

1. **REA 吃不进视频。** REA 的通道是二进制 / WASM / CDP，没有视频帧分析；本机 WASM 通道卡在宿主禁止 `ps`。所以「把片子交给 REA 逆向」这一步，实际执行的是本地 Chrome + canvas 管线。
2. **237 条不可能一轮做完。** 每小时一轮、每轮 12 条，落地 4~6 条，这是当前速率。剩 190 条。
3. **impostor 欠账已清，但只做了一半。** 上一版说「缺 RT 管线」——第 4 轮已经用 `WebGLRenderTarget` 烘了 8 方位，云和树都上了。但原文说的是**八角** impostor（八个面互为过渡），我们做的只是「8 张图按方位硬切」：转相机时 45° 换一张，切换瞬间没有交叉淡化。要补的是相邻两帧按方位角插值（或做一个八棱柱，每面对应一张）。
4. **`outline.js` 的树冠暖色描边还在**：深度边是拿 pass 1 的颜色深度算的，所以 impostor 会被画一圈描边（参考片的树没有）。本轮把树冠削圆了，那圈描边反而更显眼 —— 修法仍未做（把 impostor 从深度 pass 里拿出来单独预渲染一次）。
5. **AO 是"粗"的。** 96² 的 AO 栅格 vs 一格 0.8 世界单位的 quad，勉强能分辨"一格宽的缝"；再细的接触阴影（比如屋檐与墙之间 0.1 单位）就分辨不了。参考片里还有一点点屋檐下的暗，我们这一步到不了。
6. **条纹是灰的，不是白的。** 参考片的岩脉是米白，我们因为台地本身是灰绿顶点色（1.34 倍乘法提亮后仍偏灰）所以只能算"深浅条纹"。要真像，得给崖面单独的色相（第 3 轮的 `surface.js` 投影贴图已经能做到，只是还没接）。

## 七、按主题的下一步建议

1. **网格侧最后一块大改**：`1151770831619534848` + `1332410042784641026` + `1151137783785771008` 三条是同一件事（patch/cluster 双层网格 + 三角插值权重）。建议先做 1D 验证权重，再上 `src/grid.js`。
2. **对比贴图 / 边层级**（`1482346496460828674` + `1670720537662836736`）：两条都要"边分类"，可以一起做：先给 `grid` 的边打 hard/tile/material 三级，再拿它同时喂 `outline.js`（对比图）和 `relax.js`（分层平滑）。
3. **AO → 反弹**（`1580835075629133825`）：AO 场（96² 栅格）已经在了，下一步是把这个场当"注入源"跑 1~2 轮扩散，再把结果乘进环境项 —— 就是原文的"光反弹"。
4. **mega texture**（`1580845127207387137`）：缺的不是光照管线，是 UV 展开。`surface.js` 现在只有投影 UV，而 mega texture 要求"射线打中处能反查 UV"，得先有真正的 unwrap。
5. **Impostor 收尾**：八角交叉淡化 + 把 impostor 从 `outline.js` 的深度 pass 里摘出去（否则树冠那圈暖描边会一直留着）。
