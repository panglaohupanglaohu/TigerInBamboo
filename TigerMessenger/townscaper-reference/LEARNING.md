# LEARNING — 这一轮从视频里学到了什么，改了哪里

素材：`REA-agent/gifs/` 的 237 段视频 + `README.md` 里每段的原文说明。
做法：**先读原文，再看画面**（每段抽 20 帧拼成总览图），原文和画面对上了才动代码。
怎么看结果：`./start.sh` → 总览页 `index.html`，里面有新版游戏、新旧对比、学习笔记（可播放原视频）和 engine 各页。

顺手修掉的一个老问题：three r160 里 `new THREE.Color('#hex')` **已经**转到线性空间，旧代码又调了一次 `convertSRGBToLinear()`，颜色被转两次——这就是 README 里"画面只有色板 37% 亮度"的真正原因，旧版是靠把灯拧得很亮来掩盖的。新文件里去掉了重复转换，灯光按正常强度重标。

存档格式升到 v4（网格变了，旧字符串的格子编号对不上，会被拒绝而不是读错）。

## 二、为了不影响 engine，保留了什么

`engine/` 目前还在被另一条学习线推进，它依赖 `src/grid.js`（旧网格）和 `src/mesh.js`（含 terrain 模式）。这两个文件**原样保留**，新版游戏用的是新文件：

```
src/quadgrid.js   新网格（GridGenerator）
src/townmesh.js   新建筑网格 + AO/反弹光烘焙（ModuleBuilder / BigMesh / AoBaker）
src/shore.js      岸浪 + 浪裙
src/scene.js      倒影、海面、光照档位（只被 game.html 用）
```
