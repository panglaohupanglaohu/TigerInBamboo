# 原作书店近景林带 · 来源与接入证据

本批继续资产总规划中的原作近景环境，不恢复已经停用的默认房屋/街灯/电线杆。主代理负责来源、现场数据和资产账本，Godot书店协作任务负责原生局部替换与实景/路线测试。

## 源数据已核对

- 来源是完整默认Web世界中书店局部18米内、带走廊身份的6棵树。不是从目录挑一株通用树复制，也不是重新设计的树。
- `web-source.png` 为该次默认场景实际玩家镜头，已查看；`web-source.json` 记录6个实例的位置/尺度/碰撞和输出摘要。
- 数据 `godot/data/bookshop-surroundings.json` 保留每树原表面网格、原色区、朝向、尺度与松烟墨壳，约1.07MB。282个实物mesh合并为按色区的数据，3876个实物三角形，另有3876个墨线三角形；六树高度约3.15–4.93米。
- 网格仅作完整节点变换烘入树局部空间及6位小数舍入，最大单分量舍入误差0.0000005。不是重新减面或新Blender造型，不改变原 .blend/GLB。
- `data-validation.json` 合约检查通过：6个唯一实例、SHA一致、全部数据有限、法线归一、实物/墨线面数匹配、原有两档飞白参数完整。
- 代码中工厂仍存在并不表示场景应放置：五类候选资产的实际调用与停用结论详见 `docs/BOOKSHOP_ASSET_LEDGER.md`。

复查命令：`rtk proxy node TigerMessenger/tools/test_bookshop_surroundings_data.mjs`。捕获器 `tools/capture_bookshop_surroundings.mjs` 只允许新建目标，已有数据不会被默默覆盖。

## 原生检查的范围

原生旧近景预检在相邻 `bookshop-context/godot-preflight.json`。只考虑独立实验装饰，章节root、邮筒、石径、庭园、路线与原书店模型不在过滤范围。新原树必须按当前物理共享地形落地、保留书店局部XZ和scale/yaw，并核查保留边界旧松是否碰冠。

原生接入现已通过实际验证，主代理已查看同玩家镜头前后：14米内6座实验house、2座实验tower、12棵实验pine在生成时跳过；不删除其源文件，禁用此原作环境可回退。六棵源树按7色与2档墨线合批，沿真实地形碰撞网格射线落点，局部XZ误差在浮点精度内，scale/yaw保持。默认书店行走/墙体/R与原六地点连续步行（12.5秒）通过。

渲染器同镜头draws703→565；原树分枝更详细，图元157902→169722，因此只声明绘制次数降低，不声明全场性能达标。远处保留模型的完整变换/尺度指纹逐一与legacy回退一致，随机缩放消耗顺序不变。

两棵边界旧松与源tree-5的AABB相交，但逐三角形表面相交检查未命中；保持14米原范围，不额外排除它们。证据在相邻 `bookshop-context/`：`godot-before.png` / `godot-after.png`、`godot-before.json` / `godot-after.json`、`godot-boundary-check.json`。AABB告警未被误当作实际穿模。

## 仍未迁移的范围

完整世界地形/色彩、书店附近16丛程序草、动态航空座舱/鸟群、其他章节原模型及完整镇区，仍是后续批次。六棵现场实例不计成六项新的目录资产；本批只改善原生近景，Web作为来源未被修改。
