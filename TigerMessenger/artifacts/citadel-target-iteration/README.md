# 2026-09-12 按目标图重做整体读图关系

用户否定上一轮“成功导入即完成”的验收方式。本轮以用户提供的蓝调山城战役目标图为标准，实景对照仍未达到目标，不宣称 1:1 / AAA 完成。

## 实际改动

- `targetCastleSilhouette.js`：保留并隐藏旧 crown 外观，替换五座对称圆筒为八座错落方塔、三座蓝顶、垛口与拱窗。中心塔为空壳，原 22.3 m 入口、37 m 出口保留。修正檐口共面重叠；五材质合并，新外壳进入相机/行走检测。
- `newCityBackdrop.js`：连续、折面的三层山脊，第二轮根据截图抬高山谷，去掉过分孤立尖锥与峰顶孤树。290 株实例化柏树，总计 25824 三角 / 6 对象，仅装饰背景。
- `environment.js`：天空球 220 → 2000 m，修复高山相机逼近天空壳产生的黑色大边带；将天空投影至远平面，兼容游戏默认 500 m 远裁剪。只在圣城附近、蓝调时段混合蓝色天空，其他地点/时段保持原主题。
- 隐藏圣城白色球状云团，保留原件和树冠卡片。旧港两株原树缩到 .38，避免盖住旧城。
- `targetHillside.js`：在原可玩地形上采样，检查四角落差并补基础；旧城核心/桥廊留空。另在新背景山壁布置远景聚落。不是把平面水/湖盆重新导入。
- 导入民居改为较深蓝顶、米白墙、金色及少量粉色窗；月光降低，门与广场的暖光增强。

## 仍未解决的目标差距

1. 主堡总体轮廓更接近，但比例、前堡细节及表面质感仍偏简单；个别边缘仍需近景检查。
2. 原可玩山体仍有大平面/圆钝山包；新装饰山脊并未修掉这些原地形。
3. 旧城仍缺目标那种连续、密集的梯田街区；海上旧道路支撑关系未改。
4. 新城主台阶还没有目标图的真实大队士兵。应把可用攻城路线/防守点接至新城，然后验证 AI，不能只是添加假人。
5. 港口舰队、水上长条暖倒影与近景摊位密度仍有很大差距。完整航线已有阻碍，未在此次视觉改动中绕过。
6. 光照仍不够细腻，UI/整局战斗/移动端/Godot 未在本轮重做。
