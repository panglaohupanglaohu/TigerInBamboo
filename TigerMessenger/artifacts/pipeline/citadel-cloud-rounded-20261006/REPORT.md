# 云团 v13：圆润宽瓣候选

已实际查看 `citadel-old-street-infill-20261006/live-front.png`：旧城后云团峰顶偏尖、几朵云轮廓接近小山峰。当前实际入口是 `targetCityDetailCandidate.js` 的 `mountainCloudBanksCandidate.js?revision=12`；本轮不改入口，交主线程切 13。

只修改云工厂和专属测试。旧源码在 `source-before/mountainCloudBanksCandidate-v12.js`。

- 海后云模式的团瓣由高椭球改为扁椭球：未缩放高度半轴 3.25±0.65m，横向宽度半轴 5.3±0.9m；沿轴半长 9–10.6m。中央瓣允许 1.4m 层次偏置。
- 沿轴采样从 41 截面增加至 65，仍每圈 20 点；去除重复整云 sin 收尖，使端头由真实椭球自然收口。单闭合壳、无内部透明球重影。
- 不改候选布点、城市禁区、实际山海采样、2m 扫掠网格及命中面顶点最高值保护、2m 离地、有限漂移、昼夜和资源回退。

正式地形/实际三角海面 fixture：5 组，12980 三角，5 draw；构建 59.61ms（本机一次纯 CPU，非帧性能）。三组后肩构图仍存在。全部存活云扫掠最小净空≥2m、海面漏采0；原地形坐标不变。检查闭壳边两面、圆冠非单截面尖点、纵横比例、运动有界/10秒可见位移、确定性、昼夜、不透明深度写入、城市大包络阻挡和dispose通过。

测试命令：`node tools/tests/check_mountain_cloud_banks_candidate.mjs`。

原测试要求每朵峰间高度差>0.5m是旧高瓣造型约束，本轮改为多峰真实体积+峰顶邻环差<0.18m和整体厚长比<0.4，直接对应去尖目标；没有降低净空、资源或动画门槛。传统无sampleSea路径保持旧造型。
