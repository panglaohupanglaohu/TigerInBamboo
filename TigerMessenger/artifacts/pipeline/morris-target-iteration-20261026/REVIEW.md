# 莫里斯岛 · 道路、溪桥与高树迭代

依据用户认可两张对象目标图及“高树更高，人骑马不到树的一半”“桥再拱一些”追加要求施工。

- 悬铃：低处分叉、连续渐细枝条、较小立体掌状叶、斑驳树皮顶点色、悬挂种球；宽树冠配更高树身。实际生成高度16.37–22.91m。
- 尖柏：抛弃大型尖锥块，连贯尖冠、重叠细叶鳞、基部收拢，高约19.77–27.05m。保留原数量、受保护区域和通行约束。
- 道路：原186.4m曲线、3.2m净宽和桥位保留；5横列真实轻横坡、路沿颜色过渡、净宽以外低碎石，坡肩加宽至6.5m。未把顶点色称为几何。
- 溪流：细化动态波纹与岸边泡沫，增加低矮错落岸石；既有桥前看溪视线留空继续有效。
- 石桥：Oskar顾问独占Details；连续厚护墙/压顶、楔形拱券、闭合拱芯，替代锯齿盒块。52拱石、196浅砌石、5合并批。用户追加抬拱后：桥面相对端线冠高0.75m（旧0.25），拱腹rise2.08m，最薄拱腹0.6127m。原8m跨距、3.2m净宽和桥头不动。
- 单独测桥实际径向最大坡约28.64%，不能沿用不含桥的道路15.17%报告。中心骑乘承托与桥侧水边限制本地检查通过，完整正常骑马过桥与盘山未验收。
- 高树挡原全景桥景后，前景悬铃从(-18,39)侧移至(-30,42)候选，生产仍经原禁入检查；总览机位抬高10m。树高保留，桥前步行机位不改。
