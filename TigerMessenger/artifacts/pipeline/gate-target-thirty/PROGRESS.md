# 叹息之门新30轮

来源：本批 target.png，用户要求门离山体、下面广阔水域、远山上有水晶建筑。配色沿用最新青蓝/奶油/暖沙金，而非回退目标旧色。

r01–r30逐项实现，默认 GATE_THIRTY_RELEASE=30。?gateThirty=0 返回本批之前结构，1..30可复现渐进阶段。此前悬空山石、错误球面海拔、拱边带和柱环位置失败候选已修正，不作为额外轮次；冻结帧导致的初始水面截图也重新用实际运行页面采集。

每轮 rNN.json 是代码运行和局部功能检查，不能单独代表视觉验收；对应两角度截图已目视对照。最终另有正面、反侧与植物舱近景。全局待办老虎/全城性能不计入此批。

## 结果
两侧非通路岸坡降入水下，保留进出路线；21座远岸晶柱及山上露台/植被。远山按球面海拔落底，植被射线落根。门区水面短划线移除，微波、墩边涟漪与柔和桥影。拱线、柱头、舱框、花槽、灯具、栏杆与顶部金针补充。重复通用铁路桥柱局部减少；会面平台支柱延至退岸后的基础。新增静态金属装饰按材质合并。

## 验证
30份局部报告各1152条铁路净空射线，原进出路地面采样通过。最终 final-ground-check.json：原碰撞解算器模拟15.8秒到平台，无卡住。没有宣称手动乘车验收、完整剧情或全世界铁路性能完成。
