# 新岸长直崖：实景诊断与最小下一步

2026-10-06，只读；未修改山体、路线或 artifact。实际看过 `combined-cliff.png`、`combined-front.png` 与 `citadel-rail-cliffs-20261006/target-v11-smooth-east-connection.png`。不评分，概念图不作为量尺。

## 看见的问题

近景里广场前沿是一道从铺装直到底海的连续高墙，密集、近等宽的竖向明暗条贯穿全高；右侧更高山肩也沿相同方向落到底。目标是几块宽岩面被短崖、草台和建筑台基打断，铁路廊道嵌在城岸边缘。当前全景的铁路/上廊仍与广场高岸隔着海水空隙；单纯抹平条纹不会消掉这个断面关系。新植物已更靠可支撑面，不能再靠在直崖种草来遮住墙。

## 源码能确认的原因（不是把截图条纹全部归因于一个函数）

1. `targetEastLoadedCliffCandidate.height()` 对扫掠投影海侧的非保护点直接返回 `sea-3`，原公共三角投影及边距维持原高；这是二值断面，没有中间岩台。它用 castle XZ 投影保留完整承托柱，而非沿实际重力方向塑造自然岩层。
2. `audit_east_cliff_remesh_final_surface.mjs` 只在 **x76..94/z69..96** 精确重网格；区域以外依然在原粗网格上逐顶点 `cut.height()` 下压，再拼接。因此不能把画面所有竖褶当成精确封边的错：外围粗格上一个顶点不动、邻点降几十米，本来就会把网格边拉成长折面。
3. 精确 patch 内 `buildEastCliffRemeshPatch()` 按每条裁剪 polygon 边直接连接高侧与低侧，`wall()` 使用中心三角扇；它消除共边 T 接缝，但没有合并沿岸连续共面岩面，也没有多级纵断面。裁剪边线的小转折会被整高挤出。三角扇自身不必然有褶，真正原因是边界折向/不同上下高程的变化被拉伸整高；需按面来源验证，不能仅换 triangulation 就承诺修好。
4. 后续真实 `refineEastCliffSurface()` 保留了源地形 `.22` relief 与法线处理，它不是把上述大断面重新设计为短崖的步骤；减噪或加细线不能弥补。

## 唯一推荐：先重建连续崖面，再只在空余岩体内做两处短台

### A. 不挪城台/轨道即可试的最小候选

先限 **x76..94/z69..96 已重网格区及其直接共边带**，给 raw 输出面标记 `retained-top / cut-floor / new-cliff / outer-transition`。保留原顶边、保护承托体、底部水面交线及 patch 外边界。沿岸溶解共线的裁剪边，形成连续有序边链；只对 `new-cliff` 内部重铺，不能移动2949支持点或原公共三角。

- 去掉由源格/碎 polygon 引入的窄条分区：将近共面、同语义墙面合并后再切成 **约4–8m宽** 的少量岩块。这是试验尺度，不是已量测可用宽度。
- 先做不改位置的共面合并/一致法线验图；若条纹仍来自真实锯齿边，必须重建墙中部截线。沿顶边保留短过渡带，墙身向岩内偏移最多约0.15–0.35m作受限试样，每点均须在原可裁体内且不侵公共承托体。若完整承托柱把内侧也锁住，则此处只允许法线/合并，不能为了光滑掏空铺装。
- 与其新增整圈草裙边，优先在未受铺装覆盖的北侧肩、南侧收尾各试一处错高小岩台。建议宽1.5–3m、沿岸长6–10m、单段可见短崖约6–10m，仅用于搜索；必须从真实轨道扫掠体之外的残余岩体中 **削出台面**。没有这个净空，就不建。不沿整段统一等高，避开中央湾与广场正前承托柱。
- 外围逐顶点下压的长折面要按同一条裁剪边做局部精确插边和封面；仅修 patch 内不能保证右侧长褶消失。下一次必须输出新面来源颜色图，分辨修改作用范围。

A可以降低密集纸褶、给局部轮廓休止，**不能消除整段35–40m量级的高差**。它是可独立撤回的小样，不是目标已达成。

### B. 需要另一个布局决定才能改变的部分

广场保护边缘到海面、轨道/上步廊的相对高差固定时，没有办法仅靠封边拓扑把整堵高墙变为目标的一层短崖。要把整个立面分成可读的两三级，必须取得额外水平退台空间，或改部分非公共城岸台阶/上廊连接高程；不能在现海隙填一条大坡，也不能在车体上方保土盖形成隧道。是否可用“现公共广场不动、其下专属承托短墙+非公共山侧退台”的混合断面，需逐站求三维自由空间后再决定。本报告不授权改轨道、挪雕塑木马或缩公共广场。

## 验证与停止条件

新候选沿用严格 raw→remesh→production refinement provenance，旧 final hash 不改。必须同时重新验证2949点及实际公共三角/承托体；双线完整载货 OBB、实体内外判据、海面波包络与额外工程储备分开；raw边两面/方向一致、final共边裂缝及绕序检查；更新真实植被/草皮承托。固定当前两机位比较：减少整高窄条、出现局部宽面/短台，同时无新增海湾土坝。缺横向空间的站明确保持现状，不靠平滑法线或刷绿宣称短崖完成。
