# 十二门徒连续山肩与岸线 · 2026-10-22

顾问实施为本项目方法，不是 Oskar 私有源码复刻。只改十二门徒默认工厂与其专用海岸模块，没有改高山圣城、铁路、角色、全局渲染。当前候选冻结 wfc12，源hash见manifest.json。

## 实际更改

- 保留六边范围三角格→配对/细分/松弛的不规则模块网与既有9岩体布局及WFC约束。
- 旧墙面每row竖直拉升再补水平挑边，改为真实连续剖面连接。主要台地2.2m内收肩自高度20%开始；独立海蚀柱及back-tower保持0.38m陡肩，未外扩保护包络。只在草顶与肩面过渡共享法线，岩石折面保留。
- 最终几何射线重附现有灌木候选，拒绝无承托或陡壁候选，没有堆新植被。
- 真实水面采样的专用窄岸带，两组错相6.4秒泡沫进退，onBeforeRender更新时间，固定geometry不逐帧创建。不是流体模拟或全海洋系统。
- 根GPU评审发现的两处真实顶缘裂缝来自壁面顶排中点仍带fold偏移；上下端fold归零，帽沿同步拆分，1614分段边与肩上排精确共坐标。
