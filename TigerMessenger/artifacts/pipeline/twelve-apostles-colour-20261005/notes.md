# 十二门徒配色专项 · 2026-10-05

状态：颜色候选已接入；源语法与相关光照测试通过；日间、叶丛、黄昏实际游戏截图已保存并独立审阅，见 visual-review.md。颜色改善适中，黄昏岩面的冷暖层次仍弱，未声称完全还原 Bad North。

## 图像问题与限定

参考上一轮 r10 实景：岩石整体灰蓝偏苍白，大片立面明暗差偏弱；草皮和灌木经顶点色、实例色、照明相乘后聚成暗团。本轮只调整颜色及光响应常量，未动8柱位置、几何、法线、实例矩阵、承托、植被分布、距离场、铁路或城市。旧版源完整保存于本目录 `source-before/`，未覆盖十二门徒三小时批次的任何图像或报告。
