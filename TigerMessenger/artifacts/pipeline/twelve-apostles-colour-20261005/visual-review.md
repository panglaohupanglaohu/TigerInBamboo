# 十二门徒颜色专项：实际画面独立验收

验收日期：2026-10-05。已实际查看本批 `after-hero.png`、`after-foliage.png`、`after-dusk.png`，并逐项对照上一批 `../twelve-apostles-three-hour/r10-hero.png`、`r10-foliage.png`、`r10-dusk.png`。本次只判断可见颜色与光响应，不以几何测试通过代替美术验收。

## 对照结论

| 视图 | 实际改善 | 尚未解决 |
| --- | --- | --- |
| 主视图 | 原先偏苍白的冰蓝灰，变成明度稍低、偏中性的灰色，略带绿灰；岩石不再那么发白。台面植被比以前偏暖、偏橄榄绿，岩与草的材质区别更清楚。 | 主要岩面仍大而均匀，明暗面的区分较克制，尚不足以显著加强远景地质读形；颜色不能补足轮廓和切面的单调。 |
| 叶丛近景 | 草皮由暗绿转为较亮的鼠尾草绿／橄榄绿，叶片的黄绿色明显更容易辨认，灌木不再完全混入地面暗块。没有明显荧光绿倾向。 | 草皮仍像较平的绿色覆盖斑，植物分布稀疏；阴面的大片岩面也较均匀。分色改善成立，但不能据此声称植被质感或地貌已经完成。 |
| 黄昏 | 岩石比旧版少蓝、略沉稳，草色仍可读；没有被天空整体染成黄橙色，保留了海岸岩石身份。 | 暖亮部与冷暗部差异仍弱。黄昏的主要感受仍来自天空变化，岩体承接环境光的表现比较轻，不能说夕照层次已充分建立。 |

## 验收边界

- 新图为 1250 × 518，旧图为 1265 × 518，宽度／画幅约差 1.2%；目标机位相同，但不构成严格逐像素对照。
- 飞行器位置、背景城堡形态，以及海浪时间与碎波变化不归因于这次颜色常量调整。本报告没有用这些变化给配色加分。
- 此次可以确认的是：岩石减少苍白感，植被与岩石、叶丛与草皮的分色更清楚。改善幅度适中，适合作为下一轮沿用的海岸色板。
- 这是一套参考有限色板和主体读形原则的项目配色，不是 Oskar 的原始色板，也不能称为还原《Bad North》渲染。

**最大剩余颜色问题：黄昏时岩体自身的暖亮／冷暗层次仍偏弱，大面积灰面仍显均匀。** 下一轮应继续用同机位、同时间检验岩面的光色层次，避免仅提高整体亮度或饱和度。
