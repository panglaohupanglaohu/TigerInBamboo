# 叹息之门左侧十二门徒：研究后改造

2026-09-28。用户指定顾问 oskar_world_advisor 先研究 Bad North 与澳洲十二门徒再实施。研究与模块快照见 [顾问报告](../sea-stacks-bad-north/advisor-research.md)。

## 已实施
- 岩群限定在用户截屏2的门左侧海岸；原先全周散布取消。8个候选中7个通过保护检测，1个与保护几何冲突排除；其余13个旧候选隐藏。
- 书店圆形场地整体保护；曲面城市先用包围盒筛选，再用真实三角面与岩柱包络距离检测，避免大包围盒把空海面一起排除。
- 顾问构建12种海蚀模块，六段角色接口；WFC实际选择凹槽、崖壁、方向岩台和碎顶。当前3条合法组合，属于一维纵向模块WFC，不是完整Bad North引擎。
- 岩台向一侧展开，背侧近连续；收小岩脚、降低峰顶尖角；蓝灰崖面/浅岩台/低饱和灌木，削弱刻线。是项目配色，不是作者官方色板。

- 100种子网格闭合、接口、有限值检查通过；3个现有几何/朝向测试通过，测试适配非索引三角网格，保留原半径包络约束。
- 默认场景零JS/着色器错误，46800个铁路采样射线无命中；这是抽样检查，不等于连续扫掠碰撞证明。
- 7个接受岩群底圈均低于实际海面；7组全部顶点处在书店保护区域的对面半球，plazaMin为null代表不进入该投影半球，不代表缺测或零距离。
