# 霸天与全机型舰队飞行方案 · 2026-10-14

用户方向：霸天速度不慢，低空、巨大阴影和整齐编队造成压迫感。此文件与all-types-flight-target-v3.png是设计规格，尚未完整落实六类机型联动控制。速度为设计值，并非当前实测。仅书店镇发生手动战斗。

## 连续飞行过程

1. 移动集结：霸天保持8–12m/s沿缓弧移动，不定点等待。先形成外围等待队，再依次入槽；侦察领先，护卫翼根，保障最后归位。集结目标6–8秒，未归队单位不得直接穿过旗舰追赶。
2. 快速转场：加速至24–28m/s，队形拉成长矛。速度渐变2–3m/s²；主航线使用连续球面曲线，后排沿旗舰已经经过的轨迹跟进。大转弯半径120–180m，轻倾侧6–12°；内侧减速、外侧加速。侦察提前通报高桥/烟囱，整队提前爬升或绕行。
3. 到场压迫：侦察先到，霸天必须随后穿过书店上空；旗舰实际抵达后才允许开火。目标地面基准上28–40m，但全机腹/机翼下缘必须比实际障碍最高处至少高8–12m，有高障碍时优先安全。影子由海面推进到岸、广场、工厂；音量随真实距离变化，先远处低频再近场掠过。
4. 低空掠袭：维持12–16m/s，沿宽弧穿越攻击窗口，不悬停连续轰击。机腹先亮2–3秒，短脉冲0.6–1秒；发射后继续前进。小型机只允许一侧切入，另一侧等待；攻击后向外侧拉起，再沿后方弧线回槽。转弯半径80–110m，所有飞机避开机腹至落点射界。全程建筑结构完整，只有烟、火光、设备停机与环境/角色反应。
5. 护罩衰减：能源35以下收紧外圈，20以下关罩。霸天保持至少12m/s移动，把反击窗口表现为暴露节点与保护队形收缩，不能关罩后僵停原地。
6. 收队返航：保障单位引导受损飞机居中，健康飞机外侧、护卫最后脱离。霸天逐步爬升，连续加速至20–24m/s；编队用弧线转向水晶城，地面巨大阴影与引擎声随远离而消退，不瞬移。回港分批进位，恢复巡航和原BGM。
