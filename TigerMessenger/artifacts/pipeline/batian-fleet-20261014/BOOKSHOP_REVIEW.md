# 书店镇单区战斗验证 · 2026-10-14

范围：关闭霸天自动战斗，只注册书店镇；旧侦察机自动袭击与旧先锋跨地区更新在本模式让位。高山圣城、苔庭等不自动与莫比斯舰队开战。

正式CUA运行：手动出击，DOM审计bookshop-formal-run.json记录集结→转场→封锁→钳形→主炮→护卫→撤退→返航→停靠→idle，5原机UUID不变，能源撤退。旧时间版本18次攻击，未捕获每次攻击的近景，不能称全部武器视觉验收。截图bookshop-assemble.jpg、bookshop-returned.jpg。

已修：开火冷却改用模拟时间，低帧率不额外增加开火；回港复位热量/翼根；机器人反应只作用kind=bookshop-robot，不选robot-bookshop建筑。CPU完整循环12次攻击、未知区域拒绝、自动战斗关闭、建筑变换不动、1x/4x墙钟相同模拟结果通过。修后完整正式GPU仍待重跑。

需要改进：
1. 阵型辨识与过渡：只有5架，队形与角色尚难从地面读清；曲线转弯、集结绕翼、受损飞机补位需进一步实测。
2. 武器表现：当前脉冲/烟环首批效果，晶雨弹道、牵引场、蓄能预告未达到四种不同武器的清晰程度。
3. 设备与机器人：停机状态字段和失衡已有原型；工厂蒸汽阀、生产动画停机恢复、维修拖带尚未完整挂接。
4. 护罩与反击：罩体暂为粗线框；能量低后反击窗口偏短，反击仍由计时代理，不是三厂机器人实际命中事件。
5. 性能与观战：整场宽视角约12–13FPS快照，缺少前后对照；应先处理宽视角绘制量，再将烟效复用为对象池。
