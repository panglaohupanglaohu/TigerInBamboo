# SOCCO 伤亡与撤离诊断

这是一组注入诊断，使用实际 8931 页面和原任务更新器；不是自然受击、自然机队离站或全游戏循环验收。passed 仅表示规则与逐人记账断言通过，兜底不算真实回舱。

| 场景 | 真回舱 | 阵亡 | 兜底 | 未解决 | 断言 |
|---|---:|---:|---:|---:|---|
| casualty-normal | 18 | 3 | 0 | 0 | 通过 |
| casualty-normal-blocked | 16 | 3 | 2 | 0 | 通过 |
| casualty-emergency-blocked | 9 | 3 | 9 | 0 | 通过 |

本地代码在整轮运行期间保持稳定。每场实际 HTTP 模块 SHA256 与测试 SHA256 均保存在 report.json；各场完整注入事件、21人名册、回舱/兜底转变和路径状态保存在同名 JSON。

三人阵亡和三人轻伤均调用 applyVanguardHit 注入箭伤。受阻场景每次更新前把 uid8 固定在远处，这是明确的故障注入，不能当成障碍寻路验证。紧急场景移动实际机队根，让原 fleetLeftStation 判断转入撤离，不直接写 phase。
