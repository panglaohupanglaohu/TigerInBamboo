# 湖沼局部地面：独立审查

2026-09-09。Qwen/LLaDA 保持暂停；此次只审查 Web 湖沼碰撞补丁，没有改运行时代码，也没有构建或重跑完整世界。

最终简化浏览器 fixture **38 项通过**。证据：[fixture-review.json](fixture-review.json)。工具：`tools/pipeline/test_swamp_ground_review.mjs`。测试运行期间四个受审运行时文件哈希未变，哈希保存在报告中。

## 发现并已由主代理修复的问题

- **平台切向推出后，地面半径缓存失效。** `collision.js` 原先在平台处理前查询局部地面，平台随后改变玩家的角向位置，最终贴地仍使用旧位置半径。独立斜底/平台 fixture 重现玩家被标记为已着地，但脚底比当前位置实际地面高 **0.26010 世界单位**。当前最终地面分支重新按最终 `pos` 查询；同一 fixture 现在在距地面约 0.2099 时保持 `onGround=false`，允许继续下落。额外验证了平台把玩家从局部范围外推入、以及从局部推到外部，两种边界方向均通过。
- **地面采样不应依赖虎角色生命周期。** 当前 `main.js` 已使用独立的地面 zone 缓存，并验证其完整祖先链是否仍属于活动 `scene`。直接执行这两个小型缓存函数的 fixture 确认：删除虎保留地面；删除整个 wrapper 后不再使用旧采样器；物理子步只查询缓存，不重新遍历场景。

## 审查结论

- 采样限制为 zone 局部水平半径 42、局部高度 −20 至 120；当前坑壁、湖底及入口石阶包含于该范围。坑外、超出高度范围、对跖点均返回 `null`；碰撞分支回退与无局部采样器时一致。
- 射线沿世界径向重力，由世界坐标变换到各网格局部坐标求交，再转回世界半径。普通缩放、任意球面旋转、非均匀缩放三种小 fixture 均与 Three.js 原生射线结果一致，误差小于 1e-6；不会修改传入的玩家位置。
- 只查询显式传入的坑壁、8 级石阶、湖底，总计 256 个三角形。不会递归遍历网格子对象；独立高处装饰和模拟描边子网格均未成为地面。没有把树冠、水面或其它装饰注册为通用地形。
- 1,000 次采样平均约 **0.0146 ms**，p95 约 **0.10 ms**；该浏览器计时粒度约 0.1 ms，不能把中位数显示的 0 当作零成本。这是 256 三角形小 fixture 的测量，不是完整世界帧率承诺。
- 局部 fixture 中，通用表面原会将玩家推到半径 161.43；局部覆盖停留在实际几何半径 146.63000001。这里只证明局部覆盖行为正确，真实世界路线/对白证据仍由主代理的独立报告负责。

当前受审范围未发现剩余阻断缺陷。没有扩大为全局地形重构，也没有据此宣称完整游戏验收。
