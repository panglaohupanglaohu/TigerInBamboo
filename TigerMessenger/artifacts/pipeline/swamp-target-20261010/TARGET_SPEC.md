# 湖沼目标图规格（美术总监，2026-10-10）

## 底稿
- 5 个固定机位：入口、坑缘步道、中岸、湖心（下岸看湖心）、虎台阶，见 `stations.js`。
- 每个机位在正式游戏里渲染四张：成片、语义图、深度图、信使剪影。
- 目标图 `targets/target-<机位>.png` 由 `swamp_target.py` 从当前真实成片生成：构图、物体、镜头都用真实画面，只按下面的规则重画。
- 左右对照见 `target-<机位>-pair.png`，左边是现状，右边是目标。

## 目标规则（莫比斯平涂）
1. **清掉残留**：湖沼空间里的旧城物件不该出现；镜头前 10 米内的外部物体也不该出现（入口机位左侧的深绿色大斜面就是这类）。
2. **平涂色块**：每类表面只用 2–4 个色板色调，按光影分块，不用细碎渐变。色板取自游戏现用的湖沼色板 GREG_LAKE_PALETTE。

   | 类 | 色调（深 → 浅） |
   |---|---|
   | 水 | #6f9794 #86b4b8 #9ec8cc，保留水下可见的东西 |
   | 叶 | #5f8783 #82a89e #a6c39a #c9d6bd，每簇叶子各取一个色调，受光的上表面再亮一档 |
   | 路 | #d98d86 #e9a18f #f1e8ce |
   | 壁 | #67647c #777388 #8d8a9c |
   | 干 | #a37c87 #bd929e #cfa9b2 |
3. **远近**：14 米以外逐渐加一层月夜空气色 #a8bac6，最多 40%。
4. **墨线**：区域交界画 #514b64 墨线，近处约 2 像素，20 米以外变细，65 米以外淡出。
5. **让路**：挡在信使身前、以及贴在镜头前 4 米内的叶子和树干，都变成半透明的淡色。

## 评分 `swamp_score.py`（每个机位 0–100）
| 项 | 权重 | 含义 |
|---|---|---|
| legacy | 0.2 | 旧残留和近处外部物体占的画面比例，越少越好 |
| courier | 0.2 | 信使可见比例 |
| palette | 0.2 | 各类表面落在色板色调里的比例 |
| foliage_tone | 0.1 | 叶子明度是否有深浅变化 |
| occlusion | 0.1 | 信使周围被叶子、树干遮住的比例 |
| feet | 0.1 | 信使脚下能看到可走的路或水 |
| path_vs_wall | 0.1 | 路是否比墙明显更亮 |

评分只用来跟踪问题，最终以目标图对照和人眼判断为准。
