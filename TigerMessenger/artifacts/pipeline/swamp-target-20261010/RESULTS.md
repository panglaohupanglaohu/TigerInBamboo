## r1–r2 改动
- **悬空旧城清理**（`clearSwampAirspace`，`src/world/swampCavityClearance.js`）：湖沼外圈上空的旧城物件，若最低点比正下方地表高 3 以上，就整件隐藏。共 21 件，包括用户 00:53 截图里的深绿色绿丘平台，以及晶体塔底座、晶体装饰、透明穹顶。`?swampAirspaceClear=0` 关闭。
- **镜头第二步：遮挡物让路**（`src/world/swampOcclusionFade.js`）：
  - 湖沼里约 1000 个植物/树干材质（含树干、树冠的墨线外壳）加了视线胶囊抖动；
  - 树干不再把镜头往前拉（`swampCameraOcclusion.js`）；
  - `?swampCamFade=0` 关闭。
- **可走面墨线**（`src/world/swampTargetPass.js`）：坑缘步道、三层岸台与坡、虎台阶、码头等 11 个可走面加了屏幕宽度恒定的外轮廓（1.4 px）。`?swampTargetPass=0` 关闭。
- **叶色**：非扇叶植物的"浅叶"色调从 #99bbaa（和普通叶同色）改成 #b2cdb5。
- **镜头避让地形**：入口处镜头在信使身后、悬在峡谷坡上方，会被左侧地表坡面挡住。镜头位于步道外缘以外时，按两侧和后方的地表高度把镜头抬高。
- **出过的问题**：
  - 一个树皮材质被克隆后注入了两次，着色器编译失败，树干变成深灰紫色。已改成只注入一次。
  - r2 第一次在坑缘也抬了镜头，信使变得太小（坑缘 63.7 分）。已限制为只在镜头悬在步道外时才抬。

## r3–r4
- **镜头前的叶子**：镜头前 3.6 world 以内的叶子、树干也会抖动让路（坑缘机位右下那片大扇叶）。
- **林下扇叶、蕨的颜色**：每丛亮度范围从 .92–1.02 拉开到 .78–1.12，并加一点冷暖偏差（`swampCoralUnderstory.js`）。
- **入口镜头**：
  - 抬镜头只在镜头悬在步道外缘以外时生效；
  - 镜头向较低的一侧偏转（最多 26°，转速仍受每秒 30° 限制），避开左侧坡面；
  - 坡面占画面比例从 22% 降到 15%。
- **墨线**：
  - 天然崖石、坑壁也加了外轮廓；
  - 原有树干、树冠的墨线从 0.85 px 加粗到 1.2 px。
- **评分修正**：
  - 遮挡只统计信使前方（按深度）的叶子和树干；
  - 新增"墨线"项：区域交界处有没有深色线，权重 0.1。
- **分数**（新评分口径重算）：r0 平均 86.5 → r4 平均 88.7。

  | 入口 | 71.6 | 74.3 |

## r5
- **月夜空气层次**（`src/world/swampAirHaze.js`）：湖沼 1356 个材质随视距混入空气色 #a8bac6，14 world 以内不变，60 world 处最多 35%。`?swampHaze=0` 关闭。
- **湖沼边缘地表改色**（`swampCavityClearance.js`）：步道外缘以外 6–16 inner 单位内的旧地表（入口左侧的绿坡等）渐变为湖沼岩石色，湖沼边缘读起来是一整块。
- **评分**：已经改成岩石色的近处外部地表，不再算作闯入物。
- **分数**：r0 86.5 → r4 88.7 → r5 91.9；入口从 74.3 升到 91.1。

## r6
- **海面外壳**：湖沼外 72 inner 单位以内、rim 高度以上的海面外壳不再画出（`swampCavityClearance.js` 的 ShaderMaterial 分支）。
- **镜头贴脸的叶子**：离镜头 2.4–3.6 world 以内的叶子从"抖动透明"改成"完全不画"，避免近处一团橄榄色噪点（`swampOcclusionFade.js`）。
- **分数**：平均 90.9（r5 91.9）。
  - 中岸叶子占比从 19% 降到 3%，叶子明暗项因样本太少降到 61。
  - 坑缘的闯入物比例反而升到 2.2%：去掉海面外壳后，坑缘外下方 23 单位处的水晶城海面露了出来（inner y≈17、r≈55，离镜头 20 world）。留到 r7 处理。

## r7
- **坑缘外的水晶城海面**：海面类着色器在湖沼 72 单位内的剪除范围往下延到 inner y 8（坑外侧），坑缘外下方不再露出水晶城的海。
- **远处岩壁**：空气层次对坑壁、崖石只混一半（`swampAirHaze.js` v2），让远处岩壁比步道暗一档。
- **墨线外壳加粗**：步道、岩壁外壳从 1.4 加到 1.7（效果几乎看不出来，见 r8）。
- **评分修正**：深度图里给镜头让路的叶子也按游戏里同样的规则丢片元。之前深度图里那片叶子还在、语义图里已经让开，坑缘被误判出 2% 的"近处外部物体"。r5/r6 的坑缘分数因此偏低。
- **分数**：入口 92.1，坑缘 90.8，中岸 91.7，湖心 95.2，虎台阶 95.5，平均 93.1。
- **还差的**：墨线项五个机位都只有 67–84。放大看，步道和浮板贴着水面，外壳描线落在水面以下被挡住，画面里几乎没有线。r8 改用屏幕空间描线。

## r8
- **屏幕空间墨线**（`src/world/swampInkPost.js`，`?swampInk=0` 关闭）：
  - 湖沼镜头生效时，整帧先画进一张带深度的离屏图（4×MSAA，8 位 sRGB），再找深度倒数的拉普拉斯，在近侧轮廓和折角描 #4a4560 的线，线宽约 2 px，28–80 world 之间逐渐变淡。
  - 步道、浮板贴着水面的边、树干、荷叶、信使现在都有墨线。
  - 给镜头让路的抖动叶片带 alpha=0 标记，墨线绕开它们，不会满屏墨点（`swampOcclusionFade.js` v2）。
  - 离开湖沼镜头（骑乘、第一人称、湖沼外）直接渲染，跟原来完全一样。
  - 1024×768 下每帧 13.8 ms → 13.9 ms（含 gl.finish，隐藏窗格里测的）。
- **分数**：入口 96.5，坑缘 96.2，中岸 97.6，湖心 97.5，虎台阶 97.6，平均 97.1。
  - 对比：r0 86.5 → r5 91.9 → r7 93.1 → r8 97.1。
  - 墨线项全部到 90–100。墨线压暗的像素也抬高了"叶子明暗"项，这部分是附带效果，不全是叶子本身变好。
- **与目标图仍有差距**：
  - 目标图里坑壁是偏紫的 #777388。游戏里坑壁是 Greg 定的风化灰青（调色板里的 #6e9193 / #778e90 也是认可色），这次没改。
  - 目标图的步道是"珊瑚边 + 米色芯"两色，游戏里是米色木板加深色板缝。
  - 目标图描线更粗，岩壁内部也有折线；游戏只描轮廓和明显折角。
