# 战船划桨同步参数研究（未更新模型）

本轮只读加载现有候选，在内存改参数。原源 .blend、源快照、候选 .blend/GLB、harbor.js 的 SHA-256 均未变化。无大模型导出、无 Godot 复制、无前台操作。

原每桨 phase = index × 0.22 + (右舷 ? 0.11 : 0)。研究方案为同舷 phase = (右舷 ? 0.11 : 0)，13 桨同步。必须同时改变 oar phase 和对应 rower phase，真实手继续通过原保留上臂节点与新增前臂/手求解到实际柄点。不能只旋桨、保留旧桨手拍子。

原 Web 运动公式复现误差最大 2.682209e-7。421 原启停与匀速周期姿态：0.22 步长138次相邻交叉；0.11、0.055、0均0。选0得到同舷严格平行的同拍运动，保留左右舷小相位差以及摆幅、入水角、回桨角和速度时间规律。

追加901姿态：原181启停 + 四档速度各180相位（完整周期），所有原相邻桨杆/叶、桨柄对26身体、桨对甲板舷缘、腿对甲板和固定/折叠座板的真实三角边/面交叉均0。52手 × 901 = 46,852柄点约束；最大误差1.712013e-7。测试没有删除或放宽旧碰撞判据。

oar-sync-trajectories.html 为轻量交互中心轨迹示意，显示第12/13桨同一时刻的差异；oar-sync-study.json 含数值轨迹、完整计数与输入哈希。中心线图不替代实际厚度三角网格判定。

现有已导出的 warship-battle-v1 仍旧候选，readyForBattle:false，不因本研究自动解锁。下一次在空间足够时，将候选相位合同落实到构建/实际调用，再保存回读及检查麻醉/战损状态。25人上下船、实例恢复与舰队性能仍后续。此离散采样不是连续时间证明。
