# 信使追加迭代：面部与侧身翻墙

本轮先修改二维目标，再生成、检查三维候选。原游戏本轮没有换入这些头部和动作；上一轮已接入的斗篷垂坠与飞艇 F 键修复继续保留。

## 新目标

- `references/face-details-v2.png`：删除孤立的鼻孔底视特写，改为鼻根、鼻梁侧面与面部连续曲面的说明。没有要求删除人物正常的鼻部解剖结构。
- `references/side-vault-v2.png`：单手支撑、身体侧转、双腿从身体一侧越墙。动作实现统一固定角色右手支撑，图上遮挡可能造成的左右歧义不作为换手指令。
- 原头部多视图继续约束人物身份、颧部和下颌，不重新换脸。

## 头部新增五轮

每轮均保存 Blender、GLB、Web 几何及正面/侧面/四分之三/顶视渲染。面庞、五官、侧视各核对五次；是五套模型版本、十五项主要检查，不把截图数当建模轮数。

| 轮次 | 修改重点 | 面庞、五官、侧视检查 |
|---|---|---|
| 4 | 删除独立鼻子、鼻翼球和鼻孔小块；鼻部并入面部曲面 | 鼻根连续性、鼻梁宽度、侧面投影 |
| 5 | 高颧部转折、颊部收束、下颌宽度 | 颧颊衔接、面中与鼻部关系、侧面轮廓 |
| 6 | 眼窝、较窄的眼睑开口；缩短鼻部突出量 | 眼鼻关系、眉眼表情、鼻额过渡 |
| 7 | 收紧下颌与下唇轮廓、调整颏部 | 尖而不针状的下巴、唇部厚度、唇颏关系 |
| 8 | 鼻部最终投影、颌颈接缝与肤色 | 鼻梁不呈管状、颈部不从下颌两侧顶出、最终三视检查 |

当前仍是低多边形风格的候选，发束与皮肤细节没有达到二维插画的细腻程度；不是“完全复刻”的验收声明。

## 动作新增轮次

走、跑、跳新增第3、4轮。第3轮重排摆臂相位、跑步屈肘、跳跃蓄力与挥臂；第4轮增加脚掌滚动、头部稳定及腾空/落地时序。每个动作两段独立录像。

侧身翻墙新增第3—7轮：

1. 第3轮：新增骨盆转动层与三维腿部解算，从正面双手翻越改为单手侧身越墙。
2. 第4轮：固定右掌支撑点，调整接近支撑点的轨迹，消除第3轮抽样中的墙体穿插。
3. 第5轮：扩大髋部侧转、分开双脚着地时序。
4. 第6轮：斗篷与衣摆配合侧向动作，调整与墙面的避让。
5. 第7轮：加强头部反向稳定、空闲手臂的配重与屈肘变化。

检查墙高1.05米、厚0.24米、宽3米，避免让双脚绕过短墙端部冒充越墙。

## 文件与回放

`assets/models/optimized/human-courier-production-v2/head-4` 至 `head-8`：头部候选。

`animation-round-3`、`animation-round-4`：各轮走、跑、跳和侧身翻墙。

`animation-round-5`、`animation-round-6`：仅对应侧身翻墙。

`animation-round-7/courier-animated.blend`：最终组合，走/跑/跳使用第4轮，侧身翻墙使用第7轮。它们的轮次在采样文件 `actualRound` 中明确记录；组合打包没有增加走跑跳的迭代计数。

全部采用24 fps对象关节动画与布料形态键；在 Blender 时间轴按空格回放。最终组合的片段为走1–27、跑28–44、跳45–74、侧身翻墙75–115。

## 验证范围

`verification.json` 保存每个动作的关节解算、落地脚底、右掌支撑、墙体顶点抽样结果。最新候选的这些项目在浮点容差内通过；这是针对测试墙的离散检查，不是完整连续碰撞系统，也不代表所有配饰都无穿插。

每轮 Blender 烘焙检查局部关节位置及实际求值后的布料顶点，误差须小于0.1毫米；实际误差在该轮 `clips.json`。预览、截图和录像来自三维候选，不是生图伪装的实景。

尚未接入游戏的角色控制器、翻墙探测、连贯动作切换或 Godot AnimationTree。布料是可重复变形与避让，尚不是实时布料物理。完整游戏接入需要单独验证角色尺寸、速度、触发和旧任务持信接口。
