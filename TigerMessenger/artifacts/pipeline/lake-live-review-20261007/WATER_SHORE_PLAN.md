## 最终碗壁公式及为何仍需三角截面

`swampV2Art.js:246–258` 创建最终壁。每个原柱顶点的局部绝对高度Y、角度θ：

```
baseR(Y) = 13 + .7*(Y-10)
rVertex(θ,Y) = baseR(Y) + .8*sin(9θ) + .45*sin(17θ + .23*(Y-25))
p = [rVertex*cosθ, Y, rVertex*sinθ]
```

三角按 centroid angle 与 .5 的环绕差小于 .25 被省去，入口不是无限精细的理想扇区。上述正弦只定义采样顶点；渲染面在三角内线性插值。**新水岸应切实际最终壁，不要拿正弦连续曲线近似而再次悬缝。**

## 故事航线核对：不能全盘缩成r23.5

真实工厂运行 `inner.update(.2,t,{})`，t0–120共601次，船/鲸身份、原动画均保持：

- 出航战船26秒循环（泊9/航11/淡出6）：可见中心半径16→30.7，Y24.9700→26.2767。
- 护航鲸可见中心半径12.4347→33.5557，Y24.12→26.6；最后一段本来便跃起/消失，可越过原r33边缘，不能说全身始终由旧水盘覆盖。
- 成鲸椭圆中心[-2,-5]，rx9/rz7；实测中心最大r13.0137。幼鲸rx11.5/rz9，中心最大r15.2870；均在主要盆内。
- 超过碗壁水位半径的船/护航鲸中心位于既有入口缺口，未测得它们的中心越过有墙方向。**这只是中心轨迹验证，尚非桨、船体或鲸全身扫掠净空证明。**

因此缩小完整圆盘会把原出口剧情截到干岸上。保留缺口方向原r33水舌，同时只裁有墙方向，是不改故事的最小修复。

## 可直接实施的最小算法

新增局部 helper（建议 `swampWaterShore.js`），在 `applySwampV2Art` 最终碗壁生成完成后、Greg视觉前调用。只拥有 waterline/其边缘附件/volume 新几何；保留位置、材质、uniform钩子、角色与 update。不要改整体坑形、三层步道、船/鲸轨迹或碰撞采样。

1. **取实际Y=25交线。** 将最终壁geometry三角顶点用 `inverse(inner.matrixWorld)*wall.matrixWorld` 变至inner。对三角边A/B，以 `t=(25-A.y)/(B.y-A.y)` 插值交点；共面边去重、端点以1e-5局部容差焊接。提取有墙的一条开放截线，而不是把入口两端直接短接成整圆。
2. **水盘边界保留原出口。** 沿截线走全部有墙边界，入口处沿原水盘r33的实际48边多边形外弧连接两端（由两端射线与旧盘边相交）；两条接边沿入口侧边方向。这样边界为“主盆＋原出口水舌”，没有在入口额外造墙。以XZ原点作fan三角化，验证+Y朝向；若多截线/非星形则返回明确失败，保留旧水，不用猜测圆形替代。
3. **数学表达：** 对有墙方向 `Rwater(θ)=min(RoldDisk(θ),RwallTriangleSection(θ,25))`；对真实开口方向 `Rwater(θ)=RoldDisk(θ)`。这里`RoldDisk`为48边多边形边的射线距离，不是所有方向都33。几何交线端点全部保留，避免采样扇面跨过壁凸折点。禁止只用48个原水顶点缩放，除非加入所有截线断点。
4. **同时退役旧全圆附件。** 水面原outline仍绑定旧圆几何，应同步替换或移除；旧r33亮线与31.8–33.4光环必须改成实际岸段，不能留作漂浮假岸。只沿真实有墙截线放低对比湿岸线/窄条，入口两条径向连接段与水舌外端不画封闭海岸亮圈。
5. **水体侧壳跟随同一截面。** 保留y10–25高度。每个旧volume纵层Y，与实际壁取截面：`Rvolume(θ,Y)=min(RoldVolume(θ,Y),Rwall(θ,Y)-.04)`；开口方向仍用旧volume。取截线断点与原32边角的并集做每层闭环，统一角序三角拼接。Y10边界取真实边环/边界交点，不能把射线miss当开口。新侧壳最多缩小，不扩到新区域。`.04`为本项目局部内退候选（world .02），CPU查水体不穿壁、GPU查无可见亮缝后定。
6. **湖底原封不动。** 本批仅修水面/水侧壳越壁，湖底承托已注册，随意缩床会改玩家可达范围；旧底r13.5少量入壁可留待独立底部检查。

原泊位与出航曲线的精确表达可原样保留：k≤1时q=k²(3−2k)，θ=1.1−.8q,r=16+6q；淡出u∈[0,1]时θ=.3+.05u,r=22+9u,Y=25.02+1.3u。水裁切模块不得修改这些值。

## 上线前硬检查

- 默认实际工厂必须参与，不只测试理想锥。检查1440方向水岸，所有有墙方向水面最外缘到截线误差≤1e-4局部；开口保留原盘边≤1e-4；水位仍25、inner平移−40及scale .5不变。
- Y10/10.4/12/15/20/25分层检查volume不越最终壁；记录真实入口边界，不把恰好三角边射线漏点扩成水舌。
- 对船B完整26秒以≤.05秒、鲸至少一个各自周期采中心及真实可见船体/桨/鲸几何扫掠。原本在旧水盘内且不处于壁实体内的水依赖包络，修改后仍有水；已有穿壁/出水部分如实单列，不可改动画绕过。
- 可用具体测试点：Y25、r30、θ=0/1/2/3/4/5应被水几何排除；Y25、r30、θ=.32应保留；Y25、r20、同六角应保留。成鲸、幼鲸椭圆中心全保留。出口水舌外r33.5不得凭修水被无授权扩大。
- 验收入口俯视、三层岸边、湖底仰视与出航镜头，日/夜至少各一；看不到原r33绕墙一圈的亮线或water-volume穿岸。无需重建全湖或改全局海壳。
