# 高山圣城山势重构 · 2026-09-29

用户要求在十二门徒完成后改高山圣城山型地势。沿用已认可城市与交通布局、材质色彩；顾问负责几何方案及实现，主代理负责集成、实景判断与保护检查。

## 实现

- 旧城后方保留主峰，使用宽主脊、低鞍部及衰减支脉组织山肩。依据实际屏幕射线定位三处主山体尖部，降低次级峰，避免全部山头等高。
- 新城背景保持水平范围，修改脊线与横向肩坡，不移动城市。
- 主地形先合并同位置顶点，再按安全距离逐步移动。原已处于建筑3米、铁路20米保护范围内的点固定；途中接近保护范围的点只移动安全部分，避免原来的整点冻结造成针尖。
- 三轮受保护高度平滑，每步不超过1.2单位；保留海岸底边及原水域拓扑。不是完整WFC地形引擎或水力侵蚀仿真。
- 最终36,679个展开顶点改变，787处采用安全部分位移；2,865个受保护点固定。主山体原始10953顶点，经过既有细分/岩面处理后更多；这些数量不是独立地形格数量。

## 验证

- 10项测试通过：幂等、有限坐标、原始源不变、固定边界、建筑/铁路保护、部分安全位移、新旧分支、山脊高低关系及已有岩面测试。
- 514个受检通道/楼梯/基础/桥面等网格，59,267个世界坐标顶点，改造前后hash相同：3924031306。这是受检集合，不宣称检查了所有动画或全部建筑实例。
- 高山圣城范围23,049次铁路探测，0碰撞；后海岸抽样0湿轨。抽样不等于连续扫掠验证。
- 212处最终种植根部无缺失承托；未重做城市原有全部装饰植物。
- 页面异常0。三个旧候选/照明警告与改造前完全相同：Master terrain source changed、Parcel layout requires frozen terrain candidate、alignReleasedLighting supports未定义。未将这些已有警告隐藏或记为已修复。
- 四个固定机位前后对照、关闭山间流云的轮廓检查、三处列车眼高截图。关闭的是citadel-ridge-flow-clouds，不是全局天空云层。

## 视觉复核与范围

第一候选仍有细尖峰与锯齿过渡，保存在candidate1，未当作完成。最终中湾形成连续较低山肩，旧城后峰高于中湾，右侧仍保留一座次峰。固定城基附近保留原有陡崖；未用抬海岸、改轨道或搬建筑掩盖问题。局部岩面仍为风格化网格，不是照片级山体。

没有重做整张世界地形、全部水下拓扑或城市交通系统；未进行全天候长期游玩回归。
