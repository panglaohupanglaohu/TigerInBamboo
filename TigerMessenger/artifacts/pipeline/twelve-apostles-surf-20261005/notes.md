# 十二门徒动态碎波 · 2026-10-05

原实现只提供固定白边和海面顶点位移公式。实景录制又发现 ocean uTime 全程0：messengerIsland 的 landmarks 有 planetV8，但 updateMessengerIsland 消费的 state 漏掉它。已补接，每帧更新共享海面时钟。

新增两道错开6.4秒周期的碎波前沿，在沿实际海面射线构造的0.64–0.94米宽支持带内推进、破碎、回退、消散；沿岸周期噪声首尾接合。水面径向位移、深度测试、海面polygon offset继续共用。8柱各224个泡沫三角面，不新增逐帧几何构造。形状是项目风格化着色器，不是Oskar私有算法或真实流体求解。

证据：before-zero-clock.json 是修复前完整录制的时间零；after-clock.json 为13.25秒连续采样26次、GL错误0。被视锥裁剪的泡沫不调用onBeforeRender，故离屏对象的审计时间保留上次值；镜头内5柱持续前进。dynamic-surf.webm 是实际游戏画布录制，frame-1.png / frame-4.png 为该录像原帧导出，已检查白边亮段与位置变化，远景效果克制。

shore-tests.json：8个实际种子在倾斜球面上的贴水、包络、幂等构造、资源销毁、同步时间/变换通过。不是完整碰撞扫描；岩石/铁路/通道几何未改。静态截图不能证明动画，因此交付连续录像。
