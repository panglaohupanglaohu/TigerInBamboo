方案与组长评估：`docs/greg-team/SWAMP_CAMERA_PLAN.md`。代码：`src/world/swampCameraProfile.js`，`src/main.js` 中在 `cameraRig.update` 前调用。`?swampCam=0` 关闭。

## 结果（stations-1/2.jpg）
- 坑内（中岸、湖心、虎台阶）：默认镜头 7.5 被树干/岩壁拉到约 2 米，贴着信使背后、看不到脚下；湖沼镜头抬高后不再被拉近，脚下台阶、湖面、白鲸、浮叶都进画。
- 坑缘步道：默认镜头被扇叶树冠挡住大半；湖沼镜头近而清楚，但右侧仍有一片扇叶——需第二步（遮挡物半透明）。
- 坑缘 1.6 弧度处信使身后正好有棵大树，两种镜头都被拉到约 2.7 米——同样要第二步。
- 入口左侧的深绿色大斜面是旧城“绿丘平台”残留（用户 00:53 截图里那块），待清理。
