# Greg 湖沼八小时实现 → 正式游戏（2026-10-09 早）

用户要求：除信使、老虎的模型外，把 Greg 团队八小时的湖沼实现全部放进真实场景，不要再靠实验链接。

## 查到的情况
- 湖沼工厂本身（花船/长船活动、鲸、喂鲸黑娃、维修猴、老树/崖壁/植被、三层岸台、码头、坑缘环、虎的巡视/下阶饮水/返岸步态）在正式游戏里与检查页同一套代码、同一批对象，且全部默认开启（只有 `=0` 的关闭开关，没有需要打开的实验开关）。逐类对象清点：两边只差 18 根被铁路桥净空裁掉的坑缘根须和运行中的动态物。
- 正式游戏看起来不一样，是因为旧场景压在湖沼坑里：水晶城 V7 旧岸线（花园灌木 13、柏树 7、码头石与拱 30+、系缆桩 11、岛阶、塔基、旧环湖步道）、城市绿丘/台地、城市湖面、行星表面地形和弧形海面穿过湖沼空腔，在坑里形成墙、天花板和一层蓝色海面。

## 改动
- 新 `src/world/swampCavityClearance.js`，在 `src/main.js` 启动时执行（`?swampCavityClear=0` 可关）：
  - 完全落在湖沼空腔（坑内 + 坑缘步道及其上方天空柱）里的旧网格：隐藏并移出渲染层（92 个），实例网格隐藏坑内实例（20 个）；
  - 只有一部分落入的大网格（行星地表、海面、旧岸堤、城市地形等 9 个）：不改几何，着色器里只丢弃空腔内的像素；被别的系统换掉材质时自动补上；
  - 旧 V7 岸线地面采样在空腔内不再生效（原来坑缘外沿下有一层看不见的 143 高度地面）。
- 新 `src/world/swampWalkwaySteer.js`（`?swampSteer=0` 可关）：坑缘环形步道上，前进方向接近步道时速度沿步道走并轻轻回到中线，像航线一样不偏；明显朝内/朝外（下台阶、出坑）时不干预。
- 母塔港护栏（同一护栏模块）：下船后码头、连接板、升降台、上层步道边缘不再掉下去；升降台不在时不会走进空井。
- 信使 v2 已是默认（`?courier=classic` 回原信使）。
