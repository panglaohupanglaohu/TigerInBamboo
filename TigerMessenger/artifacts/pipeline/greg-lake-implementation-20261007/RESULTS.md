## 目标与真实改变

- 目标图：`../greg-lake-approved-coral-flower-20261007/01-overview-final.png` 至 `04-lower-final.png`，由真实场景截图约束布局，保留世界树水下根、深坑、三岸、原阶、大船和原故事角色。
- 色板：墨线 #514b64，水 #9ec8cc，深水 #6f9794，珊瑚岩面 #e9a18f，岩壁 #777388，藕色树干 #bd929e，鼠尾草叶 #99bbaa，暖象牙路面 #f1e8ce。是本项目设计选择，非 Sable 作者原参数。
- 闭合实体坑缘接入正式玩家和虎的地面采样；修复 V7 旧环岸优先级把玩家吸低约 2.365 world 的问题。水面以下仍选原低层，不把下层玩家抬到坑缘。
- 保留三岸高度 34.8 / 30.8 / 26.8 inner、2 world 净宽及原入口；修正共享法线导致的踏面三角色斑。
- 宽扇冠经历薄片、过厚、减薄三轮实际画面检查；最终 373 实例、10 draws、76,092 三角，保持原枝端和包络，隐藏旧碎球冠可回退。
- 鲸鱼连续圆身、小侧眼、圆鳍；花舟薄壁、八瓣边、细脉，每舟恰好两名黑色调皮男娃、浅色蓬松头发与完整四肢。粉色尖芯保留为植物花芯，撑杆/水下茎和动画关系保留。
- 自然崖壁经过三轮 GPU 复查：去掉重复盆状悬台，改为六处连续岩脊、长斜岩肩，蕨叶/藤根从裂缝生长。新岩壁层为 3 个绘制批次；原剧情植物保留。
- 老虎沿原入口向湖心下行，最低踏级连接内湖水面；回岸时最高踏级与实体坑缘接上。最高阶的灯与蕨叶移出巡游带，短侧墙降到脚掌以下。
- 修船小平台移至实际岸边，增加桩和短登船桥；大船、划桨人、修船猴与出航船身份保留。平台尚未与三岸主路形成陆上连接。
- 荧光雀、长尾猴、蜥蜴重塑后保留数量与故事接口；11 个普通猴栖点收拢到真实树干附近，枝长 4.07–5.89 local，原 Vector3 和每只栖点数保留；修船猴不搬。最大落点移动 23.55 local，属于本轮明确的支撑修正。
- 两岸蜥往返避开入口，湖底蜥贴实际湖底；送水蜥保留。落叶/漂叶去掉矩形墨壳，保留随机序列和原运动。
- 普通大光晕与光柱降幅，剧情信号保留。

## 边界

目标图的手绘细腻度高于当前程序化实景；没有宣称逐像素复现。世界树和岩壁仍简化；正式全场实测约 8–14 FPS，仍慢，且没有改前同机位基准，未宣称性能验收通过。桥面高度和路线保留；新增拱附近 5 片新叶转向、2 片新叶可恢复修剪，旧植物/枝条不动；并未重构全城。新城后方喷泉约束已保留在后续新城任务，本轮未扩展新城改造。
