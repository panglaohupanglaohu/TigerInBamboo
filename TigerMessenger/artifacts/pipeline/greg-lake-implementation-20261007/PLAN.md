# 湖沼珊瑚重构 · 三小时工作窗口

按用户最后批准的碗状实际湖沼总览施工。Greg team 是研究与制作智能体团队，非创作者本人。目标图与实景截图分别存放，不能互相替代验收。

## 小时计划

| 时段 | 工作与交付 |
|---|---|
| 0–0.5 h | 完成总览及上、中、下岸目标图；固化花舟、鲸、码头、动物、虎的修正 |
| 0.5–1.5 h | 并行改语义配色、动物与花舟、靠岸码头；原剧情与随机种子回归 |
| 1.5–2.5 h | 同机位实景迭代：实体坑缘承托、扇叶冠、猴栖木、微光与水面可读性 |
| 2.5–3 h | 近景和完整游戏检查；修正新问题；记录代码、截图、测试及尚未通过项 |

这是安排窗口，不把未实际耗用的小时写成工时；每轮按证据推进。

## 验收要求

- 真实碗壁、中央树下水根、原大船、入口与三层岸不被幻想布局替换。
- 虎原巡岸/下阶/饮水/迎客、猴修桅、蜥蜴送水、船出航和鲸护航保留。
- 码头固定实岸，有支柱和登船短桥。暂未接通主步道，不能写成已贯通。
- CPU仅证明几何/引用/动态契约；GPU截图才能证明视觉。完整球面游戏另验。
- 修改前源文件保存在 before/；预览提供本批改前/当前实景与动物近景。
