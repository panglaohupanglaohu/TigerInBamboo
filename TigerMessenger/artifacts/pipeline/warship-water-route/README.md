## 发现的具体矛盾

实际 `planet-surface` 是存在的网格，北极及正负 X 赤道实测半径 160；`planet-v8-curved-ocean` 水面 160.5。另一采样方向水面 160.437085、原星面 159.935415，深度 0.50167 米。并不是可随意忽略的“空水面”。

先按静态 v6 bounds 最低 Y=-.53966、船尺度 1.7、候选根位置在真实水面下 .25 米，估算需要约 1.17 米水深。最终用实际 Web v6 网格进一步测了四个保存姿态：

| 保存帧 | 实际 local minY | 所需水深（米） | 实际网格结果 |
|---|---:|---:|---|
| 60 | -0.30550812 | 0.769364 | 与 planet-surface 三角面相交 |
| 90 | -0.61568962 | 1.296672 | 与 planet-surface 三角面相交 |
| 119 | -0.30078280 | 0.761331 | 与 planet-surface 三角面相交 |
| 180 | -0.30605491 | 0.770293 | 与 planet-surface 三角面相交 |

第 90 帧真实运动点需要 **1.29667 米**，比早先静态估算更深。第 180 帧停桨姿态也需 .77029 米，仍超过 .5 米实际水深。四帧均检查 54,172 个实际可见船三角面，含 instanced 船桨与桨手；在北极实际地形网格处都检测到边/面相交。报告中的 `actualTriangleCrossing.point` 是参与检测的地形三角形首顶点，**不是精确接触点坐标**。

不能为通过而删掉 `planet-surface`、提高全球海面或把整船抬成浮空船。本轮均未执行这些操作。
