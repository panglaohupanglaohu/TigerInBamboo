# 信使：头部与动作候选交付

2026-09-14。本分支会话只修改独立信使候选、生成工具与检查页，没有替换主游戏或 Godot 工程。

## 以什么为准

使用 `human-courier-refinement/reference-pack-v1` 的头部多视图、五官图与动作帧图。保留原信使衣着、配饰、发型身份与已经收窄的肩部；没有另换角色。生成图里动作左右标注的缺陷，按该目录 `BLENDER_GUIDE.md` 的相位表处理。

## 三轮头部

每轮保存一份 Blender 源文件、GLB、Web 几何，以及正面、侧面、顶视、四分之三视角，共十二张实际 Blender 渲染。

| 轮次 | 面庞、五官 | 顶视、侧视 |
|---|---|---|
| 1 | 重新组织颌缘、颧部、眼鼻唇 | 核对颅骨宽深、头发体积和额鼻唇颏投影 |
| 2 | 调整颊部与下颌；增加眼睑、鼻翼、耳内结构 | 调整发束体积，检查眼窝与鼻根衔接 |
| 3 | 修正第二轮眼球外露，改为被眼睑包住的可见眼部；鼻梁并入面部曲面，增加眉毛、胡茬、耳轮 | 收紧鼻部侧面轮廓，复核头顶与后脑剪影 |

第二轮存在球形眼睛突出皮肤的问题，保留其截图作为失败证据，第三轮修正。三轮是三套几何修改，每轮检查四项，不以十二张图冒充十二次独立建模。鼻部与颌颈过渡仍需视觉验收，不能因为导出完成就认定与参考图完全一致。

## 两轮动作、衣服与斗篷

| 项目 | 第一轮 | 第二轮 |
|---|---|---|
| 走 | 双腿交替、根位移、基础摆臂 | 脚掌滚动、肩髋协调与头部稳定 |
| 跑 | 蹬伸、腾空、屈肘 | 加强前倾、肩髋协调、脚掌滚动 |
| 跳 | 蓄力、升起、收腿、着地 | 用明确弹道组织腾空，落点与缓冲同步 |
| 翻墙 | 双手支撑、收腿、越墙落地 | 固定墙顶支撑位置、手臂接近弧线、收腿与越墙高度修正 |
| 衣服 | 衣摆随原关节移动 | 躯干与腿之间分配下摆变形，保留开衩 |
| 斗篷 | 滞后波动 | 增加重力方向下垂、腿部和测试墙避让 |

八段录像与三十二张关键姿势截图来自实时检查场；不是重新生成的目标图。页面允许独立切换动作轮次与布料轮次。

## 已做检查与边界

- 第二轮四个片段按 24 fps 检查：数值有效；支撑脚底与地面、支撑手掌与墙顶的高度误差在浮点容差内。
- 抽样中的腿、靴子、前臂、手掌顶点未进入 1.05 米测试墙体。检查代码与原始数值保存在 `verification.json`；这不是连续三角形碰撞证明，也不覆盖所有附件和全部游戏地形。
- Blender 烘焙检查对比关节局部位置和实际求值后的布料顶点，误差必须小于 0.1 mm；实际结果在各轮 `clips.json`。
- 布料是确定性的关节混合与避让，不是完整物理布料；披风、卷轴与包袋还需要在实际游戏镜头和连贯动作切换中继续验收。
- 本页动作按片段循环，根位置会在循环边界复位。还没有接入移动控制器、跳跃碰撞、翻墙探测或场景存档。
- 浏览器错误记录在 `browser-check.json`。没有启动新的 Godot 实例；建模与烘焙只使用顺序启动、完成后退出的后台 Blender。
