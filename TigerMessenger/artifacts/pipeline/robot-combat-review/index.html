核心体验

玩家指挥来自三座书店工厂的机械部队。工厂生产、铁路运输、前线卸车与战斗使用同一批机器人身份；损伤、弹药和返厂维修构成循环。战争发生在莫比斯世界，但不把整个世界及其居民自动设为敌人：第一版敌方限定为明确标记的敌对机械守军，书店、游客、列车乘客和剧情角色不自动成为目标。

三台一批出厂，战场上可以组成混合小队。玩家默认用指挥视角下令；暂不做三套第一人称驾驶系统。

蝗虫：稳步推进的重型突击手

保留橄榄色双足重装、宽脚掌、分层装甲、背部设备和长枪。不会因为名字变成跳跃昆虫，也不增加飞行能力。

  • 任务：压制敌方主力、占据通道、掩护其他机器人推进。
  • 普攻：双手架起长枪，短停、瞄准、三连发、回收后坐。第一版移动时不精准射击，避免上身动作和步态互相打架。
  • 主动能力「架稳」：双脚撑开、降低重心，持续射击更稳定；架稳期间不能移动。收到撤离令先收姿再行走。
  • 弱点：腰部、膝关节和背部散热口。转身较慢，容易被侧翼包抄。
  • 损伤表现：肩甲擦伤、膝部火花、跛行、蒸汽泄漏；主枪损坏后撤退，不凭空生成替代武器。
  • 动作：待机、启动、迈步/落脚、转向、架枪、射击后坐、换弹、收枪、受击、跛行、失能。

蚂蚁：近距离破阵与掩护

保留圆铜锅炉、厚短腿、层叠肩甲、烟囱和茶杯。行走时茶杯固定在杯架，休息时才拿起。前臂炮来自先前动作目标图提案，仍需要在真实模型上制作，不能把胸部检修盖当炮口。

  • 任务：保护装卸口、突破近处守卫、为撤退队伍制造掩护。
  • 普攻：前臂短炮蓄压，发射一发低频游戏炮弹；小范围冲击，爆炸不穿墙。
  • 主动能力「排汽屏障」：释放短时白汽，切断敌方视线，也遮挡己方普通瞄准；禁止透过白汽继续自动锁定。甲壳虫的标记只保留最后已知位置。
  • 资源：锅炉压力与热量。开炮消耗压力；停火恢复；连续开火热量上升，满热时进入可见泄压冷却。
  • 弱点：行动慢、射程短；烟囱和压力管损伤使蓄压变慢。不会因为是蒸汽机器人就免疫炮火。
  • 动作：坐起/站稳、短步重踏、收杯、抬臂、蓄压、后坐、泄压、受击、失压跪停。饮茶只在安全待机触发。

甲壳虫：侦察、侧翼和护送

保留低矮圆壳、四轮独立悬挂、主镜头与顶部双管炮塔。站立对应驻车，行走对应轮式行驶，不改成人形或六足。

  • 任务：先行侦察、标记目标、追击轻型敌人、保护列车及维修队。
  • 普攻：顶部炮塔短连射；车身与炮塔分别转向。行驶中允许低精度射击，超过转角或俯仰范围时先调车身。
  • 主动能力「扫描」：扫描视线内一定范围的敌对机械，短时标记；不会穿墙揭露整张地图。
  • 弱点：轮组和传感器。单轮受损降速，双轮严重受损则停车求援；攻击重装正面效率较低。
  • 动作：驻车、起步、转向、悬挂压缩、刹车、炮塔追踪、连射、重新装填、轮组受损、停车失能。

三台出厂与货运闭环

每座工厂每完成同型号三台，组成一个有编号的批次，例如 LOC-001-A/B/C。蚂蚁与甲壳虫同理；不是三种各造一台凑一批。

1. 零件由蒸汽货船抵港，仓库收料，支线送至对应车间。

2. 组装工位按底盘/腿部 → 主体 → 装甲 → 武器/传感器 → 动作测试推进。第一版各90秒完成一台，可在演示模式加速，但默认不瞬间刷出。

3. 三台全部通过测试进入待运区；不足三台时排队，厂外守护机器人与待运产品分开，不会被装走。

4. 预订空的重型平板货位与卸货月台。每台占一个货位，批次必须有连续三个可用货位；满车时不覆盖现有机器人。

5. 火车进入广场环轨，调度至目标工厂背面的装卸股道，停车并锁定装载状态。客流在铁路外等候。

6. 按顺序吊装三台：关机固定 → 起吊 → 横移 → 落车 → 锁紧。建议每台8秒，三台约24秒；完成第三台后才能发车。列车或月台取消时释放预订，已装车机器人身份不丢失。

7. 到达指定前线卸车站后，解除固定、落地、启动、自检、编队。不能在高速行驶列车上直接投入战斗。

8. 受损机器人可撤回维修；失能机体可回收。批次总账满足：厂内 + 待装 + 在途 + 已部署 + 维修 + 损失 = 总生产数。

列车可连续装多个批次，但不能超过实际货位。现有八节混合货厢还不是合格的九台整机运输编组：第一版建议六节重型平板货厢载两批，另两节运备件；第三厂等待下一列。两列车服务三厂采用轮转优先级，避免某厂一直被跳过。

尺度约束必须先解决：机器人不能为装车临时缩成玩具。重型货厢、双线会车间距、隧道和门洞需要按现有机器人实际包围盒核验；超限则采用明确的折叠运输姿态或扩大路线净空。未通过前不声称整机物流完成。

指挥与战斗规则

  • 基本命令：移动、攻击指定目标、守住区域、护送列车、停火、撤退补给。先做单台和框选小队；技能按钮提供清楚的冷却和原因提示。
  • 混合队建议：蝗虫2台居中推进，蚂蚁1台保护前方，甲壳虫2台两翼侦察。它不是生产批次限制，部署后可自由重组。
  • 自动攻击优先级：正在攻击自己的敌人 → 玩家指定敌人 → 威胁护送对象的敌人 → 最近的可见敌人。
  • 先检查视线与射界。友军挡枪时暂停或侧移，不穿过书店、货车、队友开火；首版友伤关闭，但弹体仍被友方遮挡。
  • 目标丢失后前往最后可见位置附近搜索，超时返回原任务。不得隔墙持续锁定。
  • 默认耐久低于25%时请求撤退；玩家可开启自动撤退。弹药耗尽停止进攻并请求补给。
  • 玩家改变命令时按安全边界中断：射击后坐/吊装落车等短动作完成再转态，不瞬移或复制模型。

状态机与技术边界

生产：等待原料 → 组装 → 测试 → 三台待运 → 货位预订 → 装车 → 在途 → 卸车 → 部署。

战斗：待机 → 移动 → 搜敌 → 瞄准 → 攻击 → 冷却/换弹；任一状态可转受击、撤退或失能。

每台有唯一 robotId、型号、批次号、归属、耐久、部件状态、弹药、热量/压力、当前命令。位置归属同一时刻只能是车间、月台、货厢或战场之一。存档保留以上状态；加载中断的吊装恢复到最近安全锚点，不重造一台。

真实模型目前经过静态合并，不能直接宣称已有完整关节动画。需保留原静态模型并新增运动版本：蝗虫肩肘髋膝踝及枪械挂点；蚂蚁肩肘短腿与杯架、前臂炮；甲壳虫四组轮/悬挂及炮塔。武器口、命中体、脚底、吊装点、货厢固定点独立命名。

沿球面用局部切平面导航和径向上方向。狭窄道路、门洞、站台都按完整机器人尺寸检查；轮式机器人遵守坡度限制。远处采用低频逻辑与简化动画，初版上限建议24台活跃机器人，实际帧率测试后再提高。

建议的第一场试玩

“护送第一批三台蝗虫”：工厂生产三台 → 列车装运 → 前线站卸车 → 玩家指挥三台通过一个有掩体的机械哨卡 → 守住补给站60秒 → 将受损单位运回。之后加入蚂蚁白汽掩护和甲壳虫侦察，验证三者差异，暂不一次铺满世界大战。

验收顺序

1. 真实动作与碰撞：三型各站立/移动/射击，枪口不脱离、脚不滑、炮塔不穿壳。

2. 单台对练：命中、遮挡、换弹、热量、受击与失能完整闭环。

3. 三台生产运输：从工厂到列车到前线身份不变，连续三次批次无丢失、重复和超载。

4. 五台混编：不同职责有效，守点、护送和撤退命令可中断恢复。

5. 24台性能及存档：有明确机器与分辨率的帧率报告，保存/重载不复制库存。

已确认的首版实施边界

首版采用：指挥玩法、三台同型一批、六个整机货位、两批一车、友伤关闭、机械守军作为首批敌人。蚂蚁前臂炮、排汽屏障一并纳入实施；数值为初始平衡参数。这个页面是设计基线，不会通过页面按钮启动生产或战斗。
