## 统一比例后比较

实际船 scale=1.7，因此此前每侧 .314333 原单位净宽为世界 .534367。实际 Web 士兵 root=1、fig=2，启用当前认可装备后：

|兵种|身体盔裙世界宽|静态全装备世界宽|全装备世界高|
|---|---:|---:|---:|
|短剑|.330000|.725917|1.160212|
|长矛|.330000|.634667|1.153574|
|弓箭|.223364|.245682|1.285451|

人体宽度可容纳；短剑/长矛的战斗持械姿态不可直接当携行姿态。弓箭尺寸只代表此次静态姿态，不代表拉弓全过程。先前把未换算的 donor .322582 与船本地 .314333 直接比较不成立，以此统一世界单位比较为准。

船座 donor 部件为原 donor 的 .5 倍，乘船世界 1.7 后为 .85。与陆上 donor 本身相比小约15%，身份一致并不代表几何尺寸已一致；需要统一人员比例，避免站起时体量跳变。
