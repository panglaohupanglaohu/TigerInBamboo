# 顾问 v6 艺术指导与实图复核

已实际查看 target-v6-advisor-style.png，并与本轮已查看的v4、作者后期树/云样片及用户浅灰青海水参考比较。这里只审核目标图，不表示场景已经实现，也不代表Oskar本人意见。

艺术指导是锁定双视角城市布局、建筑造型与交通，把环境从写实碎纹转成少量可读色块：连贯灰青林冠、浅黄绿草坡、浅石灰岩与冷灰阴面、绵厚乳白云团、低饱和浅灰青海水。

**v6比v4明显接近参考。** 树冠已从细碎颗粒转为互相咬合的圆钝团簇，左右两城山坡都有连续林地色块；草地形成留白，与岩面分区更清楚；港湾不再深蓝发黑，水色与外海更统一；云团更厚、更整，城堡、高塔与桥仍可读。建筑仍保留细节，与简化环境形成重点关系。可作为下一步落地的表现目标，不需再生成一轮才能开始评估实现。

最多保留两条实施约束：

1. **植被不是贴图盖面。** 按真实可承土坡面建立林冠体积和根部；树冠内线进一步弱于外轮廓，不能把每个小叶团都描黑。草岩交界用少量不规则露土/低草衔接；陡崖、城基、阶梯和轨道须留空。图中的大林冠不能直接等比例放成遮挡城市的巨树。
2. **云、水必须通过动态与遮挡验收。** 云以山腰/远谷分布为主，保留城堡和主脊窗口，顶部大云不能在镜头移动时成为遮城的白墙；淡灰青海水沿岸保留深度层次，泡沫采用断续局部浪段，避免将图中的细白边实现成永久发亮的全岸轮廓线。静图未证明impostor稳定、云避山或浪的完整周期。

参考归属：以上树/云/岸浪参照作者2024–2025后期实验，不笼统写成Bad North原始技法。未改源码，未另行生成图片。
