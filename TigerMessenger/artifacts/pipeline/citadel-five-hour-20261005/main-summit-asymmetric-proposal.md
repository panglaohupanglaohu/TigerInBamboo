# 主峰偏心短脊：只读局部削切建议

实际查看 approved-target.png（citadel-mountain-two-hour）与r06-old-mountain-day-noCloud-plants.png，读取r07实际main探针。概念图的山体特色是宽厚、不对称的断面与肩部连接，不是等宽尖锥或统一平顶。当前旧城后主峰确实读成独立圆帽。

main区域936个探针中828命中表面。z=-41、x[-73,-69]的高帽基本都在40.5–40.8m；z=-38相同区仍为40.2–40.6m，缺少清楚的偏心脊线。拟削区x[-70,-65]、z[-44,-35]共60命中点，当前y34.953–40.714，最小结构保护距离13.599m、铁路距离91.988m。数据支持小削切实验，但不证明整片源三角或运动路径都安全。

建议只削东侧上帽，保留西侧偏心短脊：

- 保留(-75,-38)至(-72,-41)附近约39.5–40.8m自然高点及至少约4m宽度，不制造细线刀脊。
- 削切范围x[-70,-65]、z[-44,-35]，核心x[-69,-67]、z[-42,-37]减少约1.5–2.5m，最多3m。外约2m逐渐衰减，且只作用原最终表面y>35的上帽；接近35m时也须连续衰减。
- 使用倾斜断面/向东增加的削量，不把整个顶部压到同一高度。保留短脊内部原起伏，形成西高东低、顶部短脊接斜肩的轮廓。
- 只削不填；x<-78原外壁保留，z>-33或x>-63城侧低肩不进场。主峰仍应显著高于次峰，城基、建筑、通路与铁路完全不动。

先做一个可回退候选，沿用固定节点、safeY与相对基线有向面积/法线检查；实际削量被保护限制时不能以目标值当已达成。双机位应检查削切是否真正改变可见轮廓，而非只在山背留下浅坑。若出现新双峰、凹窝或刀脊即退回，不以增加尖柱或更多零碎噪声补救。本提案未改代码。
