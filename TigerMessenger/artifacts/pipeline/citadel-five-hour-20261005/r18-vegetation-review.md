# r18 / turf6 独立视觉对照

通过图像查看工具实际检查 r16 与 r18 的 `left-terrace-day-noCloud-plants.png`、`bay-ridge-day-noCloud-plants.png`，共四图。

**结论：拒绝 turf6，保留 turf5。本次不继续候选7。**

近景中，r18 大草头下缘的确更圆，但下方草尾中间出现横向断口，留下醒目的箭头形、尖角形绿色残片；右侧斜向长三角尾仍然存在。局部圆润改善没有抵消草斑关系变碎的问题。中湾尺度未见足够明确的净视觉收益。

沿用植被专项 25 分尺度：turf5 约 **16/25**，turf6 约 **15/25**。这不是整场景总分，不把数学承托通过、面积减少或实现成本算作美术提升。

离线少了约 8.9m² 草面不构成接受理由。候选6的全量检查仍可作为技术证据保留，但即使通过也不改变本次视觉否决。此评阅未修改参数或源码。
