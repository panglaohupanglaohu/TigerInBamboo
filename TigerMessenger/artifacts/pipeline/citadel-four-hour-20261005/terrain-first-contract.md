# 目标图三阶段合同（2026-10-05 最新用户顺序）

统一目标：../citadel-architecture-target-20261005/target-v3-landmarks.png。
最终整体对照评分严格大于95；当前不报达标分。用户允许重塑旧山、重排建筑、最后铺轨。原版与用户存档不覆盖。

1. 山体：先对应机位裸山。左前2–3级宽台，短崖分隔；左主峰、中央厚肩和鞍部、右新城低后肩连续。草地必须依真实台面；平台输出ID与范围，不能用草色掩饰坡面。
2. 建筑：绑定已验山体版本，先体量落位再彩墙橙顶小白窗模块，保留细高塔、蓝穹顶、雕塑及木马身份。输出入口、广场、港口、桥端节点；验根基承托和步行连通。
3. 交通：按节点与目标环湾弧规划铁轨和桥；验证曲率、坡度、列车扫掠、桥墩承托与行人路线。上游形变使下游验收失效。

当前citadelTerrainFirst=1仅为默认关闭的施工候选；旧布局可隐藏作裸山对照，碰撞/玩法尚未改造成新布局，不称可玩发布。几何版本→建筑版本→路线版本应独立关联，最终迁移前分别完成验证。

首个实施：highland-ravine-wall-west源面进行三高度带台地改造，保留海脚；旧foundation/rail约束仅在terrain-first参数下移除。新城后脊不再被旧轨道切断。CPU连续性/海脚/重复执行和面翻转测试通过，GPU画面对照待本轮完成。
