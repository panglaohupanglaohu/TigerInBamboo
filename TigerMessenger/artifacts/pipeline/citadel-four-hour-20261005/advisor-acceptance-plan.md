# 四小时山体批独立验收计划

本文件只规定验收，不修改运行源码。建筑目标图不是山体目标替代，也不是此批建筑施工授权。

## 不可漂移的目标

旧城现有山形及其右侧宽山块、峰与鞍部固定；新城后肩从既有末端山脊沿后缘连续延伸，最高仅略高于蓝穹顶，不另建独立高山系。后缘衔接必须在无云视角看到岩面/草台连续，不填前湾或桥下。淡灰青水、灰青林冠与简练岩面按已选v10及用户后续纠正审阅，不从建筑目标图复制新地形。

## 取证与轮次

1. 先拍当前正式无参数基线，保存代码版本/配置、场景矩阵、相机、固定日光曝光、云/植物开关、时间和种子。禁止拿旧PNG替代本批基线。
2. 每轮保留相同相机：旧城正侧、新城正侧、新城背侧、湾中央、连接山脊近景、草岩边缘近景；另保留overview。地形先在无云状态看，再补有云，不用云遮连接缺口。
3. 几何候选先验裸山及保护，再验草/树/云最终面；色光候选单独比较，不给色彩变化增加山势分。每个结论附截图路径，未拍角度不推断通过。
4. 硬检查失败则不发布；视觉倒退则回退候选，不能因离线数据更好放行。最后至少留完整重建、无query正式配置与候选一致性、同视角截图的时间；到时不足85就报告实际分数与缺口。

## 六项固定评分（100分）

|项目|满分|实际图检查|
|---|---:|---|
|山势轮廓|30|旧山不变、新肩低缓且退居建筑背景，多个固定角度无新锥柱/纸片轮廓，主次关系明确。|
|支脉/鞍部|20|旧右脊到新后肩有可见连续连接、相接草台与起伏鞍部；不以云/树遮缝，不填水湾。|
|岩面层次|15|岩肩、坡折、海崖厚度清楚，无显著长三角折片/悬空面/细长竖褶；不靠裂纹遮几何。|
|植被|15|缓坡草面与低丛、露土、裸岩自然过渡；林冠成大色块且根部真实支持，无巨型贴皮或尖树排队；两城前后都审。|
|色光|10|浅石灰岩、灰青林地、淡灰青海水统一且层次可辨；云有体积不过曝，近远与冷暖关系清楚。|
|城市融合|10|新后肩承托而不压穹顶，城基与山坡相接自然；建筑与桥、阶梯、港口、铁路保持可读和通畅。|

由实际图逐项给理由，不用平均凑分；既有明显缺陷未改善不自动加分。**终门槛为严格大于85分（整数至少86）且所有硬检查通过**，不是保证四小时必然达到。上一批63分仅作历史背景，不转抄为本批基线分；未通过时只能称阶段结果。

## 硬检查与边界

- 固定建筑、铁路、桥/阶梯/港口可走面：对象清单、世界顶点/矩阵hash与本批基线相同；若顺序变则用稳定身份逐对象比较，不用数量一致替代。
- 旧山固定区：按基线source身份/世界坐标逐点比较；连接区不能含糊扩大到旧山。若必须修改旧山才能接续，先报告与用户约束冲突，不能偷改。
- 最终新面与保护体做面级净空/相交检查，补列车眼高及港口上城实际通路；仅顶点安全不能排除三角跨轨。
- 新旧接缝共享边无裂、无新退化翻面/非相邻三角穿插；保留原三维多层/洞口/水域开口，不能最高y单值覆盖。球面法线、mesh坐标和世界坐标有明确转换。
- 全部新根及草叶基边验证最终实际首表面，保存缺支撑/穿地列表；高度场、BVH、植被、云、光场引用相同finalSurfaceRevision，重建不双份残留。
- runtime错误为零；记录三角、draw call、构建耗时/帧时对照及新增资源生命周期。功能不崩溃不是性能通过，异常须说明。
- 最终正式无参数配置重建，几何/固定边界/植物与批准候选一致；若有差异不以旧截图代替。
