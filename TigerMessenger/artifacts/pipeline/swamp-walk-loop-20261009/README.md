# 湖沼走一圈：防掉落（2026-10-09 凌晨，Claude 接手）

用户要求：信使能在湖沼方便地走一圈，环境没有封闭，走着就会掉下去。

## 实测的原因
- 湖沼坑位于大峡谷台阶中间，坑缘（世界半径约 145.4）比周围峡谷台阶有高有低（142.9 / 151.4 / 134.3 …）。
- 坑缘内侧：坑壁是陡坡，原物理会贴着坡一路滑到湖底（最深掉 15 单位）。
- 坑缘外侧：一些方位是更低的峡谷台阶（掉 2.6–19.7 单位），另一些方位会被瞬间顶到 6 单位高的台地上。
- 虎台阶入口在坑缘上留了约 9 单位宽的缺口，只有顶阶外侧约 1 单位宽能横跨；顶阶比坑缘高 0.4，超出原地面采样 -0.35 的窗口，横跨时会掉到第二级台阶（-2.41）。

## 改动（可回退）
1. 新文件 `src/world/swampEdgeGuard.js`
   - `installSwampEntranceBridge(inner)`：在入口缺口的坑缘外半圈（半径 38.45 到坑缘外沿）补一块与坑缘同高、同配色（GREG_LAKE_PALETTE）的石板，不覆盖虎台阶顶阶，人和虎下台阶的通道不变。
   - `createSwampEdgeGuard(...)`：无形护栏，只在湖沼局部（内坐标半径 < 50）生效。规则：
     - 步道网 = 坑缘环、三层岸台与连坡、虎台阶、码头、入口石板（只算朝上的踏面，不算崖面）。
     - 在步道网上时，不允许走到比当前低 0.15 以上的非步道地面（坑壁、湖底、外沿、下层峡谷）；在网外最多下 0.7。
     - 跳跃同理：会落到非步道的低处就撤回水平位移，上升段保留弧线、下落段送回最后站立处。
     - 落点仍是步道网（例如从台地跳回坑缘、从坑缘跳到下层岸台）允许。
     - 坑缘比外侧台地低的方位（约 1.6、2.6 rad）保留原来的出坑方式（前方 1.2 单位内地面明显更高就放行）。
     - 万一已经在步道下方（读档、剧情传送），送回最近的步道安全点，并提示“已回到湖沼步道”。
2. `src/main.js`（原件备份：`source-before/main.js`）
   - 地面采样链在湖沼支持之前加入入口石板；
   - 物理子步前后调用 `swampEdgeGuard.begin/end`；
   - `__tm.swampEdgeGuard / __tm.samplePlayerLocalGround / __tm.playerSupportRadius` 供回归测试。
3. 新测试 `tests/world/swampEdgeGuard.test.mjs`（16 项，用真实湖沼几何）。

关闭开关：URL 加 `?swampEdgeGuard=0`（只关护栏；石板仍在）。未提交 Git、未发布、未改存档。

## 限制 / 未做
