# 世界球面圆弧联合候选：曲率瓶颈已消除，贴岸版因土内穿行拒绝

本轮真正更换路线构造法：大圆直行段与相切小圆弧在世界球面生成，未先画chart样条后投影。`targetSphericalShoreArcCandidate.js` 默认关闭，原生产/main/release/terrain均未改。没有改25m、4%阈值。

## 几何方法与源接头

使用已扫描三线合格的红source u=.59（蓝按现对应差、约.59258443）；比原东接头额外替换约157m原红线，不隐瞒影响扩大。返回现release新岸中部，实际接回比例保存在JSON。两端精确位置和切线由生产曲线提供。

圆弧名义半径32m，所有点直接在world球面曲线计算。径向高程由两端真实坡度的10%余弦缓入/缓出连接恒坡中段，解决原三次Hermite高程把最大坡放大的问题。伴线端点混合后单独恢复真实端坡的径向高程，不改变方向路径。圆弧连接是C1、不是曲率连续的clothoid；这项局限仍保留。

测量修正不是盲调Bezier手柄：贴岸方案前后小圆弧曾在第2腿缺1.97m切线长度；缩尾太多又在末腿缺2.64m。尾段27m后两处相切空间均满足，未缩弯曲半径。

## 最贴岸方案的真实结果

`shore-directed-32` 中间方向节点来自castle[94,64]；完整world节点、圆弧切点、逐米结果见 spherical-audit-0.59.json。

- 红线最小半径32.203m，最大坡3.282%；蓝线28.197m、3.447%。曲率与坡度通过有限采样。
- 实际闭合最终地形，1.5m站距 loaded OBB：红42、蓝33个姿态碰表面。
- 每姿态27个载货体内点，射线奇偶法独立检实体内部：红673、蓝318个点在土内。**明确不是0表面交叉就认定通过。**
- 红侵土范围x67.527..101.771,z59.021..99.107，y−37.840..−16.598；蓝x78.578..100.859,z63.860..96.119，y−37.137..−21.653。
- 这些侵土点没有一个在允许小切面x57–73/z92–95内。红29点的XZ还进入实际广场铺装polygon下方；它们在地下，不是已证撞雕像本体，但若为此开线便成广场下隧道，违背沿外崖目标。
- 实际三角海面径向采样：未浸入静态海面的点为全部；最小源端静态余量仅约5–9cm，不满足另设.3m波动余量，不能称波峰安全。

## 对照候选与效果

较外侧inshore-32两线实际地形OBB和体内点均0，半径32.189/28.163m、坡3.355/3.360%；但所测东段近干岩距离均值仅从基线约11.77m变为约11.03m，最大仍26m，显著贴岸目标未达，拒绝作为交付。这里基线用中线屋盖背边，候选暂用红线近似背边，存在约半轨间距口径差，不能夸称0.74m是真精确改善。

真正向岸的版本均值约8.78m、局部0–1m看似贴上，但实际是入土，并非成功贴崖。最前一段仍有16–27m离岸。局部小切面无法修复全段。

## 本轮不做的危险补救

不为贴岸版挖广场/城市下隧道、不扩大填海、不生成超出授权矩形的大切崖field。实际联合地形硬门已失败，所以没有让后续支墩、上步道、站点重映射套在失败路线之上；这些项目标记未验证，而非通过。

下一修正所需已可量化：必须让载货包络离开上述东南地下体积，同时保留>=27.05m中线转弯空间。当前曲率问题已经解决，不应继续修手柄；矛盾转为当前岩缘/公共平台与期望线路的空间关系。若保持实际广场及城基不变，本轮可行外侧线仍不能达到紧贴崖的视觉。需要整体重排沿岸走廊/岩缘，已超出这次1–4m小岩肩切面范围，不能默默实施。

## 测试与交付

四项纯Node测试通过：default-off/非法输入；真实32m球面转弯、端点/切线/半径不漂移；空间不足时拒绝而非缩成急弯；伴线重配径向坡保持端点和单位方向。工厂、脚本及精确数据均可重放。不操作浏览器、不安装、不自报美术分。测试通过是构造器正确，不是联合候选可发布。

### 最小影响回测补充

将伴线高程修正法回测较近source u=.602：broad-entry-30两线半径30.95/26.91m，坡3.910%/3.955%，实际地形内部点为0；可将影响控制在约126m额外原线。但它是更外侧路线，贴岸效果不足，仍不发布。其它两版blue坡约4.16%失败；没有把它们算作通过。精确结果在spherical-audit.json。
