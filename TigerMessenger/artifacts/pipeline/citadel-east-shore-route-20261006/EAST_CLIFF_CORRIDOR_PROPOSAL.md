# 新城外崖可施工走廊：只读逆向诊断

本轮不施工、不安装。推荐 **A：保留实际铺装与城基，在已求得的球面大半径走向后侧重建外立崖**。不推荐将整段轨道抬到现有坡顶，也不继续微调此前失败手柄。这里是下一轮候选施工合同，不是通过报告。

## 一个重要纠正：多边形相交不等于实际铺装相交

使用当前生产地形 fixture 和当前城市工厂，在 CPU 内构造实际新城、阶梯和广场，收集 425 个相关非实例 Mesh，共 15,921 个三角形。使用原 `shore-directed-32`、source red u=.59 的侵土点重新测量：

- 红蓝共 991 个已证实在土体内部的车体采样点，其 XZ 向上均没有实际城市三角面命中。
- 此前的 29 个“广场 polygon 内”点属于广场设计边界，实际铺装工厂因高度/坡度条件拒绝了这些格子；**不能继续写成 29 处实际铺装穿透**。
- 红线每约 1m 的载货 OBB 与上述真实城市三角面 SAT：0 个接触姿态。这里只重测红线，不能把它写成双线全量无碰撞。
- 尚未实例化原雕塑/木马；没有据此宣称演员无碰撞。真实铺装下部的承载岩体也不因上表面无碰撞就可以全部挖空。

原土体内穿行结论没有被推翻：红 673 / 蓝 318 个内部采样点，红 42 / 蓝 33 个表面接触姿态。曲率/坡度已成立，失败来自外突裸岩坡脚，而非已经证明的铺装实体冲突。

## A — 保留铺装，建立与轨道共享的外崖边界（唯一推荐）

已有球面走向阈值：红最小曲率半径 32.20m / 最大坡度 3.282%；蓝 28.20m / 3.447%。原全球替换头扩到 red .59，比已装东接头多影响约 157m，仍必须显式审批/集成，不能暗改其它全球线。

切面不是 x57–73/z92–95 小补丁。土内车体有限采样外包范围为 x67.53–101.77、z59.02–99.11，y−37.84..−16.60（castle chart）。这是**受影响范围**，不是矩形整片削除许可。需要按每个车辆姿态的世界 right/up/tangent 建立连续地侧包络，再外扩至少 0.6m 得到崖脚界线；沿其海侧连通到真实海面，形成开放外崖，禁止保留封闭土盖制造隧道。

从红轨中心沿真实世界横向地侧每 2m 取样，部分断面如下。高度为 castle Y，不能与径向列车净高混用：

因此先施工的明确区间应为东侧 x约93–102/z约63–70 的裸坡，其后逐渐转到广场东南外缘；**x约87/z约80 一带是最紧保护区**，不能把“距实际铺装4m”解读为可任意削4m。此处要用实际铺装边三角及其下方承托柱体做局部固定区，切面每一高度不得越过该固定区。若与两线地侧包络相交，报告具体三角和最小退距后再局部移线；当前数据未证明必须移动雕像/木马或铺装。

保留顶台及其自然层次，只收外露坡脚；崖顶边需随实际平台边界变化，不能统一抬成一堵长坝。靠海的表面应从轨廊背后露出，海侧仍开放。不要将 39.23m 的 castle-Y 土厚当作可直接下挖量；球面真实车辆方向与 chart Y 差异很大。

## B — 不削坡，仅以高程/平面改线

沿同一红走向，对车体横向/纵向九个脚点沿真实车体 up 测地形，最严断面 x87.29/y−26.41/z79.51 需要约 **14.11m** 抬升才能让车辆底部越过现有坡面。这是沿固定方向的有限采样上界方案，不是最优三维路线解。

在4%坡度内，仅这次增加高程就需要至少352.67m升程，回落另计；现有源端半径/原全球线连接使成本更大。将走向移回已检 `inshore-32` 外侧虽然消除有限土碰撞，但估算离崖距离均值仅11.77→11.03m，且两者测量中心相差半轨距，不能宣称显著改善。故 B 不是本轮推荐。

## 下一轮实际施工/验收边界

1. 用 A 路径的双线完整车体扫掠生成地侧切面；保存原版，可关。不要直接按上述 XZ bbox 切山。
2. 真实铺装/阶梯/建筑基脚三角及其承托体固定；原演员 UUID、姿态和脚点不变。先输出最紧 x87/z80 剖面，再判断是否需细小外移，不预先缩放保护阈值。
3. 对新封闭山体重做双线 OBB + 土内 parity；表面0命中不足以证明不穿山。复验公共面承托、山体闭合/翻面以及全球接线一致性。
4. 仍有源头静态海面只剩约5–9cm余量；原候选虽未湿车但不满足0.3m波峰储备。切岩不会解决此问题，必须单列源头水面动态/车底安全，不能用切崖报告掩盖。
5. 本轮没有 GPU 或美术评分，没有验证完整双层结构、真实原演员与动态海峰；A 仅是有明确可施工区间的推荐。
