# 高山圣城历史石城 · 2026-09-28

当前为 50 项累计构建步骤，已接入默认 Web 场景。每一步是真实材质、表面或构件修改，保存了旧城/新城/高山之门三处实景；不是 50 次完整重建，也不把次数作为美术验收。记录 r00–r50 共 153 张图。没有声称连续工作满 5 小时。

## 目标与实际
沿用 assets/concepts/citadel-style-v2/target-v2.png 与 assets/concepts/highland-gate/target-v1.png。对应旧象牙石、深石缝、局部雨痕、石质檐口、修补痕和常绿植物。旧城有更强的风化，新城保持较浅的石色。

实际复核发现并修正：首次材质筛选误将无名合批岩石/植物当石墙；改按地形祖先与合批 sources 排除。门区植物原先已被旧配色系统染成米色，第 39 步恢复常春藤、柏树、灌木、岩石的分类颜色。新增线脚第二次被旧调色染红的问题已通过作用域标记修正。凹凸导数使用视空间，避免球面朝向改变时出现错误法线。
