# 岩石色层光源绑定修正 v6

原实现scene.traverse只看灯本身visible，因此隐藏父组下强光也可能被选为岩石朝向着色光。新实现缓存方向灯集合，渲染时按完整祖先可见性和当前相机layers筛选，再取最强有效方向灯；允许灯光导演和昼夜切换。基色、山体几何及所有轨道不变。候选引用已改palette-v6，尚未最新GPU验证，不声称山色视觉达标。

四项测试通过：连续色层/方向性/不改顶点，实际世界到castle坐标转换，缺光中性，以及隐藏父灯与相机排除层不参与、切换后重新绑定。已保存before。

实际启动后新增方向灯须重新安装该外观句柄；本实现不在每帧扫描全场景。此前13:33真实GPU仍是rock5，不得冒充rock6。
