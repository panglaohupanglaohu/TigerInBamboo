# 圣城参考图续修 · 全球海面与山岸（2026-09-12）

本轮最新约束：用户明确“都是海”，圣城建筑位于山体，水域属于同一个球面世界海洋，不需要独立湖盆。先处理山水穿模，再继续参考图美术。此批是 Web 实际游戏改动，未声称完成 1:1 复刻，未同步 Godot。

## 实际修复

- 旧城朝向 30°→12°，建筑、桥端点、地形反向采样、编辑器/攻城路线使用统一角度；旧水盖原父级旋转也被抵消。
- 停用 `highland-waterfront-water` 与 `west-city-water-channel` 两片局部不透明水盖，保留节点和数据便于诊断。实际只渲染原 `planet-v8-curved-ocean`。旧湖面倒影父组同样停用。
- 根因：旧局部水高以未平移的作者坐标及独立 +4.8 水位计算，但整个城域后来平移 -52m；新港虽有正确世界海高校正，Claude 新增波动的旧 `waveBase` 下一帧又把它覆盖。当前已停止这段回写。
- `createOceanHeightSampler` 在最终世界变换下求解 `|world| = R + officialOceanLevelAt(world)`，新码头、登船点、系船附件及倒影使用同一海高。没有改全球 SEA_LEVEL=.5。
- 原全球海面网格只细化圣城海岸区域及其共边相邻面：6768→38528 三角形，新增31760，区域最长边1.984m。全部原顶点不动，同一网格/材质/球心，无新增海面盖板。源网格保存在运行时专用引用以便回退。
- 原山体开放临海边补171段岩壁/342三角形/1次绘制，底部到真实海面以下2m，源地形顶部顶点不动。原内部切口只有删面而无侧壁，是薄片岸线暴露的原因。
- 修复 Claude `newCityBackdrop` 对非凸山脊进行扇形剖分造成的重叠三角面；保留其布局、种子和配色。
