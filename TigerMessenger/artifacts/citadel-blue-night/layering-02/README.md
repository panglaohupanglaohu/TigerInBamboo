# 圣城层次：两轮视觉迭代

范围限本目录及相邻 layering-01 独立候选，未改正式工程。

第一轮 Blender 对原建筑的独立几何组件按深度区间抬升 0/4/9/15m；圣塔竖向比例改为 72%，基底抬升 9m。Godot 增加台地、外侧阶梯和六处庭院。创建带低蓝屋顶、座椅、四盏灯的城堡游船 .blend / GLB。

第一轮检查发现相邻材质组件偏移不一致、庭院对称重复、船出画。第二轮 Blender 改为统一深度平面切分，再按面所在台地整体抬升，降低材质接缝错位。庭院偏移并调整阔叶树与柏树比例，减少树木重复。新增水岸全景、船近景；船沿原曲面水面三角形采样定位。

验证：Godot 资源导入成功，实际 Metal Forward+ 五视角截图；具体绘制量见 godot-report.json。退出仍报告 7 Texture RID 泄漏。近景绘制开销明显高于总览，不能以当前帧时间宣称性能达标。

未验收：仍有台地规整、内庭不足、山水外边界生硬的问题，不能视为目标图复刻完成。建筑跨台地切口、碰撞、导航、楼梯连续通行、登船、巡游均待后续处理。本轮是候选几何排布实验，没有修改原 WFC 求解器或宣称规则验证通过。

复现：tools/build_layers.py 由 Blender 后台执行；Godot project 中 stage.gd 为局部布景，review.gd 使用 --capture 输出实景。保留 layering-01 供对照。
