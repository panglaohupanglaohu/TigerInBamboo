# 圣城蓝夜第二轮：街区局部暖光

用户要求加强参考图中街道灯光照到环境的效果；本批仅修改独立 round-02 工程，未改主线程文件或正式游戏。

从 round-01 复制原 WFC/Blender 几何；三个 GLB 哈希一致。保留原占用、中央圣塔与地形。本轮没有发现并修复 WFC 反例，未宣称求解器进一步完成。

原两盏大范围灯换成六处小范围灯池，挂点来自实际低层窗网格中心，分隔至少7单位。暖橙为主、少量桃红；强度0.65、范围7，其中两盏开阴影，加原方向光共三盏阴影灯。首版过亮且七盏阴影灯的结果保存于 initial-*。挂点目前是窗边代理，不是已经验证的街道灯具位置；可见灯具、遮挡与导航后续须补。

Godot 实际输出 street-off/on.png：相同几何、相机、天光、亮窗，唯一变量是局部灯组开关。可见局部墙面/地面获得暖光；与目标图的丰富街灯、植物反光、岩壁细节和水面倒影仍有明显距离。无阴影灯可能穿墙，尚需逐巷核验。绘制开销仍偏高，godot-report.json 为真实计数，不是性能验收。

打开 index.html 看对照；独立 project/project.godot 可运行，空格切日夜，L切局部灯。复现：Godot --path 此目录/project -- --capture。validation.json 保存几何哈希与图像差异检查。

本轮加载 threejs-aaa-graphics-builder 及 authoring-recipes/technical-art；未重新生图、未重建 Blender 几何、未接正式世界。下一步以原巷道面和门洞提取灯具挂点，再校验WFC露台/屋檐是否挡光挡路；出现具体几何反例再修模块约束，不以灯光遮掩缺陷。
