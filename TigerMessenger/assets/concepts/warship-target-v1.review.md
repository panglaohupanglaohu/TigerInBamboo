# 古战船目标图检查

参考原 `createFisherBoat()` 和原 Godot 导入图，由内置生图生成。不是已优化的三维模型，也不是已获用户认可。

可采纳：甲板连续通道、木质结构、浆架与手握、低岸登船板、原橄榄/红橙/骨白配色、帆面蛇纹。

不能照抄的图像错误：大三分之四视图把船眼放在上翘船尾，原船眼应在青铜撞角旁的船头两侧（小侧视位置正确）；多个视图桨手/船桨数量不一致。建模必须以原工厂13桨/侧、26桨及对应桨手为准；不能依据图中可数到的数量减件。原单船25登陆战斗兵与26桨手是不同对象集合，不可合成一批。

原船头+X、船尾-X；原甲板和桨枢轴、衣甲及全部动态节点引用保留。登船板是候选新增交互结构，须在实际岸线、船身摇摆及手脚接触中验收，静态图不证明已可上下船。
