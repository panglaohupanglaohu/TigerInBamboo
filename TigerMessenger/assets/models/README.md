## 原书店回接 Web

原书店已接入 Blender 工作副本的顶点共享关系。运行时保留原工厂的节点、材质、墨线着色器、阴影参数、招牌 Canvas 与编辑回调；位置、法线和 UV 使用原始浮点值，避免墨线随机函数因微小量化而变化。

- 独立几何统计：GPU 顶点 1,264 → 810，属性与索引缓冲 40,456 → 28,424 字节（约减少 29.7%）。面数、绘制调用没有因此减少；这不是帧率改善承诺。
- 导出仅保存 Blender 顶点共享映射和原几何指纹，不重复下载整份位置、法线和 UV。原程序工厂仍执行，后续可继续优化构造成本。
- 完整节点与属性检查成功后才整体替换；自定义土坡参数或结构变化会保留原工厂几何。
- 同相机、同光照 Web 对照逐像素一致，并验证招牌修改、节点和材质引用保留、自定义参数回退。图像和结果见 optimized/verification/bookshop-web-*。
- 重新导出：用 Blender 后台执行 tools/originals/export_bookshop_runtime.py；然后运行 tools/test_bookshop_runtime.mjs 与 tools/test_original_assets.mjs。导出器遇到位置或 UV 改变会停止，避免将造型改动冒充无损整理。

目前书店与湖沼之虎已完成 Web 几何回接。其他模型的 Blender 导入不等于已经优化或接回游戏；Godot 的原作材质与动画适配仍待完成。

## 全目录批处理

用户要求加快全部模型处理后，72 项目录资产已生成 [Blender 整理候选清单](optimized/batch-candidates-v2/README.md)。63 项存在通过保守检查的重复顶点整理，9 项保留原网格。总计减少 1,033,650 个 Blender 编辑顶点；整区与单件资产有重复内容，此数不是游戏内唯一资源节省，更不是 GPU 或帧率结果。

候选文件保留原作层级、面角坐标、UV、材质和实例变换；特殊属性、变形、线条和法线敏感网格自动保留。候选副本尚需逐项原代码阅读及 Web 渲染/动画检查，不作为已经完成游戏回接的模型。保存后独立重读检查结果见该目录 saved-verification.json。

湖沼之虎的单独工作副本为 optimized/moebiusTiger.blend：编辑顶点 2,552 → 1,468，2,208 个面不变，两个法线敏感网格保留。Blender 实体视图对照曾有 358 个像素不同。Web 回接保留原始法线浮点值，静止、行走、饮水三种姿态均通过零像素差异对照，全部节点变换、原材质及八节尾巴动画引用不变。GPU 顶点 1,340 → 1,162，几何缓冲 49,744 → 44,048 字节，约减少 11.5%。完整游戏检查确认原湖沼虎正在使用整理后的几何。验证记录为 optimized/verification/tiger-web-comparison.json；原作 Git 几何、贴图和层级比较也通过。

回接代码共用 src/assets/blenderTopology.js：只应用通过原属性指纹检查的顶点共享映射，参数或结构不符时整体保留原几何。它不重建材质、节点或动画。
