# 811 古松 · 用户要求的两轮 Blender 迭代

交付范围仅一株811。原25株v1、Web工厂、世界布局、Godot未在本子任务替换。工程负责人决定实际场景接入时机。

- `user-round-1/`：移除物理树皮噪动，七色纵向面带真实写入GLB；保留当时1.42倍冠厚。真实回读后发现树干大平面、冠太圆。
- `user-round-2/`：冠厚改为原1.00倍、水平1.20倍，原37段枝路与29冠中心输入继续保留；过长木面细分以承载纵向色差，无物理噪动。六个原根方向补片状融合，末梢减薄；七色收紧为灰褐色系，减少近白与近黑反差。

最终候选：`user-round-2/ancient-pine-811-v2-aged.glb`，SHA256 `79fae93ecc205baac365a5252bdf2d3046cf7ad2e52f4b304ad95efbc5e73f01`。同目录 `.blend` 是实际交付GLB重新导入后保存的工程，含核对灯光和相机。

两轮完整交付索引、Blend哈希、同机位图片及报告在`artifacts/pipeline/saihoji-pine-v2-811/index.html`和`two-rounds.json`。被否定的旧图明确作为基准，不算新两轮。新两轮相机、目标、正交范围误差均0。

## 后续接入合同

树皮n8/n9为白色基色×线性`COLOR_0`；Web必须设置`vertexColors:true`，不能再用单色树皮palette覆盖。七个sRGB设计色只在线性转换时转换一次，实际GLB回读最大误差1.2783e-8。每个木网格实际保有7种颜色。叶冠仍沿用当前Web的三色因子。

原17节点、根yaw/1.02缩放合同不变；世界放置覆盖yaw时不能再叠一遍工厂变换。此模型13020三角面，未添加LOD；不应未经真实镜头/性能验收直接复制替换25株。原37枝段与29冠中心是构建输入保持，重建后表面顶点和体积中心有意改变，不能声称逐顶点保真。

木材实际GLB合并焊接检测：单连通、0边界、0非流形。颜色pass前后五个网格的三角形指纹一致；颜色变化不是用新形体或灯光冒充。源811归档Blend/JSON、v1 GLB和原生成脚本SHA均未改。

## 重建

在项目根的父目录使用后台Blender运行`tools/pipeline/build_saihoji_pine_v2_hero.py`，随后运行`tools/pipeline/color_saihoji_pine_v2_bark.py`；最后以Python运行`tools/pipeline/package_saihoji_pine_two_rounds.py`更新第二轮档案与页面。路径均以`TigerMessenger/`为前缀。两轮脚本快照已随证据归档，仅供版本审查，不直接从归档目录运行。

视觉限度：比被否定的石柱/黑三角版本更连续，但811原枝路仍较直、根片端部仍偏棱角；概念图的针叶细节、根围苔藓未完全复现。本批不宣称完美复刻、整批优化或完整游戏验收。
