# PLAN — Townscaper 全盘模拟（算法 · 配色 · 动画 · 风格）

> 目标：对照 Oskar Stålberg《Townscaper》的**机制、配色、动画与视觉风格**，
> 对高山圣城「城堡层」 + 运河交汇古堡做全盘模拟。不满足于「像」，而是
> 逐项对齐原版的生成规则、动效语言与美术气质。
>

## A. 算法（机制模拟）

### A1. 扭曲网格（distorted grid）—— 核心补缺
原版：逻辑规则网格 + **顶点几何扰动**（确定性 hash，非随机每帧），建筑块跟随
网格形变，产生「手工搭积木」的有机歪斜感。本作 25×25 网格**逻辑保持规则**
（拾取/存档/裁剪全部不变），扰动只在**几何层**做：

- [ ] `citadelGridVertexJitter(ix, iz, seed)`：每格四角顶点按格坐标 hash 出
      ±2~3% 的偏移（cellSize 1.4 → 扰动 ~0.03），确定性、可缓存
- [ ] 体块几何生成处（buildCitadelTownAssembly 的立方体/墙/窗/屋顶）统一走
      「角点 4 顶点扰动」的立方体工厂，替代裸 BoxGeometry
- [ ] 扰动幅度随层高累积（上层比下层略歪，像真实堆叠），但**不超过拾取容差**
- [ ] 屋顶/穹顶/尖塔沿用各自角点扰动（保持同一格的四角一致）
- [ ] 性能：扰动只作用于顶点坐标，材质/合并/拾取（faceToCell）不变；
      静态合并后 draw calls 不变
- [ ] 开关：`citadelDistortion` 参数（默认开，关 = 现正交外观），便于对比验收

### A2. 邻接模板细化（对齐原版 WFC 观感）
原版每块按上下左右邻居选预制模块。现有实现已覆盖：内芯/立面墙/窗/门/拱/
城垛/围栏/屋顶。补缺口：

- [ ] **角落墙柱**：外墙转角格出竖柱（pilaster 已有，确认转角全覆盖）
- [ ] **窗密度按户**：同户竖柱窗种子一致（已有），补「临街面窗多、背街面窗少」
      （朝向 = 是否邻空）
- [ ] **悬空拱**：底层悬空且两轴有支撑 → 拱（已有）；补**跨水拱门**（底邻水道）
- [ ] **退台**：顶层内缩格自然形成露台（已有 plaza 判定），补露台栅栏转角柱

### A3. 屋顶分类（不含塔楼红旗——用户明确不喜欢该点缀）
原版：屋顶形状分类 + 塔楼尖顶插红旗。**红旗装饰不做**（用户偏好），
其余屋顶细节对齐：

- [ ] **人字坡山墙**：条带屋顶两端山墙出圆窗（已有 oculus），补山墙
      **挑檐木板**（屋脊两端小三角封板，原版常见）
- [ ] **L/十字教堂**：尖塔四棱锥顶 + 十字饰（已有），补塔身**竖条窗**

## B. 配色（对齐原版色感）

现状已对齐 15 色盘 + 5 档明度抖动 + 竖柱同色户。补微调：

- [ ] **色盘核对**：按 Townscaper-palettes 社区整理的官方 15 色（白/米白/沙黄/
      柠黄/橙/砖红/陶土/褐/深褐/蓝灰/石板灰/蓝/藏青/青/松绿）逐项比对
      CITADEL_PALETTE 十六进制，偏差 >5% 的校正
- [ ] **屋顶统一瓦色**：原版屋顶不随柱色（红瓦/石板蓝灰两类）；本地 roofTile
      已有，确认人字坡/尖顶/教堂用同一瓦色族，**不参与户色抖动**
- [ ] **窗色统一深墨**：原版窗是统一深色（不随墙色）；本地窗色跟随材质，
      统一为深墨蓝灰（含夜间亮灯材质的基色）
- [ ] **明度抖动档位**：原版每块 ±4~6% 且**相邻块差异尽量小**（低对比抖动）；
      本地 5 档 -4~+4%，补「同户同档、相邻户差一档」的平滑约束

## C. 动画（动效语言模拟）

### C1. 放置/拆除动画（plop）—— 核心补缺
原版：点一下，块**从上方落下**（或弹起），带一次软弹簧 bounce（约 0.25s），
水面/建筑有轻微涟漪。本作 3D 直编辑目前是瞬移重建：

- [ ] `citadelPlopAnimation(container, cells)`：重建后对新增/移除的 level 组
      做 0.25s 弹簧动画——新增块 y 从 +0.5 落位（overshoot 8% 回弹），
      移除块 y 上浮 0.3 淡出（透明材质克隆）
- [ ] 动画挂在 `citadelSceneEdit.tick` 的轻量队列（不阻塞重建），
      完成即移除临时材质恢复静态合并结果
- [ ] 2D 平面图点格（面板）同样触发 3D plop（复用同一入口）
- [ ] 运河古堡/高山圣城通用；`citadelAnimationsEnabled` 开关（默认开，
      SwiftShader 测试关，避免 e2e 时序抖动）

### C2. 水面波浪（顶点动画）
原版：海/运河水面顶点缓慢起伏（正弦波叠加），近岸浪花白边。
本地：静态 bumpMap 扰动法线。

- [ ] `canal-junction-water` 与运河水面加**顶点波浪**：每帧按 (x,z,t) 双正弦
      位移 y ±0.02~0.03（幅度小，保持 low-poly），`onBeforeRender` 更新
      position 属性（或 shader onBeforeCompile 注入 uniform）
- [ ] 台地梯湖/瀑布潭水面复用同一动画材质（citadelRange 水系）
- [ ] 近岸浪花：运河立壁/岸线内侧加一道**白色低浪条**（静态几何即可，
      原版是岸边白线）

### C3. （已取消）旗帜飘动——红旗点缀整体不做，无旗可动

### C4. 鸟群 Boids（起飞/降落）
原版：鸟**落屋顶一个模型、起飞一个模型**，飞行动画是 shader 顶点偏移。
本地：台地鸟群已有 Boids 漩涡/栖飞；城堡层鸟静态。

- [ ] 城堡层静态鸟升级：**俯仰 + 双翅扇动**（翅膀两个 Box 绕肩轴旋转，
      `tick` 驱动 sin 摆幅），落地静止、受惊起飞（复用台地鸟惊飞信号）
- [ ] 起飞瞬间模型切换（收翅滑翔 → 展翅扑动），与台地鸟群同 Boids 空间

### C5. 晾衣绳（Italian wires）—— 新点缀
原版：高层外墙之间拉**晾衣绳**，挂几件彩色小衣物（威尼斯风）。

- [ ] 相邻两栋 ≥3 层建筑、间距 ≤4 格、同层高处：拉一条细绳（CatmullRom
      下垂曲线）+ 2~3 件小衣物（Box 拼色块，随绳下垂）
- [ ] 静态几何（并入合并），衣物色从 15 色盘取随机邻近色
- [ ] 数量控制：每 8 格高层墙对最多 1 条，防视觉噪

### C6. 灌木视错觉（billboard 双片交叉）
原版：灌木用**凹脸错觉**（两片交叉平面 + 剪影贴图）制造立体感。

- [ ] 花园/墙脚灌木改双片交叉 billboard（两 PlaneGeometry 垂直交叉，
      顶点色做枝干/叶团剪影），替换现 3D 低模灌木
- [ ] 双片各自随机偏转 45°，剪影用程序化 Canvas 贴图（不引外部资源）
