## 九个区域

| 区域 | 配置用途 | 部署前必须验证 |
|---|---|---|
| 入口石阶与补给点 | 红狐同行、维修包、泊位伏笔 | 原八级入口支撑与船的可见方向 |
| 蓝猴狭路 | 单方向投石教学与非致命驱退 | 预告、掩体、母亲可通过 |
| 相认岸边 | 虎相见、灯谜与认亲 | 玩家/虎接地、稳定近距、三者镜头净空 |
| 软泥捕获点 | 引导失衡、缴械 | 玩家绕行、重甲兵可达、安全拉回边缘 |
| 树根维修避风处 | 救出士兵、达成合作、装配 | 四参与者容纳、真实遮蔽、读提示时安全 |
| 第一次掩护 | 教会停稳开盾、趁窗口通过 | 定向覆盖、吸取预告、失败退路 |
| 根隙与巨叶撤离路 | 两次窗口、自然掩体冷却 | 连续导航、全身体型净空、没有无解等待 |
| 最后会合点 | 确认家人与合作兵都在 | 回头接应通路与泊位可见性 |
| 气泡艇泊位 | 收纳护板、四名乘员入艇、飞离 | 入口与舱内空间、载重、起飞净空 |

所有位置仍为未绑定，不放虚构坐标。测绘时必须使用实际湖沼根的变换、坑壁/石阶/岸地碰撞；局部高度不能直接当球面半径。不能为摆镜头把虎、船或整个湖沼移位，也不能把地面支撑检查当成人体净空认证。

## 十六阶段与条件来源

主线 01–07 → 插曲 07A 捕获 → 07B 获救合作 → 07C 改装 → 07D 首次掩护 → 主线 08–12。

配置中的 `requires` 和 `completeWhen` 都是 **全部满足** 的条件；`produces` 只在该阶段完成后提交。`next` 明确唯一下一阶段，计时仅是建议表演长度，不能到时就过关。条件名称需要由真实场景事件/传感器提供，不能由「下一镜」按钮伪造。

前置：红狐同行、苔庭救援机会、唯一失散兵交接、补给包和气泡艇预置。最终成功：认亲、改装、四名乘员真实入艇、艇实际离开湖沼，才提交下一章「escape」，不是全游戏完成。

士兵必须来自苔庭的存活受损个体，绑定舰队、原花名册 UID、原运输载具；这些值暂未解析，保持空值。移交后不得再被原舰队攻击控制或回收逻辑拿走，不算击杀，不复制、不因机队飞临湖沼额外刷兵。现有重甲伤害常量保持。

## 调试初值

以下是关卡设计初值，均未实景试玩认证：

- 接石：同时一个主投石者；预告 1.2 秒；接石窗口 0.6 秒、辅助 1.2 秒；首投无伤害。
- 互动：一般 3 世界单位；灯谜复用当前 7.5 的近距口径，无回答倒计时。
- 改装：收起武器 → 安装组件 → 联合测试。改装备不改写士兵意识，合作需明确同意。
- 护幕：持续 5 秒、掩体内冷却 8 秒、结束前 1.5 秒预告；有效范围暂取 3 世界单位／100° 定向扇区，强抗吸需停稳；不自动开火。
- 扫描：预告 2 秒、吸取脉冲 3 秒、间隔安全窗 10 秒；撤离段两次窗口。真实路程必须落在可通过时间内，不能仅因秒数匹配就说通过。
- 会合：3 世界单位，分离超过 6 时在掩体等待；不通过瞬移队友来完成。
- 登艇：父亲、母亲、女儿、合作兵四个唯一占用者；护板收好、舱位和载重通过才起飞。当前四乘员容量未验收。

## 六个检查点

入口 → 相认完成 → 捕获开始 → 改装完成 → 护送开始 → 泊位安全点。

每个点配置恢复阶段、区域、解锁时机和保留项。保留同一士兵身份、认亲与已完成改装；重置临时威胁/热量或未完成登艇。**这些是恢复策略配置，尚无实际保存/恢复适配器**。

未来单独使用 `tm.level.swamp-rescue.v1`，不覆盖当前救援主线或故事板草稿。已完成旧版湖沼章节的存档保持现状，不自动强制重玩；新契约启用时需显式处理迁移。
