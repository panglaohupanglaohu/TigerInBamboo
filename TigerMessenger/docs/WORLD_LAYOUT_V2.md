# 全球布局 V2 候选

这是供 Godot 切换预览的**全局布局候选数据，尚未正式部署**。本批只写 `godot/data/world-layout-v2.json`、本说明和验证脚本；没有改原世界坐标、海洋、地形、场景或资产库。

已查看用户提供的 `assets/references/world/layout-reference.png`。参考图明确两文明、南北跨度、六景与移动白鲸的关系，但其标注经度仍集中在约 −120° 至 +25.6°，不直接照抄为新世界。V2 的所有目标数值都是本项目拟定值，**不是用户原坐标**。原作依据来自 `original-world-manifest.json` 的正式 Web 装配快照及 `GODOT_WORLD_GAP.md`；该快照没有复制用户浏览器里的保存布局，不能覆盖用户存档。

经纬采用原项目 `latLonToGardenDir` 的约定：+Y 为北，0° 经线在 +X，正经度朝 +Z；单位向量为 `[cos(lat)cos(lon), sin(lat), cos(lat)sin(lon)]`。区域中心纬度范围为 −63° 至 +75°，约 138° 南北跨度；规划聚落不伸进 |纬度|>80° 的极冠，南北高纬留给生态/天气边界。

`angularRadius` 是导航与区域分配的规划半径，**不是裁剪原模型的圆、不指示缩放，也不等于真实网格占地已验证**。当前规划圆有间隔；真正的原城市、水面、峡谷与高塔包围范围仍须在三维预览中复核。

## 保留区域内部设计

- 书店、营地、月亮湖和丘陵林道按一个原作群迁移，保留彼此关系；书店是源锚点，月湖等未独立出现在 manifest 中的内容仍通过实际模块补齐。
- 水晶城、城内海水湖、运河与花厅泡艇属于同一城市群。不得分别拉向四个目标点，把内部设计拆散。
- 圣城连续山谷、街区、木马与夜潜关系保持；旧港独立区域保留实际海湾设计，再重建往圣城的合理通路。
- manifest 的 `mossSaihoji` 只是已捕获的地被锚点，不能拿它冒充整个苔庭六景。完整花园与白鲸来自独立 saihoji 场景，后续整组迁移并保留载体父子关系。
- 镜像小岛来自当前 Godot 的实验入口，单独标为 `experimental`，不变成传统世界新聚落，也不进入主线完成统计。

预览迁移推荐采用从原锚方向到候选方向的**球面刚性旋转**，保留半径、高度、局部比例和区域内部变换，不平移后压回球壳。原世界的部分 group 位于世界原点，不能用它们 matrix 的零平移当锚；需取映射地标的有效中心/位置。先解析父子所有权再变换，避免父场景和其中子地标被重复旋转。

## 通路和主线

主线图保持连续：书店身份信 → 叹息之门 → 苔庭结盟/诱敌 → 旧港与红狐重逢 → 返回文明边界 → 水晶城 → 湖沼救虎 → 气泡艇带家人抵达圣城。返回门与穿城是这个候选中为跨区交通拟定的转乘路径，不冒称已有剧情演出。

`routes` 每条含 `from`、`to`、`mode`、`storyOrder`。有序主线连续到圣城；其他航路的 storyOrder=null，保留回程与补给选择。原故事中的苍鹭诱敌、鲲吸不动、英雄争取时间、木马夜潜和屋顶回望仍需行为事件触发，不能以到点按键替代。

旧港同时连接陆路圣城、南西文明边界和东洋航路。海运外环是旧港 → 东洋 → 白鲸海区 → 西洋 → 水晶城，并从西洋经北西岛链回到书店海岸。南洋连接湖沼与东洋。这样大片水面承担跨文明旅行、退路、生态与远景视线，而非被随机房子或树填满。

所有 route 当前仍是候选通路：航道尚待真实海岸、水深/高度、登陆点和船体净空检查，电车还需坡度/曲率验证。图连通只说明设计没有断路，不能宣布玩家已可通关。

## 白鲸与镜像实验岛

`leviathan-circuit` 是显式动态闭环，起止苔庭，经过南方海域、负经度外洋、跨 ±180° 海区和东洋。候选提供 9 个经纬路点与走廊宽度；每段应按球面最短弧插值，跨日界时不能把经度从 −170 直接线性插到 +140 而绕过 0°。

导航锚始终取白鲸载体的实时世界矩阵；苔庭局部六景与动态载体关系保持。任务状态需要控制白鲸在战争附近的停留/升沉，迁徙闭环只是后续海域使用方案，不能立即替代原战斗行为。固定的 `leviathan-migration` 区域中心只是走廊中继和总览标注，不是永久鲸位。

镜像小岛只通过 `debug-transfer` 可选边连接；没有 storyOrder、不是主线必经点。预览切换时实验区与正式原作必须保持标识。

## 空白海域的内容责任

| 责任区 | 后续负责的内容 | 当前状态 |
| --- | --- | --- |
| 北西岛链 | 少量有停泊/补给/生态用途的中继岛、具体岛型 | 仅预留，不生成随机镇 |
| 东洋/西洋 | 跨日界航线、船只搭乘与运行、地平线可读性 | 先交通、后必要场景内容 |
| 南洋/北极边界 | 季节迁徙、风浪、天气与休息窗口 | 生态用途预留 |
| 白鲸海区 | 动态载体导航、六景附着、战争停留与沿途碰撞 | 路径候选，行为未部署 |

当前任务优先继续资产和系统接入，不在此批重新生成全星球地形。海洋保持开阔，其内容由航道和生态机制提供。

## 已运行的检查

```sh
rtk proxy python3 TigerMessenger/tools/pipeline/test_world_layout.py
rtk proxy python3 TigerMessenger/tools/pipeline/test_world_layout.py --self-test
```

候选验证通过：14 区域、19 路线；原作目的地覆盖四经度象限及南北两半球；最大未分配经度弧 42°，最小区域中心角距约 25.16°，最小规划圆边界间隔约 7.34°；旧港海运/陆路、主线、可选区图连通；镜像不计主线；白鲸为闭合动态跨经度路径。7 项防回退测试通过，包括拒绝挤回半球、断主线、实验岛插入主线、静态白鲸、港口失联和区域重叠。

这些检查仅验数据合同。默认原世界未改变；实际几何无穿插、交通可玩、剧情触发、海岸与保存布局兼容仍需后续实景验证，不能从这份数据测试推断完成。
