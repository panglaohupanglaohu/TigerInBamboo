# 湖沼之虎 · 模型重塑目标

这是 **TigerMessenger** 的救援主线角色：送信人和红狐要救出的湖沼之虎。与竹虎图及其绘画资产无关，不能混用模型或身份。

用户在 2026-09-09 再次确认的目标图：`assets/references/tiger/user-target-20260909.png`。本轮直接按此图修改 3D，不再更换设计。

- 成年虎：宽颅、圆耳、明显眉弓鼻梁、两瓣米白口鼻与下颌。
- 厚颈、肩胸力量与长躯干；前后肢不同结构、宽白掌与脚趾。
- 深炭灰毛色与可辨黑虎纹、红眼；长尾从臀部顺势下垂并轻回钩、米白尾尖。
- 保留原 root/body/head/四腿/八段尾的连接身份；新比例用新的静止姿态，动画偏移在此基础上叠加。
