# 战船两轮造型迭代

本轮依据用户反馈：眼睛所在端与认可的大透视目标不符，船体端部过方。以 `assets/concepts/warship-target-v1.png` 的大透视图作为装饰与轮廓主参考。

该概念图自身存在视图矛盾：大透视图眼睛位于卷曲高端附近，侧视图位于撞角端。原代码 `src/assets/harbor.js` 中眼睛位于 +X，撞角也位于 +X；并非 Blender 导出翻转。本轮按主透视图移动眼睛，但不颠倒原游戏航向与撞角。

## 第一轮 v3

- 双眼移到卷曲高端附近的左右外舷，眼白、瞳孔随船壳贴合。
- 眼睛不能藏进船壳，也不能保留旧端的重复眼睛。
- 保留原色、卷曲装饰、帆与26桨手。

## 第二轮 v4

- 两端船壳、甲板与舷带共同收尖，顶视应摆脱等宽方截面。
- 保留中部划桨空间，检查端部与登船板连接。
- 每轮保存独立 Blender/GLB，真实渲染采用一致镜头，以便比较。

## 验证与边界

新船体几何不能沿用 v2 的旧碰撞结论。需要对新保存文件重新检查船桨、身体、甲板、登船接点与导出结果。两轮造型候选不等于正式战场替换，也不代表25名登陆兵调度完成。
