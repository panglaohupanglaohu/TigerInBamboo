# 新城广场外侧岩肩 · Blender R01 / R02

## 本轮变化

默认8931及同一Godot已加载 `assets/models/optimized/citadel-rock-shoulder/rock-shoulder-r02.blend` 导出的2974三角形岩面（1网格）。依据当前真实山体采样，在广场前侧及右侧增加分层岩肩，嵌住部分尖长石墙下部。R01检查发现色差，R02沿用原山体顶点颜色，并使外缘错落；Godot使用既有山体颜色适配着色器。

原柏树与灌木通过新岩面和原山体共同采样重新贴地；右侧新增候选树位，仍只使用原Blender柏树家族。新增岩面最高约2.82米，低于广场4米，原步道、雕像、木马与主堡尺寸未改变。岩肩是新增承托表面，不是删除原山体；外缘回落并埋入原岩面。

## 证据

- 原始测量：artifacts/pipeline/citadel-rock-shoulder/source.json。
- 默认网页实景：target-angle-near.png，与before.png使用同一新城局部机位(96,31,117)看向(60,13,61)，FOV59。
- web-route.json：2911路面及障碍采样无缺失/阻挡，原木马夜间战斗引用保留；不是完整攻城验证。
- godot-march.json：实际场景原短剑兵由广场至塔顶559段到达，碰撞检测启用。
- godot-after-day.png / godot-after-night.png：实际场景，脚本断言新岩体存在、主城门/灯位/雕像/原木马位置。只有一个Godot进程，捕获后退出。

## 剩余差距

只改善了广场临岩边界，主堡下方石墙尖角、塔群细长比例、大块光滑岩面与稀疏植被仍未达目标。没有以岩肩替代目标的门后转折平台或删除防御墙。Godot远处仍可见部分漂浮旧植被，记作原场景同步缺口；旧桥阻挡、完整海港卸载与攻城仍待修复/验证。下一轮继续新城主堡及岩台形体，不扩展旧城美术。
