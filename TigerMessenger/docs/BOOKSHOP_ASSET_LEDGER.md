## 捕获与转换合同

- 数据：`godot/data/bookshop-surroundings.json`，独占只写新文件；脚本 `tools/capture_bookshop_surroundings.mjs`。
- 从完整 Web 世界取书店18米局部范围、带 corridorId 的真实树。全局随机初始种子固定用于本次源场景；既有走廊位置随机规则不改。
- 六棵树属于同一资产类型的六个不同现场实例，不把它们计成六个新目录资产。
- 树表面网格在树局部空间按原色区合并；原节点坐标经完整变换烘入，根尺度、书店相对位置与朝向单独保留。原本282个实物mesh，共3876表面三角形；另保留等量原压力墨线壳。浮点舍入6位。
- 实物颜色是 Three.js 线性RGB。墨线宽度来自原树干0.011/树冠0.008，飞白0.07/0.05；原颜色与局部厚度表达式不改。Godot需要匹配色彩输入、三角面绕序与当前球面的直立/落地。
- 本批没有重生成、覆盖现有原作 .blend/GLB，也不更改 Web 默认场景。原生导入是源运行时网格的本地数据适配，不虚称新的 Blender 美术优化。
- 来源画面/摘要：`artifacts/bookshop-surroundings/web-source.png`、`web-source.json`；源数据验证：`data-validation.json`。
