# 高山圣城：按认可目标图执行的迭代过程

2026-09-11。目标图：`assets/concepts/citadel/citadel-battle-target-v1.png`。用户箭头图指定的空间关系优先于临时坐标。负责人承担对照与纠偏，不让用户替代日常检查。目标是按图还原可见构图、建筑关系、比例、材质和光照；背面及不可见结构按实际游玩补全。

## 当前状态与交付门槛

当前旧城中心已左移至x=-52，并按用户最新要求绕自身中心逆时针30°（本地Y+30°），原默认978建筑格减少到329，沿三层基面分区；新城广场中轴保持x=8。真实地形已扩展承托广场并建立山坡建造带；新城沿原建筑规则生成7个蓝色圆顶。这些是已回接的中间版本，远未达到目标：主门及连接翼楼已接入，三座高塔上部已有圆形剖面，但整体比例、山势和细节仍需继续迭代。旋转版1040通路采样通过不代表画面还原完成。

每轮保存：输入版本、实际修改文件/Blender副本、同机位渲染、目标对照、缺陷列表、Web/Godot分别状态。使用固定广角构图相机、玩家高度港口/广场/城门相机、俯视布局三组视角；调相机必须单独记录，不能通过改变镜头冒充对象搬迁。8931原游戏实际加载后再导出，独立检视镜头须标注。

## 0 山脉与山势：先承托两城

- 0A：读取真实地形和装饰山体，辨认巨型尖角、平板裸边、海湾与岩壁遮挡。建立左侧旧城山坡、中央前景新城岩台、后方远山三层；保留两城间可见水道。将当前真实几何导入独立Blender工作副本，保护原文件和未保存编辑。
- 0B：Blender第一轮改主要轮廓。左侧山体自山脚向左后方升起，预留山脚、山腰、山脊三个建造带；中央新城岩台承托广场—阶梯—主堡，前缘下降到港口。不能靠完整建筑柱堆出山高。
- 0C：第二轮核对目标图的山峰高低、谷口留白、近远遮挡；第三轮处理岩壁转折、接地及可见平板裸边。若主要轮廓未通过则继续本阶段，不能因做满三轮而通过。
- 回接：同一高度/支撑依据用于网格、植被、碰撞与水岸；静态Blender网格不能偷偷取代仍被玩法使用的高度场。实际检查地面无裂缝、无建筑穿山及水壳穿港口。

## 1 旧城：左侧沿山势分层，减少建筑单元

- 1A：原旧城建筑与主塔身份保留，按地形建造带确定平面位置与基面高度。山脚形成连续街面，山腰为疏密错落建筑群，山脊保留少量地标。
- 1B：WFC使用可建造掩码和不同基面分区。减少被山遮住、仅用于垫高及重复填满坡面的单元；报告迁移前后实际占格数与可见体量，不能机械按比例删建筑。
- 1C：对照目标左侧城市天际线和露出的岩壁，检查旧塔入口、旋梯、顶层、编辑与夜袭锚点。只有原塔局部坐标或明确声明的城域坐标可以进入对应控制器，禁止混用。

## 2 新城：中央前景按目标逐层构建

- 2A：以实际士兵身体尺度核定港口、32×24广场候选范围及宽阶梯。广场中央雕像、右侧原木马；中轴直达主堡，绕雕像左右分流。位置以固定相机构图为准，候选尺寸允许调整。
- 2B：WFC构建主门、主体、肩塔和侧翼，主堡形成明确体量，取消三排住宅式安排。近景低建筑—中层台阶—高层主堡形成三个递进层次，保留可玩门洞和塔内路径。
- 2C：Blender迭代岩台、广场铺地、雕像与非重复细节，按目标匹配蓝屋顶、白墙和旗帜比例。至少两轮实际渲染反馈；雕像必须是完成的资产，圆环/立柱不算雕像。
- 2D：接入真实战船、卸货点与同一拨士兵；原木马迁到右侧后更新系绳、舱门、夜袭起点缓存和夺取目标。完成船—码头—广场—城门—塔内—顶层连续路线，既有旧港身份不随意覆盖。

## 持续执行规则

同一时间最多一个重型渲染/引擎测试；复用一个Godot编辑器。独立数据/代码审计可以并行。每阶段有可运行版本才更新完成状态。遇到失败保留已验证版本，写明失败证据及下一条动作；恢复任务从该动作继续，不重新规划、不重复宣称全部读完。当前长程任务已建立；额度耗尽或应用关闭不等于任务完成，也不保证后台模型仍运行。
