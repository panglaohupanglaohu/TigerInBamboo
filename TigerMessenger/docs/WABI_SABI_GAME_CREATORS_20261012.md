## 有创作者直接表述

- **本根康之 Yasuyuki Honne — Baten Kaitos 导演、地图美术。** Nintendo Dream 104 期访谈英文译文明确说侘寂是主题之一，同时主张鲜明幻想色彩和一眼成立的画面，而非堆细节。这是本轮最贴近环境美术的直接证据。可研究自然形态如何变成地形、区域色彩和整体构图；不能因此把他的全部作品称为侘寂。
  来源：https://shmuplations.com/batenkaitos/
- **岩谷彻 Toru Iwatani — PAC-MAN 设计师。** OPENERS 40周年本人访谈把简省、未完成之美与侘寂作谨慎比较；并非环境设计案例。适合作为删去多余符号、给玩家想象空间的辅助方法。
  来源：https://openers.jp/en/design/design_features/4CoXi
- **崎元仁 Hitoshi Sakimoto — 朧村正声音制作人。** 原声集本人说明（英文译文）明确谈到将侘寂经验转成词语与声音，重视单音的美与宁静。他是音乐创作者，不应冒称关卡或美术设计师。可供水滴、木响、风声及音乐留白参考。
  来源：https://squareenixmusic.com/features/liners/muramasa.shtml

## 与项目适配，但未查到本人宣称侘寂

- **上田文人 Fumito Ueda — ICO / 旺达与巨像 / 最后的守护者。** 本人访谈强调世界来自功能约束、统一性与暗示性；可用于月湖的空旷尺度、残存建筑和到达路线。把这些用于侘寂方向是本项目推论，不是他的风格自称。
  来源：https://caneandrinse.com/fumito-ueda-interview/
- **Joel McDonald — Prune。** 开发者商店说明把树木生长修剪、极简画面和冥想体验作为设计重点。适合苔庭树形、枝间留白和生长关系；尚无本轮可验证的侘寂自述。
  来源：https://apps.apple.com/be/app/prune/id972319818

## 针对本项目的建议（推论，待设计验证）

苔庭先研究本根康之的自然形态/色彩整体与 McDonald 的树形留白：苔藓沿湿度、阴影、接缝成片，保留踩踏处和排水处裸石；树形偏生，枝叶疏密不同；旧木和石阶磨损有原因，避免均匀噪点做旧。保持苔绿层次，不把侘寂做成整屏灰褐。

月湖先研究上田文人的空间暗示：月面倒影及大块水面作为主要留白，用少量旧石、岸树与可走路线定尺度；有水位痕迹、苔线和局部缺损，但通行逻辑完整。声音再参考崎元仁的单音与停顿，不常驻满铺音乐。

Andrew Lackey 的 Wabi Sabi Sound 是声音公司；公司名称本身不能证明其服务游戏的视觉风格是侘寂。本轮不以公司名充当环境美术证据。
