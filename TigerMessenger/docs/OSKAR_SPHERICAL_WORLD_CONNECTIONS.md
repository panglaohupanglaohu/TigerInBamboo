# 球面场景连接与十二门徒表现：2026-10-04

普通场景以连续网格及模块规则连接；特有场景保留独立造型。十二门徒先作为样区，再将通过验收的连接方法用于其他景区。统一的是承托、接口和环境衔接，不是把所有区域变成同一种岛屿或建筑。

## 本次新学到的内容与实景差距

2023演讲26:21–30:56、42:07–43:00介绍按边界语义分层的平滑：保留重要硬边，材质交界和普通内部点具有不同影响关系。34:42–38:57展示几何完成后绘制颜色与法线、另用对比场控制线条。39:09–41:19介绍距离场与预计算空间光照供环境及动态物件采样。自动翻译有术语错误，精确shader公式、纹理通道及音画对应仍待核实；这属于2023实验，不能全部倒填成Bad North原版实现。

本次实际阅读 seaStackCoastalGeometry.js、seaStackVegetation.js、gateSeaStacks.js：当前海柱由三个横向体积硬并集抽面，仅平均顶点法线，没有语义分层的几何松弛。草皮整三角形筛选，边界继承离散三角面。岩石和植被使用MeshBasicMaterial，顶点预设阴面不能替代共同空间光照。这解释了可见风险，尚不是本轮前后实景验收。

## 项目实施合同（我们的设计，不声称作者原代码）

1. **共享球面基准。** 单元以稳定顶点/边ID表达邻接，位置和高度由统一表面服务提供。径向重力up、真实地表normal、相机朝向分开。禁止将独立平面景区各自弯曲后靠目测拼缝。
2. **分区共享边界。** 每个场景提供有序边界点、地表高程、海陆/材质标签和连接出口；相邻区共享边界数据。普通区域生成缓坡、岸线、道路等过渡带。跨LOD仍须共享边缘采样，不能独立重采样后产生裂隙。
3. **特色场景固定。** 城堡、书店环形广场、叹息之门、十二门徒批准位置、港口及铁路具有保护包络。生成器只调整允许的外部衔接带。离岸岩柱是合法景观，不能因为无步行路径被导航清理删除。
4. **两张图。** 表现网格负责外形与材质过渡；通行图负责港口、城门、步桥和道路连接。接口几何合法与全局可达分别验证；铁路有独立曲率、坡度和车辆扫掠约束。
5. **分层松弛。** 先调整模块承载单元，再按硬边/材质界/玩法边界/普通点处理几何。锁定重要交点与净空边界，限制位移、台宽和体积损失，检查翻面和退化。只在缓崖肩小幅圆润，保留海蚀断裂性格。
6. **共同环境表面。** 最终几何确认后，草皮轮廓、植被根部、石材笔刷和遮蔽均读取同一surfaceRevision。共享光照不等于全部材质同色；蓝灰海岩、低饱和草绿及各城镇配色仍独立。
7. **分区构建。** 整颗球体不套一张巨型UV和一个光照体积；局部景区分块构建、缓存，接缝保持位置和照明连续。过期revision不能覆盖新布局。

## 第一项可审阅结果

用现有叹息之门左侧岩群的一根主柱、两根矮柱及相邻岩台，做相同seed、机位和日照的候选；不先重造整颗星球。比较白模剪影、材质交界、近景草根、接触阴影及列车眼高画面。几何净空、承托和步行连通通过后，再接入主场景。
