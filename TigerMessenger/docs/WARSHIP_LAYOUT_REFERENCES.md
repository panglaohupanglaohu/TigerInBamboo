# 战船与士兵布局：参考与本项目取舍（2026-09-10）

本次以用户指定的目标图Top View为美术依据：两侧连续坐席、可看清的中央甲板、桅杆处可绕行。参考资料只约束可用性，不把游戏26座船宣称为考古复原。

## 核实来源

- Olympias复原项目介绍（Charlie Day文字）：https://eodg.atm.ox.ac.uk/user/dudhia/rowing/trireme/ttintro.html 。实际复原船按两侧三层安排桨手，介绍明确身高会影响座位适合程度。启示是先固定人体和划桨活动范围，再定坐席；不能拉扁人物去适配船宽。我们仍保留游戏原单层布局。
- 希腊海军官方复原说明：https://averof.hellenicnavy.gr/en/trireme-olympias/construction-of-the-trireme-by-the-hn/ 。说明复原基于文字、图像及发现，实船长36.90m、宽5.50m、吃水1.25m。仅作结构与海面承托参考，不按实船人数/尺寸直接套用游戏比例。
- Godot官方 NavigationMesh：https://docs.godotengine.org/en/stable/classes/class_navigationmesh.html 。agent_radius会将可行走面从障碍边缘向内收缩，agent_height/爬升/坡度也影响可通行性。因此两条看似不相交的网格间隙，不能直接叫通道。
- Rare官方船设计幕后入口：https://www.seaofthieves.com/news/behind-the-scenes-brigantine 。已找到设计师和工程师介绍该船的页面；本轮未获取可核对的视频全文，不能宣称观看视频或引用其中具体布局规则。

## 本项目布局决定（游戏设计，不是已证实的古代统一惯例）

1. 以已认可罗马士兵原比例作为尺寸基准，26个坐姿随同左右桨位整体外移，保持手与桨的局部握点。船体横向加宽，不能拉宽人体。
2. 中部低窄兵器架分成桅杆前后两段，枪矛顺船长方向收纳、盾牌插槽分开，按25个战斗士兵ID管理。架两侧保留可通行余量，不能把宽度全部用作仓储。
3. 船尾四箱移至后排之后并分置中轴两侧，避免压住最后一排士兵和封住尾部通道。
4. 25名战斗兵的坐姿与步行姿态绑定同一身份，兵器随其上下船切换归属；第26人留守船上。这是延续原26桨位/25战斗兵数量的游戏取舍，不额外刷出一队士兵。
5. 完整验收必须覆盖停桨、起身、取械、绕桅、到跳板的实际人体/装备外廓，而不仅是静态排布或单个横向净宽。当前跳板展开及海底/靠岸仍未通过，不能把身份切换当自然登船动画。
