# 旧城滨水建筑与侧向入口

2026-09-13，本批模型回接、入口与昼夜验证已完成。8931 为 common-frame + old-harbor 构建候选；默认布局未合入。

## 造型和布局

按认可目标图的低层白石港口、蓝色坡顶和布棚，复用现有 harborArchitecture 港口构件。只增加两处有实际台基的建筑，分布于岸门旁和中段平台旁；不恢复旧城被删去的密集住宅。

两处均从主楼梯陆侧偏移 7 米，建筑宽 6.6 米、深 3.5 米；台基宽 7.4 米、深 5.2 米。高度跟随两处实际平台，高差约 4.216 米；台基下缘埋入自身四角海面最低处以下 1 米。保持中央主路、岸门及原船位置。

前脸由既有 simple-tiled WFC 求解器组装三个槽位：中间真实拱口，两侧约束为石墙。屋体和坡顶复用既有港口构件，并非宣称整片城池已由 WFC 完整复刻。

## Blender 回接

export_old_shore_arcades.mjs 从实际游戏提取源局部几何、UV、材质和世界布局。bake_old_shore_arcades_blender.py 通过 MCP 写入独立 TigerMessenger_Shore_Arcades_Review 场景，保留原平滑法线、布棚 UV 与材质。导出的 20 个分材质几何、2772 个三角形回接同名源组件。源几何指纹不一致会要求重新生成，避免错接旧资产。

资产：assets/models/optimized/citadel-shore-arcades/shore-arcades-r01.blend 与 shoreArcadesR01.js。Blender 模型源和游戏截图均在 artifacts/pipeline/citadel-shore-arcades/。

## 入口迭代
