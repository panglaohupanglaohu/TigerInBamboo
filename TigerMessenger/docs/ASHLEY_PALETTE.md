# 高山圣城：用户所供 Ashley Wood 图像的配色关系

依据本轮8张参考图片归纳，而非作者官方色卡。重点是有限色域、暖灰亮部与冷灰中间色、深褐阴影的面积关系。配色调整不等于复制油画笔触。

|工作色|色值|场景用途|
|---|---|---|
|骨白|#DED5B9|石墙受光面|
|旧象牙|#C9BEA1|次级浅色|
|赭石|#A58A58|旧金属、饰边|
|锈棕|#8F583E|屋顶、穹顶、木构|
|灰橄榄|#74765B|树木、灌木|
|烟蓝灰|#758B8C|山石、冷色构件|
|深灰褐|#45483F|窗洞与凹部|
|褐黑|#302C29|最深结构色|

以骨白、灰土色为大面积，锈色集中在屋顶和旧金属；减少高饱和度装饰。保留圣城旧城/新城/高山之门的既有模型、城防与交通。只克隆圣城局部材质和颜色属性，跳过角色、光源、瀑布等动画对象，不修改莫比斯色板。

运行时入口 citadel/ashleyPalette.js；查询参数 ashleyPalette=0 可只关闭此色彩修订。颜色检查与前后截图位于 artifacts/pipeline/holy-ashley-palette/。原文件快照保留 source-before/。
