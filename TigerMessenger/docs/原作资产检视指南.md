# Godot 原作资产检视

这是原作几何迁移的检视入口，尚非完整可玩世界。旧的十个实验资源继续保留，但检视器只读取 `godot/assets/originals/` 下的原作。

## 打开与操作

在 Godot 工程中打开 `res://scenes/asset_review.tscn`，按 F6 运行当前场景。左侧选资产；拖动旋转，滚轮缩放，空格暂停，R 重置视角。大型区域按需加载，切换会释放旧模型。底部显示原名、源 Blender 路径和未适配能力。

不要用 F5 判断本批结果：主场景仍是前期实验关卡，本批没有将它换成原作完整世界。

## 制作通路

原始快照 → `assets/models/originals/blender-r3/*.blend` → `godot/assets/originals/*.glb` → Godot 自动导入 → 检视场景。

当前导出取自原作档案；72 个整理候选仍需视觉和运行时确认后再替换导出源，不能把档案导入当成造型优化完成。前台 Blender 的未保存内容不受后台导出影响。

在游戏目录运行：

```sh
rtk proxy python3 tools/originals/build_godot_import_map.py
rtk proxy python3 tools/originals/export_godot_originals.py --all
rtk proxy python3 tools/originals/validate_godot_glb.py
```

导出遇到已有文件会保留它。只在确认目标为可替换生成产物后用 `--force 资产ID`。失败日志位于 `artifacts/godot-export/`，每项结束立即保存 export-report，可在中断后继续。

## 已知限制

材质已转换为基础 PBR、保留贴图和实例色，但 Three.js 飞白墨线、屏幕空间线宽、程序动画、文字编辑与碰撞行为尚未迁移。线图元可由 glTF 导出；原代码没有 Points 节点，因此关闭松散顶点导出，避免多出散点。

全部资源暂标为 partial；可见三角面数量一致和可实例化只证明导入通路，不能证明全部视觉、交互或性能通过验收。

## 后续顺序

先在此检视器补书店和虎狐的材质/描边，保存与原作同角度对照；随后在原作书店周围搭建可走、可投递、可触发救援任务的 Godot 场景。新虎按真实成年虎参考重塑，当前 GLB 中的虎仍是旧版。
