# 圣城双城布光：认可目标图约束

状态：已记录设计约束，尚未接入或视觉验收。基准为 `assets/concepts/citadel/citadel-battle-target-v1.png`；与双城布局一并实施，不另换目标图。

两城共用蓝色暮光、曝光及阴影方向，分别组织局部照明。老城以山脚、山腰、山脊的暖窗灯形成疏密层次，山体间保留暗部；新城以城门为最亮焦点，台阶平台、雕像次之，木马侧灯及港口灯承担辨认与通行。避免全城同亮、白墙过曝和士兵颜色被辉光淹没。

灯位绑定各城局部锚点，随建筑布局迁移。大量窗户用自发光材质，局部灯只承担实际照地与照墙；控制范围和投影灯数量。港口水面反光跟随灯位与真实水面，不铺整片假发光水。

实施顺序：完成双城建筑/山体/道路锚点 → 统一暮光环境 → 分别调老城、新城局部灯 → 同镜头同曝光合看 → 8931原世界实际截图 → Godot重建对应灯光并实景对照。导出GLB不等于灯光同步完成。

验收必须包含两城同框、两组局部灯分别关闭的对照，以及港口—广场—主堡的玩家高度视角。当前代码存在零散湖灯和自发光窗材质，但尚未证明达到上述目标。颜色和语义约束见 `artifacts/pipeline/citadel-composition-v3/layout.json` 的 lighting 字段，具体亮度以实景校准。
