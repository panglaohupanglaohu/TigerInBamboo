# Greg team · 湖沼色板、描线与移动可读性

日期：2026-10-07。角色：借鉴 Antoine Dekerle / Paul Rabbitte 的公开制作方法的代理；不是作者本人。本轮已接入湖沼默认 v50 局部代码，CPU 验证通过；尚未进行 GPU 编译、同机位实景或移动录屏验收。

## 学习范围与不同作者的方法

已通读 [Dekerle 文字问答（2022-09-26）](https://www.gamedeveloper.com/art/deep-dive-rollerdrome-art-direction-q-a) 的全部问答，重点是色彩规则、远景简化与繁简对比。其团队采用四至五个主色、固定屏幕宽的线、色块和阴影的轮廓以及平色；材料细节通过少量线和斑点表达。这些是 **Rollerdrome 的规则**。

已查看用户两张 Sable 对照图与官方演讲 09:20 实帧：加线后，远景岩层与门的结构仍读得清，线色随距离减弱，近处服装、地毯和灌木保留更多细线。单张图不能证明算法。

[Sable 官方演讲](https://www.gdcvault.com/play/1027721/The-Art-of-Sable-Imperfection) 的全片字幕及逐段实帧由本团队视频代理审核，本角色接收了以下精确段落；本角色不声称独立观看完整视频：

| 时间 | 视频代理核实的内容 | 湖沼转化 |
|---|---|---|
| 07:27–09:57 | 平色底图逐步加入光影、距离渐变、轮廓、远距线透明度 | 把轮廓、色块、接地关系分别验收；不能以全屏描线替代空间施工 |
| 10:51–11:24 | Color Profiles 调整阴影、渐变、线条起止距离，区分环境 | 湖沼独立参数与月夜色板；不改圣城与整个星球 |
| 12:36–14:24 | 距离边缘检测、顶点绘色辅助边缘、独立黑白噪声阈值纹理线 | 本轮反向壳是项目折中，不宣称复刻其渲染管线；以后在单区试验独立的控制通道 |

**区别：Sable 有光影与距离渐变，不执行 Rollerdrome 的“全部禁渐变”。** 本轮石墙采用几段色块，是湖沼第一批局部实现选择；后续环境深度色应服从月夜与层次需要，不能错误归因于 Sable。

## 可执行色板

下表面积是构图目标，按湖沼环境可见面积估算，排除天空、UI 和角色；不是当前截图测量结果。五个色族及其明暗变体，不是十二个同等抢眼的主色。

| 色族 / 目标面积 | HEX | 场景语义 |
|---|---|---|
| 水 / 40% | `#75ADB2`、深水 `#386675` | 安静的较亮水面与深层；不把整湖刷成强光蓝 |
| 植被 / 27% | `#7DA294`、阴叶 `#507E7C` | 成簇冠层与可读边缘；深叶承托白鲸及暖色花蕊 |
| 岩土与路径 / 16% | 壁 `#6E9193`、石 `#B5BCB0`、阴石 `#778E90`、路径 `#D3D1B8` | 可走面明亮、崖壁较暗；阶级以实体厚度和明暗区分 |
| 木质 / 12% | `#739187` | 干、根、分叉统一，细纹仅供近看 |
| 暖色标记 / ≤5% | 花 `#CC8C91`、灯 `#EAD4AC` | 到达节点、故事焦点；本轮既有花蕊/萤火动画色暂不替换 |
| 描线辅助 | `#263E49` | 深蓝灰墨线，避免纯黑把冠层吞成一块 |

这是一座受冠层遮蔽的月夜湖。人物、虎、鲸、舰船、萤火、花蕊保持原身份及动画；不因色板统一而抹去故事信号。

## 本轮真实实现

- `src/world/swampGregVisuals.js`：局部语义角色注册、色板与线条参数；只替换命中名称或 `userData.gregVisualRole` 的材质。不会遍历染色全部演员。
- `src/world/swampV2Art.js`：`installSwampSpatialPlan(swamp)` 后调用视觉层，覆盖新增台地的 `path/stone` 角色。
- 主干和实例树冠用反向壳：**0.85 CSS px**，按真实 renderer viewport 与 DPR 换算，不随实体缩放或镜头距离变粗。树冠实例保留原矩阵，法线使用余子式适配非均匀缩放。
- 主轮廓在 **32–85 世界单位**平滑淡出；这是项目初值，需要实景校准，不是 GDC 作者参数。树皮、岩层细线先按像素导数退出，避免远景密集纹理闪烁。
- 替换旧树冠世界单位膨胀线；旧高频主干细线关闭。新增轮廓实际工厂 **11 draw objects**，不是整个模型逐件增加描边。
- 壁面三个平色层次；地面清晰统一；石台顶面和侧面使用法线阈值区分。原台地多材质合并为单材质后，侧面仍取 0.75 倍亮度，地形三角形与碰撞没有改动。
- 保留透明水及原涟漪钩子；改变水面基色。不会硬画出透明水体的所有边。
- 比较开关 `?gregLakeVisuals=0` 可关闭本视觉层；空间层是独立功能，不随此开关关闭。

## 近、中、远的线层级

| 距离角色 | 保留 | 抑制 | 验收方式 |
|---|---|---|---|
| 近景步行 | 台阶顶边、主根结构、少量中断树皮纹 | 三角剖分边、每片小叶内部线 | 1×/2× DPR 截图，线宽不变；脚边台阶轮廓连续 |
| 中景到达 | 主干、树冠大轮廓、三层岸台、路径明暗 | 细碎苔点、重复冠团双重线 | 行走/沿岸运动，入口与下一层落点不丢失 |
| 远景坑缘 | 世界树剪影、水域留白、三层整体落差 | 小裂纹、叶脉、过密轮廓 | 远到近连续录屏；不出现突然黑块/突然弹出线 |

本轮没有实现全场景阴影边缘检测、手绘顶点 edge mask 或完整 Sable distance gradient。几何体交界、演员接地阴影、夜色的移动体验仍需之后测试；不能把本 CPU 合同测试称为视觉通过。

## 后续 TODO 与验收门槛

1. **P0：真实镜头回归**。坑缘俯视、入口、第一岸台、低岸台、水面五机位，同时间/曝光 A/B；确认现有虎、白鲸、修船/出航流程保持可见、无新黑面。
2. **P0：线条 GPU 编译与性能**。检查普通/实例两类 ShaderMaterial 编译，统计 11 个新增轮廓实际 draw calls 与帧时；若有失败先回退局部视觉开关，不能让游戏启动失败。
3. **P1：接地阴影样区**。仅以演员脚下/根部的接触关系为目标；保持月夜主色，不全局加强 AO。对比关闭后是否仍能判读落脚位置。
4. **P1：按环境深度调整 Color Profile**。先量测镜头、湖径和主树距离，校准 32/85；室内根洞与坑缘允许不同参数。远处保留地标，细线先淡出。
5. **P1：受控线测试**。在一段岸墙比较“手工结构线 + 独立纹理阈值 mask”与当前解析地层线；不把高频噪声直接当颜色。只在样区有效后扩展。
6. **P2：生态与居住色彩联动**。植物可通行状态、灯、维修点用有限暖色呼应；由生态/居住角色定义功能后再映射，不凭外观给所有植物添加交互。
