## 给湖沼目标图的空间硬约束

这是本项目设计提案，不是 Sable 作者提供的数值。尺度来自现有 `swampSpatialPlan.js` 与既有实际工厂审计；图像生成不能冒充几何测量。

1. **同一个湖盆、同一棵世界树、同三层侧岸。** 保留深蓝绿湿润森林身份；浅色鲸是水域中的主要浅色形体。世界树偏心，主要分叉轮廓在总览/上岸/中岸/下岸能相互识别。成年虎在有承托的下岸或原故事岸面，不能漂浮；无篷维修筏靠近原故事区。不能用帆船、城堡、水晶巨塔替代。
2. **尺度必须人可理解。** 坑缘相对 H=0，上岸 −2.6 world、中岸 −4.6、下岸 −6.6、水面 −7.5；下岸高水面 0.9。参考人高 1.66 world，路径净宽 2.0。目标图以人物、虎、筏和根部共同显露尺度，具体坐标与球面变换留给施工验证。树冠是生态层，不假装已是第四个可走楼层。
3. **不画体育场同心环。** 岸台依壁呈不等长月牙，一岸较宽停留、下一岸由转折通路连接；总览须能追踪一条入口→上岸→中岸→下岸的连续路线。三层之间各落差 2 world，仅是现有侧岸关系；原入口过陡尚未修复，目标图不能标注“已可走”。
4. **上岸镜头：看懂目的地。** 略俯视，前景一小段脚边路、中景下行入口，远中景世界树分叉与浅鲸所在水面。叶群放侧边和上方，世界树不能是一整面占中间的圆柱。
5. **中岸镜头：短遮挡、再显露。** 眼高在中层，前景有一组贴壁根与藤，不形成密栅；下一段下行台阶和水面缺口可见；浅鲸允许暂时被树根局部遮挡，但鲸所在连续水域仍可定位。只用一两根主结构表达树的尺度，内部细根择要。
6. **下岸镜头：贴水与生活。** 虎的四足有实际岸面，鲸有相对清楚的水线/水下身体关系，无篷维修筏和原住民在侧边工作，工具、绳和修补件不过度抢色。大面积安静水面承担前后层次；不以强光柱、全屏萤火或星云充满空域。
7. **同一色板，不同明度范围。** 深蓝墨线/阴林，青绿水和中层叶，灰青岩岸，浅青白鲸；少量暖木与粉色生物点缀。借鉴 Sable 的大色块与选择性线条，不抄其黄沙与粉崖。近景可有叶脉/接缝，远景只留结构与外轮廓。

## 图面验收与待验证

目标图验收：三层可辨、路线连续可追踪、世界树识别点一致、成人尺度成立、虎/浅鲸/无篷维修筏关系保留、水陆边界明确、没有大片前景遮挡水域、蓝绿密林而非沙漠或写实高光场景。总览＋三岸图都需同一地理关系，不生成互相矛盾的四个场景。

施工待验证：默认 round51 调用链与 .5 缩放、正式球面映射；原入口坡度；故事船鲸全周期与岸壁；真实玩家落脚与净空；透水与线条在运动中的稳定性。**本文件没有新增 CPU 或 GPU 验收结果。** 本轮文件回退仅移除本研究记录，不涉及运行时开关。
