# 鲲背原掩护点：真实兵模净空审计

专用脚本：`godot/tests/audit_kun_cover_geometry.gd`。只读运行，不改变生产脚本或50点。

串行运行：Godot --headless --path TigerMessenger/godot --script res://tests/audit_kun_cover_geometry.gd。可用 KUN_COVER_GEOMETRY_REPORT 指定绝对输出路径。默认报告写入 artifacts/pipeline/saihoji-target-integration/kun-cover-geometry-report.json。

审计50点×三兵种真实GLB×站立/正式潜伏前倾×四个朝向，共1200例。角色使用正交世界米制坐标，不继承岛的约0.5缩放；脚部高度沿用正式foot_offsets。报告保存岛三轴实际长度。

池塘采用原始椭圆的64边外接多边形。分别报告脚部网格与全体网格的投影重叠；装备高处伸过池面不等于落水。树干与枝干只查真实n8/n9三角面，先做高度与平面包围盒筛选，再与角色每个可见网格的凸投影检查。凸投影有保守误报，候选不是确证穿模；不得把完成审计称净空全部通过。树冠、士兵互碰、射箭/投矛动作全过程仍不在范围内。

重点输出 pine-1247-cover-0、pine-3020-cover-45、pine-4101-cover-48 全部姿态。退出码表示审计运行完成，不表示没有碰撞候选。运行结果由主任务串行验证后填写。
