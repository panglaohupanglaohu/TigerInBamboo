# TigerMessenger

**TigerMessenger** 是一款运行在浏览器中的球面 3D 探索与送信游戏。玩家扮演小星球信使，在两半球之间步行、乘坐载具、探索场景并帮助居民传递信件。项目仍在持续开发；网页游戏是当前完整主线，Godot 工程是独立的紧凑关卡实验，并未覆盖全部网页世界。

## 开始游玩

- 在线版：<https://panglaohupanglaohu.github.io/TigerInBamboo/TigerMessenger/>
- 本地启动：双击仓库根目录的 `Start-Web.command`，或在项目目录执行：

  ```bash
  python3 -m http.server 8766 --bind 127.0.0.1
  ```

  然后打开 <http://127.0.0.1:8766/>。需要通过 HTTP 服务访问；不要用 `file://` 直接打开。

进入后从书店镇开始。按屏幕提示接收家书并推进救援主线；靠近角色或物件时按 `E` 交互。场景资源较多，首次启动和帧率会受设备性能影响。

## 游戏内容

- **球面探索**：在半径约 160 的小行星表面行走、奔跑和跳跃；重力与移动方向随球面变化，跌落后返回最近检查点。
- **双半球世界**：北半球包含书店镇、旧港、运河、高山圣城与西芳寺苔庭；南半球包含莫比斯水晶城、大峡谷、白鲸海水湖和原初湖沼。场景和部分地标仍在迭代。
- **送信与救援**：与寄件人、收件人交互，查看任务面板和信袋；主线剧情与原有投递玩法共存。
- **交通工具**：可搭乘或驾驶电车、莫比斯航空艇、侦察飞行器、战船和气泡艇。各载具的操作方式不同，按近距离提示操作。
- **可编辑场景**：开发者菜单提供地图摆放、圣城和水晶城编辑器，以及故事板工具。编辑结果可能保存在本地浏览器，不同浏览器或设备之间不会自动同步。
- **角色与生态**：场景包含阿狸、居民、纸士兵、虎与湖沼生物等。美术资产、动作和场景布局尚在持续制作，检查页或候选页面不等于正式游戏已经通过完整验收。

## 操作

| 按键 | 功能 |
|---|---|
| `WASD` / 方向键 | 移动 |
| `Shift` | 奔跑 |
| `Space` / `J` | 跳跃 |
| `E` | 接信、送达或与附近角色和物件交互 |
| `F` | 登车、下车或使用附近载具交互 |
| `C` | 在支持的载具上切换视角 |
| `V` | 进入或退出飞行器驾驶舱（适用时） |
| `G` | 使用当前载具的特殊功能（适用时） |
| `Q` | 召唤航空艇（适用时） |
| `L` | 打开或关闭信袋 |
| `M` | 静音或恢复声音 |
| `Tab` | 折叠或展开任务面板 |
| 滚轮 / 中键拖动 | 缩放或环视 |
| 右键拖动 | 环视 |
| `Esc` | 关闭当前对话或浮层 |

触屏设备可使用屏幕上的移动和环视摇杆。具体可用动作以当前场景中的提示为准。

## 场景入口

常用 URL 参数：

| 参数 | 说明 |
|---|---|
| `?scene=messenger` | 加载信使主岛场景 |
| `?scene=saihoji` | 加载西芳寺苔庭场景 |
| `?scene=messenger,saihoji` | 同时加载上述场景 |
| `?tour=saihoji` | 从苔庭入口开始漫游 |
| `?autostart=1` | 跳过启动介绍并自动开始 |

不带参数时使用默认游戏入口。检查页、工厂预览和候选演示位于 `artifacts/`，用途是开发验证，不替代默认入口。

## 开发与验证

本项目使用原生 ES modules 和 Three.js，不需要前端打包步骤。`package.json` 提供 Node.js 的 ES module 配置；浏览器运行时通过 `index.html` 的 import map 加载本地 `vendor/` 依赖。

运行 CPU 单元测试：

```bash
node --test
```

测试使用 Node 内置 `node:test`，覆盖角色、场景几何、路线、编辑器和运行时支持等多个模块。它们不能替代浏览器中的 WebGL 实景检查；改动渲染、动作或碰撞后，应按对应模块的说明再做浏览器验证。

启动 Godot 紧凑关卡（需要本机安装 Godot）：双击仓库根目录的 `Play-Godot.command`。它不是完整网页世界的 Godot 移植。

## 代码结构

```text
TigerMessenger/
├── index.html          # 网页入口与 import map
├── src/
│   ├── main.js         # 游戏运行时装配与主循环
│   ├── core/           # 输入、相机、舞台、参数、地图编辑器
│   ├── scenes/         # 场景注册、加载与场景接口
│   ├── world/          # 星球、地形、城市、运河、湖沼与环境系统
│   ├── player/         # 玩家控制、动画和载具交互
│   ├── quest/          # 投递任务、NPC、信袋和记忆桥接
│   ├── assets/         # 角色、载具和场景资产工厂
│   ├── story/          # 救援主线、故事板与演出
│   ├── render/         # Toon、光照、阴影与后处理
│   ├── audio/          # 音效和音乐
│   └── ui/             # HUD、触屏控制和编辑器面板
├── vendor/             # 浏览器运行所需的本地依赖
├── tests/              # Node 内置测试
├── godot/              # 独立的 Godot 关卡实验
├── docs/               # 设计、工程与集成说明
└── artifacts/          # 候选、检查页、截图与阶段记录
```
